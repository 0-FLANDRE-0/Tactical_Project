# WIP12 effect atlas

`wip12-effects-atlas.png` is an original transparent RGBA atlas generated by
`scripts/build_effect_atlas.py`. Its four 64×64 cells contain a muzzle flash,
smoke/dust, impact sparks, and a tracer streak. The build embeds the PNG into
the standalone HTML as a data URL; no network request or third-party texture is
used.
