# WIP09 게임 명중 확률

현재 실행 버전의 차이: [WIP10 예측 사격·비행·착탄](FIRE_CONTROL_WIP10.md)은 결과 추첨을 실제 ToF 뒤로 옮기고 조준/이동 관측 초기화를 분리한다. WIP09의 `sigma.man`, `maneuverAccel`, `maneuverReferenceSpeed`는 제거했으며 실제 이동 편차를 예측 위치와 착탄 시점 위치의 차이로 반영한다. 아래 표와 발사 즉시 판정/표시 설명은 WIP09 당시 기록이다.

2026-11-07 KST. [사용자 지시서](TACTICAL_WIP09_HIT_PROBABILITY_INSTRUCTIONS.md)를 적용했다. 시작은 WIP08A `68a549bbb4c379174902268e10278dec9ddc9f0d`이며 PR #4가 아직 미병합인 것을 확인했다. 새 `feat/wip09-hit-model`에서 최신 main `2d70fe6bf9c701352b80e6da370bd5b122515cc2`의 탄약 문서 변경을 보존했다. 장갑/탄약 아카이브의 전투 수치를 런타임에 자동 수입하지 않았다.

모든 계수는 **검증되지 않은 게임 튜닝값**이다. 실차 사통장치·탄약 성능이나 실제 사격 해법으로 보정하지 않았다. 계산은 게임 명중 확률과 조건부 구역 선택에만 쓰며 탄착 좌표·실제 비행·충돌·고각·관통/피해는 생성하지 않는다. WIP08A 도안·포구·표시용 0.35초 이동은 그대로다. 아래 `tof`는 확률식의 내부 척도이고 화면 포탄 비행을 제어하지 않는다.

## 모델과 시간

이전 거리 선형 명중률과 `zoneWeights`를 제거했다. 가로/세로 게임 오차와 **현재 자기 포수에게 보이는** 차체/포탑 직사각형 최대 두 개를 사용한다. 제시 크기는 거리·상대 차체/포탑 방향·보이는 열/행으로 정한다. 차체 띠와 포탑 띠는 높이가 겹치지 않는다. 포신과 상부 피격은 포함하지 않는다.

각 직사각형에 2차원 독립 정규분포 확률을 적분한다. 평균은 두 직사각형의 면적 가중 중심이며, 게임 내부의 확률 기준점일 뿐 월드 탄착점이나 실제 조준 명령이 아니다. `P_hull + P_turret = hitChance`; 명중했을 때만 각 질량을 합으로 나눠 차체/포탑 비중을 구한다. 각 묶음의 전/측/후는 기존 방향 가중을 유지하고 `upper`는 0이다. 빗나감은 `zone:null`로 끝난다.

오차는 포·탄 산포/조준/거리측정/횡단 잔차/기동/자차 안정화의 **게임 항**을 축별 제곱합으로 합성한다. 표적 이동을 추가 구역 편향으로 다시 곱하지 않는다. 구역 비중은 같은 계산의 `P_hull/P_turret`에서 나오므로 오차가 바뀌면 두 질량의 비율도 자연스럽게 바뀔 수 있다. 탐지 점수·숲 광학깊이·관측 중심 품질·기존 노출 비율을 명중률에 다시 곱하지 않는다.

`aimElapsed`/`aimProgress`는 기존 1.2초 준비 게이트다. 새 `layTime`은 유효 확보/정렬이 유지되는 동안 1.2초 이후에도 증가하며 조준 항이 점차 최솟값에 접근한다. 표적 변경, 관측/정렬/거리/장비/탄수/발사 간격 등 기존 게이트 실패, 발사, 지정 취소·초기화 때 초기화한다. 이때 관측 속도 추정도 비운다. 준비 완료 전 0.4초 사례는 식 검사만 하며 실제 발사할 수 없다.

`targetVelocity`는 자기 포수 관측 갱신의 위치 차/시간 차다. 시간 차가 `queryPeriod × 5`(초깃값 0.5초)를 넘거나 새 표적/초기화이면 0이다. 숨겨진 실제 속도는 읽지 않는다. `targetMotion`은 호환용 벡터 크기다. 시간/확률은 0.05초 시뮬레이션 스텝 기준이며 렌더링·패널·배속 프레임 묶음은 난수를 쓰지 않는다. 승인 단발은 기존 seed/차량 ID/단발 번호의 명중/구역 두 해시 난수만 사용한다. 제시 면적 0인 입력은 난수와 탄수를 소비하지 않는다.

## 표본과 공개 정보

기존 9개 표본에 `along`, `z`, `col`, `row`만 추가했다. 순서, 월드 좌표, LOS 알고리즘과 캐시 키는 유지했다. 자기 포수의 샘플 사본은 거리/FOV/기존 가시선 조건을 적용한 가시 마스크를 갖는다. 발사 순간에도 기존 포수/포구 정밀 가시선의 공통 마스크로 새로 확인한다. **기존 지형·건물·숲 광학 가시선 게이트는 변경하지 않았다.** 새 식에서 숲 깊이를 추가 감쇠로 쓰거나 별도의 수풀 탄체 저항/충돌을 구현하지 않는다.

차체는 보이는 열 수/3을 폭 비율로, 행 높이의 중간점들을 세로 구획 경계로 사용한다. 기본 높이 0.8/1.4의 중간은 1.1m다. 포탑은 보이는 표본 수/3으로 폭을 정하고 링의 횡방향 오프셋을 반영한다. 각 부위를 한 직사각형으로 합치는 근사이므로 분리된 작은 틈의 정밀 형상을 재현하지 않는다.

패널에는 예상 명중률·두 오차 축 중 큰 1σ·보이는 외곽 폭×높이·차체/포탑의 **전체 명중 확률**을 표시한다. 차체/포탑 확률의 합은 전체 명중률이다. 기존 위쪽 부위 목록은 **명중한 경우의 조건부 확률**이다. 정수 반올림 때문에 표시 합에 1% 차이가 날 수 있다. 미식별/기억·다른 차량의 팀 정보만으로 이 요약이나 발사 권한을 공개하지 않는다.

개발 snapshot/이벤트의 `breakdown`은 `{range,tof,sigma:{disp,lay,rng,lead,man,own,x,z},rects,aim,pHull,pTurret}`의 사본이다. 외부 읽기가 내부 배열/상태를 바꾸지 않으며 기하나 관측을 다시 계산하지 않는다.

## 검증 연결

원본 LOS의 기존 필드는 동결 WIP07A와 대조하고, 추가 인덱스/좌표/캐시는 별도 검사한다. 동결 WIP08A 관측 코드와 탐지·식별·유지·기억·이벤트·시간·횟수를 대조할 때는 추가된 샘플/모델 메타데이터만 제외한다. 성능 비교의 원본 LOS 경로에는 관측 경계에서 인덱스만 붙여 양쪽이 같은 현재 확률/관측 상태를 처리하게 한다. 원본 oracle 파일의 기하 코드는 수정하지 않는다.

기존 검사에서 바꾼 계약은 폐기된 선형 정확도/고정 zoneWeights, 이동이 조건부 비중을 전혀 바꾸지 않는다는 가정, 새 필드가 없는 노출 객체의 완전 일치뿐이다. 입력/선회/도안/미식별/기억/일시정지/선택/Worker 회귀는 유지한다. [전체 검사·성능·산출물·미실행 항목](../TACTICAL_RELEASE_WIP09.md).
