# WIP23 T-80U 정지 사격·3BM42·자동장전 구현

WIP23은 `T80U_1989` 프로파일 하나에 정지 사격만 확장했다. 기존 WIP21 장갑/Kontakt-5와 WIP22 관측·24°/s 포탑·40°/s 큐폴라·0.50초 전차장 인계·0.40초 포수 확보 값은 바꾸지 않았다. `t80u-armor`는 관측과 사격을, `t80u-observation`은 사격을 실행 마스크로 끈다.

## 연결한 흐름

- 실제 관측 접촉과 포수 확보가 기존 공통 fire-control에 들어간다.
- 2A46M-1은 2,000m 사거리, 1.60초 조준, 1.5° 정렬 허용, 2.05m 발사 높이를 사용한다.
- 포구는 T-80U 도안의 공통 `muzzleLocal`과 포탑 회전축에서 계산한다.
- 3BM42의 1,700m/s가 발사 시 비행 정보에 동결되며, 공통 비행/착탄/도탄/피해 경로를 사용한다.
- 장전탄 1발과 즉응 저장 12발은 예약탄을 포함해 `초기 13 = 발사 수 + 현재 재고`를 유지한다. 자동장전은 실제 발사 시각부터 6.00초이고 보류·표적 상실 중에도 진행한다.
- 자동장전 차량에는 수동 장전 피로, 장전수 효율, 피격 동요, 임시 사통/관측 고장, 탄약고 사고 상태를 만들지 않는다.
- T-80U는 기동과 TacticalAI가 없고, 격파되면 예약 장전을 정리하지만 이미 비행 중인 탄은 한 번 착탄한다.

## 탄약과 피해

3BM42는 KE·기본 370 HP·1,700m/s다. 관통력은 10m에서 505/425/280mm, 2,000m에서 450/380/250mm(0/30/60°)이고 공통 선형 보간과 60~90° 연장을 사용한다. 도탄 확률은 78° 0%, 80° 50%, 81° 100%다. 근접 비관통 HP 피해는 명시적으로 비활성이다.

125mm APFSDS 곡선은 잔여 관통력 비율 0/.09/.18/.77/.90/.96에서 .65/1.04/1.07/.65/.35/.25이며, 기존 120mm 곡선은 별도 ID와 기존 정밀도를 보존한다. M1A2_1998은 들어오는 `tank-ke/3BM42` 반응과 `tank-ammo-incident/3BM42` 0.30 정책을 명시적으로 소유하지만, 3BM42를 자기 지원탄·저장탄 반응 목록에 넣지 않는다.

## 확인 결과

seed 7 실제 라스도르프 교전시험에서 T-80U는 1.05초 탐지, 7.45초 식별, 7.50초 포수 확보, 9.05초 첫 발사 후 15.05초부터 6.00초 간격으로 총 13발을 발사했다. 정면 M1A2는 정상적으로 비관통했고, M1A2를 측면으로 둔 별도 실제 코어 fixture에서는 3BM42 관통·HP 감소·격파를 확인했다. 기존 기본 전투·방호시험·관측시험의 seed 7 90초 상태와 관측/전투 통계는 작성 기준 `origin/main`과 일치했다.

실제 Chromium에서는 예광 비행 프레임과 착탄 프레임, 일시정지·reset, 적 내부 정보 비공개, 아군 T-80U의 13발/3BM42/자동장전 UI를 데스크톱과 844×390 DPR1·2에서 검증했다. 세부 명령·성능·배포물 해시는 [릴리스 기록](../TACTICAL_RELEASE_WIP23.md)과 [검증 JSON](../tests/releases/WIP23-validation.json)에 기록한다.

## 의도적으로 제외한 범위

T-80U 기동/경로/교전 AI, 혼합 45발 프리셋과 보급, 주포 고각, 자동장전 장치 고장, 승무원/모듈/탄약고 피해, Kontakt-5 소모·폭발, 야간/열상/기상은 구현하지 않았다. 6초·조준 오차·370 HP·관통/피해 표는 실제 성능 인증값이 아닌 게임 시험 데이터다.
