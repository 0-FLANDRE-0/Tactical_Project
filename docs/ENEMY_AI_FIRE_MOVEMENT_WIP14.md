# WIP14 적 기동 AI와 사격 시 이동 정책

WIP14는 적 차량도 WIP13 구동 적분기와 기존 길찾기를 사용하게 하고, 물리 경로와 별도로 이동·순찰 임무를 보존한다. 정상 시나리오는 T01에 이동 유지 순찰, T02에 정차 교전 순찰, T03에 성능 기준 단일 이동을 명시적으로 부여한다. 일반 `makeTank()` 차량에는 AI가 자동으로 붙지 않는다.

## 상태와 실행 순서

시뮬레이션 고정 틱 순서는 **양 팀 이동 → 기존 관측/식별 → AI 결정 → 기존 사격**이다. AI는 자기 차량의 현재 식별·적군 확인 접촉 사본만 읽는다. 상대 실체 배열, 숨은 좌표·HP·명령은 행동 입력으로 받지 않는다.

임무는 `move` 또는 `patrol`이며 ID, 갱신 번호, 최대 8개 경유점, 순번, 반복 여부와 `active/paused/blocked/completed/cancelled/destroyed` 상태를 가진다. 이 상태는 비열거 Symbol 속성에 보관해 차량 snapshot과 JSON에 섞이지 않는다. 플레이어의 이동·정지, 명시적 취소, 격파는 임무를 무효화하므로 예전 경로가 다시 살아나지 않는다.

일반 판단 주기는 0.75초이고 차량 ID 해시로 결정적 위상을 나눈다. 틱당 새 경로 요청은 2건, 실패 재시도 간격은 2초다. 같은 goal/path가 남아 있으면 새 명령을 내지 않는다. 접촉에 따른 자동사격 억제 안전 조건은 매 틱 적용하지만 정지·재개와 경로 명령은 저주기 판단에서만 바뀐다.

## 교전 이동 정책

- `maintain`: 접촉 중에도 기본 경로를 유지한다.
- `halt`: 자체 식별 접촉이 있으면 임무를 일시 중단하고 실제 제동한다. 정차 유지 조건 뒤 자동사격을 허용한다.
- `auto`: 기동간 사격 불가 프로파일은 정차한다. 가능한 차량은 임무의 `maintain/halt` 선호를 따른다.

정차 정책은 1.5초 접촉 상실 유예와 2.5초 관측 대기를 거친 뒤 같은 임무·순번으로 한 번 재개한다. 탄약이 없으면 교전을 위해 영구 정지하지 않고 임무를 재개한다. 기존 `auto/hold` 사격 모드는 바꾸지 않는다.

## 차량 능력과 공통 발사 게이트

`fireControl.movement`에 다음 게임 설정을 추가했다.

| 필드 | M1A2 시험값 | 의미 |
|---|---:|---|
| `fireOnMove` | `true` | 기동 중 발사 허용 |
| `stationarySpeedMps` | 0.10m/s | 정차 필수 차량의 실제 종방향 속도 허용치 |
| `stationaryHoldSeconds` | 0.35초 | 허용 속도 이하 고정 틱 누적 시간 |

현재 M1A2/M1A2_1998은 이동 사격을 허용하고 기존 `stabMradPerMps` 오차를 유지한다. 정차 필수 동작은 합성 프로파일 검사로만 확인했다.

공통 사격 경로는 아군/적군과 수동/자동 모두 `drive.velocity`의 절댓값과 정차 누적을 확인한다. 수동 요청이 큐에 들어간 뒤 다시 움직여도 탄약·발사 번호·판정 난수·비행체·효과를 만들기 직전에 다시 거부한다. 정차 정책의 임시 자동사격 억제와 차량 능력 게이트는 별도 상태다.

## 검증과 성능

`tests/tactical-ai.test.cjs`는 임무 보존·순찰 진척·경로 요청 예산/재시도·정차/재개·자동 정책·정보 경계·격파·100대 판단을 검사한다. `tests/fire-control.test.cjs`는 양 팀, 수동/자동, 전진/후진 실제 속도, 0.35초 정차, 요청 후 재이동과 무부작용을 검사한다. 기존 이동·관측·전투·WIP12 효과 회귀도 유지한다.

실제 Chromium에서는 T01이 이동하면서 자동사격하고 T02가 실제 속도 0까지 제동한 뒤 발사하는 것을 확인했다. 청군을 관측 범위 밖으로 옮긴 비공개 fixture에서 T02가 상실 대기 후 같은 순찰 순번으로 한 번 재개했고, 공개 snapshot에는 적 임무·정책·경로가 없었다.

순수 판단 벤치마크는 경로·LOS·물리·렌더를 제외한 고정 입력 1,000회다. 이 환경에서 100대 중앙값 0.0176ms, P95 0.0387ms로 1ms 목표 안이었다. 실제 지도 5대 기본 시나리오의 2초 준비+20초 측정 3회는 전체 틱 중앙값의 중앙값 0.280ms, P95의 중앙값 0.826ms였다. 여기에는 이동·관측/LOS·AI·사격이 모두 포함되며 WIP13 대비 순수 AI 비용으로 해석하지 않는다. 자세한 fixture와 경로 방문/LOS 수치는 `tests/releases/WIP14-ai-benchmark.json`과 `WIP14-ai-map-benchmark.json`에 있다.

## 한계

집단 전술, 위협 지도, 은폐 위치 선택, 복잡한 행동 트리, 실제 차종별 사통 성능과 확률 기반 정차 선택은 후속 범위다. 현재 정상 시나리오의 경유점과 정책은 고정 게임 데이터다. 실제 모바일 기기의 장시간 발열·멀티터치 검증도 별도다.
