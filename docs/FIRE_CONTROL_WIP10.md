# WIP10 예측 사격·비행·착탄

2026-11-07 KST. WIP10은 확률 기반 명중 판정을 발사와 착탄으로 나누고, 이동 표적 예측과 착탄 시점의 실제 자세·차폐를 최종 확률에 반영한다. 탄착점은 결과를 정한 **뒤** 그 결과와 모순되지 않게 생성하는 표시용 부산물이다. 관통·장갑·피해에는 사용하지 않는다. 모든 계수는 실제 사통장치나 탄약 성능을 나타내지 않는 게임 튜닝값이다.

시작은 WIP09 `04d6d2e85bd4e599332f03f0614989dbbc79990b`이다. 작업 중 최신 main `e2f44d92d06d35782dfa0f5ce81f6c3eb3a77bf6`까지 정상 병합해 다음 단계·전차·탄약 아카이브 변경을 보존했다. 브랜치는 `feat/wip10-flight-impact`이며 main 병합과 공개 배포는 하지 않는다.

## 발사와 착탄 판정

발사 승인은 포수 자체 확보, 현재 포수 시야, 실제 포탑 정렬, 거리, 탄수, 간격, 포구에서의 새 LOS를 다시 확인한다. 승인 시 탄수를 차감하고 다음 값만 스냅샷으로 저장한다.

- `ToF = R0 / (muzzleVelocity × velocityRetention)`
- `P_pred = pose0 + v_obs × ToF`
- `β_s = atan2(P_pred − origin)`
- 발사 때 보이는 차체·포탑 직사각형의 면적 가중 중심 `a`
- `σx = √(σdisp² + σlay² + σlead² + σown²)`
- `σz = √(σdisp² + σlay² + σrng² + σown²)`

`origin`은 공통 차량 기하가 계산한 실제 포구다. `R0`은 사수 차량 중심에서 발사 시 표적 중심까지 거리다. `fired` 이벤트에는 결과·부위가 없고 결정 난수를 사용하지 않는다. 비행 목록은 시나리오별 런타임에 보관하며 `impactAt` 오름차순, 같은 시각이면 발사 ID 순으로 처리한다. 일시정지는 시뮬레이션 시간과 비행을 함께 멈춘다.

착탄 시점에는 저장한 포구와 발사선 높이에서 실제 표적의 현재 위치·차체 방향·포탑 방향을 읽고 9개 노출 표본을 다시 계산한다. 포수 FOV와 관측 거리는 탄체 차폐에 다시 적용하지 않는다. 완전히 가리면 제시 직사각형이 없어 최종 명중률은 0이다. 표적이 삭제되면 `target-gone` 빗나감으로 마친다.

탄 방향 단위벡터를 `e∥`, 그 왼쪽 수직을 `e⊥`라 할 때 `d = pose1 − P_pred`에서 다음을 구한다.

- 가로 편향 `b = d·e⊥`
- 거리 편향 `δR = d·e∥`
- 세로 영향 `δz = −g·R1·δR / (2·vavg²)`
- 평균 탄착 위치 `μ = (a_x − b, a_z + δz)`
- `Sx = σx·R1/1000`, `Sz = σz·R1/1000`

현재 보이는 각 직사각형에 정규분포를 적분해 `P_hull`, `P_turret`, `finalHitChance`를 다시 구한다. 그 뒤 seed, 사수 ID, 단발 번호로 고정된 hit/zone 스트림을 사용해 한 번 판정한다. 렌더링, 패널 읽기, 카메라, 배속 프레임 묶음은 결과에 영향을 주지 않는다.

WIP09의 통계적 기동 오차 `σ_man`, `maneuverAccel`, `maneuverReferenceSpeed`는 제거했다. 표적 기동은 예측 위치와 착탄 때 실제 위치의 차이로만 한 번 반영한다. 조준 리셋, 발사 간격, 짧은 정렬 이탈은 자기 포수 관측으로 만든 속도 벡터를 지우지 않는다. 표적 키가 바뀌거나 관측 간격이 `queryPeriod × 5`를 넘을 때만 초기화한다.

## 구역과 탄착점

차체와 포탑은 각자의 실제 방향과 박스 크기로 전·측·후 투영 면적을 계산한다. 폭 방향 코사인이 전·후, 길이 방향 사인이 측면 비중을 만든다. 0°와 360°는 이어지고 측면은 표적 기준 `left`/`right`를 기록한다. `upper`는 0이며 세부 장갑 구역은 아직 없다.

최종 명중·구역 판정 뒤 별도 `impact:k:a/b` 난수로 정규분포 점을 만든다. 명중이면 선택된 차체 또는 포탑 직사각형 안의 점만, 빗나감이면 모든 보이는 직사각형 밖의 점만 최대 64회 채택한다. 실패하면 명중은 `μ`를 선택 직사각형에 고정하고 빗나감은 보이는 외곽 위로 보낸다. 이 스트림은 hit/zone 결과를 바꾸지 않는다.

명중 좌표는 현재 표적 평면에 놓는다. 빗나감은 포구에서 그 점을 지나는 포물선을 10m부터 2m 간격으로 전진시키고 지형 또는 건물 지붕과 처음 만난 구간을 이분법 4회로 다듬는다. 표적 평면 뒤 최대 3000m 또는 지도 경계까지 찾으며 `ground`, `building`, `out-of-map`, `max-distance`와 표적 대비 앞·뒤 거리 `beyond`를 기록한다. 숲은 탄을 막지 않는다.

프로파일에는 다음 표시용 탄착 설정이 있다.

```js
impact: { rejectionAttempts: 64, marchStepM: 2, maxBeyondM: 3000 }
```

고정 `flightSeconds`와 프로파일 `effectSeconds`는 폐기했다. 화면 섬광과 먼지는 지시서에 정한 2초 연출이며 판정 시각은 `impactAt` 하나뿐이다.

## 공개 정보와 화면

착탄 때 팀이 표적을 현재 관측하면 결과, 구역, 측면, 편향, 최종 확률과 탄착 좌표를 공개한다. 관측하지 못하면 `result:'unobserved'`이며 구역·측면·편향·최종 확률을 숨긴다. 미관측 명중 좌표도 숨긴다. 빗나간 탄의 지면·건물 먼지는 보이는 것으로 처리해 좌표와 종류를 공개하되, 숨은 실제 표적 평면을 역산할 수 있는 `beyond`는 `null`로 정제한다. 개발용 실제 결과는 `recordFireEvents:true` 장면에서만 기록한다.

화면 예광선은 실제 포구에서 `β_s` 방향으로 실제 ToF 동안 진행한다. 공개된 빗나감 좌표가 있으면 그 지점까지 이어지고, 결과 뒤 명중 섬광 또는 빗나감 먼지를 2초 표시한다. 패널은 발사 시 예상 확률을 한 곳에만 표시하고 비행 중 남은 시간, 최근 결과, 앞·뒤 거리와 지면/건물 종류를 보여준다. 미식별·기억 접촉과 숨긴 좌표는 그리지 않는다.

## 기준표와 검증

사용자가 제공한 `wip10_hit_reference.py`를 바이트 변경 없이 `tests/fixtures/`에 보관했다. SHA-256은 `142e5001ee9bd4042a88e6011a1342a2b96cc94eb093f9b0faec069c6aaf6dc6`이다. `python3 scripts/generate_wip10_reference.py`가 체크섬을 먼저 확인하고 격리된 임시 디렉터리에서 실행해 46행을 [WIP10-reference.json](../tests/releases/WIP10-reference.json)에 만든다.

자동 검사는 미리보기 24행, 착탄 편향·최종 확률 6행, 360° 구역 11행, 포물선 높이 5행을 JavaScript와 비교한다. 1000개 seed의 명중점/빗나감점과 강제 대체 경로, 평지 장·단탄, 건물 충돌도 검사한다. 통합 검사는 횡단 표적의 발사 직후 정지, 착탄 전 엄폐, 관측 상실, 삭제, 일시정지, 초기화, seed·배속·렌더링 배치 재현성을 실제 코어에서 확인한다. 전체 검사 수와 실행 환경은 [릴리스 문서](../TACTICAL_RELEASE_WIP10.md)에 기록한다.

지도·기동·차량 반경·길찾기·관측 확률과 주기·9개 표본·LOS 알고리즘·M1A2 도안은 바꾸지 않았다. `archive/combat`의 7절은 WIP06 코드 상태를 설명하므로 현재 WIP08~10 사격 연결과 다르며 아카이브 원문은 수정하지 않았다.
