# WIP15 장전·피격 동요·장비 일시 이상

WIP15는 시험용 1초 발사 간격을 차량별 실제 장전 상태로 교체하고, 실제 착탄 사건이 장전 작업과 관측·사통에 짧은 반응을 일으키게 한다. 활성 시험 구성은 계속 양측 `M1A2_1998`과 `M829A2` 한 종류다. 아래 시간과 확률은 게임 튜닝값이며 실차 장전 속도, 승무원 상태나 장비 신뢰도의 측정값이 아니다.

## 적용 계수

| 항목 | WIP15 값 |
|---|---:|
| 기본 장전 작업 | 5.98초, 0.05초 틱에서 약 6.00초 |
| 장전 작업 상한 | 14초 |
| 피로 | 4발째 실제 발사부터 +0.35초, 최대 5초 |
| 피로 회복·연속 발수 해제 | 장전 완료 뒤 초당 0.25초 회복, 6초 대기에서 연속 발수 0 |
| 피격 동요 | 일반 +0.25초, 근접 비관통 +1초, 관통 +2.5초, 최대 5초 |
| 동요 회복 | 장전 중에도 초당 0.25초 |
| 근접 비관통 | `0 < 방호력−관통력 < 15`, 30% 발생 |
| 근접 피해 표 | 부족량 0→120, 5→80, 10→35, 15→0 선형 보간 |
| 포탑 일시 이상 | `0.02 + 0.18 × clamp(계산 피해/405, 0, 1)` |
| 이상 종류·수명 | 사통 50%, 전차장 25%, 포수 25%; 3~8초 |

초기 42발에는 장전탄 한 발이 포함된다. 실제 발사 성공 때만 탄약과 장전탄을 한 번 소비하고, 남은 탄이 있으면 자동 장전을 시작한다. 마지막 탄 이후 빈 장전은 시작하지 않는다. 장전 진행은 매 틱 `progress += dt / clamp(5.98 + fatigue + shock, 5.98, 14)`로 누적되므로 진행 중 피격이 이후 속도를 늦춰도 이미 한 작업을 되돌리지 않는다.

피로는 장전 중 회복하지 않는다. 장전 완료 뒤 탄을 유지하고 기다리는 시간만 회복과 6초 연속 발수 해제에 포함한다. 조준은 장전과 함께 진행한다. 표적 상실이나 정렬 실패 같은 기존 조건은 조준을 초기화하지만 장전 진행률은 유지한다.

## 착탄·피해·일시 이상

기존 M829A2 관통표, 405 기준 피해, 관통 후 배율과 과관통 감소는 바꾸지 않았다. 비도탄 비관통에서 양의 관통력이 방호력보다 15 미만 부족할 때만 독립 난수로 근접 피해를 한 번 판정한다. 동률은 기존 관통이고 부족량 15 이상, 도탄, 빗나감은 근접 피해가 없다. 실제 남은 HP로 자르기 전 계산 피해를 일시 이상 확률에 사용한다.

실제로 처리된 포탑 전·측·후 피격만 일시 이상을 한 번 판정한다. `upper`와 차체 피격은 제외한다. 같은 종류의 재발은 기존 남은 시간에 더하지 않고 `max(oldUntil, now + duration)`으로 갱신한다. 격파 차량에는 복구 사건을 예약하지 않는다.

- 사통 이상은 조준 진행률과 장전 상태를 보존하면서 새 조준 작업과 발사를 막는다.
- 포수 이상은 포수 채널의 현재 관측과 확보를 끊는다. 복구 뒤 새 표본과 확보 시간이 다시 필요하다.
- 전차장 이상은 전차장 채널만 끊고 정상 포수·주변 관측은 유지한다.

기억과 이미 얻은 식별 지식은 기존 감쇠·만료 규칙을 따른다. 일시 이상이 끝났다는 사실만으로 이전 LOS 캐시를 현재 관측으로 되살리지 않는다.

## 고정 틱 순서와 결정성

코어의 0.05초 틱 순서는 이동 → 도착 비행체/피해/동요/이상 → 관측 → AI → 장전·조준·새 발사다. 같은 시각의 착탄으로 사통 또는 포수 이상이 생기면 그 틱에 대기 중이던 발사는 탄약·발사 번호·판정 난수·비행체·효과 없이 거절된다. 이미 비행 중인 포탄은 취소되지 않는다.

근접 피해와 일시 이상은 발사 ID와 시나리오 seed에서 분리된 결정 난수 영역을 사용한다. 기존 명중·구역·도탄 난수와 이펙트 난수를 바꾸지 않으며 UI 조회, 렌더 프레임, 배속 묶음이 결과를 바꾸지 않는다. 중복 착탄 ID는 HP·동요·이상 어느 것도 다시 적용하지 않는다.

## UI와 정보 공개

선택한 아군에는 장전탄/저장탄, 장전 진행률과 현재 예상 잔여시간, 피로, 동요, 사통·전차장·포수 대응 잔여시간을 표시한다. 적 차량의 실제 장전탄, 탄약 재고, 피로, 동요와 이상 타이머는 팀 접촉·효과·공개 snapshot에 추가하지 않았다. 식별된 적 HP도 기존처럼 마지막 실제 관측 사본만 갱신한다.

## 성능과 한계

같은 AMD EPYC 9V74 환경에서 200틱을 40회 측정한 순수 fire-control 상태 갱신은 50대 중앙값 0.00743ms/틱, 100대 0.01425ms/틱이었다. 구현 전 main은 각각 0.00311ms와 0.00547ms였다. 증가폭은 100대에서 틱당 약 0.00878ms다.

기본 실제 지도 5대, seed 7/17/27, 2초 준비 뒤 20초 측정의 중앙값의 중앙값은 main 0.283ms에서 WIP15 0.319ms, P95의 중앙값은 0.639ms에서 0.695ms였다. 장전 주기가 바뀌어 발사 수와 생존 관측자 수가 달라졌으므로 이 전체 지도 차이를 순수 장전 비용으로 해석하지 않는다. 세 seed의 경로 요청 3회·실패 0회는 같았고 새 렌더·LOS·경로 순회는 추가하지 않았다. 재현 자료는 `tests/releases/WIP15-performance-comparison.json`에 있다.

이번 범위에는 영구 모듈 HP, 승무원 부상, 수리, 자동장전 차량, 탄약 구획별 이전·재보급·탄종 선택과 추가 탄속 피해 보정이 없다.
