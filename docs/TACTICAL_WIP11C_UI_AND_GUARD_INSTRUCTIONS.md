## 2. UI 정리

1. **가로 전용:** 세로에서는 ‘가로로 돌려주세요’ 안내를 표시하고 게임 명령 입력을 막는다. 세로 진입 시 일시정지하고, 가로 복귀 시 진입 전 재생/정지 상태를 복원한다. 사용자가 원래 정지해둔 게임을 임의로 재생하지 않는다. 회전 중 경계 지점 입력·드래그·시야 홀드는 정리하고 가로 복귀 후 정상 조작되게 한다.
2. **왼쪽 상시 관측 패널 제거:** 하단 명령바의 수동 `발사` 자리를 **`경계` 버튼**으로 바꾸고, 버튼을 눌렀을 때 명령바 위에 작은 팝업을 연다.
3. 경계 팝업에는 **전차장/포수 선택, 방향 지정, 자율 경계 복귀**를 둔다. 유지 시간은 기본 ‘해제까지’로 하고 접힌 추가 옵션에서 변경할 수 있게 한다. 설명문·장비 제원·사격 상태를 팝업에 계속 쌓지 않는다.
4. 방향 지정을 누르면 팝업을 닫고 지도 지점 선택으로 이어진다. 입력 안내를 표시하며, 팝업 내부 클릭이 지도 이동/명령으로 전달되지 않게 한다. 팝업 닫기·Esc·차량 선택 변경은 미완료 입력만 취소하며 이미 확정한 경계 명령은 유지한다.
5. **오른쪽 선택 차량 패널:** 현재 경계/교전 상태, 후보 수, 잔탄·비행 상태를 간단히 표시한다. 자동사격 보류, 우선 지정 취소와 수동 단발은 이 패널의 작은 교전 영역에 모은다. G키의 수동 단발은 유지한다. 같은 버튼/DOM ID를 두 군데 복제하지 않는다.
6. 기존 표적 선택·우선 지정, 차량 명단, HP, 지도 이동·확대·일시정지·초기화는 유지한다. 선택 가능한 차량이 없으면 관련 명령을 비활성화하고 화면 오류 없이 처리한다.

PC와 모바일 가로에서 같은 조작 구조를 사용한다. 세로용 차량 카드나 별도 모바일 화면을 새로 만들지 않는다.

## 3. 유닛 위 이름·체력과 선택 정보 [사용자 추가]

- **아군:** 생존 차량 위에 작은 이름과 체력바를 표시하고 실제 현재 HP를 반영한다. 현재/최대 HP 숫자는 기존 선택 차량 정보에서 확인할 수 있게 한다.
- **적:** 완전히 식별된 적에만 공개된 이름/차종과 작은 체력바를 표시한다. 미식별 실루엣에는 이름·차종·체력바·HP 수치가 노출되지 않아야 한다. 표적 상세에도 공개 가능한 현재/최대 HP를 추가한다.
- **시야 상실:** 적이 기억 접촉이 되면 마지막으로 확인한 이름·체력만 유지하고 기억 정보임을 구분한다. 기존 접촉 만료 시 사라진다. 미관측 상태의 피해·격파로 체력바가 실시간 변경되거나 사라져 격파를 알려주면 안 된다. 다시 실제로 관측하면 공개 정보를 갱신한다.
- 적 HP는 실제 관측·식별 경로에서 팀 공개 사본으로 기록한다. 렌더러·표적 패널이 실제 적 객체의 HP를 매번 읽지 않는다. 팀 공유와 선택 차량 자체 확보는 계속 구분하며, HP 표시를 AI의 숨은 HP 조회 경로로 사용하지 않는다.
- 이름은 유닛 위, 체력바는 이름 바로 아래에 작게 배치한다. 기존 이름 라벨과 중복하지 않게 정리하고, 줌을 줄여도 읽을 수 있는 화면 픽셀 크기를 유지한다. 기존 아군/적군 색 체계를 따르고 선택 표시·표적 표시를 가리지 않게 한다.
- 확인된 잔해는 기존 잔해 표시를 유지하고 생존 유닛 체력바를 붙이지 않는다. 잔해 선택 불가와 미관측 격파의 공개 조건은 그대로 유지한다.

## 4. 지정 경계 중 자동교전 연결

현재 재현: 같은 합성 전장에서 **전차장 지정 경계는 적 식별 후 자동 사격하지만, 포수 지정 경계는 식별하고도 사격하지 않는다.** `guard()`의 교전 취소와 `handoff()`의 gunner guard 차단, `control()`의 방향 우선순위를 함께 확인한다.

**목표 동작: 지정 방향 경계 → 적 식별 → 자체 확보·조준·자동교전 → 임무 종료 후 지정 경계 복귀.**

- 경계 지점·만료 시간은 **기본 관측 명령**으로 보존하고, 교전 임무와 분리한다. 포수 지정 경계도 적을 확인하면 기존 자체 확보 또는 전차장 인계 경로로 교전할 수 있어야 한다.
- 유효한 교전 임무 동안 포수는 실제 표적을 추적한다. 저장된 경계 방향 때문에 포탑이 표적과 경계 지점 사이를 왕복하거나 확보·사격이 영구 차단되면 안 된다.
- 교전 종료 또는 다음 유효 후보가 없어 임무가 해제되면, 남아 있는 지정 경계로 복귀한다. 그동안 경계 시간이 만료됐거나 사용자가 해제했다면 자율 경계로 복귀한다. 시간은 기존 시뮬레이션 시각 기준을 유지한다.
- 플레이어가 우선 표적을 지정해도 저장된 경계 지점을 삭제하지 않는다. 지정 표적을 우선 확보·조준하고 기본 auto에서 별도 발사 입력 없이 교전한다. 전차장은 독립적으로 경계·후보 관리를 계속한다.
- 경계 명령을 사격 보류로 취급하지 않는다. 기본 auto와 명시적인 hold는 그대로 구분한다. hold에서도 관측·식별·인계는 진행하고 자동 발사만 보류한다.
- 기존 자체 시야·식별·확보·조준·발사선 검사를 모두 유지한다. 경계 중 발견했다는 이유로 미식별/차폐 표적에 발사하거나 확보를 강제로 완료하지 않는다.
- 전차장 후보는 기존 **최초 발견 순서**, 플레이어 새 지정은 최우선으로 유지한다. 관측·발사선 상실 시 후보 전환, 이미 발사한 탄의 해결과 피해 중복 방지도 유지한다.
- 경계의 의미 변경에 필요한 작은 상태 분리만 한다. 관측·사격 시스템 전체를 재작성하지 않는다.

- **코어:** 전차장 지정 경계와 포수 지정 경계 각각에서 실제 탐지·식별·확보·조준 후, 발사 입력 없이 자동 발사까지 확인한다. contact/ready 주입만으로 대체하지 않는다.
