`vehicle-profiles.js`의 각 장비 `scan.amplitude`, `scan.period`, `scan.rate`와 `fov`, `rate`는 별도 값이다. 왕복 목표는 실제 차체 방위에 사인파 오프셋을 더한다. 차량 ID·장비·seed로 초기 위상을 분리하고 사인파의 끝점에서 매끄럽게 반전한다. 360° 연속 수색을 제거했다. 차체 선회 중에는 탐색 구동에 차체 방위 변화율을 더하되 장비 최대 구동속도를 넘지 않는다. 빠른 차체 선회에는 물리적인 추종 지연이 있을 수 있으며 각도를 순간 이동시키지 않는다.

지정 지점과 관측한 접촉 추적은 기본 왕복 범위 밖도 허용한다. 왕복 폭을 기계적인 회전 한계로 사용하지 않는다. 마지막 플레이어 관심 지점 메타데이터는 남기지만 평상시 자동 수색의 기준은 항상 차체 전방이다. 사용자가 지정한 지점 경계는 명시 해제/선택한 시간 만료 전까지 유지한다.

주변 채널은 200m/360°, 해당 채널만으로 식별하지 못한다. 기존 높이 2.65m, 부위 표본·중심/거리 가중치·숲 감쇠·기하 차폐를 유지했다. 4000m는 기하 조회 상한, 3000m는 비활성 주포 메타데이터다. 포수 거리 2000m를 늘리지 않는다.

## 출처와 책임

차량별 접촉은 다음 상태를 구분한다.

- `sources.ambient/commander/gunner`: 현재 자체 관측, 마지막 자체 관측 시각, 최초 자체 확인 시각. 현재 관측을 잃어도 출처 이력은 남는다.
- `detectedBy/detectedAt`, `identifiedBy/identifiedAt`, `enemyConfirmed`: 탐지·식별 완료 출처와 시각, 식별 후 적군 확인. 미식별을 적군 확인으로 취급하지 않는다.
- `confirmationOwner`, 장비별 `focus`: 현재 확인 담당. 포수의 실제 자체 관측 이력이 없는 전차장 단독 접촉으로 포수를 미리 돌리지 않는다.
- `designation`: 전차장 명시 인계(`source=commander`) 또는 플레이어 직접 지정(`source=manual`).
- `tracking`: 포수 자체 확인 경로(`source=gunner`). 가짜 전차장 인계 사건을 생성하지 않는다.
- `shared`: 직접 지정을 통해 받은 팀 접촉의 마지막 관측 사본. 지식 전달과 자체 탐지 효과/현재 LOS는 별개다.
- `pending`: 전차장이 확인한 다음 후보의 관측 위치·시각. 유효한 현재 관측으로만 갱신한다.

탐지 완료 채널은 당시 품질이 높은 채널을 기준으로 정하며, 동률은 고정된 채널 순서를 사용한다. 식별 완료 시 포수의 직접 확인 담당/최초 직접 발견이 있고 현재 포수 관측이 유효하면 포수 출처를 사용하고, 그 외에는 유효 전차장 관측 출처를 사용한다. 두 장비의 유효 관측이 동시에 경합해도 고정 순서로 결정한다. 개별 차량 안에서 지식을 공유할 수 있지만 이것이 자체 LOS나 사전 선회 허가를 대신하지 않는다.

진단은 선택 사항이다. 순수 모듈의 `onEvent` 또는 코어 시나리오의 `recordObservationEvents=true`로 탐지·식별·장비 접촉 획득/상실·확인·인계·확보/상실·후보 전이를 기록한다. 코어 로그는 최대 4000개로 제한한다. 각 사건에는 시뮬레이션 시각, 관측 차량, 접촉 키, 출처, 현재 관측, 실제 차체/포탑/전차장 각도와 전이 사유가 들어간다. 게임 기본 실행에서는 이 로그를 쌓지 않는다. 로그는 제어 입력으로 재사용하지 않는다.

## 제어 우선순위와 경로

포수는 플레이어 지점 경계 → 실행 중인 직접 지정/인계/자체 표적 유지 → 포수 자신이 실제로 발견한 접촉 확인 → 전방 왕복 수색 순서로 동작한다. 명시적인 새 직접 지정은 기존 포수 명령을 바꿀 수 있다. 자동 접촉은 사용자 경계를 빼앗지 않는다. Esc·선택 변경은 새 명령 입력만 취소한다.

전차장은 자신의 지점 경계를 우선하고, 자동 경계일 때 주변/전차장 자체 관측으로 얻은 의심 접촉을 확인한다. 전차장 단독 미식별 접촉은 포수 자동 집중의 후보가 아니다. 식별·적군 확인 뒤 HK가 켜져 있고 포수가 비어 있으면 `designated`를 생성한다. 다음 0.05초 갱신에서 실제 포탑이 최대 40°/s로 선회하기 시작한다. 별도의 인계 지연을 추가하지 않았다.

포수가 직접 발견·식별/인식한 접촉은 HK·전차장 장비 유무와 관계없이 `tracking`으로 유지한다. 식별 지식이 이미 있으면 같은 차종 식별 임계값을 반복하지 않는다. 다만 포수 자체 거리·시야각·LOS와 0.4초 연속 유효 관측을 확인한다. 동시에 포수가 이미 유효하게 알고 관측하는 경우에는 자체 경로를 우선하여 중복 인계를 만들지 않는다.

`acquired`인 유효한 표적을 2초마다 다른 후보로 교체하는 WIP07 경로를 제거했다. 전차장이 다른 표적을 식별하면 후보로 보관하고, 자동 경계라면 집중을 해제해 수색한다. 기존 포수 표적이 유효한 동안 새 후보로 덮어쓰지 않는다. 후보는 마지막 관측 시각부터 30초 뒤 만료하며, 인계할 때 6초보다 오래된 정보는 사용하지 않는다.

표적 유지 종료 조건은 새 플레이어 지정/경계/해제, 포수 자체 관측 상실 후 1.2초 유예 만료, 접촉 유효기간 종료다. 유예가 끝나면 `lost`로 해제한다. 전차장이 계속 본다고 포수 관측 유예가 늘어나지 않는다. 아직 확보하지 못한 인계는 최대 18초 또는 마지막 관측 정보 6초 초과 시 만료한다. 이후 재시도 유예는 12초다. 파괴 판정은 이번에 추가하지 않았다.

독립 전차장 시야·전차장 장비 활성·HK는 별도 플래그다. 포탑 연동 전차장은 포탑 각도를 따르며 독립 경계 명령을 받지 않는다. 포수 자체 확인과 플레이어 직접 지정은 HK OFF에서도 작동한다.

## 탐지·식별 감쇠

20Hz 고정 스텝과 10Hz 분산 관측, seed 기반 임계값을 유지했다. 두 장비가 동시에 보더라도 최대 유효 품질 하나로 경과 시간을 한 번 적립한다. 관측 첫 미측정 시간이나 오래된 비유효 캐시에 관측 효과를 적립하지 않는다.

- 탐지 효과는 주변/전차장/포수 어느 채널도 유효하지 않을 때 감소한다.
- 미완료 식별 효과는 전차장/포수의 유효 식별 품질이 모두 0일 때 감소한다. 주변 탐지만 유지되어도 식별 효과는 감소한다.
- 반감기는 기존 8초이며 `tuning.evidenceHalfLife`로 조절한다.
- 완료된 식별 지식은 별도의 120초 규칙, 위치/자세 기억은 30초 규칙을 사용한다. 짧은 단절에 지식을 초기화하지 않는다. 유효한 식별 채널 재관측 시 지식 확인 시각을 갱신한다.

## 팀 표시와 자체 관측

팀 공개 사본은 실제 아군 관측 결과만 합친다. 선택 차량의 접촉 목록에 팀 지식이 들어와도 자체 `current`, 채널 이력, 탐지/식별 효과와 포수 확보를 올리지 않는다. 직접 지정은 팀의 마지막 관측 위치와 완료 지식을 전달한다. 선택 차량은 그 위치로 선회한 뒤 자기 센서로 확인해야 한다.

UI는 팀 표적 표시와 별도로 ‘선택 차량 자체 관측 없음 / 주변·전차장·포수’, ‘포수 확보/미확보’를 표시한다. 인계 상태에는 ‘포수 자체’, ‘전차장 인계’, ‘직접 지정’과 후보 수를 구분한다. 미식별 이름·차종·실제 ID·노출률 비공개, 실루엣 외곽, 기억 자세 고정 규칙은 유지한다. 개발 snapshot에서도 내부 적 ID·focus/cooldown 키를 공개하지 않는다.

## 실제 LOS와 캐시

정확히 같은 광선만 최대 0.5초 재사용하는 조건은 유지한다. 관측점 x/y·eye, 표본 x/y/z가 달라지면 해당 광선을 즉시 다시 조회한다. 차체 회전은 영향받은 차체 표본, 포탑 회전은 포탑 표본을 무효화한다. 양 끝점이 함께 움직이면 정밀 광선을 재조회한다. 채널 높이가 같으면 한 후보 안에서 기하 결과를 공유하고, 현재 각도·거리·품질은 매 관측 조회에서 확인한다.

홀드 마스크는 선택 차량 하나의 지형 가능 영역을 캐시한 뒤 현재 부채꼴을 합성한다. 포수 30°와 전차장 90°의 화면 부채꼴·실제 각도·프로파일 일치는 실제 Chromium Canvas 호출과 그림 포즈를 대조했다. 화면·패널에서 정밀 LOS를 다시 계산하지 않는다.

## 배포 파일과 미실행 범위

`python3 build.py` 후 `python3 scripts/package_release.py WIP07A`로 버전 HTML과 ZIP을 만든다. ZIP은 실행 HTML 하나만 포함하고 CRC·압축 해제 결과의 바이트/SHA-256·dist 일치를 검증한다. 이전 WIP07 HTML/ZIP·기록은 보존한다. README와 완료 응답은 GitHub ZIP 다운로드를 우선한다.

실제 Chromium을 이번 환경에서 다시 실행했다. file://는 정책 차단이므로 로컬 HTTP로 같은 단일 HTML을 제공해 검사한다. 실제 Android 터치·발열·지속 FPS, 원본 DEM/GDAL 대조, 실제 장비 광학/사격 성능 검증은 실행하지 않았다. 현재 검증의 수치·체크섬·통과/미실행 항목은 릴리스 문서를 참조한다.
