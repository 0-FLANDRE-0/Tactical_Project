# WIP19 탄약 운용·우측 명령 패널 구현

## 적용 범위와 데이터 소유권

WIP19의 혼합 탄약 운용은 `M1A2_1998.ammunition`에만 명시적으로 활성화된다. 공통 `M1A2`는 기존 단일 탄수 fixture를 유지하며 다른 차량·무기·1989년 적재 프리셋에 M1A2 시험 데이터를 상속하지 않는다. 공통 코드는 작은 고정 스키마와 작업 전이만 제공한다.

탄약 레지스트리는 M829A2, M829A1, M830의 독립 레코드를 가진다. 활성 차량의 지원 탄종, 초기 장전탄과 구획 수량, 자동/구획 우선순위, 즉응탄 목표와 시간은 로드 단계에서 검증한다. 활성 피격 반응 프로파일은 각 지원 탄종의 `hitReactionPolicyId`와 차량 전용 정책 `ammoId`가 실제로 연결되어야 한다. 없는 ID, 중복/불완전 우선순위, 잘못된 용량·합계, 누락된 활성 효과 정책은 조용히 무효화하지 않고 거부한다.

모든 값은 게임 시험 데이터다. 실제 M1A2 적재 배치·장전 절차·탄약 성능이나 승무원 운용 인증을 뜻하지 않는다.

## 탄종별 게임 표

| 탄종 | 종류 | 포구속도 | 기본 피해 | 관통·도탄·피해 규칙 |
|---|---|---:|---:|---|
| M829A2 | KE | 1680m/s | 405 | 기존 거리/각도·78/80/81° 도탄·A1형 피해 곡선·WIP15 근접 비관통 유지 |
| M829A1 | KE | 1575m/s | 380 | 10/100/500/1000/1500/2000m 0° 600/595/590/580/570/560, 30° 505→475와 60° 345→325는 끝점 선형 보간, 78/80/81° 도탄, 자체 근접 비관통 표 |
| M830 | CE | 1140m/s | 435 | 전 거리 0/30/60° 480/415/240, 90° 0, 65/72/77° 도탄, 관통 배율 1, 비관통·도탄·장갑차 폭발 피해 0 |

M829A1 중간 거리 값은 런타임 실수 보간값이며 매번 5mm로 반올림하지 않는다. M830은 CE 방호만 조회하고 LOS 경사 배수를 장갑에 다시 곱하지 않는다. 탄약별 피격 반응은 피해를 받는 `M1A2_1998`의 `tank-ke/M829A2`, `tank-ke/M829A1`, `tank-heat/M830` 정책이 소유한다. M830 비관통·도탄·근접 비관통 행은 모두 0이다.

## 재고와 단일 작업 전이

초기 총량은 42발이며 실제 장전탄도 총량에 포함한다.

| 위치 | M829A2 | M829A1 | M830 | 합계 |
|---|---:|---:|---:|---:|
| 장전 | 1 | 0 | 0 | 1 |
| 즉응 | 7 | 4 | 6 | 17 |
| 준즉응 | 8 | 6 | 4 | 18 |
| 예비 | 2 | 2 | 2 | 6 |
| 전체 | 18 | 12 | 12 | 42 |

자동 다음 탄은 M829A2→M829A1→M830, 공급 위치는 즉응→준즉응→예비 순이다. 수동 선호는 현재 장전탄을 꺼내지 않고 다음 준비/장전 작업에만 적용한다. 선택 탄종이 없으면 선택을 보존한 채 `selected-ammo-unavailable`로 교전 불가 상태가 되며 다른 탄으로 대체하지 않는다. 진행 중 작업은 선호 변경으로 바뀌지 않는다.

차량별 작업은 최대 하나다. 저장 구획에서 한 발을 예약한 뒤 다음 단계를 거친다.

- 즉응탄: 준비 0초 → 기존 WIP15 장전.
- 준즉응탄: 준비 3초 → 기존 WIP15 장전.
- 예비탄: 준비 10초 → 기존 WIP15 장전.
- 장전: 기본 5.98초, 피로·동요·장전수 능률을 기존 규칙대로 적용하고 14초 상한을 유지한다.

준비와 보충에는 장전수 능률만 한 번 적용하고 WIP15 피로·동요를 중복 적용하지 않는다. 작업은 0.05초 시뮬레이션 틱에서만 진행한다. 예약탄은 총량에 계속 포함되며 작업 중단·실장전 선점·격파 때 원래 구획으로 정확히 반환된다. 실제 발사만 해당 탄종과 전체 총량을 한 발 줄인다. 마지막 탄 발사 뒤에는 작업을 만들지 않는다. 새 시나리오/reset은 프로파일 초기값으로 새 상태를 만든다.

## 자동 즉응탄 보충

장전탄이 있고 실제 종방향 속도가 0.10m/s 이하이며 마지막 실제 발사 또는 피격 뒤 10초가 지났고 자체 현재 관측 위협이 없을 때만 보충을 시작한다. 즉응 목표는 A2/A1/M830 7/4/6이며 A2→A1→M830 순으로 부족분을 한 발씩 고른다. 준즉응에서 4초, 없으면 예비에서 8초가 걸린다.

이동, 자체 현재 위협, 새 피격은 예약탄과 진행률을 보존한 채 작업을 일시 중단한다. 숨은 적 실제 좌표나 다른 차량의 비공개 상태는 조건에 쓰지 않는다. 장전탄이 비면 보충을 취소·반환하고 실제 장전을 우선한다. 일시정지, UI 조회, 카메라, 렌더 프레임 묶음과 Worker 완료는 진행률을 바꾸지 않는다.

## 발사·비행·AI 연결

발사 직전 실제 장전탄 ID를 소비하고 해당 탄약의 탄속을 오차 예산과 비행시간에 사용한다. 발사체는 탄종 ID, 탄약 레코드, 사통 설정을 발사 시 사본으로 보존한다. 이후 선호 변경이나 피격 차량의 장전탄은 이미 발사된 탄의 비행·KE/CE·관통·도탄·피해·반응 정책을 바꾸지 않는다. 공개 발사/착탄 사건의 `ammoRemaining`은 실제 발사 뒤 총량이다.

AI는 총량과 현재 교전 가능 탄약을 구분한다. 준비/장전 중인 탄은 총탄 소진으로 오인하지 않고, 수동 선택 탄종이 없거나 실제 총량이 0이면 성공하지 않은 자동 인계 때문에 `halt` 정차를 무한 유지하지 않는다. WIP16의 수동 지정 소유권·차폐 재확인·능선 통과·정차 첫 발 규칙과 무발사 probe의 무소비 계약은 유지한다.

## 우측 패널과 공개 정보

지도 도구, 이동/정지, 시야, 경계, 등고선·지형, 자동/보류·발사, 탄종 선택과 reset을 실제 DOM의 우측 상단 명령 영역으로 옮겼다. 그 아래 독립 스크롤 영역에 작은 아군 선택 메뉴, HP·속도·교전, 장전탄/다음 선호, 탄종×구획 재고, 현재 작업, 일시 이상·승무원 상태, 지형/경로, 표적 정보를 둔다. 큰 전차 명단, 정적 상면 도안, 고정 제원/도움말은 제거했다. 선택 차량 격파는 다른 차량으로 자동 이동하지 않고 명시적 무선택 상태가 된다.

아군 지도 문구는 실제 활성 상태만 화면 고정 크기로 최대 두 줄 표시한다. 우선순위는 사통 → 기동/포탑 → 관측 → 탄 준비/보충이다. 양수 시간은 올림 초이며 보충 중단은 `즉응탄 보충 대기`로 표시한다. 승무원 정상/경상/중상은 지도 문구에 넣지 않고 우측 선택 정보에서만 보여준다.

적 재고·장전탄·선호·작업·고장·부상은 접촉, 표적 패널, 지도 문구, 공개 사격/효과 사건에 추가하지 않는다. 렌더와 패널은 이미 계산된 상태만 읽고 LOS, 재고 전이, 사건 또는 난수를 만들지 않는다.

## 성능과 검증 범위

`scripts/benchmark_wip19.cjs`는 WIP18/main baseline과 WIP19의 50/100대 탄약 상태 갱신·조회/문구, 기본 5대 전체 코어 틱을 분리한다. 현재 환경에서 활성 작업 50대의 한 0.05초 갱신은 중앙값 0.0771ms/P95 0.2033ms, 조회·문구는 0.2009/0.4661ms였다. 100대는 갱신 0.0792/0.1527ms, 조회·문구 0.2738/0.4409ms였다. 열거 가능한 탄약 상태는 작업 중 50대 11,550바이트, 100대 23,100바이트였다.

실제 Chromium 156의 1440×900 프레임 콜백 측정은 기본 WIP19 5대 중앙값 0.9ms/P95 5.2ms, 활성 문구/작업 50대 2.3/3.9ms, 100대 4.8/6.9ms였다. 이는 headless 데스크톱에서 시뮬레이션·Canvas·예약된 DOM 갱신을 함께 잰 값이며 전체 FPS나 물리 모바일 성능 보장이 아니다. 원자료는 `tests/releases/WIP19-performance.json`과 `WIP19-browser-performance.json`이다.

핵심 회귀는 별도 3종 데이터/정책, KE/CE, 총량·예약·마지막 탄·격파, 선호/공급 위치, 준비·장전·보충 중단/재개, 실제 3종 발사→비행→착탄, 공격 탄종/피격 차량 장전탄 교차, 결정성/읽기 무부작용, AI 소진 처리, DOM 이동·무선택, 활성 문구·승무원 비공개, 844×390·DPR2·390×844와 기존 WIP12~18 계약을 포함한다.

## 제외

화재·유폭·특수 즉사, 외부 재보급, 전투 전 적재 편집, 수동 강제 탈탄, 자동장전 차량, 승무원 교대/치료/사망, 기관포·미사일·보병, 비장갑 폭발 피해, 새 차종/무기, 실제 8×8 지도 제작은 포함하지 않았다.
