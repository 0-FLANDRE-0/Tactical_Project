# WIP15 수정 — 관측 유지·조준 속도 및 정확도 저하

> 2026-11-09 (KST). 사용자 변경 요구 반영. **수정 구현·재검증 대기.**
> 기존 WIP15의 관측 차단·복구 후 재확보 요구는 아래 기준으로 대체한다. [기본 지시서](TACTICAL_WIP15_RELOAD_AND_TEMPORARY_REACTIONS.md)의 장전·피격·HP 피해 등 나머지 요구는 유지한다.

## 1. 작업 대상과 확인된 문제

- 대상은 `feat/wip15-reload-reactions`의 초안 `296053940094cb07b02a337faadb6b053617c769` 및 이후 수정이다. 최신 main의 지시서 변경을 기존 구현 브랜치에 반영한다. 이미 완료한 장전·피해 기능을 다시 구현하지 않는다.
- 초안은 전차장/포수 이상 때 관측 채널을 중단한다. 전차장이 다른 곳을 보는 동안 포수 이상이 6초를 넘으면 지정 표적이 `expired/stale`로 끝나고 12초 재시도 대기가 붙는다. 독립 코어와 실제 Chromium에서 seed 79의 7.2266초 이상이 약 19초 교전 중단으로 이어짐을 확인했다.
- **새 요구:** 관측장비 이상 중에도 볼 수 있다. 일시적으로 조준 속도와 정확도를 떨어뜨리며, 관측 이상 자체로 표적 명령·확보를 끊지 않는다. 사통 이상은 기존의 조준·새 발사 일시 정지를 유지한다.

## 2. 적용 동작

- 전차장·포수 관측 이상 중에도 정상 탐지·식별·관측 갱신·표적 추적을 계속한다. 정상 LOS·거리·시야각·현재 관측·포수 확보 조건은 그대로 검사한다. 실제 차폐나 관측 상실을 무시하고 보이게 만들지는 않는다.
- 관측 이상 때문에 `current/acquired`를 지우거나 `interrupt()`로 임무를 대기로 돌리지 않는다. 기존 지정 표적·조준 진행률·경계·이동·AI 임무를 보존한다. 이상 종료 때 강제 재확보나 추가 재시도 대기를 만들지 않는다.
- 관측 이상 때의 **초기 시험 제안**은 차량 조준 진행 속도 **0.70배**, 유효 조준 오차의 표준편차 **1.25배**다. 사용자가 확정한 감소율은 아니므로 프로파일에 모으고 최종 조정값·이유를 기록한다.
- 이번 시험에서는 전차장 또는 포수 관측 이상이 하나라도 활성화되면 차량에 위 불이익을 한 번 적용한다. 두 종류가 겹쳐도 배율을 중복 곱하지 않는다. 각 종류의 타이머는 기존대로 독립 관리한다.
- 조준은 진행률을 보존한 채 느리게 계속한다. 이미 완료한 조준을 이상 발생만으로 초기화하지 않는다. 사통 이상이 동시에 있으면 조준·새 발사는 정지하고 장전은 계속한다.
- 명중률 저하는 기존 게임 오차 예산에 반영하고 수동/자동, UI 예상치, 실제 발사·착탄 판정이 같은 설정을 사용한다. 표시된 명중률만 낮추거나 발사 후 별도 실패 추첨을 추가하지 않는다.
- 발사 순간의 보정값을 비행체에 보존한다. 비행 중 이상 발생/복구가 이미 발사한 탄의 정확도를 소급 변경하거나 보정을 두 번 적용하지 않게 한다. 기존 명중·구역·도탄 난수 영역을 유지한다.
- 관측 이상 자체는 발사 금지 사유가 아니다. 조준·자체 확보·발사선 등 기존 조건이 맞으면 불이익을 적용해 발사할 수 있다. 큐 진입 뒤 상태가 변한 경우도 실제 발사 시점의 조준 상태·보정을 사용한다.
- 기간은 기존 **3~8초**, 발생 확률·피해량 연동·재발 상한·장전·피로·동요·HP 피해는 유지한다. 관측 이상 종료 시 배율만 정상으로 복원한다. 새 탄약 소모·조준 완료 보너스·임무 재생을 만들지 않는다.
- 실제 관측 상실·표적 교체·취소·격파는 기존 규칙대로 처리한다. 관측 시각을 허위 갱신하거나 전역 만료 조건을 없애서 이전 문제를 가리지 않는다.
- 선택 아군에는 `관측장비 불안정 · 조준 저하`와 남은 시간을 표시한다. 사통 이상은 별도로 구분하고 적의 내부 타이머·불이익을 공개하지 않는다.

## 3. 수정 후 필수 확인

- 전차장이 다른 방향을 경계하고 포수만 확보한 표적에 6~8초 포수 이상을 적용한다. 이상 중 실제 관측·기존 지정이 유지되고, 이상 종료로 `expired/stale`·12초 재시도 대기가 추가되지 않는지 확인한다.
- 전차장/포수 이상 각각, 동시·반복 발생, 종료 시점에 조준 속도·오차 배율과 표적 명령을 확인한다. 같은 관측 입력에서 조준 진행이 느려지고, 포화되지 않은 정렬·가시 표적 사례에서 예상/실제 판정의 명중 확률이 낮아져야 한다.
- 관측 이상 중 수동/자동·양 팀이 정상 조건에서 계속 사격할 수 있는지 확인한다. 사통 이상 동시 발생 때는 기존처럼 발사를 막고 장전탄·진행률을 보존해야 한다.
- 큐 진입 뒤 관측 이상 발생, 이미 발사한 탄의 비행 중 복구, 조준 완료 상태에서 이상 발생을 검사한다. 효과 중복 적용·기존 난수 변경·별도 명중 실패 추첨이 없어야 한다.
- 실제 차폐·FOV 이탈·표적 교체·취소·격파, WIP14 이동/정차/재개, 장전·피해·미관측 이펙트·정보 공개·일시정지/배속 회귀를 유지한다.
- 초안의 관측 차단을 기대하던 W15-C02/C03, 브라우저 검사와 문서를 새 요구로 갱신한다. 사통 차단 검사는 유지한다. 새 동작을 독립 코어와 실제 Chromium에서 재검증하고 HTML/ZIP·체크섬을 다시 만든다.
- 완료 보고에는 이 수정 지시서와 기본 지시서의 최신 내용을 연결한다. 기존 완료 안내·아카이브 사본의 관측 차단 설명을 현재 요구처럼 남기지 않는다. 이전 검사 통과 수치는 초안 검증으로 구분한다.
