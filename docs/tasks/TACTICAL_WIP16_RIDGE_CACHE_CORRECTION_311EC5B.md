# WIP16 능선 차폐 캐시 보완 완료

> 2026-11-11 구현·검증 완료. 기준 head는 `311ec5b8ec96075bd5f23c14552bb1d22025b7f0`이다. 원본 보완 지시는 [archive/instructions](../../archive/instructions/TACTICAL_WIP16_RIDGE_CACHE_CORRECTION_311EC5B.md)에 보존한다.

차폐 기하에 사수의 발사선 방향 좌표와 지면 고도를 추가했다. 종료된 차폐 후보는 의미 있는 기하 변화에서 이동 중 재확인 대상으로만 열리며, 기존 fire-control의 실제 발사선 검사가 통과한 뒤 정상 교전으로 복구된다. 후보별 LOS는 추가하지 않았고 작은 흔들림은 새 정차·재지정으로 처리하지 않는다.

같은 직선의 전진과 실제 후진으로 합성 능선 정상부에 도달하는 실제 코어·Chromium 재현에서 수동 지정 없이 자동 인계 → 포수 확보 → 자동 사격과 성공 뒤 캐시 제거를 확인했다. 기존 단일·복수 지속 차폐, 차폐 해소·대안 등장, 사거리 밖 수동 지정·취소·만료·재진입 회귀도 유지했다. 상세 결과는 [구현 문서](../ENGAGEMENT_DECISIONS_WIP16.md)와 [릴리스 문서](../../TACTICAL_RELEASE_WIP16.md)에 기록했다.
