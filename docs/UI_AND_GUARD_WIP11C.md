# WIP11C 경계·교전 UI와 공개 체력 정보

WIP11C는 WIP11B의 탐지·식별·헌터킬러·자동교전·영구 잔해를 유지하면서 플레이어가 경계 명령과 교전 상태를 구분해 볼 수 있도록 정리한다. 관측 명령은 하단 **경계** 팝업에, 확보·조준·자동/보류·교전 취소·수동 단발은 우측 교전 영역에 둔다. G 수동 단발과 L 방향 지정 단축키는 유지한다.

## 경계와 교전 임무

전차장/포수의 기본 관측 명령과 포수의 교전 임무는 별도 상태다.

```text
기본 관측 명령: 자동 수색 또는 사용자 지정 월드 경계점
                           │
                           ├─ 전차장: 경계 방향을 계속 관측하고 후보를 만든다
                           └─ 포수: 접촉 없음 → 경계점 / 교전 임무 있음 → 표적 자세
                                                           │
                                                           └─ 종료·상실·격파 확인 → 남은 경계점 복귀
```

- 포수 지정 경계는 자체 발견과 헌터킬러 인계를 막지 않는다. 실제 교전 임무가 생기면 임무 표적이 포탑 제어에서 일시적으로 우선한다.
- 교전 중에도 경계점과 만료 시각은 보존된다. 임무가 끝났을 때 유효하면 그 점으로 돌아가고, 이미 만료됐거나 플레이어가 자동 복귀를 눌렀다면 자동 수색으로 돌아간다.
- 직접 지정은 자동 후보보다 우선하지만 포수 경계점을 삭제하지 않는다. 교전 취소도 현재 교전 임무만 끝낸다.
- 전차장 경계는 포수 임무와 독립적으로 계속 작동한다. 기존 최초 발견 순 후보, 플레이어 우선, 포수 거리·시야·가시선, 사격선 재검사와 비행탄 1회 처리는 유지한다.
- `보류`는 관측·식별·확보·조준을 유지하고 자동 발사만 막는다. 수동 단발/G는 기존 준비 조건을 그대로 사용한다.

## 화면과 입력

상시 지도 위에 있던 관측 패널은 제거했다. 하단 경계 버튼은 장비 선택, 방향 지정, 자동 경계 복귀를 제공하며 유지 시간은 접힌 추가 옵션에 둔다. 팝업 닫기, Esc, 장비 변경, 차량 선택은 완료하지 않은 방향 입력만 취소하며 이미 실행한 경계는 유지한다. 팝업 이벤트는 지도 탭으로 전달되지 않는다.

세로 화면에서는 전면 회전 안내가 지도 입력을 막는다. 세로 진입 시 홀드 시야, 방향 지정, 포인터 제스처와 경계 팝업을 정리하고 시뮬레이션을 일시정지한다. 가로 복귀 시 세로 진입 직전의 재생/일시정지 상태를 복원하므로, 원래 멈춰 있던 게임을 자동 재생하지 않는다.

우측 교전 영역은 다음만 간단히 표시한다.

- 전차장/포수의 자동 또는 지정 경계와 남은 시간
- 현재 교전 출처·확보 상태와 대기 후보 수
- 자동/보류, 조준 상태, 시험탄 수와 비행탄
- 교전 취소와 수동 단발

선택 가능한 아군이 없으면 관련 버튼을 모두 비활성화한다. DOM ID는 한 번씩만 사용한다.

## 유닛 정보와 적 정보 공개

생존 아군은 실제 차량 상태에서 이름과 현재 HP 막대를 그린다. 적군은 팀 공개 접촉만 사용한다.

| 공개 단계 | 지도 표시와 패널 |
|---|---|
| 미탐지 | 표시 없음 |
| 탐지·미식별 | 검은 실루엣과 `미식별 표적`; 이름·차종·HP 없음 |
| 식별·현재 관측 | 공개 사본의 이름·차종·현재/최대 HP와 정상 외형 |
| 식별 기억 | 마지막 관측 자세·이름·차종·HP를 흐리게 고정하고 기억임을 표시 |
| 확인 잔해 | 영구 잔해 표시, HP 막대와 선택 없음 |

HP는 전차장 또는 포수의 유효 식별 광학 표본이 있는 관측 갱신에서 `known.combat`으로 복사한다. 팀 접촉과 UI에는 이 분리된 사본만 내보낸다. 여러 아군의 접촉을 합칠 때는 자세의 `lastSeen`과 식별 정보의 `knowledgeAt`을 따로 비교해 가장 최근에 확인한 HP를 유지한다. 유닛 배열 순서나 주변 채널로 갱신한 자세가 오래된 HP를 우선시키지 않는다. 관측을 잃은 동안 실제 적이 피해를 받거나 격파돼도 기억 HP·이름·자세는 바뀌지 않으며, 재관측해야 새 HP 또는 잔해가 공개된다. 주변 200m 채널만으로는 HP를 새로 식별하거나 갱신하지 않는다.

## 검증 범위

`tests/wip11c-ui-guard.test.cjs`는 합성 준비 상태를 넣지 않고 실제 코어·9개 노출 표본·고정 스텝으로 전차장 경계와 포수 경계를 각각 탐지→식별→확보→조준 게이트→자동 발사까지 실행한다. 경계 복귀, 직접 지정, 취소, 임무 중 만료/해제, 보류, 공개 HP 고정/재관측을 함께 확인한다. `tests/input.test.cjs`는 팝업·Esc·선택·세로 전환 입력을 검사하고, `tests/browser.test.cjs`는 단일 HTML과 내장 Worker를 실제 Chromium에서 1440×1000, 844×390, 390×844 viewport로 실행한다. 모바일 viewport는 실제 휴대폰의 멀티터치·발열·방향 잠금 검증을 대신하지 않는다.
