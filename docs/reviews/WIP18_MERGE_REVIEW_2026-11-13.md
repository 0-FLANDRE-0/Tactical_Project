# WIP18 병합 검토 — 2026-11-13 KST

최종 검토 구현은 `6c5e4f3b8b3480525ecd9e9bf04df5883269c0cd`, 통합 기준 main은 `cb3f68f88429bdc46aa089c141fdaccc258eeae3`다. 사용자의 검토 통과 시 병합 지시에 따라 통합한다. 최신 main의 차량 설계 아카이브를 보존하며, 실행 코드·지도·차량 데이터·도구·배포물은 검토한 최종본과 동일하게 유지한다.

## 결과와 이전 지적 재현

실제 명중·HP 처리 뒤 살아 있는 `M1A2_1998`에 일시 구동/포탑 이상 또는 한 명의 경상/중상을 적용한다. 현재 확률·구역별 분포·인원 구성·능률 계수는 해당 피격 차량의 전용 설정이며 기존 공통 `M1A2`에는 없다. 다른 차량의 참여는 자기 설정과 적용 대상 검증을 요구한다. 기존 WIP15 반응 및 WIP16 표적/임무·정차 사격 규칙은 유지한다.

| 이전 지적 | 최종 독립 재현 |
|---|---|
| 전차장 부상이 자동 탐색에 미적용 | 동일 속도 제한 조건의 자동 탐색이 정상 15, 경상 12.75, 중상 9.75°/s. 지정 지점 재지향도 50, 42.5, 32.5°/s로 계수 한 번 적용 |

| 범주별 감수성 대신 단일 수치 | 일시 이상/경상/중상 계수 분리. 서로 다른 계수의 범주 경계를 독립 확인하고 현재 M1A2 시험 계수는 모두 1로 보존 |

추가 재현은 프로파일 구성과 제어된 부상 상태를 사용하는 의미 있는 경계 검사이며, 실제 착탄을 통해 부상이 발생하는 end-to-end 검사는 아래 실제 코어/브라우저 회귀와 구분한다. 검사한 범위에서 추가 병합 차단 문제는 발견하지 못했다.

- 실제 Chromium **68개 통과**: WIP18 5, 일반 앱 31, WIP17 가변 지도/내장 Worker 3, WIP16 7, WIP15 4, WIP12 효과 18.

- 실제 WIP18 HTML의 정상 발사→비행→착탄→부상, 전차장 자동/지정 선회율, UI 상태·기간 만료/부상 유지·차량 선택·pause/reset·적 비공개·모바일 방향 회귀를 재실행했다. UI 직접 상태 주입 검사와 실제 착탄 검사를 구분한다.
- HTML 두 번 빌드·ZIP 두 번 패키징의 바이트 일치, HTML=dist, ZIP 단일 항목·CRC·해제 바이트·SHA-256 일치 통과.
- 기존 지도/파생자료와 공통 `M1A2` 내보내기 데이터가 기준 main과 동일함을 확인했다. 통합 때도 검토한 최종 실행/데이터/도구/배포 파일의 동일성을 검사한다.

제출자의 전체 Node runner 324에는 실제 브라우저 실행 파일 6개가 포함된다. 이번 독립 기록은 이를 비브라우저 318과 별도 실제 브라우저 검사 68개로 나눈 것이며 서로 더해 Node 테스트 수로 보고하지 않는다.

HTML=dist는 **8,494,990 bytes**, SHA-256 `16cb3e589427cdba7b7862c0dfa00d08d660c4adaa0eee9730d8ac208b8bb138`다. ZIP은 **1,678,122 bytes**, SHA-256 `e1b3a7c36e61df652cb753f1cb6cac451682d161fde6a39c69ad169c795eb93e`다.

## 비용과 한계

동일 WIP17 기준 런타임과 신규 비활성/활성의 벤치마크를 별도로 재실행했다. 활성 상태만 갱신하는 50대의 틱당 중앙값/P95는 **0.006806/0.015168ms**, 100대는 **0.012446/0.017087ms**였다. LOS·경로·렌더를 제외한 상태 처리 비용이며 전체 전투 FPS가 아니다.

기본 5대, seed 7/17/27, 2초 준비+20초 진행의 전체 틱 중앙값은 각각 기준→신규 **0.6691→0.7345**, **0.4980→0.4652**, **0.4277→0.4392ms**였다. 부상으로 이후 기동·조준·전투 경과가 달라질 수 있는 소표본이며 순수 기능 오버헤드나 일반 성능 개선으로 해석하지 않는다. 실제 휴대폰의 메모리·발열 검사는 실행하지 않았다.

수치·확률·전투 중 부상 유지 방식은 게임 시험 제안이다. 실제 취약부/의학 모델, 영구 모듈 손상, 승무원 사망·치료·교체, 화재·탄약고 유폭/특수 즉사, 탄약 구획 이동, 새 차종/무기와 실제 8×8 지도는 이번 완료 범위가 아니다.
