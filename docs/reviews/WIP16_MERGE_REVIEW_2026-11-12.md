# WIP16 병합 검토 — 2026-11-12 KST

최종 검토 구현은 `47f9e07368d1fb221b8dc91af8869a79b941247c`이며 기준 main은 `bb479ad97df0fd8ab22ad3fd38f54475ccac13cb`다. 사용자 요청으로 최종 수정본과 이 검토 기록을 main에 통합한다.

## 결과

자체 현재 관측·식별·사거리 안 접촉의 안정된 선택, 실제 observation `ai` 인계와 포수/사격 표적 연결, 수동 지정 소유권, 이동 유지/정차/기본 임무 복귀와 WIP15 반응의 연결을 확인했다. 검토에서 발견한 네 문제는 최종 회귀에서 해결됐다.

| 항목 | 최종 결과 |
|---|---|
| 지속 차폐 재시도가 종료 대기를 초기화해 영구 정차 | 재시도와 종료 시계 분리, 같은 실패 기하에서 단일 복귀 |
| 사거리 밖 수동 지정과 거절된 자동 인계의 교전 상태 불일치 | 수동 소유권 보존, 적용되지 않은 후보로 정차 유지하지 않음 |
| 같은 방위의 능선 이동 후 차폐 표적 영구 제외 | 선 방향 이동·높이 변화에 따른 제한 재확인과 자동 교전 복구 |
| halt 재확인 중 제동 전에 첫 자동 발사 | 발사선 전용 검사와 실제 발사 분리, 첫 발부터 제동·정차 유지 충족 |

최신 코드의 발사선 전용 검사는 기존 정밀 `freshSight`를 사용하되 탄약·발사 번호·판정 난수·비행체·효과 생성 전에 종료한다. `halt`는 검사 중 자동사격 억제를 유지하며 정상 교전으로 복귀한 뒤 실제 정차 조건을 충족해야 발사한다. `maintain`의 기동간 사격은 유지된다.

## 독립 재현과 재실행

이전 검토와 같은 통과 가능한 합성 능선, 해당 지형에서 새로 계산한 길찾기, 정상 이동/경계 명령으로 실제 코어와 Chromium 배포 앱을 재현했다. 관측·식별·획득·AI 상태를 강제로 바꾸지 않았다.

- 시뮬레이션 **49.35초**: 13.4112m/s로 이동 중 발사선 검사 성공. 탄약 42발, 발사 번호 0, 자동사격 억제 true, 비행체 0·효과 0.
- **54.90초**: 속도 0·정차 유지 0.85초 뒤 첫 자동 발사. 요구 최소 정차 유지 0.35초 충족.
- **60.90초**: 정차 상태에서 다음 자동 발사.

이 별도 재현은 명시적 합성 지형이며 실제 Rasdorf 지도에서의 사례로 주장하지 않는다. 일반 실제 지도 앱 회귀는 아래 별도 검사로 확인했다.

- 전체 Node runner **304/304 통과**. 브라우저 실행 스크립트가 포함된 수치다.
- 실제 Chromium 일반 앱 **31개**, WIP16 **7개**, WIP15 **4개**, WIP12 효과 **18개** 통과. 브라우저 항목 수를 Node 총합에 다시 더하지 않는다.
- Python 지형 **7/7**, 시스템 Python의 원본 소스·체크섬 **7/7** 통과.
- 제출된 HTML/ZIP과 두 차례 반복 빌드·패키징의 바이트 일치, HTML=dist, ZIP 단일 HTML·CRC·해제 바이트 일치 통과.

HTML=dist는 **8,470,662 bytes**, SHA-256 `03d36c308e2f190458cfd198abf54332e2d782524756a0211d1a572551ab663e`다. ZIP SHA-256은 `6d293cc643e4f917bcba19436bacf7808ee670db8218cc942bd5b38f2ea4b69d`다.

## 성능과 범위

순수 100대 판단 중앙값은 **0.126149ms**, P95 **0.561474ms**였다. 모든 차량을 실제 평가했으며 LOS·이동·길찾기·렌더 비용은 제외한다. 중앙값은 1ms 경량 목표 이내다. Node v24.22.1, Chromium 156.0.8078.79 환경이다.

전체 지도 비용 비교는 작성자 결과를 확인했고 이번 독립 검토에서 별도 재실행하지 않았다. 실제 휴대폰의 장시간 실행은 범위에 포함하지 않았다. 검사한 범위에서 추가 병합 차단 문제는 발견하지 못했다. 병합 시 실행 코드·지도 데이터·배포물을 검토한 최종본 그대로 보존하고 상태 문서와 다운로드 링크를 갱신한다.
