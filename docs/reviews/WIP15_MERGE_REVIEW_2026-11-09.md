검토한 최종 구현은 `5a0b516b2d33f8ec25c1e4cfc161bd860d1b500c`이며 최신 지시 기준 main은 `eb485b7c9022b43d6edfe1ee5029ac7289e00d0b`다. 사용자 병합 요청에 따라 이 최종본과 검토 기록을 main에 통합한다.

## 결과

장전탄을 포함한 42발 보존, 기본 장전 5.98초·작업 상한 14초, 지속 사격 피로·피격 동요, 근접 비관통 시험 피해와 기존 과관통 감소를 확인했다. 포탑 장비 이상은 3~8초의 일시 상태이며 영구 모듈 손상·승무원 부상을 추가하지 않는다.

초안 `2960539`에서 관측장비 이상이 표적 명령을 만료시키던 문제는 해결됐다. 전차장이 동쪽을 경계하고 포수만 표적을 확보한 정상 상황에 seed 79의 실제 피격을 다시 실행했다. 독립 코어에서는 20.55초에 약 7.2266초 포수 이상이 시작되고 27.80초에 끝났다. 전 기간에 포수 현재 관측, `acquired`, 지정 표적과 사격 가능 상태가 유지됐다. 이전의 6초 표적 만료·12초 추가 재시도 대기는 발생하지 않았다.

실제 Chromium의 배포 HTML에서도 같은 경계·지정·발사 명령으로 27.60초부터 34.80초까지 이상 발생·복구를 확인했다. 관측·확보·지정과 사격 가능 상태가 유지됐으며 브라우저 오류는 없었다. 결과를 강제하거나 차량 프로파일을 수정하지 않은 별도 재현이다.

관측 이상은 조준 진행 0.70배·유효 오차 표준편차 1.25배를 한 번 적용한다. 전차장/포수 이상이 겹쳐도 중복되지 않는다. UI 예상치와 실제 발사 판정에 같은 보정을 적용하고 발사 순간의 오차를 비행체에 보존하므로 비행 중 복구가 이미 발사된 탄을 바꾸지 않는다. 관측 이상 중에는 정상 조건에서 사격할 수 있으며, 사통 이상은 기존 조준·새 발사 정지와 장전 보존을 유지한다. 배율은 조정 가능한 초기 게임 시험값이다.
