# WIP18 피격 반응·승무원 경중상 구현

## 범위와 데이터 소유권

WIP18은 기존 착탄이 HP를 처리한 뒤 피격 차량이 살아 있을 때만 실행된다. 활성 조합은 공격 정책 `tank-ke/M829A2`와 피격 프로파일 `M1A2_1998`뿐이다. 확률표, 7구역 대상 가중치, 4개 승무원 역할, 감수성, 지속시간과 능률 계수는 `src/vehicle-profiles.js`의 `M1A2_1998.hitReactions`에만 있다. 공통 `M1A2`에는 이 필드가 없으며, 설정이 없는 차량은 공통 코드가 즉시 비활성 결과를 반환한다.

이 값은 실차 취약부나 의학 모델이 아닌 조정 가능한 게임 시험 제안이다. 영구 모듈 피해, 화재·유폭, 승무원 사망·회복·교체, 대체 장전, 새 차량·무기·탄약은 구현하지 않았다.

## 사건과 난수 계약

`combat-state.js`는 기존 명중·도탄·관통·근접 비관통·구역·탄약·사건 ID를 그대로 소비한다. 추가 구역이나 피해를 다시 계산하지 않는다. 빗나감, 중복/무효 사건, 이미 격파된 표적, 해당 착탄으로 격파된 표적에는 WIP18 판정을 하지 않는다.

확률은 `구역별 기본률 × M1A2_1998 감수성`이며 정규화하거나 잘라내지 않는다. 일시 이상 → 승무원 경상 → 승무원 중상의 고정 누적 반개구간에서 최대 한 범주를 고르고, 이후 별도 난수로 구역별 대상을 고른다. 일시 이상만 세 번째 독립 난수로 6~10초 수명을 정한다. 난수 키는 사건 ID와 시나리오 seed의 `wip18:occurrence/target/duration`으로 분리되어 기존 명중·구역·도탄·WIP15 난수 순서를 바꾸지 않는다.

반응 상태에는 비열거형의 bounded 사건 ID 기록이 있어 WIP18 자체로도 중복 적용을 막는다. 내부 전투 기록은 확률/roll/대상을 보존하지만 공개 착탄 기록과 팀 접촉에는 포함하지 않는다.

## 상태와 실제 능력 연결

- 기동계 이상: 구동 출력 0.65배, 6~10초. 전진/후진 가속에 적용하고 제동·속도 상한은 바꾸지 않는다.
- 포탑 구동 이상: 실제 포탑 선회율 0.60배, 6~10초. 전차장 독립 관측축은 건드리지 않는다.
- 운전수 경상/중상: 출력 0.85/0.65배, 차체 선회 0.90/0.75배.
- 전차장 경상/중상: 자동 수색과 지정 경계의 실제 독립축 선회 0.85/0.65배. 시야각·거리·증거 축적은 그대로다.
- 포수 경상/중상: 조준 진행 0.85/0.65배, 유효 sigma 1.10/1.30배. 관측·지정·확보·발사 자격은 유지한다.
- 장전수 경상/중상: 기존 WIP15 작업시간을 효율 0.85/0.65로 나눈 뒤 14초로 제한한다. 진행률은 되감지 않는다.

같은 일시 이상 재발은 `max(기존 종료, 현재+새 수명)`이고 서로 다른 이상은 공존한다. 부상은 `정상 < 경상 < 중상`으로만 진행하며 시나리오 초기화까지 유지된다. 같은 능력의 WIP15/WIP18 효과는 곱하지 않는다. 배율은 최솟값, sigma는 최댓값을 택한다. 이미 발사된 탄은 발사 시 저장한 조준/sigma를 계속 사용한다.

고정 틱 순서는 `이동 → 도착 착탄/HP/WIP18/WIP15 → 관측 → AI → 장전·조준·발사`다. 착탄 직후 반응 계수를 다시 계산해 같은 틱의 관측과 사격에 반영한다.

## UI와 공개 정보

아군 차량 목록과 선택 차량의 장전/대응 줄에 기동계·포탑 구동 이상 남은 시간과 운전수/전차장/포수/장전수 상태를 표시한다. WIP15 사통/관측 대응과 WIP18 상태는 문구를 분리했다. 일시 이상은 만료 후 사라지고 부상은 초기화 전까지 남는다.

팀 접촉, 적 표적 패널, 효과, 공개 사격 사건에는 적의 WIP18 상태·타이머·확률·roll·대상을 넣지 않는다. 적의 실제 이동이나 포탑 움직임 차이는 자연스럽게 관측될 수 있다. 렌더/UI 읽기는 판정이나 LOS를 다시 계산하지 않는다.

## 검증과 성능

`tests/wip18-hit-reactions.test.cjs`는 확률 경계, 정책/차량 분리, 가중치·한 범주, 중복, 수명/중상 승격, 실제 전후진 출력·조향·제동, 포탑/전차장 축, 조준/sigma/장전, 비행 중 동결, 코어 이동·초기화·접촉 비공개를 검사한다. `tests/wip18-browser.test.cjs`는 실제 단일 HTML에서 seed 2의 강제하지 않은 발사→비행→착탄→WIP18 결과와, 별도로 표시한 UI 상태 주입 검사의 만료·부상 유지·차량 전환·일시정지·초기화·적 비공개·모바일 방향을 확인한다.

`scripts/benchmark_wip18.cjs`는 최신 main/WIP17 baseline, 신규 비활성, 신규 활성의 50/100대 상수시간 상태 갱신과 기본 5대 전체 틱을 분리해 기록한다. 결과는 `tests/releases/WIP18-performance.json`에 있다. WIP18은 새 LOS·피해 순회나 렌더 계산을 추가하지 않는다.
