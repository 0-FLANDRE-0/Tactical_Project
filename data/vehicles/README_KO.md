# 차량 프로파일 레지스트리 · M1A2 시험 구성

현재 실행 버전은 **WIP19 탄약 운용·우측 명령 패널**이다. 활성 시험 프로파일은 양측 `M1A2_1998`이며 M829A2·M829A1·M830을 실제 장전탄과 즉응/준즉응/예비 구획으로 관리한다. 이 혼합 적재와 작업 시간은 `M1A2_1998.ammunition`에만 있고 공통 `M1A2`나 다른 차량으로 자동 상속하지 않는다. WIP18 발생률·대상 가중치·능률 계수도 같은 활성 프로파일의 전용 정책이며 각 탄약 레지스트리 정책 ID를 명시적으로 연결한다. 구동·전투·부상·탄약 수치는 게임 튜닝이며 실차 취약성·의학·적재/성능 인증값이 아니다. [WIP19 구현](../../docs/AMMUNITION_AND_COMMAND_PANEL_WIP19.md), [WIP18 구현](../../docs/HIT_REACTIONS_AND_CREW_INJURIES_WIP18.md), [피해 상태](../../docs/COMBAT_STATE_WIP11A.md)을 참조한다.

미국 M1A2 기본형을 기준으로 한다. SEP v2/v3의 중량·센서 세대·장갑값을 섞지 않았다. 실행 코드의 원본은 `src/vehicle-profiles.js`, 필드별 출처와 근사·게임 설정 구분은 `M1A2.json`이다.

WIP07A은 주변/전차장/포수 채널별 높이를 설정한다(초깃값은 모두 2.65m). 방향·시간·seed·차체/포탑 노출·숲 감쇠로 탐지/식별을 누적한다. 전차장 독립 선회와 헌터킬러는 별도 기능이다. 4000m 기하 계산 상한이나 3000m 주포 참고 기준이 포수 2000m를 늘리지 않는다. 센서의 수치·확률·기억·인계 시간은 게임 튜닝이며 실제 광학/열상 장비·기상·야간 성능을 재현한 값이 아니다. [관측 구현과 전체 튜닝값](../../docs/OBSERVATION_WIP07A.md)을 참조한다.

탱크 외형과 선택 UI를 분리했다. 차체와 포신은 월드 단위, 이름·선택 링·24px 선택 영역은 화면 단위다. 포탑 외곽은 M1A2를 표현하는 근사 형태이며 정밀 장갑 형상은 아니다.

속도는 명목 상한이며 지형·도로·숲·경사·선회·도착 감속이 실제 속도를 줄인다. 실제 위치는 부호 있는 종방향 속도로 적분하고 반대 방향은 제동·정차 확인 뒤 연결한다. 자동변속 범위비 외의 변속표, 구동력, 손실, 제동과 조향은 게임 조정값이다. 가속 기준점 하나에 맞았다고 실차의 모든 가속 곡선이 검증된 것은 아니다.

이동 반경은 차체 반대각선에 0.25m 여유를 더한 4.62m 원이다. 종·횡 경사를 경로 방향에 따라 검사하며, 이에 맞춰 16m 길찾기 캐시를 다시 제작했다. 정밀 사각 차체 충돌, 포신 충돌, 도랑 통과 및 수심 기반 도하는 구현하지 않았다.

공개 제원 출처는 JSON의 `sources`에 원문 링크와 적용 범위를 기록했다. 같은 계열의 다른 형식에서 가져온 값은 M1A2 실측값처럼 취급하지 않는다.

## 상부 도안의 비율 검토

`references/proportion_review.json`에 공통 차체 도면의 픽셀 기준점과 정규화 방법을 기록했다. 공식 USMC M1A1 도면의 차체를 같은 길이·폭에 맞추고, M1A2 실제 사진의 CITV·해치·조준경 배치를 함께 비교했다. WIP05 도안은 이 도면에 동일 축척으로 겹쳐 외곽을 다시 그렸다. 포탑 본체는 4.75m 길이, 외부 수납함 포함 3.28m 폭, 뒤 바스켓까지 포함한 길이 약 5.30m다. 이는 게임 외형을 위한 근사 치수이며 정확한 M1A2 포탑 실측 제원으로 쓰지 않는다. 앞 버전의 지나치게 좁은 지붕과 짧은 버슬, 세 칸 패널 표현을 고쳤다.

실제 사진: [DVIDS 3055956](https://www.dvidshub.net/image/3055956/m1a2-abrams-main-battle-tank), 미 육군 Erick Ritterby, 2016-12-08. 공통 배치 도면: [MCWP 3-12 A-3](https://www.marines.mil/Portals/1/Publications/MCWP%203-12%20Marine%20Corps%20Tank%20Employment.pdf), 공개 교범. 도면 페이지는 동일한 공개 교범의 w9cr 미러에서도 확인했다.

WIP07A의 자동 수색 중심은 전방 기준 전차장 ±45°/20초·포수 ±15°/12초다. 순간 FOV와 별도 필드이며 `sensors.commander/gunner.scan`에서 조절한다. 평상시 구동은 15°/s·8°/s, 표적 확인 상한은 50°/s·40°/s다. 전차장 단독 접촉은 식별·적군 확인·명시 인계 뒤에 포수에게 전달한다. 포수 자체 확인/표적 유지와 관측 출처, 8초 반감기의 독립 식별 감쇠는 [상태 문서](../../docs/OBSERVATION_WIP07A.md)를 참조한다.

## WIP08 레지스트리와 시험 사격

`src/vehicle-profiles.js`의 ID 레지스트리는 입력을 복사·깊게 동결하고 중복/미등록 ID를 거부한다. 현재 등록 목록은 `registry.json`의 M1A2 하나다. `profileId`와 `artId`는 별개이며, 차체 도안을 공유해도 센서/사격 설정과 차량별 탄수는 합쳐지지 않는다. 32종 설계 아카이브를 자동으로 수입하지 않았다. UI 제원과 발사 규칙은 선택 차량의 프로파일에서 읽는다.

`fireControl`은 **실차 사통장치 제원이 아닌 게임 시험 설정**이다. 확보 후 조준 1.2초, 정렬 오차 1.5°, 사격 거리 2000m, 근사 발사선 높이 2.2m, 입력 간격 1초, 시험탄 42발이다. 명중률과 명중한 경우의 부위 분포를 별도로 계산한다. 현재 포수 자체 관측과 발사 순간 LOS를 모두 확인한다. 장갑/관통/피해/상세 장전은 아직 계산하지 않는다. [상태·모든 튜닝값·한계](../../docs/FIRE_CONTROL_WIP08.md)를 참조한다.

## WIP08A 제공 도안과 포구

제공 HTML의 M1A2 벡터를 사용한다. 원본은 `references/M1_Abrams_TopView.html`, 체크섬/수입 범위는 `references/top_view_import.json`에 보관했다. 다른 형식의 프로파일이나 Lab UI는 활성화하지 않는다. 제공 파일의 실측 주장을 별도로 인증하지 않았으며 도안용 근사값으로 기록한다.

`model.turretOrigin=0.15`는 벡터 배치 원점, `turretPivot=[0.66,0]`은 차체에 고정된 링 축, `muzzleLocal=[5.717,0]`은 벡터 포구 끝이다. 모호한 `turretCenter`를 대체했다. `src/vehicle-geometry.js`의 변환을 그리기/발사에서 공유한다. 포구 발사선은 기존 게임 높이 2.2m를 차체 지면 기준으로 유지한다. 본격 탄도나 포신 충돌 모델은 추가하지 않았다. [현재 도안·발사 연결](../../docs/M1A2_ART_MUZZLE_WIP08A.md)을 참조한다.

## WIP09 게임 명중 모델

WIP08 선형 정확도·이동 곱셈·고정 `zoneWeights`를 제거하고 게임 오차 예산과 제시 직사각형을 사용한다. 준비 게이트 1.2초 이후에도 `layTime`이 계속 누적된다. 표적 이동은 현재 자기 포수 관측에서 벡터로 추정하며 숨겨진 실제 속도를 읽지 않는다. 모든 수치는 실차 성능이 아닌 게임 튜닝이다.

`fireControl`의 추가 필드·범위 검증·35개 Python 기준표와 JS 비교는 [현재 상태 문서](../../docs/FIRE_CONTROL_WIP09.md)에 있다. 높이 띠는 표적 프로파일에서, 오차는 사수 프로파일에서 읽어 섞지 않는다. 레지스트리는 폐기된 정확도 필드가 남은 프로파일을 거부한다. `node scripts/export_vehicle_profile.cjs`로 현재 JSON을 내보낸다. 현재 활성 차종은 M1A2 하나이며 장갑/관통/탄약 아카이브를 자동 적용하지 않는다.

## WIP10 예측 비행과 표시용 탄착

발사 시 실제 포구, 관측 속도, 예측 위치, 오차 예산을 저장하고 실제 ToF 뒤 한 번만 명중/구역을 추첨한다. 프로파일의 `impact`는 정규분포 점 재시도 64회, 지형 경로 2m 전진, 표적 뒤 최대 3000m 탐색을 설정한다. `maneuverAccel`, `maneuverReferenceSpeed`, `flightSeconds`, `effectSeconds`는 폐기 필드로 거부한다. 제공 Python 기준 46행, 1000개 seed 탄착점, 평지 장·단탄과 건물 충돌 검사는 [WIP10 문서](../../docs/FIRE_CONTROL_WIP10.md)에 기록했다.
