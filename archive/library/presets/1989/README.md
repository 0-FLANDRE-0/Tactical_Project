# 1989 본편 전차 32종 × 3 = 96개 탄약 프리셋

> **3단계 이관·원본 비교 통과.** 원본 공유 템플릿 **18개 × 3 = 54개 행**을 **차량 32종 × 3 = 96개 행**으로 확장. 모든 구획 발수 합계를 검산했고 **원본 32개 차량 최대 HP 목록과 차명 집합을 대조**했다. 프리셋 수치 변경·게임 코드 수정 없음. ## 데이터 경계

- **1989년 본편만 포함:** M1A2 (1992/1998), 현대 Leopard 2A8, 1990년 이후 TOW 2B는 포함하지 않음.
- **프리셋과 기본 지급탄은 별개:** 특정 편성의 AP/HEAT 분량만 기록하고, 실제 탄종명/호환성은 원본의 기본탄 목록에 따름.
- **실행 코드 미변경:** 라이브러리 생성으로 96개 프리셋이 런타임에 자동 등록되는 것은 아님.
