# 1989년 서독 게파르트 35mm KDA 전용 탄띠 프리셋 — 정본

> **2026-11-21 사용자 확정.** 이것은 기존 전차 **32종×3=96개** 프리셋과 별도인 대공자주포 프리셋이다. 단순 탄종 비율뿐 아니라 **주급탄 실제 반복 탄띠 순서**가 다르다. 게임 코드·기존 96개 JSON은 수정하지 않는다.

## 공통 적재

- 차량: [Flakpanzer Gepard](../../vehicles/1989/air_defense/GEPARD.md), **35mm KDA 2문** (문당 550RPM, 합계 1,100RPM).
- **주급탄 혼합 탄띠 640발** (DM21 HEI + DM13A1 SAPHEI-T).
- **DM23 APDS-T 40발은 주급탄과 별도로 적재/급탄**.
- **합계 680발**. 주급탄 640발을 두 포 각각에 중복해서 1,280발로 합산하지 않는다.

## 프리셋 2종 — 사용자 확정

| 프리셋 | 주급탄 4발 반복 탄띠 배열 | DM21 | DM13A1 | 별도 DM23 | 합계 |
|---|---|---:|---:|---:|---:|
| **대공형** | **DM21 → DM21 → DM21 → DM13A1** | **480** | **160** | **40** | **680** |
| **범용형** | **DM13A1 → DM13A1 → DM13A1 → DM21** | **160** | **480** | **40** | **680** |

- 640발 주급탄은 **4발 패턴 × 160회**로 표현한다. 480:160은 비율 설명일 뿐, 실제 사격 도중 자유롭게 3발/1발을 선택하는 AI 방식이 아니다.
- 대공/범용 전환 시 이미 장전된 벨트의 즉시 교체·부분 사용 잔량, 두 포 각각의 탄띠 분배와 동기화, DM23 급탄 전환 소요시간, 급탄장치 손상·과열·보충은 **미정**.
- 대공 교전거리 **유효 3.5km / 최대 4.0km**는 차량 고유 제원이다. 탄띠마다 포의 고정 사거리가 달라지는 규칙은 없다.
- 탄약 고유 관통력·DM21 공중/지상 피해·DM13A1 신관·DM23 과관통은 [35mm 탄약 정본](../../ammunition/autocannon/GEPARD_35MM.md)을 따른다.
