# TACTICAL 프리셋 라이브러리

> **3단계 이관·검산 완료.** 1989 본편 32개 전차 형식의 게임용 기본/대기갑/화력지원 3종 프리셋을 [원본 ammo §11](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/ammo/README.md) 기준으로 펼쳐 보존한다.

- [**1989년 96개 프리셋 표**](1989/README.md)
- [**96개 엔트리 정형 JSON**](1989/TANK_LOADOUTS_96.json)
- [**1989 게파르트 35mm 대공형·범용형 실제 4발 반복 탄띠**](1989/GEPARD_BELTS.md) — 두 프리셋 각각 주급탄 640발 + 별도 DM23 40발; **기존 전차 96개 프리셋과 별도**.
- [**원본 18그룹·54행 템플릿 보존본**](1989/SOURCE_TEMPLATES_54.md) — 별도 원본 대조용

1989년 본편 차종 이름 집합은 원본 전차 HP 32종과 일치하며 모든 구획 수량의 합계 검산을 통과했다. 현대 Leopard 2A8 및 1992/1998 M1A2·TOW 2B 후속 탄약 구성은 별도 미정이고 1989 프리셋에 포함되지 않는다.

게임 코드의 실제 적재 프리셋을 이 파일로 교체한 것은 아니며, 현재 정본은 [96개 JSON](1989/TANK_LOADOUTS_96.json)이며 구형 원본은 출처·이력으로 보존한다.
