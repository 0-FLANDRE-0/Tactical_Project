# M1A2 1992/1998 — 후속 시대 전차 2종

> **3단계 원문 기반 이관본; 기존 정본 대체 전.** [원본 전차 아카이브](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/tanks/README.md)에서 내용 이관. 1989 본편 32종에 포함되지 않는 1992/1998 두 형식. 기존 WIP 시험 구현과 설계값의 상태를 혼동하지 않음. 게임 코드·기존 1989년 프리셋에는 변경 없음.

## 8. 이후 시대 확장 전차 — M1A2 (1992) / M1A2 (1998)

> **상태:** 두 형식 모두 게임용 7구역 기본 방호력 확정(2026-11-07). 1989년 NATO·소련·NVA 본편 **32종에 포함되지 않는 후속 시대 전차**다.
> **형식명:** **M1A2 (1992)**와 **M1A2 (1998)**를 별도 게임 형식으로 관리한다. **M1A2 SEP는 별도 모델**이며, 1998년형에 SEP 사양이 포함된다는 의미가 아니다.
> **기준:** 사용자 지정 **게임용 KE(CE), mm RHAe**. 연도별 형식과 장갑값은 게임 설계 구분이며 실제 해당 연도 차량의 장갑 실측값·공식 미군 개량 내역을 주장하지 않는다.

| 장갑 구역 | M1A2 (1992) KE(CE) | M1A2 (1998) KE(CE) |
|---|---:|---:|
| 차체 전면 | **385(700)** | **390(720)** |
| 차체 측면 | **120(240)** | **120(280)** |
| 차체 후면 | **40(40)** | **40(40)** |
| 포탑 전면 | **660(1050)** | **720(1150)** |
| 포탑 측면 | **320(600)** | **340(630)** |
| 포탑 후면 | **55(55)** | **55(55)** |
| 통합 상부장갑 | **40(40)** | **40(40)** |

- **2026-11-07 수정 — M1A2 (1992):** 기존 대화의 검토값 차체 전면 490(740) → **385(700)**, 포탑 전면 700(1080) → **660(1050)**. 다른 구역은 기존 제시값을 유지하며, 이번에 정식 기록한다.
- **2026-11-07 수정 — M1A2 (1998):** 차체 전면 520(880) → **390(720)**. 포탑 전면 **720(1150)**과 나머지 구역은 유지한다.
- **Abrams 포탑 후면 통일:** 본편 M1·IPM1·M1A1·M1A1 HA + 후속 M1A2 (1992/1998) = **총 6개 형식 모두 55(55)**. 본편의 최신 수치는 §3 참고.
- **기존 7구역 기준값만 확정.** 차체 상·하부, 포방패·좌우 뺨, 측면 전후방, 상부 지붕 세분화 및 경사·LOS 확률식은 [기존 장갑 아이디어](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/tanks/ARMOR_SUBZONES_AND_PROBABILITY_IDEAS_2026-11-07.md)와 [2단계 명중 판정 메모](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/combat/TWO_STAGE_HIT_AND_360_ARMOR_RESOLUTION_DESIGN_2026-11-07.md)의 **검토 사항**으로 유지한다.
- **M1A1 HA보다 높은 M1A2 두 형식의 방호력은 게임 밸런스 설정**이다. 연식별 실제 장갑 성능 향상량이 해당 수치와 같다는 의미는 아니다.
- 이 절은 **장갑 데이터만 추가/수정**한다. M1A2 두 형식의 탄약 적재 프리셋·희귀도·포인트·세부 사통 수치는 미확정. 기존 [탄약 문서](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/ammo/README.md)의 1989년 차량 **32종 × 3 = 96개** 프리셋은 변경 없음.
- 기존 `M1A2` 기본 프로필은 WIP10 호환 fixture로 보존했다. WIP11A 활성 `M1A2_1998`은 기존 시각·관측·기동 설정을 이어 쓰고 이 절의 1998년형 장갑과 HP만 게임 데이터로 연결한다.
