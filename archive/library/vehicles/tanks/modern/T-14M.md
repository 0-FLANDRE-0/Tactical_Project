# T-14M 아르마타 — 현대 전차 게임 설계 정본

> **2026-11-19 사용자 확정·추가 설계 진행 중.** 이 문서는 TACTICAL 현대 전차 확장용 **T-14M(125mm 기본형)** 차량 제원의 정본이다. 아래 **차량 HP 1,500 및 기본장갑 7구역 KE(CE) 전부 확정**. 증가장갑과 폭발반응장갑(ERA)을 **함께 탑재하는 방식**도 확정한 설계 방향이며, 그 외 부위별 추가값·피복률·소모·내구도·상세 판정은 미정. **실물 T-14의 공인 장갑 시험값이 아닌 게임 전용 수치**이며, 본 문서 등록만으로 실행 코드에 구현된 것은 아니다.

## 1. 장갑 수치의 읽는 법과 구역 순서

- **항상 아래 순서로 읽는다:** **① 차체 전면 / ② 차체 측면 / ③ 차체 후면 / ④ 포탑 전면 / ⑤ 포탑 측면 / ⑥ 포탑 후면 / ⑦ 상부**. 다른 차량 제원과 비교할 때도 동일한 순서를 쓴다.
- **표기 `KE(CE)`:** 바깥 숫자는 운동에너지탄에 대한 **KE**, 괄호 안 숫자는 화학에너지탄에 대한 **CE** 방호력이다. 예: `580(890)` = KE 580mm RHAe / CE 890mm RHAe.
- **단위:** mm RHAe, 게임에서 사용하는 부위별 대표 방호값. 장갑 배치의 기본 경사 효과 등을 이미 반영한 게임 설정값이며, 수치 자체를 실물 강판 두께로 보거나 LOS 경사 보정을 이중 적용하지 않는다.
- **상부:** 차체 상판과 포탑 상판을 분리하지 않은 **통합 제7구역**으로, 1989년 상부장갑 체계의 동일한 읽기 원칙을 따른다. 참고: [7구역·상부 판정 정본](../1989/UPPER_ARMOR.md).
- 아래 숫자는 **오직 기본장갑**. 증가장갑·ERA 추가 방호를 합산하지 않는다.

## 2. 사용자 확정 기본 방호력 및 차량 HP

- **차량 최대 HP: 1,500** (증가장갑의 별도 부위 HP와 혼합하지 않음).

| 순서 | 장갑 구역 | **기본 KE(CE) mm RHAe** | 결정 상태 |
|---:|---|---:|---|
| 1 | **차체 전면** | **580(890)** | 확정 |
| 2 | **차체 측면** | **95(140)** | 확정 |
| 3 | **차체 후면** | **30(30)** | 확정 |
| 4 | **포탑 전면** | **75(85)** | 확정 |
| 5 | **포탑 측면** | **55(65)** | 확정 |
| 6 | **포탑 후면** | **25(25)** | 확정 |
| 7 | **상부** | **40(40)** | 확정 |

**한 줄 표기:** `580(890) / 95(140) / 30(30) / 75(85) / 55(65) / 25(25) / 40(40)`.

## 3. 증가장갑 + 폭발반응장갑(ERA) 병용 — 구조 확정, 상세 미정

**사용자 확정 방향:** T-14M은 **기본장갑과 별개로 증가장갑 및 ERA를 함께 사용하는 형태**다. 둘 중 하나를 택하는 선택형 구성으로 기록하지 않는다. 다만 각 시스템을 어디에 얼마나 적용하고 어떤 순서로 계산할지에 대해서는 사용자 추가 결정 전까지 단정하지 않는다.

| 항목 | 상태 | 미정 사항 |
|---|---|---|
| **기본장갑 7구역** | **수치 확정** | 위 표에 명시 |
| **비폭발성 증가장갑** | **탑재 방향 확정** | 장착 부위, KE/CE 추가 방호량, 각 부위 피복률, 독립 HP 여부·수량, 피해 감쇄 및 잔존 방호력 |
| **폭발반응장갑(ERA)** | **탑재 방향 확정** | 장착 부위, KE/CE 추가 방호량, 각 부위 피복률, 피격 후 피복률 소모, Anti-ERA와의 상호작용 |
| **두 증가 방호 수단의 조합** | **병용 확정** | 동일 부위 중첩 여부·공간 배치, 피복 판정, 적용 순서, 소모·손상 독립 처리 |
| **능동방호(APS) 및 승무원 캡슐** | **추후 별도 설계** | Afghanit 정량값·요격 규칙, 승무원 캡슐 추가 방호·피해 분리, 무인포탑 손상 처리 |
| **주포·탄약·장전·적재** | **후속 별도 설계** | 125mm 2A82-1M 운용 제원, 현대 3BM59/60/69/70의 차량별 지급 및 적재 프리셋 |

- **정량값 상속 금지:** T-80U의 Kontakt-5 `+215(+560)`, Leopard 2A8의 증가장갑 수치·독립 HP·최저 잔존 42.5%, M1A2C의 TUSK/ARAT 피복률 또는 Trophy HV 제원을 T-14M에 자동 적용하지 않는다.
- **Malakhit ERA 및 Afghanit APS**는 논의 중인 장비 컨셉이며, 해당 **게임 정량 프로필은 아직 확정하지 않았다**. 두 장비의 실물 구성·작동 세부도 게임 수치로 임의 확정하지 않는다.
- **무인포탑:** 포탑 기본 방호력이 차체보다 낮은 사용자 확정 수치를 그대로 유지한다. 이를 이유로 새로운 피격 판정·승무원 생존 보너스·포탑 피해 무효화 효과를 자동 부여하지 않는다.
- **125mm 현대 날탄:** [3BM59 / 3BM60 / 3BM69 / 3BM70 제원 정본](../../../ammunition/modern/APFSDS_125MM.md)은 별도 확정. 이 차량의 탄약 적재·장전·주포별 지급 확정으로 오해하지 않는다.
- **T-14M-152:** 152mm 2A83 기반 후보는 125mm T-14M과 **별도 실험형 분기**이며, 이 문서의 현행 기본장갑에 추가 주포 또는 Grifel 계열 탄약을 자동 장착하지 않는다.

## 4. 시대 및 구현 상태

- **현대 전차 확장용 아카이브 설계 제원**만 등록. 기존 1989년 소련 전차, M1A2C, Leopard 2A8의 개별 정본을 변경하지 않는다.
- **1989년 32종 본편·96개 적재 프리셋·게임 실행 코드 미변경.**
- 후속 결정 시 먼저 **이 문서의 해당 영역**을 수정하고 [차량 카탈로그](../../README.md)에서는 링크만 관리한다. 공통 방호/피해 판정은 [시스템 카탈로그](../../../systems/README.md)의 정본 원칙을 따른다.
