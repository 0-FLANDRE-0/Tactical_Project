# T-90M (2026) — 현대 전차 게임 설계 정본

> **2026-11-19 사용자 지정 신규 확정.** TACTICAL 현대 전차 확장용 **T-90M (2026)** 설계 사양이다. 차량 최대 **1,450 HP**, 기본장갑 7구역, Relikt ERA의 부위별 최초 피복률·탄종별 피복 지점 소모량, 차체/포탑 측면 **2겹 Relikt**, **Arena-M APS 탑재**를 확정했다. 실차 실측 제원이나 실제 게임 코드 구현 완료를 뜻하지 않는다. **1989년 본편 전차 32종·96개 적재 프리셋은 변경하지 않는다.**

## 1. 차량 HP 및 기본 장갑

- **차량 최대 HP: 1,450**. 방호력 KE/CE, ERA 피복률, APS 재고/성능과 별도 값.
- **7구역 순서:** 차체 전면 → 차체 측면 → 차체 후면 → 포탑 전면 → 포탑 측면 → 포탑 후면 → 상부장갑. 상부는 차체·포탑 지붕 통합 1구역.
- **단위:** mm RHAe, **KE(CE)**. 아래 기본값은 **ERA 적용 전**, 게임 밸런스용 대표 방호 수치.

## 2. Relikt ERA — 부위별 추가 방호력과 초기 피복률

- **일반 Relikt (차체 전면·포탑 전면·상부):** 피복 지점에 **KE +240 / CE +560**. 기존 Relikt 공통 추가 방호력 설정 유지.
- **차체 측면·포탑 측면은 2겹 Relikt:** **안쪽 KE +80 / CE +420**, **바깥쪽 KE +240 / CE +560**. 두 겹 모두 유효한 피복 지점의 **단순 합계 KE +320 / CE +980**. 측면에 일반형 +240(+560)을 세 번째로 또 더하지 않는다.
- 초기 피복률은 **사용자 지정 5개 장갑 구역 각각의 값**. 이중층 피복률은 측면 구역별 단일 명시값 **80% / 78%**이며, 층별 독립 피복/소모·부분 상실의 세부 판정은 아직 미정이다.

| 장갑 구역 | 기본 KE(CE) | ERA 구조·추가 KE(CE) | **피복 지점 총 KE(CE)** | **초기 피복률** |
|---|---:|---|---:|---:|
| **차체 전면** | 525(780) | Relikt **+240(+560)** | **765(1340)** | **92%** |
| **차체 측면** | 75(85) | 이중층 **안 +80(+420), 밖 +240(+560)** | **395(1065)** | **80%** |
| **차체 후면** | 40(40) | 사용자 미지정 | 미지정 | 미지정 |
| **포탑 전면** | 575(880) | Relikt **+240(+560)** | **815(1440)** | **90%** |
| **포탑 측면** | 315(420) | 이중층 **안 +80(+420), 밖 +240(+560)** | **635(1400)** | **78%** |

> **피복 지점 총 방호 수치**는 **두 겹이 모두 유효한 경우의 감쇄 전 단순 합계**다. 실제 교전에서는 탄종별 Anti-ERA 등의 판정이 추가될 수 있다. **후면은 피복률·장착 상태가 지정되지 않았으므로 자동으로 0%나 미장착 확정으로 처리하지 않는다.**

## 3. T-90M 전용 Relikt ERA 피복률 소모

| 피격 탄종 분류 | **ERA 피복 지점 피격 시 해당 구역 피복률 감소** |
|---|---:|
| **AP 계열** (APFSDS/APDS 등) | **−20%p** |
| **HEAT / ATGM** | **−28%p** |
| **HE / HEP** (HE-FRAG/HESH 등 해당 분류) | **−40%p** |

- 피복 지점에 유효 명중한 **해당 장갑 구역의 피복률에서 위 %p만큼 차감**한다. 방호 수치 KE/CE를 위 비율만큼 감쇄하는 뜻이 아니다.
- **ERA 비피복 지점 명중 시 주변 피복률 소모 여부·량**, **2겹의 개별 상실 및 동시/순차 반응**, **한 발에 층별로 피복률을 별도 차감할지 여부**, **부분 잔존 시 방호력**, **피격 후 수리/복원**은 별도 지시 전까지 **미정**. Kontakt-1/5의 비피복 반값 소모·피복 소모량이나 Malakhit의 층별 판정을 자동 복사하지 않는다.
- 기존 **M829A2×Relikt 18.6%**, **M829A3×Relikt 47.6%** 추가 KE 방호 감쇄는 [Anti-ERA 시스템 정본](../../../systems/armor/ANTI_ERA.md)의 확정값이다. **측면 이중층의 안쪽/바깥쪽에 감쇄를 각각 어떻게 적용할지는 미정**이므로, 위 측면 총 방호 표는 **Anti-ERA 적용 전** 값이다. M829A4 수치는 아직 비교 후보.

## 4. Arena-M APS

- **탑재 확정:** T-90M (2026)에 **Arena-M 능동방호체계(APS)**를 장착한다.
- **정량 미정:** 담당 방위·고저각, 요격탄 발수 및 재고, 대상 탄종/속도 범위, 반응시간, 재발사 간격, 성공률, 피격 피해 경로, 상부 대응, 수리/재보급.
- 다른 APS인 **Trophy HV**, **Afghanit**의 요격률·방위·탄수·반응시간을 자동 상속하지 않는다.

- **HP 1,450 / 7구역 기본장갑 / Relikt 피복·소모·측면 이중층 / Arena-M 탑재** 이외의 수치를 실제 역사 제원이나 다른 차량 수치에서 자동 추정하지 않는다.
- **기존 다른 전차·K1/K5·Relikt 일반형 KE +240/CE +560·Malakhit·ARAT·APS 및 M829 탄약 관통력/Anti-ERA 수치는 변경하지 않는다.**
