# M1A2C (M1A2 SEP v3) — 현대 전차 게임 설계

> **2026-11-19 사용자 지정 / 현행 현대 전차 아카이브.** 기존 [M1A2 (1992/1998)](../post-1989/M1A2_1992_1998.md)과 별도 형식. 아래 KE(CE)는 **TACTICAL의 게임용 mm RHAe**이며 실제 미 육군의 공개 장갑 시험 수치가 아니다. **1989 본편·96개 프리셋·실제 게임 코드 변경 없음.**

## 1. M1A2C 기본 차체·포탑 방호력 — 7구역

> **2026-11-19 사용자 확정:** 초기 제안 포탑 전면 **855(1450)**은 철회, **830(1360) 고정 기본장갑**으로 변경. 포탑 전면에 2A8식 별도 손상 가능한 증가장갑 HP를 만들지 않음.

| 7구역 | **기본 KE(CE)** | 비고 |
|---|---:|---|
| 차체 전면 | **435(880)** | 기본 고정장갑 |
| 차체 측면 | **120(285)** | **단, TUSK I/II에서 차체 측면 ERA 장착 시 기본 부분은 75(80)으로 대체** |
| 차체 후면 | **40(40)** | 고정장갑 |
| 포탑 전면 | **830(1360)** | **고정장갑**, 증가장갑 HP 없음 |
| 포탑 측면 | **355(720)** | TUSK II 선택 시 ARAT-2 단독 추가 가능 |
| 포탑 후면 | **55(55)** | 고정장갑 |
| 통합 상부 | **40(40)** | 고정장갑 |

- **차량 최대 HP:** **미정**. 기존 M1A2(1998)의 1,450 HP를 M1A2C에 자동 상속하지 않는다.
- **탄약·적재:** M829A3/A4의 자체 성능은 [미국 120mm 탄약 정본](../../../ammunition/cannon/US_120.md)에 확정돼 있으나, M1A2C의 기본 지급탄·적재수·혼합 프리셋은 미정.
- **Trophy HV:** M1A2C에서의 장착 상태·운용 변수는 별도 미정. TUSK I/II와 자동 연동하지 않는다.

## 2. 교체형 TUSK 장갑 구성

**장착 상태는 '미장착 / TUSK I / TUSK II' 중 하나.** TUSK I과 II를 동시 장착해 중복 합산하지 않으며, 두 키트 간 전환에 필요한 시간·보급·수리 조건은 미정.

| 항목 | 미장착 | **TUSK I** | **TUSK II** |
|---|---|---|---|
| 차체 측면 **기본** KE(CE) | 120(285) | **75(80)** | **75(80)** |
| 차체 측면 ERA | 없음 | **ARAT-1 +10(+520)** | **ARAT-1 +10(+520) + ARAT-2 +5(+180)** |
| 차체 측면 시작 피복률 | — | **85%** | **85%** |
| **차체 측면 피복 지점** 초기 합계 | 120(285) | **85(600)** | **90(780)** |
| 포탑 측면 기본 KE(CE) | 355(720) | 355(720) | 355(720) |
| 포탑 측면 ERA | 없음 | 없음 | **ARAT-2 +5(+180)** |
| 포탑 측면 ERA 시작 피복률 | — | — | **75%** |
| **포탑 측면 피복 지점** 초기 합계 | 355(720) | 355(720) | **360(900)** |

- 위 합계는 **해당 ERA가 실제 피복된 지점에 맞고, 모든 관련 층이 유효한 조건부 수치**. 비피복 지점에는 각 TUSK 구성의 기본장갑만 적용한다.
- **차체 측면 기본값 75(80)은 ERA가 장착된 TUSK 구성의 기본 구역값**이다. 120(285) 위에 단순히 반응장갑만 추가하는 방식이 아니다. ERA가 소모된 뒤 키트가 남아 있을 때도 기본 75(80)을 기준으로 판단하며, 키트 제거 시 기본 120(285)로 복귀하는 설계 방향.
- TUSK II 차체 측면 **ARAT-1 안쪽, ARAT-2 바깥쪽**의 중첩 방호. TUSK II 포탑 측면은 ARAT-2 단독. 장갑 두 층의 공간적 상세 배치와 손상별 독립층 유지 여부는 아직 확정하지 않음.
- 사용자 확정 **ERA 소모 규칙 및 탠덤 판정은 [ARAT/TUSK 시스템 정본](../../../systems/armor/ARAT_TUSK_I_II.md)**을 따른다.

## 3. 탠덤탄에 대한 TUSK II 핵심 규칙

- **탠덤 효과는 오직 ARAT-2 층의 추가 CE(+180)에만 적용한다.** 이것을 'ARAT-2를 무조건 완전히 무시한다'는 뜻으로 해석하지 않는다.
- TUSK II 차체 측면에 ARAT-1·ARAT-2 두 층이 동시에 피복된 경우, **탠덤 효과로 ARAT-1의 추가 CE(+520)를 감쇄하지 않는다**. ARAT-1의 보호는 정상 계산한다.
- 포탑 측면은 ARAT-2 단독이므로 해당 층에만 탠덤 효과를 적용할 수 있다.
- **탠덤의 ARAT-2 CE 감쇄율·성공률·상세 판정 조건은 미정**. 독립적인 ERA 피복률 소모는 아래 시스템 규칙을 따른다.
- **M1A2C 설계 확정과 실제 구현은 별개**. 1989년 본편 전차·레거시 M1A2(1998)·Leopard 2A8의 수치는 변경하지 않는다.
