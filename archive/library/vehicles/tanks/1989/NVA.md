# 동독 본편 전차 — TACTICAL 1989 이관본

> **3단계 데이터 이관·검증 전 병행본.** 원본 [`archive/tanks/README.md`](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/tanks/README.md)의 §6와 §9-D 내용에서 **원문 수치와 확정/잠정 표현을 그대로 보존**함. 1989년 본편/코드 수정 없음. 시스템 공통 방호 규칙은 [기존 전차 원본 §1](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/tanks/README.md) 참조. 최종 정본 전환은 5단계 이후.

## 6. 동독 NVA 전차

T-72 Ural (1973), T-72M (1981), T-72M (1986), T-72M1 (1987), T-55A, T-55AM2, T-55AM2B.

- T-55AM2B는 게임 편성상 9M117 포발사 미사일 적재를 허용하며 3종 프리셋도 확정됐다. T-55AM2는 해당 ATGM을 기본 지급하지 않는다. 실제 역사적 보급 범위는 별개 확인 사항.
- **2026-11-07 확정 추가:** 사용자가 **T-72 Ural (1973, Object 172M) 초기형**을 명시적으로 NVA 정식 목록에 추가. 기존 T-72M/M1과 **별개 차량**으로 취급. 소련군 GSFG 14개 세부형 라인업은 이번 변경으로 늘어나지 않음. 동독군 초기 운용 T-72와 원형 소련 내수형의 세부 수출 사양은 차이가 있을 수 있으므로, 본 항목은 사용자 지정 1973 우랄 사양의 게임상 편성임.
- T-72 Ural (1973)은 복합장갑 차체 전면·주조강 포탑의 초기형이며 구형 광학 거리측정기와 125mm 자동장전장치를 사용한다. 기본 ERA와 포발사 미사일 유도 기능은 없다. **게임 탄약 총 39발(즉응 22·예비 17), 3종 프리셋 확정**([탄약 기준표](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/ammo/README.md) §11). 동독 수출형의 역사적 용량 검증 여부와 게임용 확정값을 혼동하지 않는다.
- 동독 NVA T-72 4형식과 T-55 3형식의 방호력은 아래 표를 따르고, **모두 3종씩 확정한 적재 프리셋**은 [탄약 기준표](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/ammo/README.md) §11을 따른다. 역사적 편성과 구획 용량의 검증 상태는 별도로 유지한다.
### 동독 NVA T-72 초기형·수출형 — 최신 방호력 제시값 (2026-11-07)

**게임용 기본 방호력 KE(CE), mm RHAe, ERA 없음.** 수치는 사용자의 제시값 및 이후 수정값을 우선 반영하고, 실제 기밀 방호력이나 균일한 주조판 두께를 뜻하지 않음. 방호력은 차체 전면/측면/후면, 포탑 전면/측면/후면의 6구역으로 관리.

| 부위 | T-72 Ural (1973) | T-72M (1981) | T-72M (1986) | T-72M1 (1987) |
|---|---:|---:|---:|---:|
| 차체 전면 | **295(415)** | **310(435)** | **350(480)** | **380(505)** |
| 차체 측면 | 90(100) | 95(105) | 95(105) | 95(105) |
| 차체 후면 | 40(40) | 40(40) | 40(40) | 40(40) |
| 포탑 전면 | **365(365)** | **380(380)** | **380(380)** | **410(540)** |
| 포탑 측면 | 160(160) | **185(185)** | **185(185)** | **230(290)** |
| 포탑 후면 | 65(65) | 65(65) | 65(65) | 65(65) |


- **장갑 구조:** Ural과 T-72M 계열 포탑의 단일 주조강/복합장갑 구성, T-72M1의 개량 장갑을 구분하는 게임 방호력 설정. 주조 포탑이라는 제작 방식과 내부에 복합 충전재가 있다는 사실은 상호 배타적이지 않음.
- **T-72M (1986):** M (1981)에 비해 차체 전면만 강화하고 포탑은 동일하게 유지하는 과도기형.

- **T-72M (1981/1986) 포탑 측면 확정값:** 185(185). 두 생산형은 포탑 방호력이 같고 차체 전면만 구분된다.
- 4개 형식 모두 **기본 ERA 미장착**, 포발사 미사일 유도 기능 없음(현재 NVA 편성). 이 표에는 125mm 탄약 조합·즉응/예비 적재량은 포함하지 않음.

### 동독 NVA T-55A / T-55AM2 / T-55AM2B — 기본방호력 및 BDD 확정 (2026-11-07)

단위: **KE(CE), mm RHAe**. **BDD 효과를 제외한** 기본 방호력. 이 수치는 RTS 밸런스를 위한 사용자 지정 게임 대표값이며 실제 장갑 물리 두께·실측값으로 해석하지 않음. T-55AM2 및 AM2B의 기본 6구역 방호력은 T-55A와 동일하고, 증가장갑은 별도 적용.

| 장갑 부위 | T-55A | T-55AM2 | T-55AM2B |
|---|---:|---:|---:|
| 차체 전면 | 200(200) | 200(200) | 200(200) |
| 차체 측면 | 80(80) | 80(80) | 80(80) |
| 차체 후면 | 45(45) | 45(45) | 45(45) |
| 포탑 전면 | **250(250)** | **250(250)** | **250(250)** |
| 포탑 측면 | 165(165) | 165(165) | 165(165) |
| 포탑 후면 | 65(65) | 65(65) | 65(65) |

**BDD 추가장갑 — T-55AM2 / T-55AM2B 공통. T-55A에는 장착하지 않음.**

| 장갑 부위 | BDD 추가 방호력 KE(CE) | 해당 부위 피복률 | BDD 정상 적용 시 총 KE(CE) |
|---|---:|---:|---:|
| 차체 전면 | +120(240) | **80%** | **320(440)** |
| 포탑 전면 | +100(240) | **75%** | **350(490)** |
| 포탑 측면 | +80(150) | **35%** | **245(315)** |
| 나머지 부위 | 미장착 | 0% | 기본 방호력 그대로 |

- **T-55 계열 확정값:** 기본 포탑 전면은 3형식 모두 250(250). T-55AM2/AM2B의 BDD가 정상 적용된 포탑 전면 총 방호력은 350(490).
- **피복률과 내구도 분리:** BDD 피복률 고정, 부위별 HP **차체 전면 850/포탑 전면 950/포탑 측면 550**, 감쇄율 **APFSDS/APDS 30%, HEAT/ATGM 35%, HEP/HESH 80%, HE 85%**, 최소 잔존 방호력 **25%**를 §1-B처럼 적용한다. **폭발성 탄종은 비관통이어도 기폭 시 장갑 HP 손상**, 빈 지점은 감쇄율 적용 후 피복 지점 손실의 50%. 빈 지점 APFSDS/APDS는 손실 0. 미기폭·수리 방식 미정.
- T-55A는 BDD 미장착 기본형. T-55AM2/AM2B는 BDD 추가장갑을 적용하며, **AM2B만 9M117을 게임용 프리셋에 적재**한다. 각각의 기본·대기갑·화력지원 발수는 [탄약 기준표](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/ammo/README.md) §11에 확정됨. 실전 지급에 대한 역사적 검증은 별도다.

- **NVA ERA 조사 메모(2026-11-07):** 1989년 동독군의 위 7형식 중 **Kontakt-1/Kontakt-5 폭발반응장갑의 표준 장착 실전형은 확인되지 않음**. T-72M 1986형 전면 보강은 강철 증가장갑이며 ERA가 아님. T-55AM2/AM2B의 BDD는 비폭발성 복합/반응형(NERA)으로 기술되는 추가 장갑이며, 게임상 소모식 폭발반응장갑과 구별해 **기본 KE/CE와 별도 추가장갑 수치·피복률·내구도로 관리**한다. 역사적 기본 편성에서 ERA 없는 전차로 취급을 권장하지만 **대체역사 희귀 개수형 ERA 장착 여부는 사용자가 아직 결정하지 않았음**.
- **조사 근거:** [NVA T-72 개량형 기록](https://tank-afv.com/coldwar/East_Germany/Nationale-Volksarmee.php) / [동독 T-72M1과 Kontakt-1 비장착 구분](https://armoredwarfare.com/en/news/general/development-t-72m1) / [T-55AM2B의 BDD 장갑](https://tank-afv.com/coldwar/East_Germany/T-55-AM2B.php).
