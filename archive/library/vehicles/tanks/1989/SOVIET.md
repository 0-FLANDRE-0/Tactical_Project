> **3단계 데이터 이관·검증 전 병행본.** 원본 [`archive/tanks/README.md`](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/tanks/README.md)의 §5와 §9-C 내용에서 **원문 수치와 확정/잠정 표현을 그대로 보존**함. 1989년 본편/코드 수정 없음. 시스템 공통 방호 규칙은 [기존 전차 원본 §1](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/tanks/README.md) 참조. 최종 정본 전환은 5단계 이후.

## 5. 소련군 전차

T-80U, T-80BV, T-80B, T-72B, T-64BV, T-64B, T-72A, T-64A.

- T-80U: 소수 **최정예 선봉/특별 증강 전력**이라는 가상 전시 편성.
- T-72B 및 T-72A: 소련 본토에서 오는 **후속 지원/증원 전차** 구상. 평시 GSFG 배치 이력과 혼동하지 않음.
- 나머지 T-80/T-64 계열은 독일 주둔군의 기존 전력 기반 구상.
- **T-80B(1978/1984), T-80BV(1985), T-80U(1985) 및 T-64A(1969/1975), T-64B(1976/1984), T-64BV(1985)의 기본 방호력을 확정·작성함.** T-80BV 및 T-64BV에는 Kontakt-1, T-80U(1985)에는 Kontakt-5 피복률이 설정됨. **T-64BV 포탑 측면 ERA 피복률은 50%가 최신값**. **T-72A(1979/1983), T-72B(1985/1989), T-80U(1989)의 기본 방호력 및 해당 후기형 ERA 피복률을 2026-11-07 확정함**. **소련 125mm 전차 14형식의 기본 APFSDS/HEAT/ATGM 지정(2026-11-07)**. 기본 대표탄과 각 전차별 적재 프리셋·구획 발수는 [탄약 기준표](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/ammo/README.md) §7·11에 확정됐다.

### T-80B 두 형식 — 신규 설정 (2026-11-06)

단위: mm RHAe, KE(CE). 게임용 정면 기준 대표 방호력이며 **ERA 미포함**.

| 부위 | T-80B (1978) | T-80B (1984) |
|---|---:|---:|
| 차체 전면 | 370(480) | 420(540) |
| 차체 측면 | 75(85) | 75(85) |
| 차체 후면 | 40(40) | 40(40) |
| 포탑 전면 | **450(580)** | **450(580)** |
| 포탑 측면 | 280(350) | 280(350) |
| 포탑 후면 | 70(70) | 70(70) |

- 1978형과 1984형의 차이는 현재 **차체 전면 방호력만** 설정. 1984년은 게임상의 후기 생산형 구별명이며 실제 장갑 개량이 정확히 1984년에 시작됐다는 확정 주장은 아님.
- 포탑 측면 대표 수치 KE 280은 소형 곡면 포탑의 전방 측면 두꺼운 장갑 영역까지 단일 구역에 포함하려는 설계 의도. 실제 측면 전체의 균일한 방호력을 뜻하지 않음.
- **T-80B 두 형식의 포탑 전면 확정값:** 450(580). T-80B(1984)의 차체 전면은 420(540), T-80B(1978)은 370(480)이며 다른 기본 장갑 부위는 공통이다.
- 전투 밸런스 의도: 기준 2,000m/0°에서 M829·DM33 (KE 450)과 같은 수준. **동률 관통 처리 규칙은 미정**이고, 거리·각도에 따라 최종 관통이 달라짐.
- T-80BV(1985)는 T-80B(1984)의 기본 방호력을 바탕으로 Kontakt-1 방호와 부위별 피복률을 별도 적용한다(아래 확정값 참조).
- T-80A / Object 219A는 사용자 요청으로 검토된 **실험형 후보**이며, 현재 확정 소련군 8종의 정식 라인업에는 아직 추가되지 않음.

### T-80BV (1985) — Kontakt-1 ERA 설정 (2026-11-06)

- **차체 기본장갑 확정:** T-80BV (1985)는 T-80B (1984)와 동일한 차체 방호력인 전면 420(540), 측면 75(85), 후면 40(40)을 사용한다. 포탑은 현재 T-80B (1984)와 공통값 450(580) / 280(350) / 70(70)을 **잠정 공유**하며, BV만의 별도 포탑 수치는 정하지 않았음. ERA는 이 기본장갑과 별도.
- **추가 방호력(ERA가 있는 지점에 명중하여 방호가 적용된 경우):** KE **+5mm RHAe**, CE **+380mm RHAe**. 게임용 수치이며 실제 시험 확정치가 아님.
- **피복률:** 명중 부위마다 ERA가 남아 있는 면적의 비율로 관리; 방호가 적용될 확률로 사용하며 피격·소모에 따라 감소.

| ERA 부위 | 시작 피복률 | 상태 |
|---|---:|---|
| 차체 전면 | **95%** | 제시값 |
| 차체 측면 | **60%** | 제시값 |
| 포탑 전면 | **100%** | 제시값 |
| 포탑 측면 | **55%** | 제시값 |
| 차체 후면 | **0%** | **ERA 미장착** |
| 포탑 후면 | **0%** | **ERA 미장착** |

- **ERA 피복 지점 적중 시** 기존 방호 보정 후 §1-A의 **Kontakt-1 통합 손실량**을 적용한다(HEAT/ATGM −25%p, APFSDS/APDS −12%p, HEP/HESH −32%p, HE 계열 −40%p). **빈 지점에 HEAT/ATGM −12.5%p, HEP/HESH −16%p, HE −20%p**, APFSDS/APDS 0%p. 주변 블록 탈락·연쇄 반응은 이미 해당 숫자에 포함.
- **HEP/HESH의 기존 CE/ERA 방호 판정 유지.** §1-A의 손실은 **K1/K5 피복 지점 −32/−40%p, 빈 지점 −16/−20%p**이며 주변 탈락·연쇄 반응이 포함된 수치라 추가 차감하지 않는다. BDD/D-Tech 내구도는 별도 미정.
- ERA는 **일회성 소모**. 이미 반응하여 상실된 면적은 재사용할 수 없음.
- **차체/포탑 후면에는 Kontakt-1 미장착(0%)**. 표의 후면 0%는 추정이나 미정이 아니라 확정된 게임 설정.
- HEP의 내부 박리·파편화가 유효 피해를 만들면 게임 결과에서는 **성공한 내부 피해/관통**으로 통합 처리. 물리적 메커니즘의 완전한 재현이라는 주장이 아님.

- **시작 피복률:** 차체 전면 85%, 차체 측면 45%, 포탑 전면 90%, 포탑 측면 40%. **K5 §1-A 최종 통합 손실:** 피복 지점 HEAT/ATGM −32%p, APFSDS/APDS −24%p, HEP/HESH −40%p, HE −52%p. 빈 지점은 HEAT/ATGM −16%p, HEP/HESH −20%p, HE −26%p, APFSDS/APDS 0%p. 주변 탈락·연쇄 반응 추가 차감 없음.

- **차체/포탑 후면:** Kontakt-5 **미장착으로 ERA 피복률 0% 확정**. 기본 방호력은 **차체 후면 40(40), 포탑 후면 70(70)**로 구분한다. 이는 사용자가 후면 ERA 수치를 적지 않은 이유를 직접 명확히 한 결정이다.
- Kontakt-5는 Kontakt-1보다 KE·CE 모두에 큰 추가 방호 효과가 있도록 설정. 현실의 확정 실측값이 아니라 게임상의 대표 방호 수치.
- 소련 본토 증원군/최정예 선봉대의 **소수 T-80U**라는 기존 전시 가정 유지.
- T-80U(1985/1989)의 기본 주력탄과 즉응·예비 구획별 프리셋은 [탄약 기준표](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/ammo/README.md) §7·11에 확정돼 있다. 차량 포인트와 각도별 상세 관통 판정은 미정이고 **ERA 소모는 §1-A 통합 규칙 확정**이다.

- T-80U (1989)는 기존 1985형 기본장갑·K5 피복률을 소폭 강화한 게임용 후기형. **1989년형 포탑 강화 정도나 피복률 상승은 역사적 실측 확정값이 아님**.
- 서방 기본 날탄과의 KE 관통 관계는 **2,000m/0° 게임 설계 기준**이다. 명중·도탄 세부 확률은 별도 검토하며 **ERA 피복/빈 지점 통합 소모는 §1-A 확정**이다.
- T-72A/B 및 T-80U 후기형 방호력·ERA 초기 피복률·기본탄·3종 프리셋의 발수는 확정([탄약 기준표](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/ammo/README.md) §11). 포인트·가용대수는 미정이며 **Kontakt 피복/빈 지점 통합 피복률 소모는 §1-A 확정**이다.
