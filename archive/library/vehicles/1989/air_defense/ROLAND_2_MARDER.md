# TACTICAL 1989 — 서독 Marder 기반 Roland 2 자주방공차량 정본

> **2026-11-21 사용자 채택 게임 설계.** 서독군 **마르더 계열 차체 + 방호가 얇은 전용 롤란드 발사대** 구성. **최대 525 HP**, **7구역 장갑 KE(CE) 35/25/20/10/5/5/5 mm RHAe**, **즉응 2발 + 차내 예비 8발 = 총 10발** 채택. 이 수치는 **실측 장갑/공식 방호 수치가 아닌 게임값**. **아카이브만 갱신, 실행 게임 코드 미구현**.

**미사일 고유 수치 정본:** [Roland 2/3 미사일](../../../ammunition/missiles/ROLAND_2_3_SAM.md). **기존 서독 차체 수치 참고:** [Marder 1A2/1A3](../ifv/MARDER_1A2_1A3.md). **공통 추적 시스템:** [공중 수색·정밀추적](../../../systems/air/RADAR_SEARCH_TRACKING.md).

## 1. 차량 방어력·HP — [사용자 채택]

**7구역 순서:** 차체 전면 / 차체 측면 / 차체 후면 / 발사대(포탑 대응) 전면 / 발사대 측면 / 발사대 후면 / 상부. KE(CE)는 게임용 mm RHAe.

| 구역 | Roland 2 차량 게임값 |
|---|---:|
| **차체 전면** | **35(35)** |
| **차체 측면** | **25(25)** |
| **차체 후면** | **20(20)** |
| **발사대 전면** | **10(10)** |
| **발사대 측면** | **5(5)** |
| **발사대 후면** | **5(5)** |
| **차체·발사대 통합 상부** | **5(5)** |
| **최대 HP** | **525** |

- 사용자 선택 구성은 **기존 Marder 1A2의 차체 전/측/후 35(35)/25(25)/20(20)**을 기준으로 유지하면서, 방공 발사대/상부 장갑은 가볍게 추상화한 것이다. 마르더 1A3의 추가 방호를 이 차량에 복사하지 않는다.
- **발사대가 얇다**는 것은 장갑 구역별 KE/CE 값으로 표현한다. 포탑 파괴 즉사·발사대 독립 HP 등 별도의 신규 피해 규칙을 자동 만들지 않는다.
- 게임 최대 HP **525**는 초기 제안 **530~550 후보를 폐기**하고 사용자가 지정한 값. 마르더 IFV 1A2의 550 HP와 구별.
- 발사대 외형 및 실제 역사적 개별 방호 두께·1989년 가용 수량은 별도 검증 대상. 본 수치가 실측치라는 주장은 아님.

## 2. 발사대·탑재 미사일 — [사용자 채택]

| 항목 | 설정 |
|---|---|
| 플랫폼 | **서독 Marder 차체 기반 Roland 2 방공차량** |
| 발사대 | **즉응 2발** |
| 차내 예비 | **8발** |
| **총 적재량** | **10발** |
| 미사일 성능 데이터 | **Roland 2 (기본 지급 권장), Roland 3 (개량형 후보)** |
| Roland 2 최대 사거리 | **6,300m** |
| Roland 3 최대 사거리 | **8,000m** |

- **2발 즉응 + 8발 예비**는 10발 일제사격을 뜻하지 않는다. 발사 간격, 자동 재장전 시간, 2발 발사 후 발사대 재보충, 혼합 적재/보급 규칙은 미정.
- **Roland 3 미사일의 1989년 6월 20일 실제 해당 부대 배치량 및 게임 지급 비율은 미정.** 성능 데이터 채택과 기본 지급 보장은 구분한다.
- Roland 2·Roland 3 미사일의 **개별 30/35 CE·직격 395/420 HP·근접 기본 155~295/180~325 HP**는 [미사일 문서](../../../ammunition/missiles/ROLAND_2_3_SAM.md)에서 관리하고 차량 정본에 중복 독립 소유하지 않는다.

## 3. 교전 방식 — [공통 로직 재활용 방향]

- **레이더 수색 → 레이더 또는 광학 수단으로 정밀 추적 → 무선 지령유도 미사일 발사 및 추적 유지**. 광학 추적은 **발사차량의 광학 장비**가 표적을 추적한다는 뜻이지 **미사일 자체 IR 탐색기**가 있다는 뜻이 아니다.
- [퉁구스카 9M311 시스템](../../../ammunition/missiles/9M311_SAM.md)의 **표적/미사일 위치 추적, 지속 무선 지령유도, 추적 및 LOS 상실, 직격과 별도 근접신관 확률 판정**이라는 공통 구조를 재활용한다.
- 단 **Roland 고유 레이더 근접신관, 비행/사거리/명중 성능**은 9M311에서 숫자를 복사하지 않는다. **IR 플레어·Lipa·AN/ALQ-144 대상 미사일도 아니다**(레이더/지령유도 교란 계통은 별도 설계).
- 수색레이더 최대거리, 추적레이더/광학 성능·범위, 기본 명중률, 거리/기동 감쇄, 추적 안정성·재획득·동시 목표 수와 교전 고도는 **아직 미정**. 공통 [탐지·추적 정본](../../../systems/air/RADAR_SEARCH_TRACKING.md) 규칙 우선.

## 4. 유지·미정

- 차량 실제 기동성, 최대 주행속도/급가속, 탐지/추적 확률표, 레이더 음영, 최소 사거리, 발사 가능 조건, 교전/재장전 AI, 미사일 비용 및 재보급은 별도 설계.
- **차량 525 HP·7구역 장갑·10발 탑재**와 **미사일 별도 성능**은 사용자 게임 채택값. **런타임 유닛/무장/미사일·유도/신관 로직은 구현하지 않았다.**
