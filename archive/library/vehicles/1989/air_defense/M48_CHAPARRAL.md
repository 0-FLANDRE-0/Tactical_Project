# TACTICAL 1989 — M48 Chaparral / M730 단거리 자주 지대공미사일 차량 정본

> **2026-11-21 사용자 확정 게임 설계.** **M48 채퍼럴**을 M730 계열 궤도식 발사 차량 + 4연장 M54 발사대로 모델링한다. 사용자 지정 **7구역 KE(CE) 5/0/0/5/5/5/0 mm RHAe**, **최대 285HP**, **즉응 4발 + 내부 예비 8발 = 총 12발**을 정본으로 채택한다. **게임 설계 아카이브만 반영, 코드 미구현**.

**미사일 고유 정본:** [MIM-72A/C/E/G](../../../ammunition/missiles/MIM72_A_C_E_G_CHAPARRAL.md). **공통 기만 판정:** [플레어 저항성·IRCCM](../../../systems/air/COUNTERMEASURES_FLARE_IRCCM_ECCM.md). **소련군 비교:** [9K35M2 스트렐라-10M2](STRELA_10M2.md).

## 1. 장갑 7구역 및 최대 HP — 사용자 확정

| 구역 | 게임 장갑 KE(CE), mm RHAe |
|---|---:|
| **차체 전면** | **5(5)** |
| **차체 측면** | **0(0)** |
| **차체 후면** | **0(0)** |
| **발사대 전면(게임 포탑 대응 구역)** | **5(5)** |
| **발사대 측면** | **5(5)** |
| **발사대 후면** | **5(5)** |
| **통합 상부** | **0(0)** |
| **차량 최대 HP** | **285HP** |

- **차량 7구역 값 배열 순서 = 차체 전면/측면/후면, 발사대 전면/측면/후면, 상부.** KE와 CE의 게임 방호량은 동일하게 설정한다. 수치 0은 해당 구역에 **게임상 장갑 방호 보너스가 없음**을 의미하며 HP가 0이라는 뜻은 아니다.
- 실차 참고: **M730은 M548 궤도식 수송차량을 바탕으로 한 채퍼럴 발사 차체**. M113 APC형 전면/측면 장갑을 자동 복사하지 않는다. **5/0/0/5/5/5/0 RHAe는 실측 판금 두께가 아닌 사용자 선택 게임 수치**.
- 같은 게임의 [9K35M2 스트렐라-10M2](STRELA_10M2.md)는 **325HP·15/10/5/5/5/5/5 KE(CE)**이므로 채퍼럴의 **285HP·5/0/0/5/5/5/0**과 구별한다.
- 측·후면과 상부의 방호력 0은 **실제 피격·관통/비관통·HP 피해 계산의 입력값**이다. 별도의 '모든 공격 즉사' 같은 규칙을 신설하지 않는다.

## 2. 미사일 탑재 — 사용자 확정

| 항목 | 채퍼럴 게임값 |
|---|---|
| 발사대 | **M54 4연장** |
| **즉응 미사일** | **4발** |
| **차량 예비 미사일** | **8발** |
| **총 탑재량** | **12발** |
| 적용 미사일 설계 | **MIM-72A, C, E, G** 각 형식별 게임 데이터 |

- **4발 즉응 + 8발 예비**이며, **12발을 한꺼번에 발사할 수 있는 12연장 발사대가 아니다**. 탄체 교체·재장전 시간, 예비탄 전개 방식, 한 발당 발사 간격·혼합 적재 제한/우선순위 등은 미정.
- **G형의 게임상 미사일 성능 자체는 사용자 확정**이지만, **1989년 6월 전장에 일반 보급할지/소수 초기 개량탄으로 취급할지 및 차량별 지급률은 미정**. 기본 장비로 무조건 배치한다고 기록하지 않는다.
- 미사일형별 차이는 [미사일 정본](../../../ammunition/missiles/MIM72_A_C_E_G_CHAPARRAL.md)에서 관리한다. 차량 HP/장갑을 미사일 형태에 따라 자동 변경하지 않는다.

## 3. 공통 교전/기만 규칙 — 게임 설계

- MIM-72 계열은 **발사 전 적외선 락온 → 발사 후 미사일 자체 추적**에 기초. **MIM-72A는 후방 락온 및 제한적 측면 락온**, **C/E/G는 전방위 락온**으로 게임 구분. **구체 허용각·탐색/추적 한계는 미정**.
- 기본 명중률은 무기동/약기동 상황의 기준 범위로 설정하고, 급기동 감쇄/거리·환경 결정식은 후속 설계. 실물 실측 명중률이 아니다.
- 플레어는 **유효 한 발당 독립 판정**하며 각 미사일의 플레어 저항성으로 별도 감쇄한다. **MIM-72A IRCCM 0단계(램프형 기만 감쇄 0%, Lipa/ALQ-144 최종 기만 90%)**, **C/E 1단계(각 감쇄 55%, ×0.45, 최종 기만 40.5%)**, **G 2단계(100% 감쇄, 최종 0%)**로 후속 확정. C와 E는 IRCCM 감쇄율이 같아도 **플레어 저항성은 C 55% / E 60%**로 다르며 저연 모터도 별도. 감쇄 전 90%, 1단계 일반 범위 40~60% 및 정확한 수치 소유권은 [미사일 정본](../../../ammunition/missiles/MIM72_A_C_E_G_CHAPARRAL.md) 참조.
- 미사일 형식별 **25 CE, 직격/근접폭발 기본 HP, 신관별 구체 특성**은 [미사일 정본](../../../ammunition/missiles/MIM72_A_C_E_G_CHAPARRAL.md) 참조.

## 4. 미정 및 역사/게임 경계

- 차량 속력·기동·급가속·엔진/연료·탐지·시계·사통·관측/표적 획득·유닛 비용·편제·혼합 적재/보급/재장전 시간·반복 발사 제약은 미정.
- 차체 종류/발사대 명칭과 실차 탄두 계보는 역사 참고자료이며 **차량 285HP·7구역 장갑·미사일 밸런스 수치와 동일한 의미가 아님**.
