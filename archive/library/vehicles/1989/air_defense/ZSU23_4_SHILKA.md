# TACTICAL 1989 — ZSU-23-4 Shilka / 23mm AZP-23 자주대공포 정본

> **2026-11-21 사용자 확정 게임값.** 차체·포탑 **7구역 KE(CE)**, **차량 최대 450HP**, **23mm 기관포 4문**, **API-T 55HP / HEFI-T 108HP**, 사용자 이미지 API 18노드 및 워썬더 HEFI-T 6거리 CE, **3 HE : 1 AP 단일 고정 탄띠**를 기록한다. **발사속도 문당 900RPM(총 3,600RPM)**, **대공 유효 2,500m/최대 3,000m(3D 경사거리)**도 후속 사용자 채택. **M163보다 불안정한 명중 특성·상대적으로 낮은 신뢰성**은 정성적 설계 방향. **탄약 문당 500발×4문=총 2,000발, 전량 즉응탄(준즉응탄 없음)**이 후속 사용자 확정. **차량 세부형, 레이더 거리·명중률 수치·고장률 및 외부 재보급 세부는 미정**. 실제 코드/유닛 데이터 아직 미구현. 과거 [자료 검토용 준비표](ZSU23_4_SHILKA_PREP.md)는 실물 참고를 위한 이력 문서이며 현재 확정값은 이 파일을 우선한다.

## 1. 장갑 및 내구도 — 사용자 채택

- **1989년 소련/바르샤바 조약군 ZSU-23-4 Shilka 계열**. 소련·동독 개별 편제/개량형(ZSU-23-4M 등) 선택은 미정.
- 기존 7구역 기준: **차체 전면 / 차체 측면 / 차체 후면 / 포탑 전면 / 포탑 측면 / 포탑 후면 / 통합 상부**. 값은 **게임용 mm RHAe, KE(CE)**. 실물 판재 두께나 실측 관통 방어성능과 혼동 금지.

| 구역 | KE(CE), mm |
|---|---:|
| ① 차체 전면 | **20(20)** |
| ② 차체 측면 | **15(15)** |
| ③ 차체 후면 | **10(10)** |
| ④ 포탑 전면 | **15(15)** |
| ⑤ 포탑 측면 | **15(15)** |
| ⑥ 포탑 후면 | **10(10)** |
| ⑦ 통합 상부 | **15(15)** |

**차량 최대 450 HP** — 사용자 채택 게임값. M163 400HP보다 높고, 게파르트 650HP보다 낮음. 7구역은 지상장갑 입사각/명중 공통 규칙을 적용하고, 차량에 임의 ERA·APS를 추가하지 않는다.

## 2. 무장·탄종·탄띠 — 사용자 채택

| 항목 | 게임값 / 상태 |
|---|---|
| 기관포 | **23mm AZP-23 계열 4문 (2A7 계열)** |
| 철갑 | **API-T/BZT 계열 / 970m/s / 기본 55HP** |
| 고폭 | **HEFI-T/OFZT 계열 / 970m/s / 기본 108HP** |
| 탄띠 | **HEFI-T → HEFI-T → HEFI-T → API-T**, 고정 반복 **3:1** |
| 탄띠 선택 | **없음**. 다른 프리셋/전환 없음 |
| API 관통 | **6거리 × 0°/30°/60° 총 18개 KE** = 사용자 제공 이미지 |
| HE 파공 | **6거리 CE** = 워썬더 HEFI-T; 6/6/4/3/2/2mm |
| 공중 직격 | 입사각 무시/거리별 0° KE·CE; 비관통 모든 탄종 기본 피해 **25% 하한**, AP 관통 후 과관통도 25% 하한 |
| 개별 공중 최소 피해 | **API-T 13.75HP / HEFI-T 27HP** (각각 해당 분기에서만) |

- **탄약 정본:** [M163·쉴카 20/23mm 기관포 제원·관통력/피해표](../../../ammunition/autocannon/M163_SHILKA_AA_20_23MM.md). 원본 숫자를 본 차량 문서에서 변경하지 않으며 모든 18개 API KE·6개 HE CE 값은 그 문서가 우선.
- **고정 탄띠 소유:** [1989 AA 고정 탄띠 정본](../../../presets/1989/AA_FIXED_BELTS_M163_SHILKA.md). 여러 개의 실제 총열에 혼합 순서를 어떻게 배분할지는 미정.
- **고폭 피해곡선:** 기존 [DM21 기준 지상 급감/공중 완만 감쇄 구조](../../../systems/combat/IFV_HE_DAMAGE_CURVES.md)를 참고하되, **쉴카 자체 108HP/거리별 CE를 유지**하고 정확한 공중 CE20·CE25 피해값·매핑·보간은 아직 정하지 않는다. 대공 관통 실패라도 실제 **직격**이면 최소 27HP; 미명중은 피해 없음.
- **2026-11-21 사용자 최신 확정 — 게임 발사속도:** **기관포 1문당 900RPM ×4문 = 합계 3,600RPM**, 지속 발사 시 **초당 60발**. 3:1 고정 탄띠를 시간당 비율로 환산하면 **이론상 HE 초당 45발 / API 초당 15발**(명중률·점사 중단·탄약 공급을 무시한 환산). 실제 참고치 약 3,200~4,000RPM과는 구분하며 **게임값은 3,600RPM이 우선**. 별도 고/저속 발사 모드, 점사/연속 사격 허용시간·과열·탄 공급·고장으로 인한 중단 정책은 **미정**.
- **2026-11-21 후속 사용자 확정 — 게임 적재량:** **기관포 1문당 500발 ×4문 = 총 2,000발**. **2,000발 모두 즉응탄(100%)**, **준즉응탄 없음**, 별도 예비 구획에서 내부 보충하는 방식은 적용하지 않는다. 각 포는 자기 **500발 탄약**을 소모하며 각 포에서 기존 **3 HEFI-T:1 API-T 고정 순서**를 유지한다. **문당 HEFI-T 375발 + API-T 125발**, 전체 **HEFI-T 1,500발 + API-T 500발**. 4문 모두 900RPM 연속 사격 시 문당 500/15=**약 33.3초**(차량 전체 총 2,000/60=약 33.3초)분의 순수 연속 사격량; AI 점사/급탄 정지/과열·고장 등으로 실제 지속시간은 달라진다. **외부 재보급, 재장전 소요시간, 4개 총열 간 사격 시차·시작 위상은 미정**. 실제 2,000발 참고치와 일치하지만 이 수치는 **사용자 선택 게임값**이다.

## 3. 교전거리 확정 / 탐지·추적·명중·신뢰성 세부 미정

- **2026-11-21 사용자 최신 확정:** 대공 **유효 교전거리 2,500m / 최대 교전거리 3,000m**. **3차원 경사거리**로 판정. 유효거리 이후 **2,500~3,000m 구간도 사격 허용**, 명중률·사통 조건 악화 가능하며 **3,000m 초과 사격 불가**. 2.5km 유효거리 자체가 100% 명중 보장이라는 뜻은 아니다. **대지 표적 교전거리/고각·부각은 미정**.
- **2026-11-21 후속 사용자 확정 — 2km 이후 탄약 관통력 처리:** API-T 0°/30°/60° KE·HEFI-T CE 원본표 **2,000m까지 수치 보존**. **2~3km는 개별 탄종의 0~2km 관통 감쇄 추세를 연장하고 먼 거리에서 가속 감쇄**하는 [모든 탄약 공통 거리 감쇄 설계](../../../systems/combat/RANGE_PENETRATION_EXTRAPOLATION.md)를 따른다. **2~3km를 위해 신규 관통력표가 필수인 것은 아님**. 감쇄 가속식·세부 계수만 미정.
- **RPK-2 Tobol / 1RL33 / NATO Gun Dish** 단일 레이더 체계의 수색·추적/사통 운용과 광학 수단. **게파르트처럼 별도 수색·추적 안테나 구성으로 혼동 금지**. 구형 및 23-4M 개량형의 독립 검색 모드 차이는 실물 참고 [준비표](ZSU23_4_SHILKA_PREP.md) 확인.
- **수색은 표적 존재의 확률적 발견**, 추적레이더/광학의 LOS·추적 성공 후 정밀 표적 정보를 얻는다. 탐지 성공을 자동 명중률로 취급하지 않는다. [공중 레이더 정본](../../../systems/air/RADAR_SEARCH_TRACKING.md).
- **명중/사격 안정성 — 사용자 채택 정성 방향:** **M163의 근거리 광학 추적 기반 안정성과 비교해 쉴카는 더 불안정한 명중률**. 점사 내 조준/탄착군의 흔들림·장시간 연속 사격 산포 증가, 표적 급기동 시 추적 오차에 더 민감하게 설계한다는 **후속 세부 검토 방향**이며 **발당 명중률 수치/산포 배율은 미정**. 실제 M163보다 *모든 거리·조건에서 절대적으로 낮은 명중률*을 숫자로 확정한 것은 아니다.
- **신뢰성 — 사용자 채택 정성 방향:** **M163보다 상대적으로 낮은 신뢰성**을 가진 무장·사격체계로 구분한다. 연속 사격 중 일시 중단·재조준/추적 불안정·급탄/기계적 이상 등은 **가능한 모델링 후보**이고, **어떤 현상을 구현할지·발생확률·수리/복구 시간·탄약 손실은 미정**. 추적 오차와 기계 고장률은 별도 변수로 취급하며 **이것만으로 포탄의 기본 피해나 KE/CE를 줄이지 않는다**.
- **수색/추적 최대거리·탐지확률 곡선·추적 시간·명중률 정량·회피기동 보정, 발사 AI의 점사/휴지·과열/탄착군 산포, 구체 신뢰성·고장률은 미정**. [게파르트/M163 잠정 비교](../../../systems/air/AA_GUN_HIT_PROBABILITY.md)는 쉴카에 숫자를 자동 상속하지 않는다.

## 4. 헬기 상대 피해판정 경계

- [AH-64A](../air/AH64A.md) **325HP / KE(CE) 20(20)**, [Mi-24D/V/P](../air/MI24_D_V_P.md) **400HP / KE(CE) 25(25)**. 두 기체 모두 7구역 입사각 계산 없이 거리별 **0° KE/CE** 값과 비교한다.
- **쉴카 HEFI-T 최대 CE 6mm는 기체 CE20/25보다 낮음.** 따라서 공중 고폭탄 직격은 두 기체 모두 **비파공 외부 폭발 피해곡선**을 사용한다. 이때 실제 공중 비관통 최소 **27HP**; **108HP를 비파공 때마다 무조건 전량 적용하는 것은 아님**.
- **쉴카 API-T는 500m 0° KE36, 1000m KE26, 1500m KE18**. **500m와 1000m에서는 두 헬기 모두 KE 방호를 수직 기준으로 넘어설 수 있고**, 1500m에서는 둘 다 관통 불가. 다만 **정상 관통인지 과관통인지, 실제 HP 결과**는 AP 피해 정책에 따름.
- 기체가 이 23mm 기관포에 피격되기 이전에 **정말 탐지·추적·명중하는지**, 실제 거리·고도·기동/급강하·엄폐·탄약·사격AI가 **피탄 수와 시간**을 좌우하므로 단순 발사속도만으로 격추시간을 보증하지 않는다.

## 5. 별도 미정·설계 코드 경계

- 구형/M/V1 등 1989 세부형, 소련·동독의 실제 지급/편제, 광학/레이더 사통 상태 차이.
- **RPM 900×4=3,600 및 문당 즉응탄 500발×4=총 2,000발(HE 1,500/AP 500) 확정**. **준즉응탄 없음**. 4문 개별 사격 시작 위상·급탄 중단, 외부 재보급·재장전 시간, 점사·기동 중 사격·사통, **명중률/산포 수치·신뢰성 고장률/복구 시간은 미정**.
- **대공 유효 2.5km/최대 3km 확정**. 대지 사거리, 전차/장갑차/보병 대상 사격 허용 조건, **2~3km KE/CE 공통 외삽 방향은 확정, 상세 수식·계수**, 탄종별 폭발 CE 피해 매핑, 고도/표적 기동 보정은 미정.
- **고정 게임 제원만 아카이브에 기록.** 실행 게임·기존 전차96개 프리셋·게파르트·IFV 탄약/장갑은 바꾸지 않음.
