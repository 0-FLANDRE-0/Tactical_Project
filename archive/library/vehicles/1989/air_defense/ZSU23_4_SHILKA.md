# TACTICAL 1989 — ZSU-23-4 Shilka / 23mm AZP-23 자주대공포 정본

> **2026-11-21 사용자 확정 게임값.** 차체·포탑 **7구역 KE(CE)**, **차량 최대 450HP**, **23mm 기관포 4문**, **API-T 55HP / HEFI-T 108HP**, 사용자 이미지 API 18노드 및 워썬더 HEFI-T 6거리 CE, **3 HE : 1 AP 단일 고정 탄띠**를 기록한다. **차량 세부형, RPM/게임 적재량/대공 사거리, 레이더 거리·명중률은 미정**. 실제 코드/유닛 데이터 아직 미구현. 과거 [자료 검토용 준비표](ZSU23_4_SHILKA_PREP.md)는 실물 참고를 위한 이력 문서이며 현재 확정값은 이 파일을 우선한다.

## 1. 장갑 및 내구도 — 사용자 채택

- **1989년 소련/바르샤바 조약군 ZSU-23-4 Shilka 계열**. 소련·동독 개별 편제/개량형(ZSU-23-4M 등) 선택은 미정.
- 기존 7구역 기준: **차체 전면 / 차체 측면 / 차체 후면 / 포탑 전면 / 포탑 측면 / 포탑 후면 / 통합 상부**. 값은 **게임용 mm RHAe, KE(CE)**. 실물 판재 두께나 실측 관통 방어성능과 혼동 금지.

| 구역 | KE(CE), mm |
|---|---:|
| ① 차체 전면 | **20(20)** |
| ② 차체 측면 | **15(15)** |
| ③ 차체 후면 | **10(10)** |
| ④ 포탑 전면 | **15(15)** |
| ⑤ 포탑 측면 | **15(15)** |
| ⑥ 포탑 후면 | **10(10)** |
| ⑦ 통합 상부 | **15(15)** |

**차량 최대 450 HP** — 사용자 채택 게임값. M163 400HP보다 높고, 게파르트 650HP보다 낮음. 7구역은 지상장갑 입사각/명중 공통 규칙을 적용하고, 차량에 임의 ERA·APS를 추가하지 않는다.

## 2. 무장·탄종·탄띠 — 사용자 채택

| 항목 | 게임값 / 상태 |
|---|---|
| 기관포 | **23mm AZP-23 계열 4문 (2A7 계열)** |
| 철갑 | **API-T/BZT 계열 / 970m/s / 기본 55HP** |
| 고폭 | **HEFI-T/OFZT 계열 / 970m/s / 기본 108HP** |
| 탄띠 | **HEFI-T → HEFI-T → HEFI-T → API-T**, 고정 반복 **3:1** |
| 탄띠 선택 | **없음**. 다른 프리셋/전환 없음 |
| API 관통 | **6거리 × 0°/30°/60° 총 18개 KE** = 사용자 제공 이미지 |
| HE 파공 | **6거리 CE** = 워썬더 HEFI-T; 6/6/4/3/2/2mm |
| 공중 직격 | 입사각 무시/거리별 0° KE·CE; 비관통 모든 탄종 기본 피해 **25% 하한**, AP 관통 후 과관통도 25% 하한 |
| 개별 공중 최소 피해 | **API-T 13.75HP / HEFI-T 27HP** (각각 해당 분기에서만) |

- **탄약 정본:** [M163·쉴카 20/23mm 기관포 제원·관통력/피해표](../../../ammunition/autocannon/M163_SHILKA_AA_20_23MM.md). 원본 숫자를 본 차량 문서에서 변경하지 않으며 모든 18개 API KE·6개 HE CE 값은 그 문서가 우선.
- **고정 탄띠 소유:** [1989 AA 고정 탄띠 정본](../../../presets/1989/AA_FIXED_BELTS_M163_SHILKA.md). 여러 개의 실제 총열에 혼합 순서를 어떻게 배분할지는 미정.
- **고폭 피해곡선:** 기존 [DM21 기준 지상 급감/공중 완만 감쇄 구조](../../../systems/combat/IFV_HE_DAMAGE_CURVES.md)를 참고하되, **쉴카 자체 108HP/거리별 CE를 유지**하고 정확한 공중 CE20·CE25 피해값·매핑·보간은 아직 정하지 않는다. 대공 관통 실패라도 실제 **직격**이면 최소 27HP; 미명중은 피해 없음.
- **게임 발사속도:** **미정**. 실제 참고치 약 **3,200~4,000RPM**, 자료에 따라 약 **3,400RPM**. 실제 값 중 하나를 게임으로 자동 확정하지 않는다.
- **게임 적재량:** **미정**. 실제 참고 약 **2,000발**이며 4문 급탄/즉응·준즉응 구획/재장전 시간도 미정.

## 3. 교전거리·탐지/추적·명중률 — 미정

- **대공 유효/최대 교전거리 게임값 미정**, 공통 룰상 채택되면 **3차원 경사거리**로 판정. 실제 자료는 유효 약 2.5km, 최대 경사 약 3km가 흔하나 채택 전까지 사격 한도를 단정하지 않는다.
- **RPK-2 Tobol / 1RL33 / NATO Gun Dish** 단일 레이더 체계의 수색·추적/사통 운용과 광학 수단. **게파르트처럼 별도 수색·추적 안테나 구성으로 혼동 금지**. 구형 및 23-4M 개량형의 독립 검색 모드 차이는 실물 참고 [준비표](ZSU23_4_SHILKA_PREP.md) 확인.
- **수색은 표적 존재의 확률적 발견**, 추적레이더/광학의 LOS·추적 성공 후 정밀 표적 정보를 얻는다. 탐지 성공을 자동 명중률로 취급하지 않는다. [공중 레이더 정본](../../../systems/air/RADAR_SEARCH_TRACKING.md).
- **수색/추적 최대거리·탐지확률 곡선·추적 시간·명중률·회피기동 보정, 발사 AI의 점사/휴지·과열/탄착군 산포 모두 미정**. [게파르트/M163 잠정 비교](../../../systems/air/AA_GUN_HIT_PROBABILITY.md)는 쉴카에 숫자를 자동 상속하지 않는다.

## 4. 헬기 상대 피해판정 경계

- [AH-64A](../air/AH64A.md) **325HP / KE(CE) 20(20)**, [Mi-24D/V/P](../air/MI24_D_V_P.md) **400HP / KE(CE) 25(25)**. 두 기체 모두 7구역 입사각 계산 없이 거리별 **0° KE/CE** 값과 비교한다.
- **쉴카 HEFI-T 최대 CE 6mm는 기체 CE20/25보다 낮음.** 따라서 공중 고폭탄 직격은 두 기체 모두 **비파공 외부 폭발 피해곡선**을 사용한다. 이때 실제 공중 비관통 최소 **27HP**; **108HP를 비파공 때마다 무조건 전량 적용하는 것은 아님**.
- **쉴카 API-T는 500m 0° KE36, 1000m KE26, 1500m KE18**. **500m와 1000m에서는 두 헬기 모두 KE 방호를 수직 기준으로 넘어설 수 있고**, 1500m에서는 둘 다 관통 불가. 다만 **정상 관통인지 과관통인지, 실제 HP 결과**는 AP 피해 정책에 따름.
- 기체가 이 23mm 기관포에 피격되기 이전에 **정말 탐지·추적·명중하는지**, 실제 거리·고도·기동/급강하·엄폐·탄약·사격AI가 **피탄 수와 시간**을 좌우하므로 단순 발사속도만으로 격추시간을 보증하지 않는다.

## 5. 별도 미정·설계 코드 경계

- 구형/M/V1 등 1989 세부형, 소련·동독의 실제 지급/편제, 광학/레이더 사통 상태 차이.
- 기관포 RPM, 4개 총열 급탄 위상·급탄량·적재량, 점사·재장전·기동 중 사격·사통, 명중률.
- 게임 유효/최대 대공/대지 사거리, 전차/장갑차/보병 대상 사격 허용 조건, 탄종별 폭발 CE 피해 매핑, 고도/표적 기동 보정.
- **고정 게임 제원만 아카이브에 기록.** 실행 게임·기존 전차96개 프리셋·게파르트·IFV 탄약/장갑은 바꾸지 않음.
