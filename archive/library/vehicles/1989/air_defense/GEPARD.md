# TACTICAL 1989 — 서독 Flakpanzer Gepard / 35mm KDA 자주대공포 설계 정본

> **2026-11-21 사용자 최신 결정 복원·기록.** 1989년 서독 게파르트의 7구역 방호력, 차량 HP, 기관포 2문, 사거리, 탄띠 프리셋을 관리한다. **탄종의 관통력·피해·신관은 [35mm 탄약 정본](../../../ammunition/autocannon/GEPARD_35MM.md), 탄띠 배열·적재는 [게파르트 전용 프리셋](../../../presets/1989/GEPARD_BELTS.md)이 우선**한다. 본 문서 등록은 실제 코드 구현이 아니다.

## 1. 차량 장갑과 HP — 사용자 확정

- 진영·시대·역할: **1989년 서독 연방군 자주대공포**, 공중 표적 우선·지상 표적 제한 공격.
- 게임용 장갑 단위 **mm RHAe, KE(CE)**. 공통 7구역 순서: **차체 전면 / 차체 측면 / 차체 후면 / 포탑 전면 / 포탑 측면 / 포탑 후면 / 통합 상부**.
- 각 구역은 실제 방호 시험치가 아닌 게임용 대표 방호력이며, 이미 반영된 장갑 경사 효과를 별도의 LOS 배율로 중복 계산하지 않는다.

| 구역 | KE(CE), mm |
|---|---:|
| ① 차체 전면 | **135(135)** |
| ② 차체 측면 | **35(35)** |
| ③ 차체 후면 | **25(25)** |
| ④ 포탑 전면 | **35(35)** |
| ⑤ 포탑 측면 | **30(30)** |
| ⑥ 포탑 후면 | **25(25)** |
| ⑦ 통합 상부 | **30(30)** |

**차량 최대 HP: 650 HP — 사용자 확정.** 7구역 선정·입사각·기본 방호체계는 [공통 시스템](../../../systems/armor/SEVEN_ZONE_AND_KONTAKT_ERA.md)을 따르며, 이 차량에 별도 ERA/APS를 자동 장착하지 않는다.

## 2. 무장 및 교전거리 — 사용자 확정

| 항목 | 값 |
|---|---|
| 주무장 | **35mm KDA 기관포 2문** |
| 발사속도 | **문당 550 RPM, 합계 1,100 RPM** |
| 유효 교전거리 | **3,500m (3.5km)** |
| 최대 교전거리 | **4,000m (4.0km)** |
| 최대거리 초과 | **사격 불가** |
| 대공 거리 판정 | **3차원 경사거리** (무장~공중 표적 직선거리) |
| 3.5~4.0km | 사격 허용, 명중률·사통 효율 감소 방향. **감쇄계수 미정** |
| 장전/적재 | **혼합 주급탄 640발 + 별도 DM23 40발 = 총 680발** |

- **2026-11-21 공중장비 각도 판정 생략:** 헬기·고정익 등 공중 표적에 대해서는 **입사각 계산·각도 관통력 감쇄·입사각 도탄 판정 없이** 탄약의 거리별 **0° KE/CE 값**으로 기체 단일 방호력을 판정한다. **3D 대공 경사거리·추적/조준/산포·비행시간은 유지**. [공중 각도 공통 정본](../../../systems/combat/ANGLE_RICOCHET_FUZE.md).
- **2026-11-21 후속 확정:** 게파르트 **MPDR 12 수색레이더 최대 탐지거리 15,000m(15km)**. **거리 증가·최대거리 접근 시 탐지확률 감소**, **레이더 LOS 지형 음영에 완전 차폐되면 탐지 불가**. 기체별 기종·고도·속도 등에 따른 피탐지 기반값과 관측자별 성능·거리·위치 보정을 조합해 **표적의 존재를 확률적으로 발견**한다. **정확한 확률 수치/탐색 갱신 주기 미정**.
- **수색레이더가 감지한 존재만으로 정확한 표적 좌표·고도·속도/사격해를 얻지 않는다.** **추적레이더 또는 광학**이 별도 LOS를 확보하고 추적에 성공한 뒤 정밀 정보 획득. **명중률은 추적 장비 종류·성능·추적 안정성·사격통제 성능 등에 따름**. **추적레이더의 거리·추적시간·오차 및 전자전 대응은 미정**. [공중 수색·추적 공통 정본](../../../systems/air/RADAR_SEARCH_TRACKING.md).
- **15km는 수색 최대거리, 3.5/4.0km는 기관포 대공 유효/최대거리**로 별도 유지한다. 탐지거리와 추적거리/교전거리를 자동 동일하게 만들지 않는다.
- **2026-11-21 후속 채택 — 대공 발당 명중률 시험 범위:** 정상적인 추적레이더 추적 상태의 **일반적인 이동 헬기** 상대, 3D 경사거리 **500m 25~35% / 1km 20~25% / 2km 10~15% / 3km 5~8% / 3.5km 3~5% / 4km 1~2%**. **실측값·본편 확정 계수가 아닌 추후 구현 및 테스트용 잠정 표**다. 수색레이더 탐지확률·점사 전체 격추 확률과 혼동 금지. 광학/급기동·사통 오차 보정, 발당 산포·구간 보간 등은 미정. [게파르트/M163 명중률 잠정 정본](../../../systems/air/AA_GUN_HIT_PROBABILITY.md).
- 지상 표적 교전거리 상한, 사격 가능한 고각/부각, 이동 간 사격 성능 및 실제 AI 명중률·산포·점사 길이·발사/중단 주기는 **별도 미정**이다. 위 3.5/4.0km는 확정된 **대공** 교전거리다.
- 공중 레이더 LOS·맵 밖 공역/항공 투입은 [항공 공통 설계](../../../systems/air/AIR_ENTRY_RADAR_AA.md)를 따른다.

## 3. 35mm 탄종 및 급탄 운용

| 탄종 | 유형 | 포구초속 | 기본 HP 피해 | 용도 |
|---|---|---:|---:|---|
| **DM21 HEI** | 폭발성 고폭소이 | **1,175m/s** | **172 HP** | 대공/비장갑, 지상·공중 피해곡선 분리 |
| **DM13A1 SAPHEI-T** | 반철갑·관통 후 폭발 | **1,175m/s** | **152 HP** | 범용, 정상 기폭 시 일반 과관통 감쇄 없음 |
| **DM23 APDS-T** | 비폭발성 순수 철갑 | **1,385m/s** | **96 HP** | 장갑 관통 특화, 기관포 전용 과관통 감쇄 |

- [35mm 탄약 정본](../../../ammunition/autocannon/GEPARD_35MM.md)에 DM13A1/DM23 각각 **6거리×3각도 KE 관통력**과 DM21 지상/공중 CE 피해곡선을 보존한다.
- **대공형 주급탄:** DM21 → DM21 → DM21 → DM13A1 반복 (DM21 480 / DM13A1 160).
- **범용형 주급탄:** DM13A1 → DM13A1 → DM13A1 → DM21 반복 (DM13A1 480 / DM21 160).
- 각 프리셋 주급탄 **640발**, 별도 **DM23 40발**. 이 배열은 단순 적재 비율이 아니라 **실제 반복 탄띠 순서**다. 두 기관포 각각의 벨트 동기화/전환 방식·급탄 지연은 미정.
- 기존 전차 **32종×3=96개 프리셋 JSON은 수정하지 않음**.

## 4. 공통 피해 규칙과 구분

- **DM21:** CE 11mm 이하 직접 파공 172 HP; 지상 CE 13/15/20/25mm 노드 16/8/2/0 HP (25mm 이상 0). **공중에는 별도의 높은 폭발 피해곡선**을 사용한다.
- **DM13A1:** KE 관통 후 신관 정상 작동 시 152 HP. **순수 철갑탄의 과관통 배율 감쇄를 적용하지 않음**. 다만 극심한 과관통에서 **신관 불발 가능성**이 있으며 불발 판정 기준·확률·피해는 미정. 지상 비관통이면 CE 방호력에 따라 감소하는 **외부 고폭 피해**, 공중 비관통 기본안 102 HP (세부 신관 작동 조건 미정).
- **DM23:** 비폭발 APDS-T이므로 기관포 [과관통 피해 정책](../../../systems/combat/AUTOCANNON_DAMAGE.md) 적용. 세부 곡선·하한 미정.
- **2026-11-21 사용자 최신 공통 확정:** **공중장비 전부에 대한 모든 탄종의 실제 비관통 직격 최소 기본 피해 25%**, **AP계열 관통 후 과관통 감쇄 피해에도 최소 25%**를 [공중 표적 공통 피해 정본](../../../systems/combat/AIR_TARGET_DAMAGE.md)에 따라 적용. **DM21 최소 43 HP, DM13A1 최소 38 HP, DM23 최소 24 HP** (각각 공중 비관통; **DM23의 AP 과관통 결과도 최소 24 HP**). 지상 표적에는 공중 25% 하한 없음. 도탄·신관 불발은 별도.
- **HEP/HESH의 스폴 438 HP와 직접 파공 556 HP 등은 이 35mm 탄약에 상속하지 않는다**. [HEP/HE-FRAG 분기 정본](../../../systems/combat/HEP_HEFRAG_APERS.md) 참조.

## 5. 미정·구현 경계

- DM13A1 지상 비관통 **정확한 개별 피해 기준점**(DM21과 유사한 CE 감쇠 방향 확정, 수치 확정은 아직 없음), 신관 불발 임계·확률·불발 피해.
- DM23 과관통 실수 배율 곡선·하한, 35mm KE 관통력표의 **2km 이후~4km 처리**.
- DM21 공중 11~15mm 및 기타 노드 사이 보간/특수 충돌 조건, HP 소수점 처리·기폭/파편/모듈 연계.
- **수색 15km 확정**, **공중 발당 명중률 거리별 잠정 범위 기록(실제 테스트 미검증)**. 탐지확률 수치·탐색 주기·추적레이더 거리/정확도·명중 보정계수·사통·발사 AI 및 탄띠/별도 급탄 전환시간, 기동, 비용/편제, 지상 사거리는 미정.
- **설계 아카이브 정본으로 기록. 게임 코드, 기존 M163 제원, HEP/HESH 정본, 전차 96개 프리셋은 변경하지 않음.**
