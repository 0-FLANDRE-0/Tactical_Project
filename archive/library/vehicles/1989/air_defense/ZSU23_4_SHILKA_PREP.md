# TACTICAL 1989 — ZSU-23-4 쉴카 설계 준비표 [자료 검토 / 게임값 미확정]

> **최신 정본 안내(2026-11-21):** 이 파일은 설계 **준비 당시의 기록**이다. 사용자가 이후 **쉴카 7구역 20(20)/15(15)/10(10)/15(15)/15(15)/10(10)/15(15), 450HP, API-T 55HP, HEFI-T 108HP, 3 HE:1 AP 고정 탄띠, 사용자 이미지 API 18개 KE 및 워썬더 HE 6개 CE값**을 채택했다. **현재 정본은 [ZSU23_4_SHILKA.md](ZSU23_4_SHILKA.md)**이며 본문 '전부 미정'은 **당시의 기록**으로만 읽는다. **RPM·적재량·사거리·레이더 상세·명중률은 여전히 미정**.

> **2026-11-21 사용자 요청으로 다음 차량 설계 준비.** 여기의 실물 제원은 **참고용**이고, 본문에서 **게임 확정값으로 별도 채택한 수치는 없다**. 1989년 전장에 넣을 형식(M/V1/M 등)을 확인한 뒤 차량 7구역·HP·23mm 탄약·탐지/추적·연사 AI·적재·사거리 등을 게파르트/M163 정본과 같은 방식으로 사용자와 개별 확정한다. **이 파일 생성은 쉴카 게임 데이터를 새로 구현·완성했다는 뜻이 아니다.**

## 2. 레이더 운용에 관한 중요한 형식별 차이

- 게파르트의 **별도 수색/추적 레이더 구성**을 그대로 쉴카의 하드웨어에 복제하지 않는다. 쉴카의 **Gun Dish 단일 레이더 체계가 수색/표적획득·추적·거리측정·사격통제를 지원**하며, **수색 상태와 추적 상태는 게임 논리상 여전히 독립**이다.
- **ZSU-23-4M 계열에서는 Gun Dish가 독립 수색 모드로 사용 가능**했다고 기술한 역사 자료가 있다. **이전 형식은 포신에 연동된 상태였음**을 함께 기록한다. 1989 게임에서 어떤 형식을 기본으로 쓸지 정하지 않고 **모든 형식에 개량형 검색 기능을 자동 부여하지 않는다**.
- 레이더 최대 탐지거리 20km 같은 실물 참고값을 **정해진 게임값으로 선언하지 않음**. 신뢰 가능한 정식 게임 스케일을 유지하되 지형 LOS 음영/거리별 탐지율 감소/표적별 피탐지 계수/정밀 추적 성공 조건은 [공통 정본](../../../systems/air/RADAR_SEARCH_TRACKING.md)으로 상속한다.
- **수색=무언가 있다는 것만 앎, 정밀추적=LOS·추적 성공 후 사격해 취득**, 광학 별도 추적 가능. **기관포 명중률은 아직 사용자 승인된 범위 없음**; [게파르트·M163 시험 명중률](../../../systems/air/AA_GUN_HIT_PROBABILITY.md)은 비교표일 뿐 쉴카에 그대로 복사하지 않는다.

## 3. 다음 쉴카 설계 순서 — 미정 항목 체크리스트

1. **1989 채택형:** 소련·동독 편제별 ZSU-23-4 세부형을 어떻게 구성할지, M 계열과 구형의 레이더 운용 차이를 적용할지.
2. **차량:** 7구역 차체·포탑·통합 상부 **KE(CE)**, 차량 **HP**, 사수/포탑 방호와 이동 성능.
3. **23mm 화력:** 실제 구경 탄종명 대조, **AP/HE 계열 개별 탄속·거리별 KE·기본 HP 피해**, 공중 직격 25% 하한, 고폭 **DM21형 지상/공중 곡선의 적용범위**와 탄띠 실제 순서.
4. **대공거리:** 무장 유효/최대 **3D 경사거리**, 지상 표적 교전상한, 발사 가능한 고각.
5. **레이더·광학:** 실물형식 기반 수색/추적 가능한 모드·거리·LOS/고도·속도에 따른 탐지 확률·정밀추적·광학 예비, 추적까지 걸리는 시간/상실.
6. **사격 AI:** 발사속도 모드·점사 길이·탄착군 오차/발당 명중률·탄약 예산·즉응/재보급.
7. **코드/시험:** 모든 데이터 확정 후 구현. 기존 전차/게파르트/M163 및 공통 레이더 정본 무단 변경 금지.
