# TACTICAL 1989 — 미국 M163 VADS / 20mm M168 대공자주포 정본

> **2026-11-20 사용자 확정 게임 설계값.** 1989년 미국 방공차량 M163의 차체 재사용, M168의 **기존 AP-I 38HP + 신규 HEI-T 68HP** 및 **HE×3:AP×1 단일 고정 탄띠**, 관통력·탄속·사거리·발사 AI·적재를 기록한다. 게임 코드와 실행 빌드에는 아직 미구현. 레이더의 실물 종류와 게임상 확정 수치를 구별한다.

## 1. 차체 및 분류 — 기본값 확정

- **진영·역할:** 1989년 미국 육군 **M163 VADS** — 단거리 자주대공포, 경장갑 지상 목표 공격 가능.
- **재활용 차체:** [M113A2 기존 확정 게임 정본](../apc/APC_BASE_AND_MACHINEGUNS.md)의 차체 장갑·차량 HP 재사용. M113 계열 개조차체를 게임에서 별도 장갑값으로 재산정하지 않는다.
- **차체 전면:** **25(25)** / **차체 측면:** **20(20)** / **차체 후면:** **15(15)** / **통합 상부:** **10(10)** mm RHAe, KE(CE).
- **차량 최대 HP:** **400 HP** (M113A2 게임값 그대로).
- **대공포탑:** M113A2의 '포탑 없음(N/A)'을 M163에 복사하지 않는다. M168을 탑재한 **개방형 대공포탑 및 사수 노출**은 독립 모델링 대상. 포탑 전·측·후 KE(CE), 사수 피해·방호 수치는 **미정**이며 0으로 임의 확정하지 않는다.
- **기동:** M113A2 기반 동력/기동 특성을 참고하되 기종별 확정 게임 속도·가속·감속·수륙 특성은 별도 미정. 정식 차량 세부형(M163A1/M163A2, PIVADS 장착상태) 및 1989년 시나리오 지급 여부는 편성 단계에서 구분한다.

## 2. 주포 및 사거리 — 사용자 확정

| 항목 | 게임 확정값 |
|---|---|
| 기관포 | **20mm M168 Vulcan**, 6총열 회전식 |
| 기본 운용탄 | **20mm HEI-T 고폭소이예광탄 + 기존 AP-I 철갑소이탄** 두 탄종, **고정 HE→HE→HE→AP 반복**, **탄띠 교체·선택 없음** |
| 포구초속 | **1,030 m/s** |
| 발당 기본 차량 HP 피해 | **HEI-T 68HP / AP-I 38HP** (각 탄종 고유 기본 피해, 관통·폭발·과관통 판정 전) |
| 저속 발사 모드 | **1,000발/분** |
| 고속 발사 모드 | **3,000발/분** |
| 모드 선택 | **사격통제 AI가 두 속도 중 선택** — 플레이어가 직접 고정 선택하지 않음 |
| 점사량 | **AI 가변 계산**, 10/30/60/100발 등의 고정 프리셋 강제 금지 |
| 유효 교전거리 | **1,200m** |
| 최대 교전거리 | **1,500m** — 초과 시 사격 불허 |
| 즉응탄 | **1,031발** |
| 준즉응탄 | **1,069발** |
| 합계 | **2,100발** |

- 대공 사거리에는 이미 확정된 [항공 체계의 3차원 경사거리 규칙](../../../systems/air/AIR_ENTRY_RADAR_AA.md)을 적용한다. 1,200m는 **유효 교전 기준**이지 1,200m 초과 즉시 관통력/탄도가 끊긴다는 뜻이 아니다. 1,200~1,500m 구간도 사격할 수 있지만 명중·사통 조건의 영향을 받는다. 지상 목표에도 동일 무기·탄약과 1,500m 교전 상한을 쓴다.
- **AI 사격 판단:** 사거리, 실시간 추정 명중률, 표적의 수평 이동·급감속·호버링·고도 변화, 추적/조준 안정성, 예상 효과 및 잔여 탄약을 고려해 **발사속도(2종), 점사 길이, 사격 중단/재개**를 결정한다. **정확한 점사 알고리즘·임계값·재평가 주기·점사 간 휴지시간은 아직 미정**. 저명중률일 때 무조건 최장 점사를 강요하지 않는다.
- **2026-11-21 후속 사용자 채택 — 명중률 정성 방향(정량 미정):** 광학 관측·추적과 AN/VPS-2 거리측정 보조를 통해 **근거리에서 안정적인 사격**을 하되, **상대 거리 증가·거리측정/선행조준 오차·빠른 횡이동·급기동·광학 시야 불량**에 게파르트보다 민감하게 명중률이 떨어지게 한다. **유효 1.2km→최대 1.5km 구간 감쇄가 두드러지는 방향**. 정확한 발당 명중률 %·배율은 **미정**이고, 게파르트의 숫자를 복제하지 않는다. [자주대공포 명중률 잠정 설계](../../../systems/air/AA_GUN_HIT_PROBABILITY.md).
- **탄약 운용:** 발사할 때 즉응탄을 사용하고 준즉응탄으로 보충하는 **구획별 적재 설계**. 보충 소요시간·자동 보충 개시·사격 중 병행 허용 여부는 **미정**. 1,031+1,069=2,100발을 한 구획으로 합쳐 무제한 즉시 발사시키지 않는다.
- **명중:** 기존 [전차포 발사/착탄 분리·수평/수직 분산](../../../systems/combat/TWO_STAGE_HIT.md)을 공통 기반으로 재사용할 설계 방향. 기관포는 연발의 **탄마다** 발사 시 스냅샷과 비행시간, 착탄 시 명중·표적 운동 변화를 평가하는 것으로 확장한다. 공중 표적의 실제 고도 및 상승·하강 중 움직임을 반영하되, 별도의 3D 탄체 메시 물리 충돌을 새로 필수화하지 않는다. 사통·탄착군의 수치 계수는 **미정**.

## 3. AP-I 철갑소이탄 — 사용자 제공 이미지 확정 관통력

> 사용자 제공 관통표의 **모든 6개 거리 × 3각도 KE 수치를 그대로 채택**. 단위 **mm RHAe**; 각도 0°/30°/60°는 기준 장갑 법선 입사각. **5mm 재반올림 금지**.

| 거리 | 0° KE | 30° KE | 60° KE |
|---|---:|---:|---:|
| **10m** | **40** | **35** | **20** |
| **100m** | **36** | **31** | **18** |
| **500m** | **21** | **18** | **11** |
| **1,000m** | **11** | **10** | **6** |
| **1,500m** | **6** | **5** | **3** |
| **2,000m** | **3** | **3** | **2** |

- **6개 거리 노드 보존:** 2km 표 값은 원자료 보존용으로만 기록하며, M163의 게임 **최대 교전거리 1,500m를 늘리지 않는다**.
- **2026-11-21 사용자 최신 공중 입사각 예외:** M168 AP-I 및 HEI-T가 헬기·고정익기 등 **공중장비에 실제 명중한 경우**, 0°/30°/60° KE 중 해당 **거리의 0° KE값**을 사용하고 **공중 입사각·각도 도탄을 판정하지 않는다**. 30°·60° 표는 지상장갑 판정용으로 유지한다. **대공 거리·명중률·산포·표적 이동은 그대로**다. [공중 각도 공통 정본](../../../systems/combat/ANGLE_RICOCHET_FUZE.md).
- 노드 사이 거리·각도별 중간값 보간은 기존 KE 공통 계산과 연계하되, **미확정 별도 손실 곡선/강제 반올림을 도입하지 않는다**.
- M168 20×102mm 탄은 Marder Rh 202 20×139mm 탄과 제원이 다르다. [Rh 202 20mm 게임 수치](../ifv/MARDER_1A2_1A3.md)는 비교 참고만 하고 동일 탄약으로 합치지 않는다.
- **2026-11-21 후속 고정 탄띠:** 기존 **AP-I 단일탄 운용안은 폐기**하고 **HEI-T 3발 + AP-I 1발(3:1)** 고정 반복. 선택형 탄띠·탄종 전환 없음. **기존 AP-I 18개 KE 숫자·38HP·1,030m/s는 보존**. [신규 AA 20/23mm 탄약 정본](../../../ammunition/autocannon/M163_SHILKA_AA_20_23MM.md) · [고정 탄띠](../../../presets/1989/AA_FIXED_BELTS_M163_SHILKA.md).
- 20mm 기관포 공통 [치명타 없음·과관통 강한 감쇄 정책](../../../systems/combat/AUTOCANNON_DAMAGE.md)은 유지한다. **발당 기본 피해 38 HP를 전탄 명중/전탄 관통/피해 배율 100%라고 간주하지 않는다**.

## 3-B. 20mm HEI-T 신형 고폭탄 — 2026-11-21 사용자 후속 채택

- **기본 피해 68HP / 탄속 1,030m/s**. 워썬더의 M168 개별 **HEI-T CE 파공** 6개 거리값을 게임 CE 기준으로 사용. **DM21 기준 지상 급감·공중 완만 감소 고폭 피해곡선** 형식 사용. 정확한 CE 방호력에 따른 피해 매핑식은 미정.
- **10m 5 CE / 100m 5 CE / 500m 3 CE / 1,000m 2 CE / 1,500m 2 CE / 2,000m 2 CE**. 마지막 2km는 자료보존용이며 **M163 최대 사거리 1.5km** 불변.
- 공중 유닛 **비관통 직격 25% 하한 = 17HP**. 해당 기체의 CE가 20~25mm이므로 **직접 파공은 못하지만 외부 폭발 + 최소 17HP는 가능**. **매 발 68HP 확정 피해 아님**.
- HE는 AP처럼 KE 관통/과관통 배율을 사용하지 않는다. [탄약별 상세 정본](../../../ammunition/autocannon/M163_SHILKA_AA_20_23MM.md) / [고폭 피해형 공통 기준](../../../systems/combat/IFV_HE_DAMAGE_CURVES.md).
- **M163 3:1 단일 고정 탄띠 총 적재 2,100발일 때 1,575 HE + 525 AP**. 즉응 1,031/준즉응 1,069 탄약 구획은 유지, 구획 경계에서의 정확한 탄순서/충전 방법은 미정.

## 4. 공중 표적 비관통·AP 과관통 최소 25% — 최신 공통 규칙

- **2026-11-21 사용자 최종 확정:** 헬기 등 **모든 공중장비**에 실제 **비관통 직격**한 **모든 탄종**은 기본 HP 피해 **최소 25%**, **AP계열 관통 후 과관통 감쇄 피해에도 최소 25%** 하한을 적용한다. 폭발성·대공 전용탄·기관총 등으로 제한하던 구형 범위는 폐기했다.
- **기존 M168 AP-I** 기본 피해 **38 HP × 25% = 9.5 HP/발**. 공중 비관통 직격 **또는 AP 과관통**의 최종 피해가 9.5 HP보다 낮아지면 **9.5 HP**로 제한한다. 반대로 공통 과관통 계산 결과가 9.5보다 높으면 그 계산값을 사용한다.
- **신규 HEI-T** 기본 피해 **68HP × 25% = 17HP/발**. 모든 공중장비에 대한 실제 비관통 직격의 하한이며 별도 폭발 피해가 더 높으면 그것을 사용. **HEI-T의 비파공 폭발 피해곡선 정확한 값은 미정**.
- **지상 표적에는 공중용 하한 비적용.** 유효 명중 없는 발은 0 HP. 9.5 HP는 가산 피해가 아니며 기존 기관포 과관통 감쇄식 자체를 폐기하지 않는다. 도탄/신관 불발은 별도 판정.
- HP 소수 처리·도탄/불발 예외 결합 미정. [공중 전 탄종 피해 공통 정본](../../../systems/combat/AIR_TARGET_DAMAGE.md)이 최종 적용 범위를 소유한다.


## 5. AN/VPS-2 거리측정 레이더 — 실물 기능 확인, 게임 수치 추후

> **2026-11-21 공통 레이더 체계 최신 확정과의 관계:** [수색·탐지·추적 정본](../../../systems/air/RADAR_SEARCH_TRACKING.md)의 **수색(전차장 역할)과 정밀 추적(포수 역할)**은 서로 독립이다. **M163은 게파르트처럼 별도 15km 전방위 수색레이더가 있는 것이 아니다.** 이 장비는 **광학 관측·추적을 바탕으로**, AN/VPS-2 **거리측정 보조**를 받아 사격통제한다. 광학/거리측정 성능과 추적 안정성이 명중률에 영향을 주며, 탐지하지 못한 표적의 실제 엔진 좌표를 자동 활용하지 않는다. 거리측정 장비의 게임상 수치와 광학 추적 수치는 미정.

- **역사 자료:** M163 VADS 계열은 **AN/VPS-2 거리측정 전용(range-only) 레이더** 및 광학 선행조준 체계를 쓴다. 대형 수색레이더처럼 주변 공역 전체를 독자 자동 수색·식별하는 기능을 부여하지 않는다.
- **게임 모델 설계 방향:** **광학/외부 표적 정보로 발견·추적 → 거리측정 레이더로 거리(필요 시 거리 변화율) 보조 → 사격통제 AI의 사격 해 계산**. 전용 수색레이더와 역할 분리.
- **아직 결정할 수치:** 게임상 거리측정 허용 범위, 측정 오차, 측정·재측정 시간, 가시선/기상/전자전 효과, PIVADS 개량형 차이. **M168의 확정 포 사거리 1.5km와 레이더 측정 가능 거리를 동일하다고 임의 처리하지 않는다.**
- 참고: [미군 교범 FM 24-2 — AN/VPS-2 range-only radar](https://www.marines.mil/Portals/1/Publications/FM%2024-2.pdf), [미 국방 표준 MIL-R-50651B](https://quicksearch.dla.mil/qsDocDetails.aspx?ident_number=27513), [M163 체계 정리](https://man.fas.org/dod-101/sys/land/docs/m163.htm). 자료의 현실 성능과 게임 수치는 별도.

## 6. 적용 범위

- **확정(2026-11-21 후속 변경 우선):** M113A2 기반 차체 방호·400HP, **20mm AP-I 38HP / HEI-T 68HP**, AP-I 사용자 이미지 **18개 KE 노드 원상보존**, HEI-T 워썬더 **6개 CE 노드 5/5/3/2/2/2**, 공통 탄속 **1,030m/s**, **단일 HEI-T×3 + AP-I×1 고정 탄띠**, AI **1,000/3,000RPM** 및 유동 점사, 교전 유효 **1.2km**/최대 **1.5km**, 즉응 **1,031**/준즉응 **1,069**(총 2,100), 공중 비관통 기본 피해 최소 25%.
- **미정:** HEI-T 고폭 피해곡선의 개별 CE 노드 대응·보간, 포탑 방호/사수, 자세한 명중·레이더·보급·발사 AI 수치, 실기체형/개량형 세부 지급, 이동/기동 수치, 게임 코드.
- 본 업데이트는 **1989년 방공 신규 아카이브 설계**이며 기존 1989 전차 32종, 탄약 프리셋 96개, 현대탄, 실행 코드에는 영향을 주지 않는다.
