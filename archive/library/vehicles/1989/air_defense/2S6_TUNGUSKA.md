# TACTICAL 1989 — 초기형 2K22 / 2S6 퉁구스카 복합 자주방공차량 설계 정본

> **2026-11-21 사용자 최신 선택에 따라 기록.** 1989년 운용 **초기형 2K22/2S6**을 대상. 기관포 **30mm 2A38 쌍열 ×2기(총 4포신)**, 총 발사속도 **5,000RPM**, 총 기관포 탄약 **1,936발**(포신당 환산 484발), **HEF-I→HEF-T→HEF-I→AP-T** 고정 4발 패턴 및 각 탄종 **152/129/152/83 HP**, 대공 유효 **3km/최대 4km**를 게임 설계값으로 기록한다. 9M311 SAM **4발(좌우 2발씩)**, 관통 **30 CE 거리 무관**, 직격 **415HP**, 근접신관 발동 시 기본 **185~285HP**를 기록. **차량 HP·7구역 방호·레이더 게임 수치·명중률·신뢰성 계수/과열/탄걸림·신관 발동 확률은 미정**. 아카이브 설계이며 코드·실제 엔진 미구현.
>
> **정본 분업:** [30mm 2A38 탄약](../../../ammunition/autocannon/TUNGUSKA_30MM_2A38.md) · [기관포 고정 탄띠](../../../presets/1989/TUNGUSKA_2A38_BELT.md) · [9M311 대공미사일](../../../ammunition/missiles/9M311_SAM.md) · [전 탄약 장거리 관통력 규칙](../../../systems/combat/RANGE_PENETRATION_EXTRAPOLATION.md). 사용자가 확정하지 않은 정량값은 임의로 만들지 않는다.

## 1. 1989 형식과 장비 경계

- **2K22 = 방공체계, 2S6 = 전투차량**. **초기형 2S6(1982~1989)**을 1989년 표준 대상으로 사용. **1990년 2S6M/2K22M의 8발 발사기, 개선 2A38M 및 신뢰성 개량과 2003년 M1을 자동 합치지 않는다**.
- **미사일:** 1989 초기형 발사기 **9M311 4발, 좌우 각 2발** 참고 제원. 8발과 10km 미사일은 이 차량에 자동 적용 금지.
- **차량 최대 HP, 7구역 KE(CE), 주행 성능, 정확한 진영별 편성·보급 및 가격은 미정.** 기존 쉴카 450HP나 게파르트 650HP를 복사하지 않음.

## 2. 30mm 기관포 — 사용자 채택

| 항목 | 게임값 / 상태 |
|---|---|
| 무장 | **2A38 쌍열 기관포 2기, 합계 4포신** |
| 전체 연사속도 | **5,000RPM** |
| 쌍열 기관포 1기당 환산 | 2,500RPM |
| 포신당 환산 | 1,250RPM |
| 전체 기관포 탄약 | **1,936발** |
| 포신당 탄수 환산 | 484발 (게임 탄창·급탄 독립 구조 확정은 아님) |
| HEF-I 고폭파편소이 | **152HP / 960m/s** |
| HEF-T 고폭파편예광 | **129HP / 960m/s** |
| AP-T 철갑예광 | **83HP / 970m/s** |
| 고정 탄띠 | **HEF-I → HEF-T → HEF-I → AP-T** 반복 (2:1:1, 전체 HE:AP 3:1) |
| 탄종별 전체 수량 | **HEF-I 968 / HEF-T 484 / AP-T 484발** |
| 대공 유효 교전거리 | **3,000m** |
| 대공 최대 교전거리 | **4,000m** (초과 시 사격 불가) |
| 대공 거리 계산 | **3D 경사거리** |
| 3~4km | 사격 가능, 거리·추적 안정성 따른 명중률 감쇄. 수치 미정 |

- 총 5,000RPM은 약 **83.33발/초**, 1,936발을 전탄 완전 연속 사격하면 이론상 **23.232초**. **점사·과열·탄걸림·신뢰성·탄약 보충을 무시한 순수 산술값**이며 연속 발사 가능 시간을 확정하는 수치가 아니다.
- 관통력·탄속 원자료는 워썬더의 2S6 2A38 계열 표를 참고한다. **게임 기본 HP 피해는 사용자가 별도로 확정**한 값이다. 포신별 탄 순서/발사 시차/급탄계통 및 즉응탄·준즉응탄 분할은 **미정**, 1,936발 자체는 확정. 각 탄종과 KE/CE 표는 [탄약 정본](../../../ammunition/autocannon/TUNGUSKA_30MM_2A38.md) 참조.
- 탄약의 2km 원본 노드를 넘어서는 **거리별 관통·폭발 CE 처리에는 [공통 장거리 감쇄 규칙](../../../systems/combat/RANGE_PENETRATION_EXTRAPOLATION.md)** 적용. 매 탄종의 0~2km 감쇄 추세를 연장하고 원거리로 갈수록 가속 감쇄. **정확한 함수·계수 미정**.

## 3. 9M311 대공미사일 — 사용자 채택

| 항목 | 게임값 / 상태 |
|---|---|
| 미사일 | **9M311 초기형** (개량형 M/M1로 자동 변경 금지) |
| 탑재 | **발사 준비 4발, 좌우 2발씩** |
| 유도 | **SACLOS식 외부 추적 + 무선 지령 유도**, 발사 후 망각 아님 |
| 최대 교전거리 | **약 8,000m** 공개 초기형 자료를 게임 설계 출발값으로 채택 |
| 최소 교전거리·고도 제한 | **실물 공개 자료에 차이가 있어 게임 수치 미정** |
| 관통 | **30 CE, 거리 무관** (사용자 게임값, 워썬더 39와 구별) |
| 정상 직격 기본 피해 | **415HP** |
| 근접신관 성공 시 기본 폭발 피해 | **185~285HP** (방호력·폭발 거리 감쇄 전 범위) |
| 신관 발동 | **조건 충족 후 확률 판정**, 구체 확률/조건 미정 |
| 고폭 피해 | 대상 **CE 방호력에 따른 피해 감소**. 직격 및 근접폭발은 별도 경로, 같은 미사일 폭발을 이중 가산하지 않음 |

- **1989 초기형 9M311 근접신관은 레이저 방식**, 접촉신관도 사용. **후기 M1의 무선 근접신관을 초기형에 복제 금지**. TACTICAL에서는 감지·접근 조건 충족 시 **확률적 작동**을 추가한다. 작동 확률, 작동 반경, 오작동/실패 처리와 고폭 피해곡선 매핑은 **미정**.
- 유도 성공 여부(추적 유지·LOS), 직격 여부, 근접 구역 진입, 신관 작동 여부, 대상 CE 및 폭발 거리별 감쇄를 **독립된 판정 단계**로 설계한다. **비직격 근접폭발은 공중 직격 전용 최소 25% 피해 규칙을 자동 상속하지 않는다**.
- [9M311 미사일 정본](../../../ammunition/missiles/9M311_SAM.md)에서 정확한 판정 경계와 헬기 예시 참조.

## 4. 신뢰도 시스템 추후 도입 — 방향 채택 / 수치 미정

- 과열·냉각, 탄걸림/급탄 장애, 점사 중단, 복구, 총열/쌍열 기관포별 신뢰성, 연사 중 산포 확대는 **추후 시스템 대상**. 기관포 기본 발사속도 5,000RPM이나 탄종 피해 83/129/152HP를 예비 페널티로 미리 낮추지 않는다.
- **쌍열 기관포 2기 각각의 동작 상태를 개별 관리**하는 것은 설계 후보. 한쪽 장애 시 다른 쪽 작동/복구 처리 세부 규칙은 미정.
- 1RL144 탐지/추적 실물 자료, 레이더 게임 탐지거리·추적가능 거리·정밀추적 성공률, 대공 명중률, 유도 상실, 전자전·광학 대체는 추후 구체화. [공통 수색·정밀추적](../../../systems/air/RADAR_SEARCH_TRACKING.md) 규칙 우선.

## 5. 자료·구현 경계

- [War Thunder 2S6](https://old-wiki.warthunder.com/index.php?printable=yes&title=2S6): **30mm 2A38/2A38M1** 4포신 합계 5,000RPM, 1,936발, 탄띠·포탄 관통·탄속. **페이지는 후속형 8발/2A38M1도 함께 포함**하므로 초기 1989형의 역사적 미사일 적재를 그 표에서 가져오지 않는다.
- [초기형 4발/1990 개량형 8발](https://en.wikipedia.org/wiki/2K22_Tunguska) · [9M311 세대별 유도·신관](https://weaponsystems.net/system/1433-9M311): 초기 2S6 4발, 초기 레이저 근접신관, 무선 지령 유도, 초기 최대 사거리 8km.
- 역사 출처의 실물 제원과 **TACTICAL 30 CE / 415HP / 185~285HP / 83·129·152HP**는 별개. 확정 게임값은 **본 파일 및 연결 탄약 문서가 우선**.
- **게임 실행 코드/통합전투 실측 결과 없음.** 기존 전차 96개 적재 프리셋·M163·쉴카·게파르트 기존 게임값 미변경.
