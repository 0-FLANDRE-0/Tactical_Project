# TACTICAL 1989 — AH-64A Apache 장갑·HP·무장·헬파이어 치명타 게임 설계 (2026-11-14)

> **문서 지위:** 2026-11-14 사용자 대화에서 **승인/채택한 게임용 수치**와 역사적 참고·아직 미정인 항목을 구분해 보존. 실물 장갑 시험·정식 탄약 관통 시험 결과가 아니며, **런타임 유닛/전투 엔진 구현 및 테스트 완료 아님**.
> **범위:** 1989년 AH-64A 초기형. 이후 AH-64D Longbow 등 후기형 기능을 이 기체에 소급하지 않는다.
> **관련:** [항공 투입·간략 외부 작전지도·방공레이더 LOS·IFV 대공사거리](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/air/AIR_ENTRY_AIR_DEFENSE_IFV_AA_RULES_2026-11-14.md), [차량 관통/피해 설계](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/combat/PENETRATION_DAMAGE_AND_VEHICLE_HP_CONCEPT_2026-11-07.md), [탄약고·승무원/모듈 방향](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/combat/TEMPORARY_MODULE_CREW_AMMO_DESIGN_UPDATE_2026-11-12.md).

## 1. AH-64A 기체 HP·장갑 — [사용자 확정]

| 항목 | 게임 설계값 |
|---|---|
| 최대 기체 HP | **325 HP** |
| 단일 기체 기본 장갑 | **20(20) mm RHAe, KE(CE)** |
| 장갑 구역 | **기체 전체 하나의 공통 방호값** — 전차의 7구역 구분 미적용 |
| 별도 조종석·엔진·로터 장갑/모듈 HP | **현재 사용하지 않음** |
| HP 소진 | **비행 불능·추락 처리 방향 채택** |
| 주된 생존 요소 | 기동·고도·지형 차폐·관측·낮은 피탄 확률, 방공 위협 |

- 이 **20(20)은 실제 AH-64A 동체 전체에 균일한 20mm 강판이 존재한다는 뜻이 아니라** 게임용 단일 KE/CE 방호값이다. 실제 주요 부위의 국부 방호를 게임 편의상 추상화한 것이다.
- **2026-11-21 공중 전체 입사각 생략:** AH-64A는 **기체 단일 KE(CE) 20(20)** 장갑만 사용하며, 모든 탄종 피격에서 **입사각·방향별 경사관통·각도 도탄을 계산하지 않는다**. 각 탄약의 **거리별 0° 관통/CE 효과값**과 직접 비교한다. **3D 경사거리·명중률·표적 운동·비행시간은 유지**. [공중 각도 예외 정본](../../../systems/combat/ANGLE_RICOCHET_FUZE.md).
- **2026-11-21 최신 사용자 확정:** AH-64A 최대 HP를 **기존 300 → 325 HP**로 변경했다. 기본 장갑 **20(20)**은 불변이다. [공중장비 전 탄종 피해 하한 정본](../../../systems/combat/AIR_TARGET_DAMAGE.md)에 따라 **모든 탄종 비관통 직격과 AP계열 과관통 피해에 최소 기본 HP 25%**를 적용한다. 도탄·불발은 별도 판정이며, 공중 전용 하한은 지상장비에 적용하지 않는다.
- 미사일/기관포의 **피격 확률**과 **장갑 관통 뒤 HP 피해**는 별개다. 실제 추락 연출·추락 후 피해, 승무원 생존, 로터 고장·기동 불능 등은 후속 세부 미정.
- 별도 모듈 HP를 도입하지 않는 것은 기존 차량의 모듈 영구 파괴 미도입 방침과 연결된다. 추가 일시 이상까지 자동 금지한다는 뜻은 아니다.

## 2. 30mm M230 Chain Gun / M789 HEDP — [사용자 확정]

| 항목 | 게임값 |
|---|---:|
| 무장 | **30mm M230 체인건** |
| 탄약 | **M789 HEDP** (이중목적 고폭/성형작약) |
| 0° 관통력 | **50 CE** |
| 30° 관통력 | **45 CE** |
| 60° 관통력 | **25 CE** |
| 기본 HP 피해 | **150 HP** |
| 거리별 CE 관통력 감소 | **없음** |
| 폭발·파편 | **소규모 범위 폭발·파편/제압 효과** 방향 |

- 관통 0°/30°/60°는 다른 HEAT와 동일한 **100% / 86.6% / 50%, 5mm 반올림** 규칙으로 계산한 게임값이다.
- **직격 관통 기본 피해 150 HP**와 폭발/파편 효과는 별도 처리한다. 동일한 대상에 '150 + 폭발 기본 피해'를 무조건 중복 적용하지 않는다.
- M230의 게임상 지상/대공 교전거리, 조준·명중률, 점사·연사 산포·탄약 적재/장전, 폭발 반경과 제압 효과 정량은 **미정**. 발사속도 약 625발/분 및 최대 적재 약 1,200발은 역사적 참고제원으로만 취급한다.
- 미국 **M792 HEI-T는 최신 피해 133 HP**, 소련 **3UOF8 HEI는 155 HP**, **3UOR6 HE-T는 133 HP**이며, M789 150 HP 합의는 그 수정과 별개다.

## 4. Hydra 70 / M247 HEAT — [사용자 채택]

| 항목 | 게임값 |
|---|---:|
| 로켓 구경 | **70mm** |
| 탄두 | **M247 HEAT** |
| 0° 관통력 | **290 CE** |
| 30° 관통력 | **250 CE** |
| 60° 관통력 | **145 CE** |
| 기본 차량 HP 피해 | **288 HP** |
| 거리별 HEAT 관통력 감소 | **없음** |
| 유도 방식 | **무유도** |
| 폭발·파편 | **소규모 범위 효과** 방향 |

- 관통 0°/30°/60°는 공통 HEAT 100%/86.6%/50%와 5mm 반올림 적용.
- **고관통·기본피해와 실명중 성능을 혼동하지 않음**: 무유도 로켓 산포·포드 발사량·헬기 기동·거리/조준에 따라 개별 명중 실패 가능. 구체 명중률·로켓 발사 간격, 살보 크기, 폭발/파편 정량, 최대 교전거리와 기본 탑재 조합은 **미정**.
- 최대 76발 로켓 포드 장착 가능이라는 실물 제원은 참고이며, 16발 헬파이어와 76발 로켓을 **동시에 각각 최대 적재할 수 있다는 뜻이 아니다**.

## 4-A. AH-64A 중구경 플레어·AN/ALQ-144 '디스코볼' 방어장비 — [2026-11-21 사용자 채택]

> **최신 개별 방어 정본:** [AH-64A 플레어·AN/ALQ-144](../../../systems/air/AH64A_FLARE_ALQ144.md) · [공통 플레어 저항성/IRCCM](../../../systems/air/COUNTERMEASURES_FLARE_IRCCM_ECCM.md).

| 항목 | AH-64A 게임값 |
|---|---|
| **기만체 분류** | **중구경 플레어** |
| **총 플레어 적재량** | **30발** |
| **일반 살포** | **3발 연속 = 3발** |
| **긴급(집중) 살포** | **5발 연속 = 5발** |
| **플레어 발당 기본 기만확률** | **34.6%** |
| **능동 IR 교란장치** | **AN/ALQ-144 ('디스코볼') 기본 장착** |
| **ALQ-144 감쇄 전 기본 기만확률** | **90%** |
| **적 미사일 IRCCM 등급별 감쇄** | **0단계 0% / 1단계 40~60%(9M37 IR=45%, MIM-72C/E=55% 확정) / 2·3단계 램프형 100%** |
| **교란 방위** | **2D RTS 평면 360도**, 수직/하방 사각지대 판정 없음 |

- 중구경 플레어 **30발·34.6%/발**은 사용자 게임 확정값. 다른 미사일의 **플레어 저항성**을 적용해 **유효한 플레어 한 발당 한 번 독립 판정**한다. 28.5%는 이전 비교 후보로 폐기.
- **AN/ALQ-144는 정상 시 상시 작동**하며 유효조건에 미사일당 최대 1회 추첨. 감쇄 전 기본 90%에 **(1−IRCCM 램프형 기만확률 감쇄율)** 적용. 0단계 0%, 1단계 40~60%(**9M37 IR=45%→최종 49.5%, MIM-72C/E=55%→최종 40.5%**), 2/3단계 램프형 100% 감쇄·기만 판정 생략. 기존 플레어 기만과 독립이며 매 프레임 재추첨 금지.
- M130 계열 발사기 참고. **게임 플레어 30발**은 확정이나 발사기 실제 수량/세부 배치·**연속 살포 간격/쿨타임·일반/긴급 자동 선택 조건**·장치 유효거리 및 회복 여부는 미정.
- **AH-64A 기존 325HP·20(20) KE(CE)** 및 무장 수치 변경 없음. 90%는 게임 수치이며 실물 기만 성공률이 아니다.

## 5. 1989년 시점 참고 제원 (게임 수치와 구별)

- 형식: 미국 육군 **AH-64A Apache**, 조종사 1명 + 부조종사/사수 1명.
- 엔진: T700 계열 2기. M230 30mm 기관포, AGM-114A 초기 헬파이어, 70mm 무유도 로켓 사용.
- 관측 장비: **TADS/PNVS**, 당대의 적외선 관측·야간 비행 능력. **AH-64D Longbow의 밀리미터파 레이더는 1989년 AH-64A에 없음**.
- 항공기 투입·외부 단순 작전지도·장거리 방공 레이더 LOS에 관한 논의는 [별도 항공 시스템 설계](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/air/AIR_ENTRY_AIR_DEFENSE_IFV_AA_RULES_2026-11-14.md)를 따른다.

## 6. 아직 미정·코드 적용 경계

- **M230/Hydra:** 사거리, 명중률·산포, 폭발·보병 제압, 탄약 적재 프리셋과 동시 장착 조합.
- **헬기 비행:** 지형 추종 고도, 선회·가속·호버링, 기관포/미사일 이동 간 발사 조건, 항공 레이더/광학 LOS, 방공미사일 요격과 기체 피해·추락.
- **헬파이어 치명:** 위 조건·확률·배율은 합의했지만 **피해 계산·관통률 보간과 탄약고 유폭의 이벤트 적용 순서**는 후속 구현에서 검증.
- **게임 코드 미구현:** 본 파일은 아카이브 백업이며 실제 AH-64A 유닛/탄약/항공 이동/치명타/투입 AI 데이터를 **구현하거나 수정하지 않았다**.
