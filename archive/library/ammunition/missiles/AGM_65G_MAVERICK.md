# TACTICAL 1989 — AGM-65G Maverick 대형 관통·폭발탄 정본

> **2026-11-23 사용자 채택 게임 설계:** A-10A의 AGM-65G Maverick은 **직격 0° KE 120mm, 정상 관통 기본 피해 1,750HP**. **비명중 초근접 폭발 CE 65mm**, 해당 파공 성공 시 감쇄 전 피해 상한 **50%=875HP**, 파공 실패 시 **HE 장갑 방호력 감쇄로 급격히 감소하고 최대 30%=525HP**로 제한, 이후 **매우 가파른 폭발거리 감쇄**를 추가한다. **비명중 폭발 피해 반경 3.8m(3.8m 이상 0HP)** 채택. **유닛 대상 치명타 존재**. 확정되지 않은 치명타 확률·배율과 개별 거리/CE별 피해곡선은 미정이며 게임 코드에는 미구현.

**관련:** [A-10A 기체 정본](../../vehicles/1989/air/A10A.md) · [AGM-65B/D 별도 탄두 및 폭발 설계](AGM_65B_D_MAVERICK.md) · [1989 항공기 색인](../../indexes/AIRCRAFT_1989.md) · [매버릭 대공 요격](../../systems/air/RADAR_SEARCH_TRACKING.md) · [공중 비관통 직격 하한/근접 구분](../../systems/combat/AIR_TARGET_DAMAGE.md).

## 1. AGM-65G 기본 채택 수치

| 항목 | 게임값 / 결정 지위 |
|---|---|
| 형식 | **AGM-65G** — B/D와 별도 대형 관통·지연폭발 계열 |
| **직격 0° 관통력** | **120mm KE** [확정] |
| **정상 KE 관통 기본 피해** | **1,750HP** [확정] |
| **직격 KE 120mm 비관통 시** | **후속 HE/폭발 피해 판정으로 전환** [방향 확정, 상세 계산 미정] |
| **초근접 비명중 외부 폭발 파공력** | **65mm CE** [확정] |
| 초근접 비명중 CE 파공 성공 상한 | **50%=875HP** (장갑/거리 감쇄 전 상한) |
| 초근접 비명중 CE 파공 실패 상한 | **30%=525HP** (HE 비파공 감쇄 후 상한, 거리 감쇄 추가) |
| **비명중 폭발 피해 최대 반경** | **3.8m** [확정]; **거리 3.8m 이상 0HP** |
| **유닛 대상 치명타** | **있음** [확정]; 발생 확률·피해 배율·적용 분기 미정 |
| 대공 요격 | **가능** [계열 공통], 탐지·추적·실제 요격 성공률 미정 |
| 30°/60° KE, 별도 폭발/신관/비행·사거리/적재량 | **미정** |

- **KE 120mm는 정상 직격의 운동에너지 기반 관통 지표**, **CE 65mm는 비명중 초근접 폭발에 대한 HE 파공 지표**로 두 판정을 합치거나 서로 대체하지 않는다. 실제 AGM-65G의 검증된 물성 측정값이 아닌 TACTICAL 사용자 선택 게임 수치다.
- **1750HP 전체는 KE 정상 관통에 대한 기본값**이다. KE 비관통 시 1,750HP가 자동 적용되지 않으며, 별도로 언급된 **후속 HE/폭발 판정**으로 넘어가되 그 상세 계산법·직격 특유의 파공/감쇄 조건과 65 CE 비명중 분기와의 연결 방식은 **추후 결정**한다. 직격 결과와 비명중 피해를 이중 합산하지 않는다.
- **유닛 대상에 한해 치명타 존재**를 확정. 건물·비유닛 표적에 대한 별도 치명타 적용은 **이번에 채택하지 않음**. 유닛의 정확한 범주, 치명타 발동이 직격만인지 비명중 폭발까지 포함하는지, 확률/관통 여유/부위·배율은 **미정**. 기존 헬파이어의 110%·부위별 5/10/15/15%를 자동 복사하지 않는다.

## 2. 비명중 초근접 폭발과 급격한 거리 감쇄

> **B/D와 같은 2축 감쇄 구조**를 채택하되, **G형 전용 CE 65 / 50%·30% 상한 / 3.8m 반경**을 사용한다. B/D의 CE 70·85%·50%나 4.5m 검토 후보를 G형에 복사하지 않는다.

1. **실제 비명중 + 정상 기폭:** 미사일이 표적에 직접 맞지 않았더라도 지면/장애물 등에 충돌해 정상적으로 기폭한 경우에만 주변의 유닛을 폭발 피해 대상으로 판정한다. **근접 통과 자체를 근접신관 작동으로 간주하지 않는다**. 신관 및 폭발 발생 조건 상세 미정.
2. **초근접에서 CE 65mm 파공 성공:** 감쇄 전 최대 **1,750×0.50=875HP**. **CE 장갑 방호력에 따른 HE 피해 감쇄**와 **폭발 중심-표적 거리 감쇄**를 둘 다 반영하므로, 파공 성공만으로 875HP를 무조건 지급하지 않는다.
3. **초근접에서 CE 65mm 파공 실패:** HE 비파공 피해곡선에 의해 **급격히 감소**시키고, 거리가 0에 가까워도 **1,750×0.30=525HP를 절대 넘지 않는다**. 이후 별도 **거리별 강한 감쇄**를 적용하므로 실제 피해는 525HP보다 더 작을 수 있다. 비파공이라고 525HP를 고정 피해로 주지 않는다.
4. **일반 근접/거리 감쇄:** 초근접 범위 밖에서도 B/D와 동일한 구조상 **폭발거리 증가에 따라 급격히 감쇄**한다. **초근접에서 일반 근접으로 넘어가는 경계·일반 근접의 별도 최대 피해 상한·거리별 숫자·HE 방호력별 노드**는 아직 미정이며 임의로 50%/30%를 다른 구간에 고정 배분하지 않는다.
5. **폭발 영향 반경:** **3.8m가 G형 비명중 폭발 피해의 완전 소멸 거리**이며 **3.8m 이상 0HP**로 처리한다. 중심부터 표적까지 거리를 표적 중심/외곽·3D 최단거리 중 어떻게 측정할지와 구간별 정확한 급락 함수는 미정. 3.8m를 폭발 VFX/소리/실물 파편의 모든 물리 반경과 동일시하지 않는다.
6. **배타적 경로:** 정상 KE 관통 직격 피해, KE 비관통 후 HE 폭발, CE 65 초근접 비명중, 일반 비명중은 **한 번의 피탄 사건에서 중복 가산하지 않는다**.
7. **공중 대상 비명중:** 기존 전 탄종 **공중 실제 비관통 직격 25% 하한**을 **비직격 근접폭발에 자동 적용하지 않는다**.

## 3. B/D와 설계 차이 및 후속 미정

| 항목 | AGM-65B/D | AGM-65G |
|---|---|---|
| 직격 관통 | **830 CE** | **120 KE** |
| 직격 기본 피해 | **1,380HP** | **1,750HP** |
| 초근접 비명중 폭발 파공 | **70 CE** | **65 CE** |
| 초근접 파공 성공 상한 | **85%=1,173HP** | **50%=875HP** |
| 초근접 파공 실패 상한 | **50%=690HP** | **30%=525HP** |
| 비명중 완전 감쇄 거리 | **4.5m 검토 후보(미확정)** | **3.8m 확정** |
| 치명타 | 존재(세부 미정) | **유닛 상대 치명타 존재**(세부 미정) |
| 대공 요격 | 가능(체계별 능력 미정) | 가능(체계별 능력 미정) |

- **G형 직격 KE 관통 실패 후 자세한 폭발 판정**, 지상/공중/구조물별 피해곡선, 대형 탄두 신관·폭압·파편·화재 처리, 실제 게임 탑재 제약 및 희귀 보급 여부, G형의 별도 표적 탐색/획득 방식은 **미정**.
- **게임 코드는 이번 문서 갱신으로 구현되지 않는다**. 다른 미사일/탄약 및 기존 1989 전차 96개 탄약 프리셋 변경 없음.
