# TACTICAL 1989 — 9M37 / 9M37M 스트렐라-10 계열 SAM 탐색기·환경별 IRCCM 설계 정본

> **2026-11-21 사용자 선택 기록.** 9M37/9M37M의 **광학 명암비(photocontrast) + 적외선(IR) 2채널 탐색기**를 게임의 확률 시스템으로 근사한다. 미사일별 **환경 유리/불리 IRCCM 범위**는 아래 사용자 제시값으로 채택한다. **야간은 무조건 광학적으로 불리한 환경**으로 판정한다. 날씨·구름·고도·표적 배경 등 환경 요소를 **종합해 범위 안의 실제 IRCCM을 결정**하며, 같은 환경은 미사일 **추적 안정성/명중에도 영향**을 주도록 설계한다. **9M37 기본 명중률 75~100%, 9M37M 85~100%**는 **무기동·약한 기동 표적**에 대한 기준 범위로 채택한다. **급선회/급격한 회피기동은 추가 감쇄**하며 구체 감쇄율과 명중률 결정 함수는 미정. **아카이브 기록이며 코드 미구현.**

**운용 차량 정본:** [9K35M2 스트렐라-10M2](../../vehicles/1989/air_defense/STRELA_10M2.md) — 차체 7구역 KE(CE) **15/10/5/5/5/5/5 RHAe**, **325HP**, **즉응 4발 + 예비 4발 = 8발** (차량 고유 확정값).

**공통 규칙:** [항공 기만체·플레어 독립 판정·IRCCM/ECCM](../../systems/air/COUNTERMEASURES_FLARE_IRCCM_ECCM.md) · [레이더 수색·정밀 추적 구분](../../systems/air/RADAR_SEARCH_TRACKING.md) · [MT-LB 기본 차체 정본](../../vehicles/1989/apc/APC_ADDITIONAL.md).

## 1. 미사일 식별·대상 범위

- **9M37 / 9M37M:** 스트렐라-10 계열의 **광학 명암비 + IR 2채널 유도 탐색기**를 게임 설계 대상으로 한다. **개량형 9M37M은 9M37보다 환경별 IRCCM 범위가 높다.**
- 운용차량 후보는 **1989년 스트렐라-10M2(9K35M2)**. 이 문서는 **미사일 시커·대응기만·기본 명중률 규칙**을 소유한다. **스트렐라-10M2 차체·장갑·HP·탄 수는 차량 정본에서 확정**, 미사일 자체 HP 피해·CE·구체 비행 제원·부대 편제는 미정이다.
- 아래 **IRCCM %는 사용자가 고른 게임 밸런스 수치**이지 실제 소련 미사일의 공개 측정 IRCCM % 또는 광학/IR 센서의 물리 실측 수치가 아니다.

## 2. 환경에 따른 9M37 / 9M37M IRCCM — 사용자 채택 수치

| 탐색 환경 | 9M37 유효 IRCCM | 9M37M 유효 IRCCM |
|---|---:|---:|
| **광학 명암비 채널에 유리한 환경** | **72~82%** | **78~90%** |
| **광학 명암비 채널에 불리한 환경** | **15~35%** | **18~40%** |

- **야간:** 반드시 **불리한 환경**. 야간임에도 단순히 표적 고도가 높다는 이유로 **유리한 범위로 승격하지 않는다**.
- **그 외 날씨/시간·구름량·표적 고도·하늘/구름/지형 배경·상대 방향 등** 환경적 조건을 종합하여 **유리/불리한 구간** 및 **구간 안의 실제 유효 IRCCM**을 결정한다. 특히 **맑음 OR 고고도**처럼 변수 하나로 자동 유리 판정하지 않는다.
- **주간이고 광학적으로 선명한 하늘 배경**이면 유리한 범위 적용 가능. **야간·악천후·복잡한 배경·저고도 지형 배경** 등에서 불리한 범위 적용 가능. 다만 **정확한 구름·고도·시정 임계값, 각 요소의 가중치, 범위 내 위치 결정 함수는 미정**이다.
- 환경이 결정하는 유효 IRCCM은 **임의의 매 발사 무작위 범위 추첨**으로 대체하지 않는다. 실제로 관측/유도에 영향을 주는 환경 조건에 연동한다. **두 미사일의 조건 평가식은 공통**으로 설계할 수 있지만, 9M37M이 **모든 가능한 상황에서 반드시 더 높은 값이 되도록 하는 구체 매핑**은 아직 미정(두 구간의 숫자가 일부 겹침).
- **IRCCM은 플레어 기만확률에 대한 저항률**이다. 표적을 발견하거나 미사일이 반드시 명중할 확률과 같지 않다.

## 3. 기존 플레어 독립 판정과 결합

```text
P_flare_decoy = clamp(P_flare_base × (1 - IRCCM_environmental) × M_aspect, 0, 1)
```

- `P_flare_base`: 대·중·소 플레어 및 기만체 유형별 기본 기만확률(**아직 미정**).
- `IRCCM_environmental`: 위 표의 **미사일 종류+환경 조건에 따른 유효 IRCCM**(확정 범위, 범위 내 세부 함수 미정).
- `M_aspect`: 미사일 시커 특성·표적 상대 방향에 따른 기만 보정(**정량 미정**).
- **유효 플레어 한 발당 1회 독립 판정**, 매 렌더 프레임 재추첨 금지. 다량 살포도 한꺼번에 1회로 뭉치지 않는다.
- 예시로 플레어 기본 35%, 방향배율 1.0일 때: **9M37 유리 72% → 발당 9.8%**, **9M37M 유리 90% → 발당 3.5%**. **35%와 방향배율 1.0은 설명용 숫자**이며 게임 확정값 아님.

## 4. 기본 명중률 — 사용자 채택 범위 및 급기동 추가 감쇄

| 항목 | **9M37** | **9M37M** |
|---|---:|---:|
| **기본 명중률 범위 — 무기동 또는 약한 기동 표적** | **75~100%** | **85~100%** |

- **정상적으로 표적을 포착해 유도 중이며 표적이 무기동 또는 약한 기동일 때** 위 범위를 기본 명중률로 사용한다. 이는 **모든 교전의 절대 최종 명중률 하한이 아니다**.
- **날씨·시간·고도·표적 배경·거리·추적 안정성 등의 조건을 평가**해 기본 범위 안의 값을 결정하는 방향이며 정확한 평가식·가중치는 **미정**. 같은 환경 원인을 **기본 범위 내 값 산정과 후속 페널티에 이중 감쇄하지 않는다**.
- **표적이 급선회하거나 급격한 회피기동을 하면 기본 명중률에 추가 감쇄를 적용**한다. 이때 실제 최종 명중률은 **9M37 75% / 9M37M 85% 아래로도 내려갈 수 있다**. 급기동 감쇄율과 기동 분류 임계값은 **미정**.
- **사용자 발언은 추가 감쇄 방향의 확정**이지 급기동마다 무조건 일정 고정 페널티를 적용한다는 수치 확정이 아니다. 필요시 명중률을 0~100%로 제한한다.
- **시커 락온·발사 가능 여부 → 비행 중 기만 성공 여부 → 기만 실패 후에도 남는 유도/명중 성공 여부**는 분리한다. 플레어 기만 실패가 자동 명중을 뜻하지 않는다.
- **플레어 기만은 이 명중률과 독립 판정**: 적외선 기만 성공 여부 → 유지되는 유도/명중 여부를 구분한다. 유효한 플레어 발당 독립 추첨이 기본 명중률을 추가 재추첨으로 대체하지 않는다.
- **야간=불리한 IRCCM**일 뿐 **IR 탐색기로 추적 불가능/명중률 0**을 의미하지 않는다. 광학 명암비 채널의 가용성·IR 채널 의존도와 고유 시커 성능은 후속 설계.
- 명중률·탐지·IRCCM에 같은 환경 입력을 사용할 수 있지만 **기만확률과 명중률을 단순히 동일 %로 취급하지 않는다**.

## 5. 뒤에 정할 사항 / 경계

- 9M37/9M37M의 **기본 명중률 범위는 위에서 확정**. 다만 실제 기본값 선정 함수·급기동 감쇄율, 시커 포착 거리/각도, 종말 유도, 미사일 기동 한계, 신관 반경/확률, 게임 CE·기본 HP 피해 및 미사일 사거리는 미정. **차량 재고 4+4=8발은 확정**, 재장전 시간·방식과 세부 운용 제한은 미정.
- **미사일 유형마다 이 수치를 다르게 적용**하며, 9M333 등의 개량탄은 나중에 별도로 조사/선택한다. **실제 1989년 배치·M2 호환을 자동 확정하지 않음**.
- **차량 정본은 별도 확정:** 기존 MT-LB 기본형 **300HP·15/10/5/15/10/5/5 RHAe**와 달리 [스트렐라-10M2](../../vehicles/1989/air_defense/STRELA_10M2.md)는 **325HP·15/10/5/5/5/5/5 RHAe·즉응 4발+예비 4발**을 채택. 두 차종의 독립 값을 혼용하지 않는다.
- **실제 탐색기 물리/이미지 신호 모델 미구현. 실제 코드·기존 9M311·기존 MT-LB 정본 수치 변경 없음.**
