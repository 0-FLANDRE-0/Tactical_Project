# TACTICAL 1989 — 9M37 / 9M37M 스트렐라-10 계열 SAM 시커 모드·플레어 저항성 정본

> **2026-11-22 IRCCM 등급제 후속 확정 반영.** 발사 전 선택하는 **광학 명암비/적외선(IR) 시커 모드**와 개별 플레어 저항성은 기존대로 유지한다. **IRCCM ON/OFF를 램프형 IRCM 기만확률 감쇄율 기준 0~3단계로 변경**. **9M37 IR 모드는 1단계(40~60% 감쇄, 정확한 값 미정)**, 9M37M IR 모드는 2단계(100% 감쇄), 광학 명암비 모드는 추적 채널 특성상 2단계 상당(램프형 IRCM 비적용)이다. 실제 미사일 실측 수치 아님. **코드 미구현**.

**운용차량 정본:** [9K35M2 스트렐라-10M2](../../vehicles/1989/air_defense/STRELA_10M2.md) — 7구역 KE(CE) **15/10/5/5/5/5/5 mm RHAe**, **325HP**, 미사일 **즉응 4발 + 예비 4발 = 총 8발**.

**관련:** [공통 플레어 저항성·IRCCM·Lipa 판정](../../systems/air/COUNTERMEASURES_FLARE_IRCCM_ECCM.md) · [Mi-24 기만체·Lipa 설계](../../systems/air/MI24_FLARE_LIPA.md) · [공중 탐지·추적](../../systems/air/RADAR_SEARCH_TRACKING.md).

## 1. 두 가지 시커 모드와 IRCCM 0~3단계 — 2026-11-22 사용자 확정

| 미사일·탐색기 | **광학 명암비 모드** | **적외선(IR) 모드** |
|---|---:|---:|
| **9M37 플레어 저항성** | **74~88%** | **15~35%** |
| **9M37 IRCCM 등급** | **2단계 상당(광학 채널)** | **1단계(40~60% 감쇄, 개별값 미정)** |
| **9M37M 플레어 저항성** | **80~95%** | **30~60%** |
| **9M37M IRCCM 등급** | **2단계 상당(광학 채널)** | **2단계(100% 감쇄)** |

- 여기서 **플레어 저항성은 확률적 기만 저항 수치**로서 이전 문서에서 숫자형 'IRCCM %'로 부르던 역할을 **명칭 변경**한 것이다.
- **새 IRCCM 등급:** 0단계 램프형 IRCM 기만확률 감쇄 **0%**, 1단계 **40~60%**, 2단계 **100%**, 3단계 램프형 **100%**·현대 DIRCM 대응 미정. 여기서 **감쇄율은 최종 기만확률이 아니며** 공통 Lipa 기본 90%에 \`(1−감쇄율)\`을 곱한다. **9M37 IR 모드 1단계의 정확한 감쇄율은 추후 개별 확정**, 범위 중간값 자동 사용 금지.
- **광학 명암비 모드인 9M37·9M37M은 둘 다 램프형 Lipa의 교란 효과가 없는 채널**이므로 게임상 **2단계 상당(100% 감쇄)**으로 표시한다. 이는 실제 IR 시커의 기술 단계가 2단계라는 뜻이 아니다. **IR 모드는 9M37=1단계 / 9M37M=2단계**. 어떤 모드든 플레어는 여전히 별도 기만 판정하며 기존 저항성만 사용한다.
- 이전 **9M37 광학 유리 72~82%, 9M37M 광학 유리 78~90%, 9M37M 적외선 불리 18~40%** 값은 **최신 74~88%, 80~95%, 30~60%로 폐기·대체**한다. **9M37 적외선 15~35%는 유지**한다.

## 2. 발사 전 자동 모드 선택 — 비행 중 변경 금지

1. **발사 전** 해당 교전의 **시간대(주간/야간), 고정 날씨, 구름량/시정, 표적 고도·배경 등**을 종합하여 발사 가능한 시커 모드를 판정·자동 선택한다. 조건별 상세 임계값·가중치는 미정.
2. **야간에는 IR 모드**를 선택한다. 주간에는 광학 명암비 표적 추적이 적합한 경우 광학 모드를, 그렇지 않으면 IR 모드를 사용할 수 있게 한다. 단순 고고도 하나만으로 광학 모드가 확정되는 것은 아니다.
3. **발사 순간에 모드가 고정된다.** 발사 후 표적 고도·배경이 바뀌어도 **다른 시커 모드로 전환되지 않는다**.
4. **전투 중 날씨 변화는 구현하지 않는다**. 날씨·시간 등은 해당 교전의 고정된 환경 입력으로 사용할 수 있다. 표적의 **비행 중 고도·기동·배경 변화는 계속 반영**할 수 있다.
5. 환경에 따른 **범위 안 플레어 저항성 실제값**과 **기본 명중률의 실제값**을 결정하는 세부 함수는 미정. 두 미사일의 범위가 일부 겹치더라도 실효값 자동 역전/절대 우위 규칙을 임의 확정하지 않는다.

## 3. 플레어·Lipa 판정은 서로 다른 방어 기제

```text
P_flare_decoy = clamp(P_flare_base × (1 - FlareResistance) × M_aspect, 0, 1)
Lipa: 유효 교란 조건 충족 시 P_Lipa = 0.90 × (1 - IRCCM_램프형_기만감쇄율)
      9M37 IR 1단계: 감쇄율 40~60% 범위, 실제 세부값 미정
      9M37M IR 2단계 / 광학 명암비 채널: 감쇄율 100%, 기만 판정 생략
```

- `P_flare_base`: 플레어 개별 탄종의 기본 기만확률. **Mi-24 ASO-2V 소구경 플레어는 발당 18.5% 게임값**. 중/대구경 및 타 기체는 별도 미정.
- `FlareResistance`: 위의 **미사일+발사 전 고정된 시커 모드+유효 환경 조건**에 따른 플레어 저항성, 0~1.
- `M_aspect`: 상대방위에 따른 플레어 기만 보정 계수(미정).
- **실제 방출되어 유효한 플레어 1발마다 독립 판정**. 매 프레임 재추첨하지 않는다. **IRCCM 1/2단계라도 플레어는 별도로 계산**.
- **Lipa의 기본 90%는 사용자 채택 게임값**. 유효한 교란을 받는 미사일 한 발에 장비별 **최대 1회만** 판정한다. 9M37 IR 1단계는 **최종 기만확률 90%×(1−개별 감쇄율)**, 감쇄율 미확정 시 계산값도 미정이다. 9M37M IR 및 광학 명암비 모드에는 램프형 Lipa의 기만 판정을 생략한다. 실물 미사일의 절대적인 방해면역을 실측으로 입증한 수치는 아니다.

## 4. 정상 명중률 / 광학 명암비 저고도 추적 실패 — 사용자 확정

| 상황 | 9M37 | 9M37M |
|---|---:|---:|
| **기본 명중률: 무기동·약한 기동 표적, 정상 추적** | **75~100%** | **85~100%** |
| **광학 명암비 모드로 비행 중 표적이 저고도로 내려가 광학 추적이 불리해진 경우** | **8~16%** | **8~16%** |

- **광학 명암비 모드로 발사한 이후** 표적이 **지형 배경의 저고도로 내려가면** 광학 추적이 급격히 불리해져 **명중률 자체가 8~16% 수준으로 하락**하고 **추적 실패가 발생할 수 있음**. 이는 기존 75~100/85~100에서 8~16%**p**를 빼는 뜻이 아니다.
- **추적 실패 별도 확률, 저고도 고도 임계값, 재획득 가능성, 세부 판정 순서**는 미정. **8~16% 명중률에 또 무조건 추적 실패 확률을 중복 적용해 이중 감쇄하지 않는다**.
- **IR 모드에는 광학 명암비 전용 저고도 8~16% 규칙을 자동 적용하지 않는다**. IR 모드의 별도 저고도/거리·기상 성능은 후속 미정.
- 표적의 **급선회/급격한 회피기동은 기본 명중률에 추가 감쇄**한다. 필요하다면 최종 명중률이 75%/85% 아래로 내려갈 수 있고, 감쇄율·임계값은 미정.
- **락온 가능 여부 → 플레어/Lipa 기만 여부 → 유도 지속/추적 실패 여부 → 명중 판정**은 서로 다른 단계. 기만에 실패해도 자동으로 미사일이 명중하는 것은 아니다. 8~16%와 기동 감쇄의 중복 적용 방식도 후속 명시.

## 5. 미사일 직격·근접폭발 피해 및 조건부 신관 — 2026-11-21 사용자 채택

| 항목 | **9M37** | **9M37M** | 참고: 9M311 초기형 |
|---|---:|---:|---:|
| **CE 관통력** | **25 CE** | **25 CE** | 30 CE |
| **정상 직격 기본 피해** | **375HP** | **375HP** | 415HP |
| **근접신관 정상 작동 시 기본 폭발 피해 범위** | **140~245HP** | **140~245HP** | 185~285HP |
| **근접신관** | **조건부 확률 판정** | **조건부 확률 판정** | 조건부 확률 판정 |

- **9M37·9M37M은 탄두/고폭 피해 수치를 동일하게 사용**한다. 두 미사일의 차이는 앞 절에서 채택한 탐색기 모드·기본 명중률·플레어 저항성/IRCCM에 있다.
- [9M311 신관·피해 판정](9M311_SAM.md)의 **작동 구조를 공통 기반**으로 한다: **직격 여부 확인 → 직격이면 375HP 기본 피해/25 CE 방호 비교**, **비직격 근접 통과면 신관 유효 조건 검사 → 조건 만족 시 작동 확률 판정 → 성공 시 기본 폭발 피해 140~245HP를 조건에 따라 선정 → 대상 CE 방호력과 폭발거리로 감쇄**.
- **직격과 근접폭발은 서로 다른 피해 경로**이며 **같은 미사일의 직격 375HP에 근접 140~245HP를 중복 합산하지 않는다**. 신관 불발 또는 조건 미충족이면 **성공 근접폭발 피해를 적용하지 않는다**.
- **140~245HP는 표적 방호/실제 폭발거리 감쇄 전 기본 피해 범위**이며, 무조건 적에게 140~245HP 최종 피해를 보장하지 않는다. 어떤 조건으로 이 범위 내 값을 고를지 **미정**.
- **9M311과 약간 다르게** 하는 부분은 **① 근접신관 감지/발동 반경, ② 조건 충족 후 작동 성공률, ③ 근접폭발 거리별 피해 감쇄폭·곡선**이다. **미사일별 독립 수치·함수로 추후 설계**, 9M311 수치를 자동 복사하지 않는다. 단, 아직 **서로의 구체적인 크고 작음/수치/감쇄 형상은 확정되지 않았다**.
- **25 CE의 비행거리별 관통 처리**, 접촉신관 불발, 파편 범위·여러 표적에 대한 피해, 근접 신관 유효 거리·정밀 신관 성공률은 **아직 미정**. 9M311의 **거리무관 30 CE 설정을 9M37 계열에 자동 상속하지 않는다**.
- 이 수치는 게임 설계값이며 **실제 9M37 탄두의 실측 관통/피해량을 의미하지 않는다**. 전투 엔진 코드 미구현.

## 6. 미결정 및 다른 미사일/차량과의 경계

- 고도·시정·거리·배경별 **자동 시커 모드 선택 임계값**, 모드별 기본 명중률 범위 내 보간, 저고도 추적실패 별도 확률·회복 가능성, 급기동 감쇄 계수 미정.
- **게임 CE 25·직격 375HP·근접폭발 기본 140~245HP는 두 미사일 공통 사용자 채택값**. 시커 포착 거리/각도·발사 가능 영역, 순항/종말 비행 속도·기동 한계, 신관 **반경·작동 확률·폭발 거리 감쇄곡선**, SAM 사거리와 재장전 시간 등은 미정.
- 9M333 및 타 개량탄의 1989년 배치·M2 호환성·시커 방식 **자동 확정하지 않음**.
- **기본 MT-LB 300HP**와 스트렐라-10M2 **325HP**는 서로 다른 독립 차종 데이터. **9M311 무선 지령 SAM은 플레어·Lipa/이 규칙에 자동 편입하지 않음**.
- **게임용 설계 아카이브만 갱신, 전투 엔진 코드 미구현**.
