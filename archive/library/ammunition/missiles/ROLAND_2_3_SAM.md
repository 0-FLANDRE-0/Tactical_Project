# TACTICAL 1989 — Roland 2 / Roland 3 자주방공 미사일 정본

> **2026-11-21 사용자 채택 게임 수치.** Roland 2/3 미사일의 **최대 사거리 6,300m/8,000m**, **CE 방호 관통·직접 파공 지표 30/35 (거리 무관)**, **정상 직격 기본 HP 피해 395/420**, **근접신관 작동 성공 시 기본 폭발 피해 155~295/180~325 HP**. **명중률·추적·신관 세부 확률과 작동반경은 아직 미정**. 실물 성능 실측이 아닌 TACTICAL 게임 설계, **코드 미구현**.

**탑재 차량:** [Marder 기반 Roland 2, 525HP](../../vehicles/1989/air_defense/ROLAND_2_MARDER.md) · [공통 레이더 탐지/추적](../../systems/air/RADAR_SEARCH_TRACKING.md) · [9M311 무선지령유도·신관 피해 분기 기준](9M311_SAM.md) · [공중 피해 규칙](../../systems/combat/AIR_TARGET_DAMAGE.md).

## 1. Roland 2/3 게임 전투 제원 — 사용자 채택

- **Roland 1/2는 역사적으로 사격통제/추적 체계의 명칭으로도 쓰인다.** 본 문서의 **Roland 2/3은 사용자 대화에서 합의한 게임용 미사일 성능 구분**을 기록하는 것. 외부 출처의 형식명·실제 동시 호환/실배치를 독자적으로 확정하지 않는다.
- **Roland 2는 기본 탄종으로 취급하는 방향**, **Roland 3의 1989-06-20 실제 서독군 롤란드 차량 지급 여부·비율은 미검증/미정**. 데이터 존재를 실편제 기본 지급으로 자동 확대하지 않는다.
- **30/35 CE는 거리별 감소 없음**: 일반 탄약 거리별 관통 외삽과 구분하는 사용자 확정 예외. CE는 미사일 자체 기본 HP 피해와 동일한 지표가 아님.

## 2. 비행/유도 구조 — 9M311 로직 재사용, 성능 독립

- **수색 성공 ≠ 정밀 추적 성공**. [공통 추적 정본](../../systems/air/RADAR_SEARCH_TRACKING.md)대로 탐지와 레이더/광학 정밀 추적을 분리하고, 표적 및 미사일 위치 정보를 이용해 **발사 후 지속 무선 지령유도**한다. 따라서 발사 후 망각(Fire-and-forget) 아님.
- 레이더/광학 추적은 **발사대 측 추적 센서**의 동작이다. 미사일이 자체 IR 시커로 추적하지 않으므로 **플레어·Lipa·AN/ALQ-144·IRCCM ON/OFF·플레어 저항성(%)**을 롤란드에 자동 부여/적용하지 않는다.
- 기존 [9M311](9M311_SAM.md)의 **추적·LOS·유도오차 및 직격/근접 피해 분기 방식**을 재사용하되, **초기 9M311의 레이저 근접신관을 롤란드에 그대로 복제하지 않음**. 롤란드용 **레이더 근접신관 조건/성공률/반경**은 별도 미정.
- 탄속·가속도·선회력·유도 지연·지상 사통 추적 유지 조건·레이더/광학별 추적 정확도·기본 명중률·급회피 감쇄·거리별 명중률·최소 사거리·교전 고도 범위는 **후속 결정**.

## 3. 직격/근접 신관 피해 분기 — 사용자 채택 구조

1. **정상 직격 시** 탄종별 **30/35 CE**를 피격 표적 방호력과 비교하고 **395/420 HP**를 기본으로 해당 고폭·직격 피해 감쇄 규칙을 적용한다. 정상 직격 피해를 자동 확정 격추율로 쓰지 않는다.
2. **직격이 없고 근접신관 유효 조건을 충족했을 때만** 별도의 **신관 작동 확률**을 판정한다. 작동하면 **155~295 / 180~325 HP 구간의 조건별 기본 폭발 피해**에서 게임상 기폭거리/상황에 맞는 값을 정하고 **표적 CE 방호력 및 폭발거리**로 감쇄한다. 신관 발동 실패에는 이 성공 근접폭발 피해가 없음.
3. **한 발의 직격+동일 사건의 근접폭발 피해를 중복 가산하지 않는다**. **근접 구간 수치 범위는 자동 무작위 최종 데미지가 아니며**, 아직 거리별 선택식 및 신관 확률은 미정이다.
4. **공중 표적 비관통 직격 및 AP계열 과관통 기본 HP 피해 25% 하한**은 [공중 공통 규칙](../../systems/combat/AIR_TARGET_DAMAGE.md)대로 필요한 경우에만 적용한다. **근접폭발 자체는 직격 25% 하한 적용 대상이 아니다**.

## 4. 기존 헬기와의 수학적 비교 (기본 피해 기준, 실제 명중/최종 피해와 구분)

- **AH-64A:** **325HP·20(20) KE(CE)**. 30/35 CE 모두 장갑 수치보다 높다. **정상 관통 직격이 기본 피해 395/420 HP대로 들어간다는 가정**에서 둘 다 1발 격추 가능하나, 명중과 최종 감쇄는 별도.
- **Mi-24D/V/P:** **400HP·방향별 25(25)/18(18)/10(10) KE(CE) 확률장갑**(2026-11-23 기체 정본). Roland 2/3의 **30/35 CE 모두 현행 장갑 등급을 관통**. **Roland 2 정상 직격 395HP는 무손상 400HP보다 5HP 낮아 단발 확정 격추 아님**, Roland 3 정상 직격 420HP는 기본값상 초과. **실제 피해 가감/직격 여부는 별개**.
- **Roland 3 근접 상한 325 HP는 AH-64A 체력과 일치하지만**, 이 값은 CE·폭발거리 감쇄 이전의 기본 상한이라서 **최종 325HP를 보장하거나 무손상 아파치 즉사 확률을 뜻하지 않는다**.
- 9M311 공통 기준 **30 CE·415HP 직격·185~285HP 근접 기본**과 나란히 비교하되 **9M311의 신관/추적 수치·레이저 근접 방식은 롤란드에 복사하지 않는다**.

## 5. 후속 미정/보존 경계

- **Roland 2/3 기본 명중률**(무기동/약기동 표적 기준 후보 포함), 레이더/광학 추적 성능, 거리·기동·사통·지형/LOS 추적 손실계수는 미정.
- **근접신관 확률·거리·고폭 피해 감쇄 곡선**, 관측·추적 갱신·발사 간격, 재장전/탄약 혼합·보급, 실제 1989년 개전일 Roland 3 배치 빈도 미정.
- 이 문서는 **차량 장갑/HP를 소유하지 않는다**(차량 문서 우선). **설계 아카이브 기록만 수행했고 런타임 게임 코드·프리셋은 변경하지 않았다**.
