# TACTICAL 1989 — AIM-9L Sidewinder 공대공 미사일 정본

> **2026-11-27 사용자 채택 게임 제원 — 설계 문서 기록, 런타임 미구현.** 1989년형 **A-10A Thunderbolt II의 자체 방어용 단거리 공대공 미사일 AIM-9L**을 채택한다. 기본 명중률·플레어 저항성·관통/피해는 **MIM-72C**와 같게, **최소 락온 IR=14와 IRCCM 1단계 램프형 감쇄율 60%**는 AIM-9L 고유값으로 설정한다. 실제 기체/미사일의 검증된 수치가 아닌 TACTICAL 게임용 값이다.

**연결:** [A-10A](../../vehicles/1989/air/A10A.md) · [MIM-72A/C/E/G Chaparral](MIM72_A_C_E_G_CHAPARRAL.md) · [공통 IR/CS/RCS·탐지](../../systems/air/RADAR_SEARCH_TRACKING.md) · [IR 시커 감도·플레어 방향 보정](../../systems/air/IR_SIGNATURE_LOCKON.md) · [플레어·IRCCM](../../systems/air/COUNTERMEASURES_FLARE_IRCCM_ECCM.md) · [공중 표적 피해](../../systems/combat/AIR_TARGET_DAMAGE.md).

## 1. IR 시커·락온·기만 대응 — 사용자 채택

| 항목 | AIM-9L 게임값 / 상태 |
|---|---|
| 분류·용도 | **단거리 공대공**, A-10A 자체 방어용 |
| 유도 채널 | **적외선(IR)**, 발사 후 자체 추적 |
| **최소 락온 실효 IR** (`IR_min_lock`) | **14** [확정] |
| 락온 방향 | **전방위** [정성 분류 확정] |
| **기본 명중률** | **75~100%** [확정] |
| **플레어 저항성** | **55%** [확정] |
| **IRCCM** | **1단계** [확정] |
| **램프형 IRCM 기만확률 감쇄율** | **60%** (×0.40 잔존) [확정] |
| Lipa / AN/ALQ-144 감쇄 전 기만확률 | **90%** (공통 기준) |
| **Lipa / AN/ALQ-144 최종 기만확률** | **36%** (=90%×(1−0.60)) [확정 설정의 계산 결과] |

- 관측 방향에 따른 표적의 기존 방향별 기본 IR → 노출면 가중 → **환경·부분 은폐까지 반영한 최종 `IR_effective`**와 `IR_min_lock=14`를 비교한다. `IR_effective ≥ 14`이면 **열 신호 조건만** 충족한 것이며, **유효 사거리·시야/발사 조건·센서별 LOS**는 별도다. '전방위'는 고정 360° 락온 보증이나 별도 고정 각도 게이트가 아니다.
- **기본 명중률 75~100%**는 정상 유도·무기동/약기동 표적 기준 범위로, 락온 확률·최종 격추율과 다르다. 거리·고도·표적 기동·급회피·환경·추적 안정성에 따른 범위 내 선택식과 추가 감쇄는 미정.
- **플레어 저항성 55%**는 플레어 기만확률 감쇄용이고, **IRCCM 1단계·60%**는 Lipa/AN/ALQ-144 등 **램프형 능동 IRCM**에 대한 별도 기만확률 감쇄율이다. 두 값을 서로 합산하지 않는다. 플레어 기만은 [공통 정본](../../systems/air/COUNTERMEASURES_FLARE_IRCCM_ECCM.md)의 **기본 기만확률 × 경과시간별 효과 × (1−0.55) × 최종 실효 IR 기반 방향계수**, 유효 발당 최대 1회 판정을 따른다.
- 1단계 60%는 공통 1단계의 허용 범위 내에서 이 형식에 선택한 **개별 확정 감쇄율**이다. **MIM-72C는 55%**이므로 동일한 IRCCM 단계여도 **AIM-9L의 램프형 기만 잔존 확률은 36% / MIM-72C는 40.5%**로 구별한다. 플레어 저항성은 둘 다 55%다.

## 2. 탄두·관통·직격/근접폭발 피해 — MIM-72C와 동일 게임값 채택

| 항목 | AIM-9L 게임값 / 상태 |
|---|---|
| **CE 관통력** | **25mm CE** [확정] |
| **직격 기본 피해** | **360HP** [확정] |
| **근접폭발 기본 피해 범위** | **130~245HP** [확정] |
| 탄두 효과 모델 | **고폭파편 계열 게임 피해 처리** [MIM-72C와 동일 게임 수치 채택] |

- **직격** 시 표적 방호력과 **25 CE**를 비교하여 기본 **360HP** 및 기존 공중 피탄/비관통 직격 공통 규칙에 따라 피해 처리한다.
- **실제 비직격** 시 자동 피해가 아니다. 근접신관 감지·작동/정상 기폭 조건을 충족한 경우에만 **기본 130~245HP**에서 조건별 피해를 산정한 후 **폭발거리·표적 CE 방호력 감쇄**를 적용한다. 근접신관의 **감지거리·작동 성공률·폭발거리 곡선은 미정**이며 MIM-72C 값을 임의 복사하지 않는다.
- 한 발의 **직격 피해와 근접폭발 피해를 중복 가산하지 않는다**. 근접폭발에 직격 전용 공중 피해 하한을 자동 적용하지 않는다. **25 CE의 거리별 변화 여부**도 아직 미정.
- 직격 360HP·근접 130~245HP·25 CE를 **MIM-72C와 동일하게 설정한 것은 사용자 게임 설계 결정**이다. 실제 AIM-9L과 MIM-72C의 탄두 실측 성능 또는 기계적 호환성이 같다는 뜻이 아니다.

## 3. A-10A 탑재·운용과 미정 목록

- **A-10A에 AIM-9L 운용 허용**을 확정한다. 역할은 **적 헬기·적 항공기에 대한 자체 방어/단거리 공대공 대응**. 다른 A-10 무장(GAU-8/A, AGM-65B/D/G)의 기존 수치와 운용 제약은 변경하지 않는다.
- **2발 장착**은 대화에서 나온 **권장 구성 후보**로 기록하되, **최종 장착 수량·하드포인트/발사대 조합·다른 무장과의 동시 적재 제한은 미확정**으로 둔다.
- **미정:** 유효/최대 사거리, 미사일 속력·가속·기동 한계, 최대/최소 사격 고도·시야각·발사 자세, 발사 간격·실제 탑재 수량, 근접신관 감지반경·작동률, 직격/근접폭발 거리별 세부 효과, 실제 확률곡선·추적 상실/재획득 및 AI 운용 로직.
- 모든 내용은 **문서상 사용자 확정 게임 설계값**과 **미정 항목**의 구분이며 **실행 코드·플레이테스트 미적용**.
