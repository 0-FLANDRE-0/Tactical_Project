# TACTICAL 1989 — 9M311 지대공미사일(SAM) 게임 설계 정본

> **2026-11-21 사용자 채택.** 초기형 2S6에 탑재하는 **9M311**, **거리 무관 30 CE**, **정상 직격 기본 피해 415HP**, **근접신관 성공 시 185~285HP의 기본 폭발 피해 범위**, **표적 CE 방호력과 폭발거리 등에 따른 고폭 피해 감쇄**, **근접신관 작동 확률 판정**을 기록한다. 미사일 유도 체계를 게임에 별도로 구현할 설계 방향. **작동 확률·발동 거리·세부 피해곡선·가속/조향·명중률/추적 상실 조건은 미정**, 코드 미구현.

## 1. 식별·1989 초기형 참고 제원

| 항목 | 실물 참고 / 게임 상태 |
|---|---|
| 체계/차량 | **2K22 / 2S6 초기형, 1989년 기준** |
| 미사일 | **9M311 초기형** (후기 9M311M/M1과 혼동 금지) |
| 장착 수 | **4발, 좌우 각 2발** — 초기형 참고, 게임 설계 출발값 |
| 유도 | **SACLOS 방식의 표적 지속 추적 + 미사일 위치 추적 + 무선 지령 조종** |
| 유도 지속 | **발사 후 망각 아님**. 유도·추적/LOS 상실 효과는 추후 구현 |
| 최대 거리 | **8,000m (초기형 참고)**. 후기 M1 10km와 구별 |
| 최소거리 | 실물 출처별 편차 존재(약 1.3~2.5km 등) → **게임값 미정** |
| 고도 | 약 15m~3,500m 실물 참고, **게임 확정 전** |
| 비행속도 | 실물 약 900~910m/s 최고 속도 참고. **게임의 가속/감속·평균속도 미정** |
| 탄두 | 고폭파편·연속봉(continuous rod) 계열 |
| 신관 | **접촉 + 초기형 레이저 근접신관**. 후기 M1 무선 근접신관과 구별 |

- 미사일 위치와 목표의 상대 오차, 표적의 추적 성공, 외부 사통의 무선 지령, 유도 지연·조향 능력·LOS 등을 개별 상태로 확장. **레이더로 발견만 한 표적을 자동 정밀추적/명중시키지 않는다.**
- [공통 레이더 수색·추적](../../systems/air/RADAR_SEARCH_TRACKING.md)과 연결하며 방공 유도 무기 특유의 로직은 **아직 신규 구현 없음**.
- **기만체 체계 구분:** [항공 플레어/IRCCM 및 향후 ECCM 공통 규칙](../../systems/air/COUNTERMEASURES_FLARE_IRCCM_ECCM.md)의 **플레어 저항성(%)을 이용한 플레어 독립 기만 판정 및 IRCCM ON/OFF를 이용한 Lipa 면역 규칙은 IR/광학 탐색기 계열의 해당 교전 모드에만 적용**. **9M311은 외부 표적 추적·무선 지령 방식이므로 IR 플레어, 플레어 저항성(%) 또는 Lipa용 IRCCM ON/OFF를 자동 부여하지 않는다**. 외부 추적·지령 링크 교란과 ECCM은 장래 별도 설계 미정.

## 2. TACTICAL 사용자 선택 게임 전투 값

| 항목 | 확정 게임 설정 |
|---|---|
| **관통력/직접 파공 지표** | **30 CE (거리 무관)** |
| **정상 직격 기본 피해** | **415HP** |
| **근접신관 발동 성공 시 기본 폭발 피해 범위** | **185~285HP** |
| **근접신관 작동** | **일정 조건 만족 시 확률 판정** (확률값 미정) |
| **직격/근접 피해 판정** | **별도 경로**. 동일 사건 415 + 185~285 이중 가산 금지 |
| **방호력 감쇄** | **표적 CE 방호력에 따른 고폭 피해 감소**; 직격·근접의 상세 판정별 곡선 미정 |
| **거리 감쇄** | **9M311의 30 CE는 모든 비행거리에서 동일** — 명시적 거리무관 관통력 예외 |
| **공중 입사각** | 공통 규칙상 **입사각 미판정, 0° CE 판정** |
| **공중 비관통 직격 25% 하한** | 직격이 실제 발생한 비관통 분기에서 **415×0.25 = 103.75HP** 최소치 |
| **근접폭발 25% 하한** | **비직격이므로 자동 적용하지 않음** |

- **30 CE / 415HP / 185~285HP**는 사용자의 TACTICAL 게임값이다. 워썬더 9M311 표의 **39mm 관통력 등과 별개**이며 워썬더 값을 무단 덮어씌우지 않는다.
- **185~285HP는 확률적으로 고른 최종 피해가 아님**. 우선 **신관이 정상 작동했을 때의 방호력 감쇄 전 기본 폭발 피해 구간**으로 기록. 근접 통과 거리·기폭 위치·파편 범위에 따라 범위 내 기본값을 어떻게 선택하고, 표적 CE와 실제 폭발거리로 얼마를 감쇄할지 **미정**.
- 신관이 **발동하지 않은 근접 통과**는 성공 근접폭발 피해를 적용하지 않는다. 불발 잔여 효과/미사일 자체 충돌 여부는 추후 세부. **추적 실패, 비직격과 신관 불발, 신관 발동 이후 피해는 별도 확률/판정 단계**.

## 3. 피해 처리 분기 — 중복 합산 금지

1. **표적 발견 → 정밀추적 확보 → 사격 허용 판단 → 미사일 발사**, 발사 후 **무선 지령 유도 지속**.
2. 비행 중 표적 운동·지형 LOS·유도/추적 오류를 반영. 실제 **직격 발생** 시 CE30과 표적 CE 방호 비교, 정상 직격 기본 **415HP**부터 탄종 고폭 피해/방호력 감쇄 판정. **접촉신관 이상은 별도 미정**.
3. **직격은 없지만 근접신관 작동 조건을 충족하면 발동 확률 판정**, 정상 발동 시 **기본 185~285HP 중 조건별 값**을 골라 대상 CE 방호력·폭발 거리 감쇄. 근접신관 실패 시 이 폭발 피해 없음.
4. **한 발의 직격 피해 + 같은 폭발의 근접 피해 중복 합산 금지**. 이후 다중 파편, 지면 충격·범위표적, 근접 구간 동시표적은 추후 별도.

## 4. 현재 헬기와의 비교 — 수학적 예시 (실전 격추율 아님)

- AH-64A **325HP / 단일 20(20) KE(CE)**, Mi-24D/V/P **400HP / 방향별 25(25)·18(18)·10(10) 확률장갑**(2026-11-23 최신 기체 정본). 9M311 **30 CE**는 두 기체의 모든 현행 장갑 등급을 넘으므로 **정상 직격 시 415HP가 유지된다는 단순 전제에서는 두 기체 모두 1발 격추 가능**. 그러나 실제로 유도/직격을 보장하거나 신관 작동확률·고폭 감쇄가 확정되었다는 뜻은 아니다.
- 근접신관 **185~285HP 기본 범위**만으로는 무손상 아파치 325HP 또는 하인드 400HP를 1발 확정 격추하지 못한다. **CE 방호 감쇄를 적용하면 실제 피해가 더 작아질 수 있다**.
- 근접폭발만 발생한 경우 [공중 직격 최소 25%](../../systems/combat/AIR_TARGET_DAMAGE.md)를 적용하지 않는다.

## 5. 미정 / 주의 사항

- **신관 발동 확률, 레이저 근접 작동 반경의 게임값, 미사일 아밍 거리/지연, 신관 실패·작동 이상, 폭발거리별 피해분포(185~285HP 선택 규칙) 및 표적 CE와 연결하는 고폭 감쇄 함수** 미정.
- 추적/LOS 유지 시간, 명중률, 3D 비행 모델·방공 유도 AI, 미사일 발사 간격, 외부 재보급/재장전 시간·비용, 표적별 고도·속도 제한/최소 사거리 미정.
- **역사 자료:** [9M311 변형별 신관·유도·속도](https://weaponsystems.net/system/1433-9M311) · [초기형 2S6/4발·후기형 구분](https://en.wikipedia.org/wiki/2K22_Tunguska) · [War Thunder 2S6의 9M311](https://old-wiki.warthunder.com/index.php?printable=yes&title=2S6).
- 최신 [장거리 관통력 공통 규칙](../../systems/combat/RANGE_PENETRATION_EXTRAPOLATION.md)의 **거리변화 관통력 처리**는 일반 탄약용; **이 미사일은 사용자가 특별히 30 CE 거리 고정으로 확정**했으므로 그대로 유지한다.
