# 전차별 기본 탄종 지정 — NATO / 소련

> **3단계 이관본.** [원본 탄약 기준표](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/ammo/README.md)의 §5와 §7에서 **기본 지급 탄종 이름**을 이관. 실제 발수·구획·임무별 96개 프리셋은 [별도 검증 표](../../presets/1989/README.md) 참조. 차종별 호환성·희귀탄·미정 범위는 원문 유지.

## 5. NATO 전차별 기본탄

| 전차 | 중장갑(대물) 기본 슬롯 | 경장갑(대인) 기본 슬롯 |
|---|---|---|
| M1 | M774 | M456A2 |
| IPM1 | **M833** | M456A2 |
| M1A1 | M829 | M830 |
| M1A1 HA | M829A1 | M830 |
| M60A3 TTS | M735 | M456A2 (HEP 선택: M393A2) |
| Leopard 1A1A1 | DM23 105mm | DM12 105mm (HEP 선택: DM512) |
| Leopard 1A5 | DM33 105mm | DM12 105mm (HEP 선택: DM512) |
| Leopard 2A3 | **DM33A1 120mm** | DM12A1 120mm |
| Leopard 2A4 (C-Type) | **DM33A1 120mm** | DM12A1 120mm |
| Leopard 2 KVT (1989) | **DM33A1 120mm** | DM12A1 120mm |
| M48A2GA2 | DM13 105mm | DM12 105mm (HEP 선택: DM512) |

- **IPM1의 기본탄은 M774가 아니라 M833**. 대화 중 사용자가 직접 정정한 사항.
- 두 슬롯은 물리적 탄종별(AP/HEAT) 분리가 아님. **각 슬롯에 복수 탄종 적재 가능**으로 개정. HEAT를 중장갑 슬롯에 사용할 수 있으며 HEP 등의 탄종도 역할에 따라 포함할 수 있음. 기존 표의 '기본 탄약'은 **자동 적재 프리셋의 대표 기본탄**이지 유일하게 실린 탄약이라는 뜻이 아님.
- 전차별 선택 탄약 범위는 **물리적 주포 호환성**과 **시나리오/부대별 보급 허가**를 분리. 예를 들어 M1에서 M728·M735·M774·M833·M900의 단계적 선택을 구상했고, 추후 M60 계열에는 M728/M392A2 같은 구형탄을 선택지로 주는 구상. 이는 실제 물리적 발사 불가능 주장과 다름.
- 105mm/120mm처럼 이름이 겹치는 DM13, DM23, DM33, DM12는 **구경별 별도 내부 ID**가 필요. DM33_105mm(KE 365)는 이번 변경 대상이 아니며 DM33_120mm(KE 450)와 DM33A1_120mm(KE 470)를 별개 ID로 구분.

## 7. 소련 전차별 기본탄

> **게임 내 1989년 전시 편성용 기본 대표탄**. 전차 생산 시점의 실제 지급 탄약목록이라는 주장이 아니며, 전차별 주포탄 사용 가능 연도의 상한도 아니다. 3BM15를 T-64A(1969)에 지정한 것은 구형 차체를 1989년에 운용할 때의 게임 기본 프리셋이며 1969년 실전 지급탄이란 뜻이 아님. 현재는 **탄종 배정만 확정**하고 탄수·적재 비율은 아직 정하지 않음.

|---|---|---|---|
| T-64A (1969) | 3BM15 (390) | 3BK14M (480) | — |
| T-64A (1975) | 3BM15 (390) | 3BK14M (480) | — |

- **HE-FRAG 3OF19/3OF26:** AP/HEAT/HE/ATGM별 적재 발수는 §11에서 확정됐지만, HE 구획에 넣을 3OF19/3OF26 세부 선택 비율은 미정이다. **3Sh7 APERS**는 선택 탄약으로 유지.
- **기본 탄약 ≠ 독점 탄약:** 현재 목록의 다른 일반 125mm탄도 1989년 시나리오 재고와 비용/희소성 조건 아래 교체·혼합 가능. MZ/AZ 장전장치별로 이 목록의 기본 날탄을 강제 제한하지 않음.
- **ATGM 예외:** Kobra 계열(T-64B/BV·T-80B/BV), Svir(T-72B), Refleks(T-80U)는 각 유도체계와 호환되는 탄종만 사용. T-64A·T-72A는 유도 장비 없음.
- **미사일 희귀/보류:** 9M112M2·9M124는 자동 기본 지급하지 않고 후보 상태 유지. 9M119M은 1989년 편성에서 제외.
- **미확정:** 슬롯별 복수 탄종 편집 UI, 희귀탄 재고 및 보급 제한의 상세 규칙, 세부 HE 탄종 배분. **차량별 총탄수·구획별 프리셋 발수는 §11에서 확정됨.**

- **2026-11-06 설계 변경:** 중장갑(대물)/경장갑(대인) 슬롯 각각 **복수 종류 탄약 적재 가능**. 전차마다 기본 혼합 적재 프리셋 제공, 플레이어는 배치 또는 재보급 시 변경. 전투에서는 AI가 숙련도에 따라 탄종 선택을 잘하거나 실수하는 시스템 구상.
- 한 슬롯에 넣을 수 있는 최대 탄종 수, 자동 선택 UI, 재보급 잔탄 처리와 희귀탄 장착 차량 대수 계산 규칙은 미정. 차량별 구획의 AP/HEAT/HE/ATGM 발수는 §11에서 확정됐다.
