# TACTICAL 1989 — 게파르트 35mm KDA 탄약 DM21·DM13A1·DM23 정본

> **2026-11-21 사용자 제공 대화 복원·이미지 2장 수치 직접 반영.** 탄속·탄종별 기본 HP 피해, DM13A1/DM23의 10/100/500/1000/1500/2000m × 0/30/60° 관통력, DM21의 지상·공중 별도 CE 피해곡선 기록. 사진의 **원본 정수 mm를 5mm로 재반올림하지 않는다.** [게파르트 차량](../../vehicles/1989/air_defense/GEPARD.md) · [탄띠 프리셋](../../presets/1989/GEPARD_BELTS.md) · [공중 비관통 공통 정본](../../systems/combat/AIR_TARGET_DAMAGE.md).

## 1. 35mm 탄약별 기본 확정값

| 탄약 | 종류 | 포구초속 | 기준 HP 피해 | 관통 및 특성 |
|---|---|---:|---:|---|
| **DM21 HEI** | 폭발성 고폭소이탄 | **1,175m/s** | **172 HP** | 지상 직접 파공 한계 **CE 11mm**, 공중 별도 비관통 폭발 피해곡선 |
| **DM13A1 SAPHEI-T** | 폭발성 반철갑·관통 후 폭발 | **1,175m/s** | **152 HP** | **KE** 관통 후 신관 작동 시 152 HP; 극심한 과관통 시 신관 불발 가능 |
| **DM23 APDS-T** | 비폭발성 순수 철갑 | **1,385m/s** | **96 HP** | **KE** 관통 + 기관포 과관통 감쇄 |

## 2. DM13A1 SAPHEI-T — 이미지 원본 KE 관통력 (mm RHAe)

| 거리 | 0° | 30° | 60° |
|---|---:|---:|---:|
| **10m** | **68** | **52** | **26** |
| **100m** | **66** | **50** | **25** |
| **500m** | **57** | **44** | **22** |
| **1,000m** | **47** | **38** | **19** |
| **1,500m** | **39** | **32** | **16** |
| **2,000m** | **32** | **28** | **14** |

- 정상적인 KE 관통 이후 **신관이 작동하면 152 HP**. 기관포 철갑탄의 통상 과관통 피해 감쇄 곡선은 **적용하지 않는다**.
- 다만 **극심한 과관통으로 신관이 불발**할 수 있으며, 임계 관통 여유·신관 작동 확률·불발 시 피해 감소계수는 **미정**이다.
- **공중 비관통:** 기존 논의의 **102 HP 외부 폭발 피해**를 기본안으로 보존. 모든 공중장비·전 탄종에 적용되는 **25% 하한 38 HP**보다 높다. 기폭·도탄 예외 조건은 미정.
- **지상 비관통:** KE 관통 실패 후 외부 기폭이 정상 발생한 경우에는 **CE 방호력 증가에 따라 DM21의 지상 비파공곡선과 같은 구간·감소 성향으로 약한 외부 폭발 피해**를 부여한다는 최신 사용자 결정.
- **지상 비관통 개별 수치 아직 미확정:** DM21 노드에 기본 피해비 `152/172`를 곱하는 방식(예: CE 13/15/20/25mm에서 약 14/7/2/0 HP)은 **이전 어시스턴트가 제시한 계산 예시이며 사용자가 확정한 숫자가 아님**. 사용자가 확정한 것은 **DM21처럼 장갑이 두꺼워지면 피해가 급감하는 방향**이다. 승인 전까지 임의로 14/7/2/0을 정본 값으로 고정하지 않는다.

## 3. DM23 APDS-T — 이미지 원본 KE 관통력 (mm RHAe)

| 거리 | 0° | 30° | 60° |
|---|---:|---:|---:|
| **10m** | **127** | **116** | **48** |
| **100m** | **125** | **115** | **48** |
| **500m** | **118** | **108** | **45** |
| **1,000m** | **110** | **101** | **42** |
| **1,500m** | **102** | **94** | **39** |
| **2,000m** | **95** | **87** | **36** |

- 관통 후 **기준 96 HP × 기관포 전용 과관통 배율**. [기관포 피해 규칙](../../systems/combat/AUTOCANNON_DAMAGE.md)에 따라 치명타 없음, 극심한 과관통 시 큰 감쇄. 정확한 곡선·하한 미정.
- **2026-11-21 최신 사용자 확정:** 비폭발성 대장갑용 DM23도 **공중장비 직접 비관통 명중 시 기본 96 HP의 최소 25% = 24 HP**를 적용한다. 관통 성공 후 AP 과관통 배율로 감쇄된 최종 피해에도 **최소 24 HP** 하한을 적용한다. **지상장비에는 이 공중 전용 하한을 적용하지 않으며**, 기존 기관포 과관통 곡선 자체와 96 HP 기본값은 유지한다.
- 두 KE 표 모두 **6거리×3각도 원본 18개 값**만 확정. 2,000m 초과~게파르트 최대 대공 4,000m의 관통력 노드·외삽 공식은 **미정**, 2km 표 값이 포 사거리 상한이라는 의미가 아니다.

## 4. DM21 HEI — CE 직접 파공과 지상 외부 폭발 피해

- **직접 파공 한계: CE 11mm**, 한계 이내 표적에 **172 HP**. 거리별 직접 파공 한계 변화는 정하지 않았으며 고정 기준 사용.
- 지상에서는 **11mm 초과 시 폭발 피해가 급락**하는 설계. 다음 값은 최신 대화에서 채택한 피해 기준점. 13mm 노드는 실제 장갑이 5mm 단위인 현재 데이터에서는 사용되지 않을 수 있으나 보존한다.

| 지상 표적 CE 방호력 | 최종 DM21 피해 | 판정 |
|---|---:|---|
| **11mm 이하** | **172 HP** | 직접 파공 |
| **13mm** | **16 HP** | 비파공 외부 폭발 |
| **15mm** | **8 HP** | 비파공 외부 폭발 |
| **20mm** | **2 HP** | 비파공 외부 폭발 |
| **25mm 이상** | **0 HP** | 비파공 |

- CE 11~13mm 사이 **11mm 초과 직후 급락/보간의 구체 함수 미정**. 기존 대화의 12mm에서 94 HP 같은 단순 선형 보간값을 확정하지 않는다.
- 지상 차량에 **공중용 최소 25% 피해 하한을 적용하지 않는다**.

## 5. DM21 HEI — 공중 외부 폭발 피해 전용곡선

| 공중 표적 CE 방호력 | 기존 설계 폭발 피해 노드 | 비관통 최소 25% 적용 후 최저 실제 피해 |
|---|---:|---:|
| **11mm 이하** | **172 HP** | **172 HP** |
| **15mm** | **167 HP** | **167 HP** |
| **20mm** | **160 HP** | **160 HP** |
| **25mm** | **154 HP** | **154 HP** |
| **35mm** | **130 HP** | **130 HP** |
| **50mm** | **95 HP** | **95 HP** |
| **75mm** | **40 HP** | **43 HP** |
| **100mm** | **10 HP** | **43 HP** |

- **최소 25% = 172×0.25 = 43 HP**는 **모든 공중장비·모든 탄종에 대한 최신 비관통 직격 하한**의 DM21 적용 사례이다. 별도 고폭 비파공 계산값이 더 높으면 그 값을 사용하고, 43 HP를 추가 가산하지 않는다.
- 원래 폭발 곡선 **75mm 40 / 100mm 10** 노드는 기록상 그대로 보존한다. 위 오른쪽 열은 공중 하한을 적용한 결과다. **지상 곡선에 공중값을 적용하지 않는다**.
- 중간 CE의 보간·높은 방호력·예외(도탄, 신관, 모듈, 파편) 세부는 아직 미정. 폭발성 HEI에는 APDS용 과관통 곡선을 적용하지 않는다.

**2026-11-21 최신 공중 공통 판정:** 게파르트 DM21·DM13A1·DM23이 **공중장비**에 직격하면 **입사각을 계산하지 않고 거리별 0° KE/CE 기준값**을 사용한다. DM13A1/DM23의 30°·60° 수치는 **지상 차량용**으로 보존한다. 공중 대상 각도 도탄/각도 신관 실패 없음; 기체 이동·산포·3D 경사거리·거리 감쇄·신관의 각도 외 불발 가능성은 유지한다. [공중 피해/입사각 정본](../../systems/combat/AIR_TARGET_DAMAGE.md).

**2026-11-21 IFV 고폭탄 공통화:** DM21 지상·공중 피해곡선이 [IFV 고폭탄 공통 템플릿](../../systems/combat/IFV_HE_DAMAGE_CURVES.md)의 기준이다. **DM21의 개별 고정 CE 11mm 파공·172 HP·곡선 원본 노드 자체는 변경하지 않으며**, 다른 IFV 고폭탄에 원본 수치와 관계없이 172 HP/11mm를 복사하지 않는다.

## 6. 탄종별 판정 경계와 구현 상태

1. 명중 여부, 피격 구역·각도는 별도 판정. **KE 관통형 DM13A1/DM23**은 사진 관통력표와 표적 **KE**를 비교한다.
2. DM13A1 **KE 관통 성공 + 정상 기폭 = 152 HP**; 극심한 과관통은 **과관통 배율이 아니라 신관 불발 분기**. KE 비관통 + 외부 기폭은 표적 **CE**를 기준으로 감소하는 고폭 피해.
3. **DM21 HEI**는 직접 파공 한계 **CE 11mm**와 **지상/공중 각각의 폭발 피해곡선**을 사용.
4. **DM23 APDS-T**는 순수 KE 관통·과관통으로 처리하고 폭발 피해나 스폴 분기를 부여하지 않는다.
5. **HEP/HESH의 내부 스폴·비파공 420→100 HP 분기**, 소련 125mm HE-FRAG 512/612 HP를 35mm에 자동 복사하지 않는다.
6. 기록된 관통력과 HP는 **사용자 지정 게임 밸런스 데이터**이지 실차의 공식 피해 실험값이 아니다. **게임 코드 미구현**.
