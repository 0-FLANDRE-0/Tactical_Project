# TACTICAL 1989 — 퉁구스카 30mm 2A38 기관포 탄약 정본

> **2026-11-21 사용자 채택:** 초기형 2S6의 **30mm 2A38 쌍열 ×2기(총 4포신), 합계 5,000RPM, 전체 1,936발**. **HEF-I 152HP, HEF-T 129HP, AP-T 83HP**. 고정 탄띠 **HEF-I→HEF-T→HEF-I→AP-T**. **KE/CE·탄속은 War Thunder 2S6 2A38 표를 참고**하고, **피해 HP는 사용자 선택 TACTICAL 게임값**이다. 현재 게임 코드 미구현.

## 1. 탄약 기본 제원

| 탄종 | 분류 | 기본 HP 피해 | 탄속 | 워썬더 TNT 환산 폭약량(참고) |
|---|---|---:|---:|---:|
| **AP-T** | 철갑예광(KE) | **83** | **970m/s** | 해당 없음 |
| **HEF-T** | 고폭파편예광(CE) | **129** | **960m/s** | 17.86g |
| **HEF-I** | 고폭파편소이(CE) | **152** | **960m/s** | 75.46g |

- TNT 환산 폭약량을 HP에 직접 환산하지 않는다. BMP-2 2A42(85/133/155HP)와는 다른 2A38용 탄약값이다.
- **AP-T는 KE, HEF-I/HEF-T는 고폭 직접 파공·폭발 효과용 CE** 지표. 고폭 CE를 HEAT 성형작약 실제 관통력으로 오인하거나 전탄 관통 때 HP 전체가 무조건 적용된다고 가정하지 않는다.

## 2. 워썬더 0° 관통/파공 수치 — 거리별 기준 노드

| 거리 | AP-T 0° KE | HEF-T 0° CE | HEF-I 0° CE |
|---|---:|---:|---:|
| **10m** | **65** | **9** | **8** |
| **100m** | **63** | **8** | **7** |
| **500m** | **53** | **7** | **6** |
| **1,000m** | **44** | **5** | **5** |
| **1,500m** | **36** | **4** | **4** |
| **2,000m** | **29** | **3** | **3** |

- **0° 기준 표만 검증·기록**. AP-T 30°·60° 각도별 원자료를 확보하지 않았으므로 숫자를 만들어 넣지 않는다. 지상 입사각은 [공통 판정](../../systems/combat/ANGLE_RICOCHET_FUZE.md)과 추후 실제 각도 노드 검증을 따르고, **공중 표적은 입사각 생략·해당 거리의 0°값** 사용.
- **2km 이후~4km**는 사용자가 채택한 [모든 탄약 공통 장거리 관통력 감쇄 방향](../../systems/combat/RANGE_PENETRATION_EXTRAPOLATION.md)에 따라 **0~2km 탄약별 감쇄 추세를 연장하고 먼 거리에서 강화 감쇄**. 각 탄의 별도 3km/4km 관통력 노드 필요 없음; **구체 공식·가속도·최저값은 미정**.
- **장거리 관통력 감쇄와 무기 자체 최대 사거리 4km는 별개**. 대공 3D 경사거리 유효 **3,000m**, 최대 **4,000m**.

## 3. 4발 고정 탄띠와 적재량

| 순번 | 탄종 | HP 피해 |
|---|---|---:|
| ① | **HEF-I** | 152 |
| ② | **HEF-T** | 129 |
| ③ | **HEF-I** | 152 |
| ④ | **AP-T** | 83 |

- **4발 반복 = HEF-I 50% / HEF-T 25% / AP-T 25%**(HE 계열 75%). [탄띠 정본](../../presets/1989/TUNGUSKA_2A38_BELT.md).
- **전체 1,936발 = HEF-I 968발 + HEF-T 484발 + AP-T 484발**, 총 **484회 완전 반복**. 포신당 **484발은 산술 환산**이며 4포신의 독립 탄창·즉응탄/준즉응탄 구획을 별도로 확정한 것은 아니다.
- 5,000RPM = **초당 약 83.33발**; 순수 연속 사격 시 전탄 소모 **약 23.232초**. 실제 점사·과열·탄걸림·급탄 불량·신뢰성 저하·냉각은 추후 시스템으로 정량화한다.

## 4. 공중 / 고폭 피해 및 미정

- 실제 **공중 비관통 직격** 및 **AP 과관통 감쇄** 결과에는 탄종 기본 HP의 **최소 25% 공통 하한** 적용: **AP-T 20.75HP, HEF-T 32.25HP, HEF-I 38HP**. 고폭 공중 폭발곡선의 정상 결과가 더 높으면 그것을 사용. 미명중은 0.
- 고폭의 **지상 급감/공중 완만 감쇄**는 [DM21 참조 기관포 HE 피해 구조](../../systems/combat/IFV_HE_DAMAGE_CURVES.md)를 이용하되, **DM21 기본 172HP/CE11을 복제하지 않음**. 개별 CE 방호 대응값·구체 보간·신관·파편 피해는 미정.
- 총열별 개별 위상·급탄계통, 탄착 산포/명중률, 과열/냉각/탄걸림, 정상 연속 발사 유지시간, 구체 신뢰성/수리시간, 30°/60° AP 표는 미정.
- **외부 출처:** [War Thunder 2S6, 30mm 2A38/2A38M1](https://old-wiki.warthunder.com/index.php?printable=yes&title=2S6). 초기형과 개량형의 역사적 구분은 [초기 2S6 차량 정본](../../vehicles/1989/air_defense/2S6_TUNGUSKA.md) 참조.
