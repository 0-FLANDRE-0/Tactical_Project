# TACTICAL 1989 — A-10A 30mm GAU-8/A Avenger 기관포·탄약 정본

> **2026-11-23 최신 사용자 채택(86HP로 최종 정정):** 1989년 A-10A의 30mm GAU-8/A 기관포를 **게임 발사속도 3,800RPM**, **PGU-14/B 계열 API 86HP/발**, **PGU-13/B 계열 HEI 144HP/발**로 기록한다. **API KE 표는 사용자 직접 제공 이미지의 6개 거리 × 3개 각도 총 18개 수치**를 원본대로 사용한다. **HEI CE 최대 8mm 및 6거리 노드 8/8/7/6/5/4mm**, **API:HEI 고정 5:1**, **동급 30mm HEI 고폭 감쇄 구조 재사용**도 2026-11-23 사용자 후속 채택이다. 앞서 비교한 API **87HP·84HP는 최종값이 아니며 사용하지 않는다**. 이 문서는 게임 설계 정본이며 **런타임 전투 코드 미구현**.

**관련 기체:** [GAU-8/A 고정 혼합급탄](../../presets/1989/GAU8_A_COMBAT_MIX.md) · [공통 기관포 고폭 피해곡선](../../systems/combat/IFV_HE_DAMAGE_CURVES.md) · [A-10A 기체/방호 정본](../../vehicles/1989/air/A10A.md) · [항공기 색인](../../indexes/AIRCRAFT_1989.md) · [기관포 AP 피해](../../systems/combat/AUTOCANNON_DAMAGE.md) · [공중 직격 피해 하한](../../systems/combat/AIR_TARGET_DAMAGE.md).

## 1. 기관포 및 실전 탄종 기본값

| 항목 | 게임 제원 / 상태 |
|---|---|
| 기체 | **A-10A Thunderbolt II**, 1989년형 |
| 기관포 | **30mm GAU-8/A Avenger**, 7총열 회전식 |
| **게임 발사속도** | **3,800RPM** [사용자 채택] |
| 초당 이론적 발사량 | **약 63.33발/초** (3,800÷60, 참고값) |
| **API (PGU-14/B 계열) 기본 HP 피해** | **86HP/발** [사용자 최종 채택] |
| **HEI (PGU-13/B 계열) 기본 HP 피해** | **144HP/발** [사용자 채택] |
| API 주 관통계열 | **KE**, 아래 사용자 이미지 관통표 사용 |
| HEI 직접 파공 CE | **거리별 8/8/7/6/5/4mm** (10/100/500/1,000/1,500/2,000m) [확정] |
| HEI 고폭 피해곡선 | **3UOF8 30mm HEI의 DM21 기반 지상·공중 감쇄 구조 재사용**; 개별 CE 방호력별 HP 매핑·보간은 미정 |
| 고정 혼합급탄 | **API 5발 → HEI 1발 반복 (5:1)** [확정] |
| 탄종별 탄속·게임 적재량 | **미정** (실물 참고 제원 자동 확정하지 않음) |
| 점사 시간·초기 회전 가속·사격중 산포·명중률 | **미정** |

- **API 86HP**는 이전에 논의한 **87HP → 84HP → 86HP** 중 최신 사용자 최종값이다. Mi-24P 30mm GSh-30-2K AP-T **85HP**보다 **1HP 높게** 설정한다. 기종별 실제 피해는 **관통·과관통 감쇄·명중률·탄착 부위**를 거쳐 달라지므로 기본 HP를 초당 발사량에 곱한 수치를 최종 피해량으로 오해하지 않는다.
- HEI는 **144HP 기본 피해**, 거리별 **CE 8/8/7/6/5/4mm**, 그리고 **동급 30mm HEI의 공통 지상·공중 고폭 감쇄 형태 재사용**을 확정한다. 다만 표적 CE별 실제 외부 폭발 HP 노드/보간·신관·파편·폭발 반경은 추가 결정 전까지 미정이다.
- **3,800RPM은 이번 게임 설정**이다. 현실의 다양한 GAU-8/A 공개 RPM 자료, 회전 가속 지연, 단일/복수 발사 모드의 운용 제약을 모두 구현했다는 뜻은 아니다.

## 2. API 거리·각도별 KE 관통력 — 사용자 이미지 원본

단위: **mm RHAe (게임용)**. 이미지의 정수값을 **수정·재반올림하지 않음**.

| 거리 | 0° KE | 30° KE | 60° KE |
|---|---:|---:|---:|
| **10m** | **79** | **68** | **37** |
| **100m** | **77** | **66** | **36** |
| **500m** | **68** | **58** | **32** |
| **1,000m** | **58** | **50** | **28** |
| **1,500m** | **50** | **43** | **24** |
| **2,000m** | **43** | **37** | **20** |

- **출처 구분:** 관통표는 사용자가 보낸 게임 참고 이미지(워썬더 계열 관통 표시)를 **GAU-8/A API용 TACTICAL 게임값으로 채택**한 것이다. **실제 PGU-14/B 감손우라늄 API 탄의 공인 실측 관통 시험값이라는 의미는 아니다**. HEI/다른 탄종에 자동 상속하지 않는다.
- **지상 표적** 관통 시 거리·각도별 공통 KE 보간, 장갑 방호·도탄·AP 과관통 감쇄 규칙을 따른다. **공중 표적**은 기존 전 기종 공통 입사각 생략 예외에 따라 거리별 **0° KE**와 추첨 방호값을 비교한다.
- 2km 초과에서의 KE 감쇄는 [장거리 관통력 공통 설계](../../systems/combat/RANGE_PENETRATION_EXTRAPOLATION.md)의 후속 결정 대상이며, **실제 게임상 GAU-8/A 최대 교전거리도 아직 결정되지 않음**. 2km 관통표 노드가 최대 유효 사거리 확정값은 아니다.

## 4. 고정 혼합급탄 — API:HEI 5:1

| 발사 순서 | 탄종 | 기본 피해 |
|---|---|---:|
| 1 | API | **86HP** |
| 2 | API | **86HP** |
| 3 | API | **86HP** |
| 4 | API | **86HP** |
| 5 | API | **86HP** |
| 6 | HEI | **144HP** |

- 6발 고정 반복, **API 83⅓% / HEI 16⅔%**, 별도 전투 중 탄종 전환 프리셋 없음. [고정 혼합급탄 정본](../../presets/1989/GAU8_A_COMBAT_MIX.md) 참조.
- **실물 GAU-8/A는 링크리스 급탄**이다. 여기서 탄띠는 **게임상 고정 탄종 발사 순서**를 뜻하며 금속 링크 탄띠 사용을 의미하지 않는다.
- 3,800RPM의 이론치 63.33발/초를 기준으로 장기 평균 API **52.78발/초**, HEI **10.56발/초**. 이는 실제 명중수·피해·연속 발사 가능시간을 확정하지 않는다.

## 5. HEI 지상·공중 고폭 피해곡선

- [BMP-2 **3UOF8 30mm HEI**](../../vehicles/1989/ifv/BMP_1_1P_2.md)에 적용하는 [DM21 기반 기관포 HE 공통곡선](../../systems/combat/IFV_HE_DAMAGE_CURVES.md)의 **동일 상대 감쇄 구조**를 GAU-8/A HEI에도 채택: 지상은 직접 파공 이후 **급격한 외부 폭발 피해 감소**, 공중은 **완만한 감쇄**.
- 단, **GAU-8/A 고유 기본 피해 144HP**와 **거리별 CE 8/8/7/6/5/4mm**는 그대로 사용. BMP-2 3UOF8의 **155HP/CE10**, DM21의 **172HP/CE11**을 복사하거나 피해를 중복 합산하지 않는다.
- **세부 수치 미확정:** 위 공통 템플릿도 개별 탄의 **직접 파공 CE값을 공통 CE 노드에 대응시키는 함수**, 표적 장갑 CE별 정확한 HP·보간/반올림, 신관·폭발 반경 등은 확정하지 않았다. 구조만 공유하며 숫자를 지어내지 않는다.
- **공중 실제 비관통 직격 최소 피해 = 144×25% = 36HP**. 공중 외부 폭발 피해곡선 결과가 36보다 크면 높은 쪽을 사용한다. 미명중/비직격 근접폭발/신관 불발에는 36HP를 자동 가산하지 않는다.
- API는 **KE 관통·AP 과관통 감쇄**를 쓰며 HEI 고폭곡선을 상속하지 않는다.

## 6. 남은 설계 및 구현 경계

1. **적재량·포구초속:** 실물 참고 1,174발·약 1,066m/s는 채택된 게임 제원이 아님. **5:1 고정급탄**만 확정, 실제 장탄 수량/보급은 미정.
2. **HEI 외부 폭발:** 30mm 공통 지상/공중 감쇄 구조는 채택. **정확한 CE별 HP·보간·파편/신관/폭발 범위**는 미정.
3. **사격:** 점사 제어, 초기 회전 가속·감속, 기수 조준, 고정익 발사조건, 명중률·산포, 교전거리·고도.
4. **구현:** 항공기 전투 유닛, GAU-8/A 발사 로직, 출격/귀환 등의 게임 런타임 미구현. 기존 차량/탄약 숫자 불변.
