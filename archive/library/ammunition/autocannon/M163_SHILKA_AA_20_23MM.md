# TACTICAL 1989 — M163 20mm M168 / ZSU-23-4 23mm AZP-23 자주대공포 탄약 정본

> **2026-11-21 사용자 후속 채택 게임값.** M163의 종전 **AP-I 단일탄 운용을 변경하여 HEI-T 3발 + 기존 AP-I 1발 단일 고정 탄띠**를 채택. ZSU-23-4도 **HEFI-T 3발 + API-T 1발 단일 고정 탄띠** 채택. **탄띠 선택/전환 없음**. 탄속과 고폭 CE는 War Thunder 개별 포탄 자료 참고, **쉴카 API 관통표는 사용자 직접 제공 이미지 18개 값을 우선**한다. HP 피해값은 TACTICAL의 사용자 선택 게임값으로 워썬더 피해가 아님. 아직 **게임 실행 코드는 미구현**.
>
> **정본 소유권:** 20/23mm AA 고폭·철갑탄 탄속, 거리별 KE/CE, 기본 HP 피해와 공중 25% 사례는 이 파일. [M163 차량](../../vehicles/1989/air_defense/M163_VADS.md) · [쉴카 차량](../../vehicles/1989/air_defense/ZSU23_4_SHILKA.md) · [고정 탄띠](../../presets/1989/AA_FIXED_BELTS_M163_SHILKA.md). 고폭 피해곡선의 **정확한 CE 매핑·보간은 미정**이며 [기관포 고폭 공통 구조](../../systems/combat/IFV_HE_DAMAGE_CURVES.md)를 참고한다.

## 1. 탄종별 게임 기본 제원 — 사용자 채택

| 차량/기관포 | 탄종 (TACTICAL) | 분류 | 포구초속 | 기본 차량 HP 피해 | 포탄 데이터 근거 |
|---|---|---|---:|---:|---|
| M163 / 20mm M168 | **AP-I** | 철갑소이 | **1,030m/s** | **38HP** | 이전 사용자 확정값 **변경 없음** |
| M163 / 20mm M168 | **HEI-T** | 고폭소이예광 | **1,030m/s** | **68HP** | CE/탄속은 [워썬더 M168](https://old-wiki.warthunder.com/M168_(20_mm)), 68HP는 사용자 게임값 |
| ZSU-23-4 / 23mm AZP-23 | **API-T (BZT 계열)** | 철갑소이예광 | **970m/s** | **55HP** | KE는 사용자 이미지, 탄속은 [워썬더 AZP-23](https://old-wiki.warthunder.com/AZP-23_(23_mm)), 55HP는 사용자 게임값 |
| ZSU-23-4 / 23mm AZP-23 | **HEFI-T (OFZT 계열)** | 고폭파편소이예광 | **970m/s** | **108HP** | CE/탄속은 [워썬더 AZP-23](https://old-wiki.warthunder.com/AZP-23_(23_mm)), 108HP는 사용자 게임값 |

- 탄종명 **M246/OFZT/BZT 등 현실 제식탄과 워썬더 표기의 상세 대응은 최종 고증 필요**. 여기서 직접 채택한 것은 **게임 내 HEI-T/HEFI-T/API-T 분류 및 개별 성능**이며 현실 보급 규격을 모두 동일시하지 않는다.
- 전작업에서 검토한 **M163 HEI-T 68HP**와 **쉴카 HEFI-T 108HP**, **쉴카 API-T 55HP**를 사용자 후속 승인값으로 채택한다. 기존 M163 AP-I 38HP, 차량 HP/장갑/사거리/발사속도는 변경하지 않는다.
- HEFI-T/HEI-T 워썬더 TNT 환산 폭약량 참고: **M168 HEI-T 12g**, **AZP-23 HEFI-T 20.02g**. HP 피해와 1:1 대응하는 물리량이 아니다.

## 3. M163 20mm HEI-T — 워썬더 CE와 사용자 피해값

| 거리 | CE 파공/관통 지표 |
|---|---:|
| 10m | **5** |
| 100m | **5** |
| 500m | **3** |
| 1,000m | **2** |
| 1,500m | **2** |
| 2,000m | **2** |

- 기본 **68HP**, **1,030m/s**. **2km CE 기록은 자료 보존용**, 1.5km 포 사거리 변경 없음.
- CE는 성형작약 HEAT의 실물 관통력과 동일한 개념이 아닌 **게임용 고폭탄 직접 파공 판정 지표**로 사용한다.
- 공중 기체에 실제 직격한 비관통 고폭은 **68HP의 25% = 최소 17HP**. 정상 고폭 외부 폭발 피해 계산이 더 높으면 그것을 사용한다. 추가 가산 아님.

- 기본 **55HP**, **970m/s**. **2026-11-21 쉴카 대공 최대 교전거리 3,000m 후속 확정**. 그러나 **KE 표는 2km까지만 제공됐으며 2~3km 구간의 KE 외삽·추가 노드·하한 정책은 미정**. 2km 표를 임의의 최대 교전거리나 3km KE값으로 간주하지 않는다.
- 공중 비관통 및 AP 관통 후 과관통 감쇄는 **최소 13.75HP** 보장. 성공한 정상 관통 피해량은 과관통 여부·공통 AP 피해곡선에 따라 달라진다.

- 기본 **108HP**, 포구초속 **970m/s**. 워썬더의 **HEF-I 980m/s/28.49g**와 이 **HEFI-T 970m/s/20.02g**는 서로 다른 탄종이므로 혼동하지 않는다.
- 공중 직격 비관통 최소 **27HP**. 공통 지상 급감 / 공중 완만 감쇄 폭발 피해곡선의 구체 CE 매핑식은 아직 미정.

## 6. 공통 판정 / 고정 탄띠와 구현 경계

1. **고정 탄띠는 두 차량 모두 HE → HE → HE → AP**, 반복. 총 탄약의 **HE 75%, AP 25%**; 별도 HE/API 선택·탄띠 프리셋 교체 없음. [고정 탄띠 정본](../../presets/1989/AA_FIXED_BELTS_M163_SHILKA.md).
2. 기관포 고폭탄은 [DM21 기준 지상 급감 / 공중 완만 감쇄 구조](../../systems/combat/IFV_HE_DAMAGE_CURVES.md)를 **폭발 피해 형태의 참고 모델**로 채택한다. **DM21의 CE 11mm / 172HP를 복사하지 않는다**. 본 AA 탄종별 CE 한계와 기본 HP는 위 표를 우선. **CE 20/25mm 공중 기체에 얼마의 정확한 고폭 피해가 들어가는지, 각 표적 CE와 DM21 원형의 매핑 공식은 미정**.
3. **모든 공중장비에는 입사각/각도 도탄 생략**, 현재 거리의 **0° KE/CE** 기준 대조. 실제 명중 시 모든 탄종 비관통 피해 최소 **기본 HP 25%**, AP 과관통 후 피해에도 25% 하한. [공중 공통 정본](../../systems/combat/AIR_TARGET_DAMAGE.md). 미명중·미발사/불발 별도.
4. M163 AI **1,000/3,000 RPM**, 즉응 **1,031발**, 준즉응 **1,069발** 기존값 유지. **쉴카 게임 RPM은 문당 900 ×4문 = 3,600RPM 확정, 대공 유효 2,500m·최대 3,000m 확정**. **쉴카 총 2,000발 = 기관포 4문 각각 500발, 전량 즉응탄 / 준즉응탄 없음**(HEFI-T 전체 1,500발·API-T 전체 500발). **쉴카 점사 규칙·재보급 시간은 미정**. 실물 참고 약 2,000발/약 3,400RPM을 게임 확정값 대신 사용하지 않음. 쉴카 **M163보다 불안정한 명중 특성 및 비교적 낮은 신뢰성**은 방향만 채택, 명중률 %·고장률/복구시간은 미정.
5. **구간별 관통력 보간·피해곡선 정수화·신관/비직격 파편/모듈 확률은 미정**. 기존 1989 전차 96개 프리셋·게파르트 DM21/DM13A1/DM23·게임 코드에 영향 없음.
