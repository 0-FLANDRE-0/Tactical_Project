# HEP/HESH·HE-FRAG·APERS — 서로 다른 관통/차량 피해 경로

> **2026-11-21 후속 사용자 확정 반영.** 105mm HEP/HESH의 CE 방호력 30mm 직접 파공, 비파공 감쇄·스폴 배타적 피해 분기를 최신 정본으로 사용한다. 125mm HE-FRAG와 APERS의 이전 확정 규칙은 그대로 유지한다. **게임 코드 미반영**, 미정 수치는 임의로 확정하지 않는다.

| 항목 | 사용자 확정 게임값 |
|---|---:|

| 파공 기본 피해 | **556 HP** |

### 판정 순서 — 2026-11-21 사용자 확정

1. 명중 및 피격 구역의 **CE 방호력 R(mm RHAe)** 확인. KE 방호력이 아니라 CE 기준으로 처리하고, 방호력에 이미 반영된 장갑 경사/LOS를 중복 계산하지 않는다.
2. **R ≤ 30mm:** 직접 파공 성공, **556 HP**. 이때 외부 충격·내부 스폴의 별도 기본 피해를 중복 가산하지 않는다.
3. **30mm < R ≤ 120mm:** 직접 파공 실패. **내부 스폴 확률을 별도 추첨**한다.
   - **스폴 성공:** **438 HP**.
   - **스폴 실패:** **30mm 초과 직후 420 HP에서 시작해 120mm의 100 HP까지 선형 감소하는 외부 비파공 피해**.
4. **R > 120mm:** 내부 스폴 성공 분기는 사용하지 않고, 120mm의 100 HP를 출발점으로 **CE 방호력 증가에 따라 외부 비파공 피해를 계속 감소**시킨다. 이 구간의 추가 감쇄 기울기·곡선과 하한은 **미정**이다.
5. 한 번의 명중에 파공 556, 스폴 438, 외부 비파공 감쇄 피해 중 **정확히 하나의 기체/차량 HP 피해 경로**만 적용한다.

### CE 30~120mm 스폴 실패 감쇄 곡선 — 사용자 채택

```text
R = 표적 피격 구역의 CE 방호력 (mm RHAe)
if R <= 30: damage = 556  // 직접 파공; 스폴 판정 없음
else if R <= 120:
  if roll_spall_chance(R): damage = 438
  else: damage = 420 - (320 / 90) * (R - 30)
else:
  damage = decay_from_100_HP(R) // R=120일 때 100에서 연속 감소; 함수 미정
```

30mm와 30mm **초과** 사이에 **556→420 HP의 의도된 불연속**이 있다. 스폴 판정이 가능한 구간에서 감쇄 피해는 언제나 438 HP보다 작아서 스폴 성공이 피해를 줄이지 않는다. 계산은 소수로 수행하며 **최종 HP 반올림 규칙은 아직 미정**.

| 표적 CE 방호력 | 직접 파공 피해 | 스폴 성공 피해 | 스폴 실패 시 외부 비파공 피해 |
|---|---:|---:|---:|
| **30mm 이하** | **556** | 해당 없음 | 해당 없음 |
| **30mm 초과 직후** | 없음 | **438** | **420** |
| **45mm** | 없음 | **438** | 약 **367** |
| **60mm** | 없음 | **438** | 약 **313** |
| **75mm** | 없음 | **438** | **260** |
| **90mm** | 없음 | **438** | 약 **207** |
| **105mm** | 없음 | **438** | 약 **153** |
| **120mm** | 없음 | **438** | **100** |
| **120mm 초과** | 없음 | 스폴 판정 없음 | **100에서 추가 감쇄 (함수 미정)** |

### 확정과 미정의 구분

- **확정:** M393A2와 DM512 모두 같은 30mm 직접 파공 한계·556 HP, 비파공 420→100 HP 선형 감쇄(30mm 초과~120mm), 스폴 성공 438 HP, CE 30초과~120mm에서 확률적 분기, 분기별 피해 중복 금지.
- **미정:** CE에 따른 **스폴 발생 확률 함수/임계값**, CE 120mm **초과** 감쇄식·하한, 스폴 라이너 및 특수 방호 보정, 실제 신관·입사각별 추가 고장 판정, 최종 HP 반올림 및 런타임 구현.
- 기존 **HEP 효과지표 CE 120/120/120**은 유지한다. 이 120을 직접 파공력으로 해석하지 않고 **스폴 판정 범위의 게임 기준**으로 사용한다.
- **125mm HE-FRAG(3OF19/3OF26)**는 게임상 직접 파공 지표 **CE 35/40** 및 기존 파공 기본 피해 **512/612 HP** 그대로 보존한다. HEP의 스폴 438 HP 또는 감쇄공식은 HE-FRAG에 자동 적용하지 않는다.
- **출처 레코드:** [미국 105mm M393A2](../../ammunition/cannon/US_105.md), [서독 105mm DM512](../../ammunition/cannon/WEST_GERMANY_105.md). 이전 2026-11-19 문서에서 'HEP 직접 파공 한계·스폴 한계·감쇄 모두 미정'이었던 내용은 **이 후속 결정으로 갱신**되며, 정확한 스폴 확률은 계속 미정이다.

## 소련 HE-FRAG / 3Sh7 APERS

### 소련 125mm HE-FRAG 비-HEP 관통 판정 방향 — 2026-11-18

- **사용자 지정 설계 원칙:** 3OF19·3OF26은 일반 **HE-FRAG(고폭파편탄)**이며 서방 **HEP/HESH처럼 장갑을 관통하지 않고 반대편 내부에 스폴을 만드는 특수탄으로 취급하지 않는다**. 장갑 표적의 **관통 판정은 폭발의 직접적인 물리적 파공·파열·뜯김으로 장갑이 실제 뚫린 경우**에 한정한다. HEP/HESH용 스폴 438 HP 경로를 이 두 탄에 자동 적용하지 않는다.
- 기존 **CE 35/35/35(3OF19), CE 40/40/40(3OF26)**은 게임용 장갑 파열/파공 판정 지표로 보존하며 **성형작약 제트에 의한 RHA 관통력이나 실증 실험치가 아니다**. 장갑 미관통 시 외부 폭발·대인·비장갑·구조물 피해, 실제 파공 조건, 피해량·범위·감쇄식은 아직 **미정**이다. 위 특성은 **3Sh7(APERS 벌집탄)에는 자동 적용하지 않는다**.

## 증가장갑 외부 충격 기준의 별도 경로

- 기폭한 HEAT/ATGM·HEP/HESH·HE/HE-FRAG는 **비관통이라도** 부위별 비폭발성 증가장갑 HP를 손상시킬 수 있다. 적용 감쇄율과 **피복/빈 지점 1.0/0.5** 판정은 [비폭발성 증가장갑 시스템](../armor/NON_EXPLOSIVE_ADDON_ARMOR.md), [Leopard 2A8 모듈러](../armor/LEOPARD_2A8_MODULAR_ARMOR.md)에 각각 근거.
- 외부 충격으로 증가장갑 HP만 줄인 경우에 **비관통 직접 파공 차량 피해를 새로 부여하지 않는다**. HEP 내부 스폴·차량 직접 관통 피해를 증가장갑 손실에 두 번 넣지 않는다.
