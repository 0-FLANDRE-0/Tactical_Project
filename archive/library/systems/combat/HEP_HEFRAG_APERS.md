# HEP/HESH·HE-FRAG·APERS — 서로 다른 관통/차량 피해 경로

> **4단계 시스템 이관본.** [탄약 원본](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/ammo/README.md)의 2026-11-19 사용자 최신 확정값을 적용한다. HEP 스폴·직접 천공, HE-FRAG의 실제 파공, APERS 유효 플레셰트 피탄 수를 **서로 합산하거나 일반 ATGM 관통 곡선에 자동 포함하지 않는다**. 구현/세부 신관·확률은 미정. 원본 문서가 5단계 전까지 최종 정본.

## HEP/HESH: 미국 M393A2 / 서독 DM512 (105mm)

| 탄약 | 게임용 효과지표 | 직접 장갑 천공 성공 시 기본 차량 피해 | 직접 천공 실패 후 내부 스폴 성공 시 기본 피해 |
|---|---:|---:|---:|
| M393A2 | CE 120(0°/30°/60°) | **556 HP** | **438 HP** |
| DM512 | CE 120(0°/30°/60°) | **556 HP** | **438 HP** |

- **두 경로 배타적**: 한 번의 명중에 `556+438` HP를 합산하지 않는다. CE 120은 **게임 HEP 효과지표**이지 실제 장갑 파공력 확정값이 아니다.
- 정확한 천공 판정·스폴 확률·효과 감쇄·스폴 라이너 보정은 **미정**, 이관 작업에서 임의로 수치화하지 않는다.
- **원문 세부 기록:** [미국 105mm](../../ammunition/cannon/US_105.md) · [서독 105mm](../../ammunition/cannon/WEST_GERMANY_105.md). 최신 수치는 450이 아닌 **556 HP**이다.

- **M393A2 HEP:** 직접 장갑 천공에 성공하면 **556 HP 기준 경로**(2026-11-19, 종전 450 HP에서 수정), 직접 천공에 실패하되 스폴이 발생하면 **438 HP 기준 경로**로 구분한다. **동일 피격에서 두 기본 피해를 중복 합산하지 않는다.** 기존 **CE 120(0°/30°/60°)**은 HEP의 게임용 효과지표로 유지하며 실제 직접 천공력 120mm 확정이 아니다. CE 120을 스폴 판정 한계로 쓰는 안, 실제 천공력, 스폴 발생 확률·장갑별 피해 배율·스폴 라이너 보정은 **미정**이다. [피해 설계 메모 §3](../combat/PENETRATION_DAMAGE_AND_VEHICLE_HP_CONCEPT_2026-11-07.md) 참고.

- **DM512 HEP/HESH:** 직접 장갑 천공 성공 시 **556 HP 기본 피해 경로**(2026-11-19, 종전 450에서 상향), 직접 천공 실패 후 내부 스폴이 발생한 경우 **438 HP 기본 피해 경로**로 구분한다. **동일 피격에서 556+438 HP를 중복 합산하지 않는다.** 기존 **CE 120(0°/30°/60°)**은 게임용 HEP 효과지표로 유지하며 직접 장갑 천공력이 실제 CE 120으로 확정된 것은 아니다. 직접 천공력 수치·스폴 한계 채택 여부·스폴 발생 확률·장갑별 감쇄 곡선·스폴 라이너 반응은 **미정**이며, 미국 M393A2의 미채택 예시 곡선을 자동 확정하지 않는다.

## 소련 HE-FRAG / 3Sh7 APERS

### 소련 125mm HE-FRAG 비-HEP 관통 판정 방향 — 2026-11-18

- **사용자 지정 설계 원칙:** 3OF19·3OF26은 일반 **HE-FRAG(고폭파편탄)**이며 서방 **HEP/HESH처럼 장갑을 관통하지 않고 반대편 내부에 스폴을 만드는 특수탄으로 취급하지 않는다**. 장갑 표적의 **관통 판정은 폭발의 직접적인 물리적 파공·파열·뜯김으로 장갑이 실제 뚫린 경우**에 한정한다. HEP/HESH용 스폴 438 HP 경로를 이 두 탄에 자동 적용하지 않는다.
- 기존 **CE 35/35/35(3OF19), CE 40/40/40(3OF26)**은 게임용 장갑 파열/파공 판정 지표로 보존하며 **성형작약 제트에 의한 RHA 관통력이나 실증 실험치가 아니다**. 장갑 미관통 시 외부 폭발·대인·비장갑·구조물 피해, 실제 파공 조건, 피해량·범위·감쇄식은 아직 **미정**이다. 위 특성은 **3Sh7(APERS 벌집탄)에는 자동 적용하지 않는다**.

### 소련 125mm HE-FRAG 직접 파공 기본 피해 확정 — 2026-11-19

| 탄약 | 사용 폭약 | 게임용 파공 지표 (0°/30°/60°) | **실제 장갑 파공 성공 시 차량 기본 피해** | 상태 |
|---|---|---|---:|---|
| **3OF19** | TNT | **CE 35/35/35** | **512 HP** | **사용자 확정 (2026-11-19)** |
| **3OF26** | A-IX-2 | **CE 40/40/40** | **612 HP** | **사용자 확정 (2026-11-19)** |

- **장갑이 폭발에 의해 실제로 뜯기거나 파열돼 파공된 경우에만** 위 기본 피해를 적용한다. HE-FRAG에는 서방 HEP/HESH의 **비관통 후면 스폴 기본 피해 438 HP 경로를 사용하지 않는다**. 동일 명중에서 직접 파공 차량 HP 피해와 별도 외부 폭발 피해를 **중복으로 확정하지 않았다**.
- **512/612 HP는 게임 밸런스 기준값**이며 실제 실험으로 측정된 폭발 파공 후 내부 피해량이 아니다. **CE 35/40, 포구초속 각 850m/s, 기존 적재 프리셋은 불변**이다. 파공 판정의 상세 조건, 비관통 외부 폭발 피해, 보병·비장갑·건물 피해, 파편 분포·반경·감쇄·신관·코드 적용은 **미정/미구현**이다.

### 3Sh7 APERS/벌집탄 피해 확정 — 2026-11-19

| 탄약 | 판정 단위 | **유효 명중 1개당 기본 피해** | 기존 대장갑 지표 | 탄속 | 상태 |
|---|---|---:|---|---:|---|
| **3Sh7** | **플레셰트 1개** | **7 HP** | **KE 5/0/0** | **900m/s** | **사용자 확정** |

- **미국 105mm M494의 유효 플레셰트 1개당 6 HP와 구별**해 소련 125mm **3Sh7은 7 HP**로 확정한다. 실제 표적에 **유효 명중한 플레셰트 개수 × 7 HP**를 기본 피해로 누적하며, 전체 탄두나 발사 1회당 고정 7 HP가 아니다. 해당 계수는 **게임 밸런스 설계값**이며 실측 플레셰트 상해·장갑 파괴력을 의미하지 않는다.
- **표적별 유효 피탄 개수, 확산각·거리·엄폐·보호장비 보정, 누적 피해 상한, 비장갑·차량 대상 특수 판정은 미정**이다. 보병에게 적용하는 다중 플레셰트 피해를 장갑차량 HP에 무조건 적용하지 않는다. **기존 대장갑 효과지표 KE 5/0/0, 포구초속 900m/s, 기존 탄약 적재·프리셋과 게임 코드 모두 불변**이다.

## 증가장갑 외부 충격 기준의 별도 경로

- 기폭한 HEAT/ATGM·HEP/HESH·HE/HE-FRAG는 **비관통이라도** 부위별 비폭발성 증가장갑 HP를 손상시킬 수 있다. 적용 감쇄율과 **피복/빈 지점 1.0/0.5** 판정은 [비폭발성 증가장갑 시스템](../armor/NON_EXPLOSIVE_ADDON_ARMOR.md), [Leopard 2A8 모듈러](../armor/LEOPARD_2A8_MODULAR_ARMOR.md)에 각각 근거.
- 외부 충격으로 증가장갑 HP만 줄인 경우에 **비관통 직접 파공 차량 피해를 새로 부여하지 않는다**. HEP 내부 스폴·차량 직접 관통 피해를 증가장갑 손실에 두 번 넣지 않는다.
