# BDD / D-Technologie — 비폭발성 증가장갑의 독립 HP

> **4단계 시스템 이관본 · 확정값/미정 구분 보존.** 원본 파일은 그대로 두며, 5단계 전체 검증 전까지 원본이 정식 정본. 아래는 **TACTICAL용 게임 방호 모델**이지 실차 공식 제원·구현 완료 보고가 아님.

**기준 원본:** [전차 아카이브 §1-B](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/tanks/README.md). 아래 구형 단일 HP는 **폐기값**임을 원문대로 보존하되 게임 설계에서 사용하지 않는다. 현대 2A8의 별도 계층은 [모듈러 증가장갑](LEOPARD_2A8_MODULAR_ARMOR.md) 참조.

### 1-B. BDD / D-Technologie 비폭발성 추가장갑의 부위별 HP·감쇄율 — 2026-11-19

> **부위별 장갑 HP는 사용자 최신 확정.** 기존 논의의 장갑 전체 단일 HP `BDD 950 / D-Tech 1,300`은 **최신 부위별 수치로 대체**하며, 전차 자체 HP와 중복 합산하지 않는다. **최소 잔존 추가 방호력 BDD 25% / D-Tech 40%는 사용자가 수용한 기준**이고, 탄종별 감쇄율은 사용자가 직접 제시한 최신 설계값을 사용한다.

| 독립 장갑 HP 부위 | **BDD (T-55AM2/AM2B)** | **D-Tech (Leopard 2 KVT)** |
|---|---:|---:|
| **차체 전면** | **850 HP** | **1,100 HP** |
| **차체 측면** | 미장착 | **600 HP** |
| **포탑 전면** | **950 HP** | **1,350 HP** |
| **포탑 측면** | **550 HP** | **750 HP** |
| 차체·포탑 후면, 통합 상부 | 미장착 | 미장착 |

- **부위별 독립 상태:** 각 장갑 부위에 `max_armor_hp`와 `current_armor_hp`를 따로 두며, 예컨대 차체 전면 BDD를 손상시켜도 포탑 전면의 BDD HP를 감소시키지 않는다. 미장착 부위에는 추가장갑 HP를 생성하지 않는다.
- **BDD/D-Tech 피복률은 감소하지 않음:** 기존 부위별 **고정 피복률**로 피복/빈 지점 여부를 판정한다. **피복 지점에서는 추가장갑 방호력이 적용되고 그 부위 장갑 HP가 정상 손상**, **빈 지점에서는 추가장갑 방호력 미적용**이지만 **HEAT·ATGM·HEP/HESH·HE(HE-FRAG 포함)가 실제 기폭하면 주변 장갑 HP에 정상 손상량의 50%**를 적용한다. 둘 다 탄종·장갑별 **감쇄율을 적용**하고 **비관통이라도 장갑 HP 손실**은 발생한다. **빈 지점 APFSDS/APDS 손실은 0**이고, 미장착 부위에는 손실 없음. 이번 피격으로 장갑 피복률은 절대 변하지 않으며, 차량 HP의 직접 관통·스폴 피해 판정은 독립이다.

**탄종별 장갑 HP 피해 감쇄율 — 2026-11-19 사용자 제시 최신값**

| 피격 탄종 | **BDD 감쇄율** | **D-Tech 감쇄율** | 실제 장갑 HP에 적용되는 기본 피해 비율 |
|---|---:|---:|---|
| **APFSDS / APDS** | **30%** | **52%** | BDD 70%, D-Tech 48% |
| **HEAT / ATGM** | **35%** | **40%** | BDD 65%, D-Tech 60% |
| **HEP / HESH** | **80%** | **85%** | BDD 20%, D-Tech 15% |
| **HE (HE-FRAG 포함)** | **85%** | **85%** | BDD 15%, D-Tech 15% |

- **손상 공식 (2026-11-19 비관통 폭발 확정):** `additional_armor_hp_loss = ammo_armor_damage_basis × (1 − armor_type_ammo_reduction) × hit_factor`, `current_armor_hp_after = max(0, current_armor_hp_before − additional_armor_hp_loss)`. **피복 지점 hit_factor=1.0, 빈 지점 폭발탄 HEAT/ATGM·HEP/HESH·HE(HE-FRAG 포함) hit_factor=0.5, 빈 지점 APFSDS/APDS hit_factor=0.0**. **폭발탄은 실제로 기폭했다면 추가장갑의 관통·파공 성공과 상관없이 장갑 HP 손실을 준다.** 차량 HP의 관통/스폴 판정과 추가장갑 HP 손실은 독립. **기준 피해값은 확정 탄약별 기본 피해**를 적용하며, HEAT·ATGM은 해당탄의 직접 관통 기본 피해, HEP/HESH(M393A2/DM512)는 **556 HP**(내부 스폴 438 HP를 장갑 HP 손실에 합산하지 않음), HE-FRAG(3OF19/3OF26)는 **512/612 HP**를 **추가장갑 HP 손상 계산에 한정하여 관통 실패 시에도 사용**한다. 이로 인해 차량 HP에 비관통 직접파공 피해를 새로 주는 것은 아니다. 정수 반올림 방식, 미기폭·신관 불발 조건 및 별도 수리 방식은 미정이다.
- **빈 지점 손상 비율 계산표 (기본 피해 대비, 피복 지점과 비교):**

| 탄종 계열 | BDD 피복 지점 / 빈 지점 | D-Tech 피복 지점 / 빈 지점 |
|---|---:|---:|
| APFSDS / APDS | 70% / **0%** | 48% / **0%** |
| HEAT / ATGM | 65% / **32.5%** | 60% / **30%** |
| HEP / HESH | 20% / **10%** | 15% / **7.5%** |
| HE (HE-FRAG 포함) | 15% / **7.5%** | 15% / **7.5%** |

- **판정 순서와 폭발 효과:** 피격 직전 장갑 HP를 사용해 그 명중의 유효 KE/CE 방호력과 **차량 HP 관통·스폴 피해를 먼저** 판정하고, 그 뒤 추가장갑 HP를 차감한다. 한 발이 스스로 약화시킨 장갑을 소급 관통하지 않는다. **HEAT/ATGM·HEP/HESH·HE/HE-FRAG가 기폭하면 비관통이어도 장갑 HP를 정상 손상**시킨다(피복 100%, 빈 지점 50%, 해당 장갑 감쇄율 필수). **HE-FRAG의 비관통 직접파공 차량 HP 피해는 0**이며, HEP의 내부 스폴은 별도 성공 판정에 따름. 관통·비관통 양쪽에서 **장갑 HP 감소와 차량 HP 피해는 서로 다른 경로**다.
- **비관통 폭발 수치 예시 — 3OF26 HE-FRAG (기본 피해 612 HP):** BDD와 D-Tech 모두 HE 감쇄율 85%이므로, **파공 실패·비관통이어도** 해당 부위 **피복 지점에서 612×(1−0.85)=91.8 장갑 HP**, **빈 지점에서 612×(1−0.85)×0.5=45.9 장갑 HP** 손실. 이 612는 **추가장갑 외부 충격 계산의 기초값**일 뿐, HE-FRAG가 파공에 실패한 차량에 **612 차량 HP 피해를 부여하는 규칙이 아니다**. HEP도 장갑 손실 계산에는 556을 쓰되 내부 스폴 438 HP는 별도 판정한다.
- **잔존 방호력 공식:** `armor_hp_ratio = current_armor_hp / max_armor_hp`; `effective_addon_multiplier = residual_floor + (1 − residual_floor) × armor_hp_ratio`, 여기서 `residual_floor`는 **BDD 0.25, D-Tech 0.40**. 피복 지점의 최종 `R_KE/CE = base_KE/CE + addon_KE/CE × effective_addon_multiplier`. 장갑 HP가 0이 되어도 **추가 방호력 자체는 각각 25%/40% 남음**. 피복률은 이 과정에서 변하지 않으며, 기본장갑과 전차 HP는 별도 유지.
- **확장성:** 추가장갑의 재질·구조·형태별로 `max_armor_hp`, `ammo_reduction_table`, `residual_floor`와 기존 `coverage`·`addon_KE/CE`를 설정해 동일 엔진에 새로운 비폭발성 증가장갑을 등록할 수 있도록 하는 설계 방향.
- **예시 (수치 검산):** 서독 KVT **차체 전면 D-Tech 1,100 HP**, 3BM29 APFSDS **기본 피해 376 HP**에 피복 지점 명중 → D-Tech 감쇄율 52% → **180.48 HP 손상**, 남은 **919.52 HP**. 최초 차체 전면 KE **450**, 손상 후 다음 피격의 KE 방호력은 `320 + 130 × (0.40 + 0.60×919.52/1100)` ≈ **437.2 KE**. 동일 3BM29의 2km/0° KE440이므로, 다른 조건이 같고 다시 피복 지점에 맞는다면 다음 발에서는 관통 가능(명중·입사각·도탄·모듈 별도).
- **현행 범위:** 본편 T-55AM2/AM2B의 BDD, 희귀 KVT의 D-Tech만 적용한다. **빈 지점 폭발성 계열은 50% 충격 전달 × 탄종별 감쇄율 적용으로 확정**, APFSDS/APDS의 빈 지점 손실은 0이다. 빈 지점 피해와 피복 지점 피해는 같은 피격에 중복 합산하지 않는다. Leopard 1의 Blohm & Voss 장갑 효과는 이미 기본장갑에 통합되어 이 독립 내구도 계층을 받지 않는다. 기존 장갑 7구역 표 KE/CE, 초기 피복률, 전차 최대 HP, 탄약·96개 프리셋, Kontakt ERA의 통합 소모 규칙은 그대로다. **게임 코드 미구현**.
