# TACTICAL 1989 — AH-64A Apache 중구경 플레어·AN/ALQ-144 디스코볼 IRCM 정본

> **2026-11-22 IRCCM 0~3단계 후속 규칙 반영.** AH-64A는 기존의 **중구경 플레어 30발·발당 기본 기만확률 34.6%**, AN/ALQ-144 **감쇄 전 기본 기만확률 90%**를 유지한다. 능동 교란 최종확률은 **미사일별 IRCCM 램프형 기만확률 감쇄율**에 따라 90%×(1−감쇄율)로 계산한다. 0단계=0%, 1단계=40~60%(9M37 IR=45%, MIM-72C/E=55% 개별 확정), 2/3단계=100% 감쇄. 모두 TACTICAL 게임값이며, **실행 코드 미구현**.

**연결 정본:** [AH-64A 기체](../../vehicles/1989/air/AH64A.md) · [공통 플레어·IRCCM·능동 IRCM](COUNTERMEASURES_FLARE_IRCCM_ECCM.md) · [Mi-24 ASO-2V·Lipa](MI24_FLARE_LIPA.md).

## 1. AH-64A 플레어 — 게임 확정

| 항목 | 사용자 선택 게임값 |
|---|---|
| 헬기 | **AH-64A** (1989 본편) |
| 기만체 분류 | **중구경 플레어** |
| **총 적재량** | **30발** |
| **플레어 한 발의 기본 기만확률** | **34.6%** |
| 기만체 운용장비 참고 | **M130 계열 디스펜서** |
| **일반 살포** | **3발 연속 발사 = 3발 소모** |
| **긴급(집중) 살포** | **5발 연속 발사 = 5발 소모** |
| 연속 발사 간격·쿨타임·자동 선택 AI | **미정** |
| 기체별 디스펜서 실제 수량·세부 발사관 배치 | **미정** (30발은 게임 확정 총량) |

- **34.6%는 최초 비교안 28.5%를 대신한 사용자 채택값**이다. 살포 한 묶음의 확률이 아니라 **실제로 방출되어 유효한 플레어 1발의 기본값**.
- 기존 [Mi-24D/V/P](MI24_FLARE_LIPA.md)의 **소구경 18.5% / 128~192발**과 달리, AH-64A는 **중구경 34.6% / 30발**의 높은 발당 효율·낮은 재고로 차별화한다.
- **실효 발당 기만 성공확률**:
```text
P_flare_final = clamp(0.346 × (1 - FlareResistance) × M_aspect, 0, 1)
```
  - `FlareResistance`: 적 미사일의 플레어 저항성 (0~1); `M_aspect`: 시커/상대방위 보정계수 (수치 미정).
  - 유효 플레어 **1발당 독립 판정 1회**, 렌더 프레임마다 재추첨 금지.
  - **IRCCM 단계별 감쇄율은 플레어 저항성 수치가 아니므로 플레어 식에 대입하지 않는다**.
- **살포 모드 정확히 2개:** **일반=3발 연속**, **긴급(집중)=5발 연속**. 세 번째 '강화' 모드 없음. Mi-24와 달리 **2발 묶음이 아닌 개별 3/5발 연속 발사**.
- **30발 재고**를 동일 모드만 사용하면 일반 10회 또는 긴급 6회 온전히 살포 가능. 두 모드 혼용 시 실제 잔량으로 계산한다.
- 30발 모두가 언제나 유효한 것은 아니다. **연속 탄 발사 간격·살포 쿨타임·AI/수동 발동 조건·유효 거리/시간·미사일 비행시간**은 미정이며, 방출되어 실제로 유효한 플레어에 한해 한 발당 한 번 독립 판정한다.

## 2. AN/ALQ-144 '디스코볼' 능동 적외선 교란 — 사용자 채택

| 항목 | 게임 설계 |
|---|---|
| 기종 기본 장착 | **AH-64A 기본 장착** |
| 장비 | **AN/ALQ-144 능동 적외선 교란장치(IRCM)** |
| 작동 | **장치가 정상인 동안 상시 작동** |
| 방향 | **2D RTS 맵 평면 360도**, 수직/하방 사각지대 판정 없음 |
| **감쇄 전 기본 기만확률** | **90%**. 최종=90%×(1−적 미사일/시커 모드의 램프형 IRCM 기만 감쇄율) |
| **미사일 IRCCM 등급별 효과** | **0단계 감쇄 0%→최종 90%; 1단계 감쇄 40~60%→최종 36~54%(개별 감쇄율 확정 전 실제값 미정); 2/3단계 감쇄 100%→0%, 기만 판정 생략** |
| 판정 주기 | **적 미사일 한 발당 유효 기만 기회 최대 1회**, 매 프레임 재추첨 금지 |
| 다른 수단 | **플레어 판정과 별개**, 동일 발사체에 시간상 유효하면 추가 플레어 판정 가능 |

- Lipa와 **같은 공통 능동 IRCM 판정 시스템**을 재사용한다. 기체별 차이점은 플레어 종류/재고, 기체 HP·장갑, 탑재 장비 종류다.
- **2/3단계 미사일**은 램프형 AN/ALQ-144 기만확률을 100% 감쇄하므로 판정을 생략한다. **0/1단계 미사일**은 감쇄 후 확률로 장비 정상·유효 교란조건에서 한 미사일당 장비별 최대 1회 추첨한다. **1단계 개별 확정값은 9M37 IR 45%(최종 49.5%), MIM-72C/E 55%(최종 40.5%)**. 공통 등급 범위 40~60%를 새 미사일의 임시 50%로 자동 지정하지 않는다. 3단계 레이저 DIRCM 저항성은 미정.
- **90%는 사용자 선택 게임 밸런스 값**이다. 적외선 미사일 전반에 90% 보편 생존율을 의미하지 않고, 실제 AN/ALQ-144의 공개 성능시험 수치도 아니다.
- 다른 센서 유도 미사일, 특히 **9M311 무선 지령 유도**에는 플레어·AN/ALQ-144 기만을 자동 적용하지 않는다.
- 유효 거리·장치 손상·발동 타이밍·플레어와의 상호작용 순서·기만 성공 뒤 시커 재획득/추적 복구는 **미정**.

- AH-64A 장갑·HP·무장은 기존 [차량 정본](../../vehicles/1989/air/AH64A.md)에 따르며, 이 문서는 추가 기만체/교란장치만 소유한다.
- Mi-24D의 Lipa 부재와 Mi-24V/P 기본 장착은 사용자 선택 게임 구성이다. 실기체 모든 D형에 Lipa가 장착 불가능했다는 역사적 단정이 아니다.
- 실제 1989년 배치별 발사기 구성·효율 및 적외선 교란장치 효과는 게임 수치와 구별한다. **실행 코드 미변경**.
