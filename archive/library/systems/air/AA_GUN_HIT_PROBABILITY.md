# TACTICAL 1989 — 자주대공포 공중 표적 명중률 잠정 시험안 (게파르트·M163)

> **2026-11-21 사용자 승인으로 잠정 설계 기록.** 아래 게파르트 발당 명중확률 범위는 **실측·확정 밸런스 수치가 아닌 구현 전 시험용 범위**이며 실제 사격·게임 시뮬레이션 결과를 보고 바꿀 수 있다. **M163은 정성적 성능 방향만 채택**, 개별 거리별 명중률·배율은 **미정**. 현재 게임 코드에 적용되어 있지 않다. [수색·추적·광학 공통 정본](RADAR_SEARCH_TRACKING.md), [발사·착탄 2단계 명중 설계](../combat/TWO_STAGE_HIT.md)와 함께 읽는다.

## 1. 무엇을 명중률이라고 부르는가

- **단위:** 특정 무장의 **발사된 탄 한 발이 공중 표적에 실제 명중할 확률**. **점사 한 묶음의 명중확률**이나 **수색레이더 탐지확률**이 아니다.
- **게파르트 시험표의 조건:** **정상적으로 추적레이더가 안정 추적**한 **일반적인 이동 상태의 헬기**, 사격통제·조준이 양호한 기준 상황. **3차원 경사거리** 기준.
- 사격 허용거리 안이라고 자동 명중하는 것이 아니다. 수색레이더로 **존재만 발견한 상태**는 정밀 추적 성공과 구분한다. 레이더/광학 추적 가능 여부, 표적 가시성, 조준 안정성에 따라 명중이 제한된다.
- 수치의 확률은 **실제 전투 명중률 실측값으로 주장하지 않는다**. 실제 3D 탄도 충돌을 그대로 구현한 시뮬레이션 결과도 아니다.

## 2. 게파르트 35mm KDA ×2: 발당 명중률 — [사용자 채택: 잠정 테스트 범위]

| 헬기까지 경사거리 | 발사탄 한 발당 명중확률 시험범위 | 상태 |
|---|---:|---|
| **500m** | **25~35%** | 임시 밸런스 범위 |
| **1,000m** | **20~25%** | 임시 밸런스 범위 |
| **2,000m** | **10~15%** | 임시 밸런스 범위 |
| **3,000m** | **5~8%** | 임시 밸런스 범위 |
| **3,500m** | **3~5%** | 임시 밸런스 범위 |
| **4,000m** | **1~2%** | 임시 밸런스 범위 |

- **유효 교전거리 3,500m / 최대 교전거리 4,000m**는 [게파르트 차량 정본](../../vehicles/1989/air_defense/GEPARD.md)에서 확정된 기존값. **4,000m 초과 사격 불가**. **수색레이더 15km는 사격거리와 전혀 별개**.
- 두 기관포 **문당 550 RPM / 합계 1,100 RPM**은 기존값 유지. 탄종별 기본 피해·탄띠 비율·적재량도 기존값 유지.
- 참고 기대값: **2km 발당 10~15%**면 수학적으로 **3발 명중까지 기대 발사량 약 20~30발**, **1,100RPM 연속 발사 가정 약 1.1~1.6초**이다. **3발 격추는 정상 DM21 폭발/유효 직격 조건의 단순 예시**일 뿐 탄종 혼합·탄착·오차·신관·관통/과관통을 무시한 보장 격추시간이 아니다. 실제 명중 탄끼리 독립이라는 단순 기대값 가정이다.
- 평균 기대 명중탄 수와 실제 한 점사의 결과는 다르다. **여러 탄이 공통 조준 오차를 공유할 수 있고, 개별 탄에는 추가 산포가 생김**. 공통 조준 오차/점사 탄착군 모델을 구분하는 것은 유력 구현 방향이나 **구체 상관관계·배율·발사/재조준 주기는 미정**이다.

## 3. M163 VADS 20mm M168 — [사용자 채택: 정성적 특성, 정량 미정]

- **기본 성격:** **안정적인 근거리 광학 추적 사격**. 거리와 예상 선행조준 오차, 표적 운동·회피기동·급격한 방향변경, 광학 시야/기상 악화에 **게파르트보다 민감**하게 명중률이 떨어지는 방향.
- **거리:** **근거리에서 조건이 양호하면 비교적 안정적**. 특히 유효거리 **1,200m를 지나 최대 1,500m**에 가까워질수록 명중률 감소가 뚜렷한 방향. **거리별 발당 확률은 아직 정하지 않았다.**
- **사격통제:** **광학 관측·추적 + AN/VPS-2 거리측정 레이더 보조**. M163에 독립적인 게파르트식 전방위 수색레이더나 자동 고정밀 추적레이더를 추가하지 않는다. **거리측정·선행조준 오차의 영향**을 반영한다.
- **표적:** 호버링/정지 비행 표적은 비교적 쉬움. 빠른 횡이동이나 회피기동, 조준이 갱신되지 않은 상황에서 정확도 급락 가능. **정확한 상태별 배율은 미정**.
- **기존 화력·탄약:** 게임상 **1,000/3,000 RPM 중 AI 선택**, 가변 점사·중단·재개, **20mm 기존 AP-I 38HP + 신규 HEI-T 68HP를 3 HE:1 AP 단일 고정 탄띠**로 운용, **즉응 1,031발 + 준즉응 1,069발** 등 확정값 유지. 낮은 명중률에 무조건 3,000RPM 최대 점사를 사용하게 하지 않는다.
- **게파르트와 성격 분리:** 게파르트는 레이더 추적·장거리 정확도·35mm 고위력, M163은 광학·거리측정에 의존하며 근거리 안정성·높은 연사속도로 보완. **M163과 게파르트가 모든 거리에서 같은 명중률을 가져야 한다는 뜻이 아니다.**

## 4. 공통 보정·확정되지 않은 사항

- 명중확률은 **추적 방식(레이더/광학), 추적 성공·안정도, 거리, 표적 고도·속도·횡이동/급기동, 사격통제 성능, 발사대 운동·자세, 조준/재조준 시간·탄착군**에 따라 변할 수 있다. **수색레이더로 존재 탐지했다고 곧바로 명중률 보너스를 받지 않는다**.
- **이전 대화의 광학 ×0.7~0.9 / 불안정 추적 ×0.3~0.6 및 표적 기동 배율 예시는 미채택**. 게임에 확정 적용하지 않는다. 본 표도 **정상 추적 중인 헬기** 조건 외에 무조건 적용하지 않는다.
- **탄마다 발사 시점의 상태와 비행시간을 보존하고 착탄 시 표적 운동을 반영**, 최종 명중 여부 판정은 [기존 2단계 설계](../combat/TWO_STAGE_HIT.md)를 우선한다. 상태를 발사/착탄 시 매번 독립 재추첨해 확률을 이중 감쇄하지 않는다.
- **쉴카 23mm 4문**은 **API-T 55HP/HEFI-T 108HP·3:1 고정 탄띠가 채택됐으나** 발당 명중률·사격통제 수치는 아직 정하지 않음. 유무장·레이더 종류를 게파르트/M163과 자동 동일시하지 말고, 개별 설계 후 비교한다.
- **보류:** 게파르트 구간 사이 확률 보간식·각 구간 최종 고정값, 호버링/기동 보정배율, 각 레이더·광학 성능별 배율, 조준 지연·발사 AI, 탄착 산포 모델, 자동 점사 종료 조건, 모든 발당 결과 상관관계, 실제 테스트·코드 적용.
