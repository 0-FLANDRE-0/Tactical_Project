# TACTICAL 1989 — Mi-24D/V/P ASO-2V 플레어 및 Lipa IRCM 게임 설계

> **2026-11-22 IRCCM 0~3단계 후속 규칙 반영.** Mi-24D/V/P **ASO-2V 소구경 플레어 발당 18.5%**, D **4×32=128발**, V/P **6×32=192발** 및 Lipa **V/P 기본 장착·D 미장착**은 기존과 동일하다. Lipa의 **90%는 감쇄 전 기본 기만확률**이며 실제 기만확률은 **미사일별 램프형 IRCCM 감쇄율**을 곱해 결정한다. 0단계=0%, 1단계=40~60%(개별 미사일 상세값 미정), 2/3단계=100%(램프형) 감쇄. 수치는 실물 시험값이 아닌 게임 설계값이며 **코드 미구현**.

**차량 정본:** [Mi-24D/V/P 기체](../../vehicles/1989/air/MI24_D_V_P.md) · [플레어·IRCCM 시스템](COUNTERMEASURES_FLARE_IRCCM_ECCM.md) · [9M37/9M37M 시커 모드](../../ammunition/missiles/9M37_9M37M_STRELA10.md).

## 1. ASO-2V 플레어 발사기·적재량 — 사용자 채택 게임 설정

| 항목 | **Mi-24D** | **Mi-24V** | **Mi-24P** |
|---|---:|---:|---:|
| 기만체 발사기 | ASO-2V | ASO-2V | ASO-2V |
| **발사기 개수** | **4개** | **6개** | **6개** |
| **발사기당 소구경 플레어** | **32발** | **32발** | **32발** |
| **총 플레어 적재량** | **128발** | **192발** | **192발** |
| **개별 플레어 기본 기만확률** | **18.5%** | **18.5%** | **18.5%** |
| **일반 살포** | **2발×4회=8발** | **2발×4회=8발** | **2발×4회=8발** |
| **긴급(집중) 살포** | **2발×8회=16발** | **2발×8회=16발** | **2발×8회=16발** |
| **Lipa 기본 장착** | **없음** | **있음** | **있음** |
| **Lipa 기만확률** | — | **90%** | **90%** |

- 사용자가 최초 고려한 **22.5%는 후속 18.5%로 교체**. 숫자는 **발사기/살포 1묶음당**이 아니라 **플레어 한 발의 기본 기만확률**이다.
- 분류는 **소구경**. 단순 외경(직경)이 아니라 **길이·전체 탄체 크기/기만재 규모 등**을 함께 보아 미국 표준 1×1×8인치 계열은 **중구경**, 이 Mi-24용은 **소구경**으로 정한다. 모든 실제 플레어 유형별 연소·분광 성능을 재현한다는 뜻은 아니다.
- 128/192발은 **게임 개별 차종의 선택 적재량**. 현실의 모든 Mi-24D/V/P가 해당 발사기 개수만 탑재했다는 선언이 아니다.
- **살포 모드는 두 가지만 채택: 일반=2발씩 4회 연속(8발 소모), 긴급(집중)=2발씩 8회 연속(16발 소모)**. 기존 임시 '강화 2발×5회/10발' 모드는 **폐기**하고 별도 세 번째 모드를 두지 않는다.
- 2발씩 묶어 연속으로 4회/8회 내보내는 구조이며, **2발 묶음 간 실제 시간 간격·개별 탄 발사 차이·명령/AI 자동선택 조건·쿨타임·유효 시간/거리·보급/재장전은 미정**. 미사일 도달 전에 실제로 방출되어 유효한 플레어만 발당 독립 기만 판정을 수행한다.
- **플레어 재고 완전 살포 횟수:** Mi-24D 128발이면 일반 16회 또는 긴급 8회, Mi-24V/P 192발이면 일반 24회 또는 긴급 12회(각 모드만 반복하고 다른 소모 없는 단순 산술).
- 실제 미사일 플레어 기만 성공확률:
```text
P_flare_final = clamp(0.185 × (1 - FlareResistance) × M_aspect, 0, 1)
```
  * `FlareResistance`는 표적을 추적하는 적 미사일의 **시커 모드별 플레어 저항성**(확률 감쇄).
  * `M_aspect`는 상대방향/시커 유형에 따른 미정 계수.
  * **실제 방출되어 유효한 플레어 한 발마다 독립 판정**, 매 프레임 재추첨 금지.
  * **IRCCM 단계별 기만확률 감쇄율은 능동 Lipa에만 적용**하고 플레어 기만확률에 대입하지 않음.

## 2. Lipa 능동 IR 교란 — 사용자 채택 기종별 기본장착

| 항목 | 현 설계 지위 |
|---|---|
| 장비 | **Lipa 적외선 교란장치(능동 IRCM)** — 플레어와 별개 |
| **기종별 기본 장착** | **Mi-24D 없음 / Mi-24V·P 기본 장착** |
| 작동 | **장치 정상 시 상시** 교란 방향 |
| 방사 방향 | **2D RTS 평면 360도 전방위**, 별도의 수직각·하방 사각지대 판정 **없음** |
| **감쇄 전 기본 기만 성공확률** | **90% 사용자 채택 게임값**. 미사일별 최종 확률은 **90% × (1−IRCCM 램프형 감쇄율)**, 해당 장치 유효 조건에 한정. 전 미사일 보편적 회피율 아님 |
| 적용 미사일 | **IRCCM 0단계(감쇄 0%) 또는 1단계(감쇄 40~60%, 미사일별 정확한 값 별도 지정)**인 시커·고정 모드에서 Lipa 실제 유효 교란조건 충족 시 |
| 램프형 면역 | **IRCCM 2/3단계(감쇄 100%) 및 광학 명암비 채널의 2단계 상당**은 Lipa 기만 판정을 생략, 최종 0%. 3단계 현대 DIRCM 성능은 별도 미정 |
| 판정 빈도 | **미사일 발사체 한 발마다 유효 교란 기회가 생길 때 최대 1회**. 매 게임프레임 90% 추첨 금지 |

- **IRCCM은 0~3단계의 램프형 능동 IRCM 기만확률 감쇄율**로 정의한다. 수치형 **플레어 저항성(%)**과 완전히 별도이며, 과거의 ON/OFF 표기와 'IRCCM=플레어 저항률' 표현은 최신 정본 기준 폐기. **1단계 정확한 감쇄율은 공통 40~60% 범위 안에서 개별 미사일이 결정하며, 기본 50% 자동 적용 금지**.
- 9M37: **광학 명암비 모드 2단계 상당(램프형 교란 비적용)**, **IR 모드 1단계(기만확률 감쇄 45%, ×0.55)**. Lipa 기본 90% 대비 **IR 모드 최종 기만확률 49.5%**(교란 유효 조건에서만, 장비별 미사일당 최대 1회). 9M37M IR/광학은 램프형 감쇄 100%.
- 9M37M: **광학 명암비 2단계 상당, IR 모드 2단계(램프형 감쇄 100%)** → 두 모드 모두 Lipa 교란 판정 생략.
- **한 미사일을 상대로 감쇄 후 Lipa 기만확률과 플레어가 별도로 작동**할 수 있으나 자동 회피·프레임별 중복 추첨은 아니다. **9M37 IR=45%, MIM-72C/E=55%**는 후속 승인된 1단계 개별 감쇄율이며, 그 밖의 미지정 미사일은 정확한 수치 결정 전까지 계산하지 않는다. 판정 순서·교란 시점·추적 회복·장비 고장·유효 조건은 후속 미정.
- 게임의 **2/3단계 램프형 IRCM 완전 감쇄**는 편의상 만든 규칙이며 실제 9M37M이 물리적으로 Lipa에 완전 면역임을 입증하는 실측 사실이 아니다.

## 3. 추가 미정과 변경 경계

- Mi-24D/V/P 기체 **400HP**는 유지. **방향별 확률장갑 25(25)/18(18)/10(10)mm**는 [기체 장갑 정본](../../vehicles/1989/air/MI24_D_V_P.md)이 소유하며 이 플레어·Lipa 문서에서 별도 변경하지 않는다.
- **게임 기종별 Lipa 탑재 여부는 확정**: D형은 없고 V/P형은 기본 장착. 이는 게임의 기본 프리셋이며 **실제 모든 Mi-24D 기체에 Lipa가 역사적으로 존재하지 않았다는 뜻이 아니다**. 장치 연식별 실배치와 외부 개량형은 추가 조사 대상.
- **중구경 AH-64A의 34.6%/발·30발**은 [AH-64A 정본](AH64A_FLARE_ALQ144.md), **중대형 A-10A의 43.8%/발·240발**은 [A-10A 기만체 정본](A10A_FLARE_CHAFF.md)에 각각 사용자 채택되었다. **대구경 및 그 밖의 미지정 기체**의 기만확률·적재량은 미정.
- **게임 엔진 로직, 헬기·SAM 유닛 런타임 미구현**.
