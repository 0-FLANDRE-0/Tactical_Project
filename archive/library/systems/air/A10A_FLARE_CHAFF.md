# TACTICAL 1989 — A-10A 플레어·채프 적재 및 사출 모드 정본

> **2026-11-23 사용자 최종 채택:** A-10A에 날개 외곽 좌·우 2곳 + 동체 중앙 좌·우 2곳 = **기만체 사출 위치 4곳**, **동시 최대 4발**, **공유 적재량 480칸**을 설정한다. **채프 1발 1칸 / 플레어 1발 2칸**, 채프가 미구현인 현재 **플레어 240발**을 탑재한다. **플레어 발당 기본 기만확률 43.8% 확정**(이전 **34.8% 폐기**). **예방: 중앙 동체 좌·우 교대 1발/2.5초 간격**, **표준: 날개 외곽 2발→동체 중앙 2발, 4회 반복·총 16발/1.25초**, **긴급: 전 위치 동시 4발을 8회·총 32발/1.8초**. 아파치 플레어보다 긴 연소시간 및 고정익 후방 방향의 기만확률 감소를 채택한다(구체 지속시간·방향계수 미정). **런타임 미구현**.

**관련 정본:** [A-10A 기체](../../vehicles/1989/air/A10A.md) · [공통 플레어·IRCCM](COUNTERMEASURES_FLARE_IRCCM_ECCM.md) · [아파치 플레어](AH64A_FLARE_ALQ144.md) · [스트렐라-10 플레어 저항](../../ammunition/missiles/9M37_9M37M_STRELA10.md).

## 1. 발사 위치·공유 적재 — 확정

| 항목 | 사용자 선택 게임값 |
|---|---|
| 사출 위치 | **날개 외곽 좌·우 각 1곳(2곳), 중앙 동체 좌·우 각 1곳(2곳)** |
| **동시 최대 발사** | **4발** |
| **공유 탑재 용량** | **480칸** |
| 채프 1발 점유 | **1칸** (채프 효과·사출 **미구현**) |
| 플레어 1발 점유 | **2칸** |
| **플레어만 적재 시** | **240발** (480 ÷ 2) |
| **플레어 기본 기만확률** | **43.8%/발** (기존 제안 34.8% 폐기) |
| 아파치 대비 연소시간 | **더 김**, 정확한 초 단위 미정 |
| 고정익 후방 기만확률 | **감소**, 정확한 감쇄계수·후방 각도 범위 미정 |

- 추후 채프 도입 시에는 `채프 수 + 2×플레어 수 ≤ 480`을 충족해야 한다. **채프 480발을 현재 사용 가능하다고 보지 않음**. 혼합 적재 구성, 채프 자체의 레이더 유도 미사일 기만 효과·UI·재장전은 별도 미정.
- 이 네 위치와 적재 수치는 게임 추상화이며, 실제 모든 A-10A의 물리적 디스펜서 배치/실측 제원이 아니다.

## 2. 사출 모드 — A-10A 전용 3종

| 모드 | 발사 순서·반복 | 플레어 소모 | 시간 | 슬롯 소모 |
|---|---|---:|---|---:|
| **예방** | **동체 중앙 좌·우 발사기 교대로 1발씩** | 발사 이벤트당 **1발** | **2.5초 간격** | 발당 **2칸** |
| **표준** | **날개 외곽 좌·우 2발 → 동체 중앙 좌·우 2발**을 **4회** | **16발** | **전체 1.25초** | **32칸** |
| **긴급** | **날개 2곳+동체 2곳에서 4발 동시** 사출을 **8회** | **32발** | **전체 1.8초** | **64칸** |

- **예방 사출:** 위험지역 진입 전에 사용자가 **켜둘 수 있는 연속 사출**. 켜진 동안 중앙 동체 좌·우가 **2.5초마다 한 발씩 교대**하며 재고를 소비한다. 날개 발사기 미사용. 자동 위험지역 감지/자동 활성화, 좌/우 시작 순서, 첫 발 즉시 발사 여부, 종료·재고 소진 시 동작은 미정.
- **표준 사출:** 날개 외곽 양쪽 **2발 동시**, 그다음 중앙 동체 양쪽 **2발 동시**를 4차례 반복. **8개 사출 이벤트·16발을 묶음 전체 1.25초**에 실행. 개별 이벤트의 정확한 시간배분·등간격 여부는 미정.
- **긴급 사출:** 네 곳에서 **4발 동시**를 8차례 반복해 **8개 사출 이벤트·32발을 묶음 전체 1.8초**에 실행. 각 이벤트 사이 초 단위 간격·쿨타임은 미정.
- **재고 계산:** 플레어 240발만 있는 경우 **표준 15회**, 또는 **긴급 7회 완전 실시 후 16발 남음**. 예방 사출 병행·부분 잔탄일 때 묶음 처리, 모드 간 중첩/전환·재장전은 미정. 예방 사출은 무료가 아니라 발당 2칸씩 소비한다.
- **다른 헬기 규칙 불변:** Mi-24의 일반/긴급, AH-64A의 일반/긴급 두 모드 설계를 바꾸지 않는다. A-10A는 **예방 사출이 추가된 3모드 기종별 예외**다.

## 3. 플레어 기만 및 효과시간·후방 불이익

- **최신 확정값** `P_flare_base = 0.438` (43.8%/발). **34.8%는 구형 제안으로 폐기**. 공통식 `P_flare_final = clamp(0.438 × (1 - FlareResistance) × M_aspect, 0, 1)`에 적용한다.
- `FlareResistance`는 **적 미사일 시커/고정 모드와 환경별 플레어 저항성**, `M_aspect`는 **적 미사일의 상대 방위에 따른 효과 보정**. **고정익 A-10A의 후방에서 기만확률이 줄어드는 사용자 방향 확정**. 후방 판정 각도·감쇄 비율은 미정이며, 같은 후방 불이익을 서로 다른 인자에 중복 곱하지 않는다.
- **A-10A 플레어는 아파치 플레어보다 오래 타는 방향**이지만 정확한 **연소시간(초), 실제 기만 유효시간, 낙하/비행 위치, 열 신호 지속**은 미정. 연소가 길어도 동일 플레어를 매 렌더 프레임 재추첨하지 않는다.
- [공통 규칙](COUNTERMEASURES_FLARE_IRCCM_ECCM.md)에 따라 적 미사일에 **시공간적으로 유효한 플레어 1발마다 1회 독립 추첨**. 아직 발사되지 않았거나 미사일 통과 뒤 발사된 플레어는 기만 계산에서 제외한다. 한 번의 표준/긴급 사출 묶음의 **모든 발이 자동으로 유효한 것은 아니다**.
- **43.8%는 저항성·방위계수 적용 전 기본값**이지 미사일 상대 최종 확률이나 기체 생존율이 아니다. **IRCCM 등급(능동 램프형 교란 감쇄)은 플레어 기만확률에 이중 적용하지 않는다**. 채프·레이더 ECCM은 아직 별도 미정, 무선지령 유도 SAM(예: 9M311)에 플레어를 자동 적용하지 않는다. A-10A에 Lipa/AN/ALQ-144 등이 기본 장착된 것으로 간주하지 않는다.
- **AH-64A는 기존 발당 34.6%·30발 유지**, A-10A만 43.8%·240발로 구별. A-10A 플레어 크기 분류(소·중·대)는 정하지 않는다.

## 4. 추가로 정해야 할 사항

**미정/미구현:** 채프 발사·효과 및 혼합 적재, 플레어 연소·유효시간의 초 수, 후방 불이익 수치·각도, 시퀀스의 개별 이벤트 시간·중복/전환·사출 쿨타임, 적 미사일 유효 판정·재획득, 실제 게임 엔진 적용 및 플레이테스트. **위 미정 항목에 임의 수치를 넣지 않는다.**
