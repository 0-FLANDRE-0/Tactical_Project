# T-90M (2026) Arena-M APS — 포탑 추종 4방향 능동방호체계

> **2026-11-19 사용자 지정 게임 설계 확정.** TACTICAL 현대 확장 T-90M(2026) 전용 Arena-M APS 규격. 실물 장비의 검증된 공식 제원이나 게임 엔진 구현 완료가 아님. 차량 장갑·HP·Relikt는 [T-90M 전용 정본](../../vehicles/tanks/modern/T-90M_2026.md)을 따른다.

## 1. 확정값

| 항목 | Arena-M (T-90M 2026) |
|---|---|
| 방어 기준축 | **차체가 아닌 포신·포탑이 향한 방향**, 포탑 회전에 연동 |
| 담당 구역 | 포탑 기준 **4개 방향 구획**, 각 구획의 방어 범위는 **서로 일부 중첩** 가능 |
| 요격 발사체 재고 | **구획별 3발 × 4구획 = 총 12발**. 구획별 독립 재고 |
| 요격 가능한 접근 발사체 속도 | **45~1,000m/s** (양 끝값 포함) |
| 반응시간 | **140ms (0.14초)** |
| 차탄 발사 대기시간 | **0.25초 (250ms)** — 사용한 해당 구획의 다음 발사까지, 구획별 별도 관리 |
| 겹치는 범위의 대체 요격 | 한 구획의 탄이 **0발**이어도 겹치는 **다른 구획**이 해당 방향을 커버하고 탄·반응·차탄 조건을 만족하면 **대체 요격 가능** |

## 2. 요격·연속 교전 처리

- 공격 발사체의 진행 방향을 **현재 포탑/포신 기준**으로 비교한 후, 그 방향을 커버하는 구획(복수일 수도 있음)을 찾는다. **어느 구획이 어느 정확한 각도를 담당하는지, 중첩 폭·중첩 경계의 선택 우선순위는 아직 미정**이다. 4등분 각도를 임의로 고정하거나 완전 360° 사각 없음으로 단정하지 않는다.
- **구획별 3발을 공유 탄창 12발로 합치지 않는다.** 소진된 구획은 발사할 수 없으나, 방향이 겹치는 이웃 구획이 사격할 수 있는지는 별도 판정한다.
- 각 구획은 자체 **마지막 발사 시각과 0.25초 재발사 쿨다운**을 가진다. 다른 구획이 발사 중이라도 이웃 구획의 재고·쿨다운이 허용하면 요격 시도는 가능하지만 **동시 발사 우선순위/중복 발사 처리**는 미정이다.
- 45~1,000m/s 범위를 충족하더라도 **140ms 대응 시간이 확보되어야** 하고, 해당 구획의 재고·대기·방어각이 모두 충족되어야 요격 시도할 수 있다. 이 조건들은 **자동 100% 성공률을 뜻하지 않는다**.
- 아직 미정: 각 구획 수평 각도와 겹침 폭, 상하 방어각·상부공격 대응, 실제 요격 성공률/효과(APFSDS 관통력 감쇄 여부 포함), 탐지 거리, 복수 표적 우선순위, 재보급·고장·손실·재장전.

## 3. 다른 APS와의 구분

- [T-14M Afghanit](AFGHANIT_T14M.md)은 **포탑 전방 ±60°, 좌·우 5발씩 총 10발, 반응 90ms, 차탄 대기 0.2초, 대상 속도 50~1,700m/s**, APFSDS 등 물리탄 유효 대응 시 관통력 최대 38% 감쇄. Arena-M에는 Afghanit의 **관통력 감쇄 38%를 자동 적용하지 않는다**.

- 본 문서는 **현대 T-90M 설계값만** 확정하며, 기존 전차·장갑·탄종 제원과 게임 코드는 수정하지 않는다.
