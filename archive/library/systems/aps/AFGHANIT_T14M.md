# T-14M Afghanit APS — 전방 120° 능동방호체계

> **2026-11-19 사용자 확정 게임 설계값.** TACTICAL 현대 확장용 T-14M 아르마타 APS의 제원·제약을 기록한다. 실물 아프가닛 공식 시험 제원이나 현행 게임 코드 구현을 주장하지 않는다. 차량 장갑/HP 및 무인포탑 피해 감쇄는 [T-14M 차량 정본](../../vehicles/tanks/modern/T-14M.md)이 우선이다.

## 1. 사용자 지정 확정 제원

| 항목 | T-14M Afghanit 확정 |
|---|---|
| 방어 기준축 | **차체 정면이 아닌 포탑이 바라보는 방향** |
| 좌측 발사기 | 포탑 정면을 기준으로 **−60°~0°**, **요격탄 5발** |
| 우측 발사기 | 포탑 정면을 기준으로 **0°~+60°**, **요격탄 5발** |
| 수평 방어 범위 | **총 120°**, 포탑 정면 ±60° |
| 요격탄 재고 | **좌측 5발 + 우측 5발 = 총 10발**; 각각 별도 방향의 재고 |
| 반응시간 | **90ms (0.09초)** |
| 차탄 발사 대기시간 | **0.2초 (200ms)** — 좌·우 각 발사기의 차탄 대기를 별도 관리 |
| 요격 대상 발사체 속도 | **50~1,700m/s** (양 끝값 포함하는 게임 기준) |
| 운동에너지/물리탄(APFSDS·APDS 등) 대응 | 유효한 APS 대응 시 **탄 자체의 관통력 최대 38% 감쇄** |
| 상부공격 방호 | **최소한으로 제한적**. 정확한 수직 방어각·성공률 미정 |

## 2. 방어각·재고·연속 교전

- 수평 각도는 현재 포탑의 조준 방향을 기준으로 측정한다. 차체만 회전하고 포탑은 다른 방향을 본다면 **포탑 방향을 따른다**.
- 포탑 정면 왼쪽 60°와 오른쪽 60°가 각기 담당하는 독립 구역이며, **한쪽 발사기의 탄이 소진되었다고 다른 쪽 5발을 공유하지 않는다**. 두 방향의 경계선(정중앙 0°) 우선순위, 서로 다른 발사기가 같은 위협에 중복 대응하는 상황, 발사기 손상 및 재장전은 미정.
- **90ms 반응시간과 0.2초 차탄 대기시간은 별도 조건**이다. 발사기가 요격 시도한 시점부터 같은 발사기는 **0.2초**가 지나야 다시 발사 가능하며 좌·우 대기는 독립이다. 다른 쪽에 재고가 남았다고 기존 구획의 방어 범위를 자동 벗어나 요격하지 않고, 발사 조건만으로 100% 성공 처리하지 않는다.
- **속도 제한과 반응시간을 모두 만족해야** 대응 가능 대상으로 취급한다. 1,700m/s보다 빠르거나 50m/s보다 느린 발사체에 대해서는 이 게임 설정상 정상 요격 조건 불충족.
- 수평 방어각 밖과 상부공격의 방호는 자동으로 확보되지 않는다. 상부공격 방호는 사용자가 지정한 **'최소한'**이라는 정성 조건만 확정하고, 상부공격 무조건 무력/0% 또는 몇 %의 임의 성공률도 설정하지 않는다.

## 3. 운동에너지탄/물리탄에 대한 최대 38% 관통력 감쇄

- 사용자가 말한 **'물리탄'은 이 게임 설계에서 대표적으로 APFSDS/APDS 등 운동에너지 관통탄**에 대한 APS 효과로 구별해 기록한다. 다른 비유도 포탄 전체에 이 수치를 자동 확대할지는 별도 미정이다.
- **유효 대응이 성립할 때 관통력 감쇄율은 최대 38%**. 즉 `0 ≤ penetration_reduction ≤ 0.38` 이며 `P_after = P_before × (1 − penetration_reduction)`으로 표현할 수 있다. **38%가 항상 적용되는 고정 감쇄율이 아니다**. 실제 적용량 결정과 성공 확률은 미정.
- 예시(오로지 상한값): 감쇄 전 유효 관통력 600mm RHAe에 최대 38%가 적용되면 **372mm RHAe**. 감쇄가 작거나 APS 대응이 실패하면 결과가 달라진다.
- 이 효과는 **탄의 관통력 감쇄**이지 **T-14M의 KE 장갑 수치 상시 +38%**, 차량 HP 데미지 −38%, 발사체 자동 파괴/격추 보장이라는 뜻이 아니다. KE·CE와 Anti-ERA·관통/도탄 등의 계산 순서는 별도 구체화할 수 있다.
- HEAT/ATGM 등 비운동에너지탄의 요격 결과, 요격 성공률, 발사탄 재고 소모 확정 시점, 운동에너지탄의 감쇄량 분포, 상부공격 세부 대응값은 **미정**. 속도·방향·반응 조건을 갖춘 것만으로 반드시 완전 요격된다고 확정하지 않는다.

## 4. 무인포탑과의 관계

- Afghanit APS는 **전방 요격/관통력 약화 계층**. 포탑 명중 시 **차량 자체 HP 피해 50% 감쇄**는 [T-14M 차량 정본](../../vehicles/tanks/modern/T-14M.md)의 **무인포탑 별도 방호 규칙**이다.
- 두 효과는 서로 다른 단계다. APS 관통력 약화가 있었다고 차량 HP −50%를 추가 APS 데미지 감쇄로 잘못 중복 표기하지 않는다. 포탑 차량 HP 피해는 실제 관통/피해가 발생한 후에 별도 50% 감쇄한다.
- 포탑 전면·측면·후면 구역에는 이 무인포탑 피해 감쇄를 적용하지만, **통합 상부 제7구역 전체**에 이를 자동 적용하지 않는다. 상부 피격의 차체/포탑 구분·모듈 피해·승무원 피해 적용은 미정.

## 5. 비교·변경 경계

- [Leopard 2A8 Trophy HV](TROPHY_HV.md)는 좌우 180°씩 총 360°, 각 3발, 50~1,000m/s, 300ms 반응, 발사기당 1.5초 차탄 대기로 **서로 다른 APS**이다. 이 제원들을 Afghanit에 자동 상속하거나 둘의 효과를 합산하지 않는다.
- 이 문서는 아카이브 설계값을 등록할 뿐이며 **1989 본편 32종·96개 탄약 프리셋·현대 타 전차·게임 코드는 미변경**이다.
