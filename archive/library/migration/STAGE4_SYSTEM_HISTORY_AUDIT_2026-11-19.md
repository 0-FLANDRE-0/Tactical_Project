### 주의: 게임 설계값과 코드 구현 상태는 다른 축

- **사용자 확정 게임 규칙이라고 바로 구현 완료는 아니다.** 예: Trophy HV 독립 발사기와 모듈러 증가장갑, 범용 1989 전차 탄종 공통 곡선의 모든 엔진 경로 적용을 이번 작업에서 주장하지 않는다.
- **WIP 지시서 작성 당시 상태는 후속 PR 결과와 다를 수 있다.** [지시서 이력색인](../history/implementation/README.md)은 원래 **2026-11-15 시점의 표**를 보존하고, 현재 main 코드·검증 아티팩트와의 직접 대조는 5단계로 넘긴다.
- **세계관 전력 보유량**은 [대체역사 원안](../world/1989/WW3_FORCE_INVENTORY_DRAFT.md)으로 보존하고 공식 확정 실제 편제라는 주장을 하지 않는다.
- **WIP HTML/SVG/JS/ZIP/PNG/Python 17개 원본 파일**은 [역사 자산 목록](../history/README.md)에만 링크하고 원위치에 보존했다. 사용자 확정 게임 제원과 과거 시제품의 숫자를 섞지 않았다.

## 4. 5단계 마감 전 해결할 사항

1. **최신 우선권 확정:** 원본과 새 이관본을 수치·표·미정 상태 기준으로 다시 검사. ERA/Anti-ERA/APS 등의 계층 간 이중 계산·중복 설명 발견 시 한 데이터 소유자만 남기고 참조로 바꾸기.
2. **32종 7구역 원본 대조:** [1989 전차](../vehicles/tanks/1989/README.md)·후속 M1A2 2종·현대 Leopard 2A8 누락/중복 검사. 전차 자체 HP와 증가장갑 독립 HP 분리.
3. **탄약/미사일 최신 수치·시대/호환 검사:** 1989 탄약 편성, TOW 2A 탠덤과 TOW 2B 상부 CE240·535 HP, 현대 날탄 Anti-ERA 단계/미정율 구분 재검사.
4. **링크·앵커·원본 정리:** [2단계 감사 A-01~A-08](STAGE2_CANONICAL_SOURCE_AUDIT_2026-11-19.md)의 **NATO 10 vs 11 표제 오기, TOW 2B 옛 §14 앵커** 등 바로잡기. 기존 외부 링크를 무작정 버리지 않고 새 라이브러리 정본으로 안내.
5. **구형 내용 삭제 경계:** 원본을 삭제하기 전 원본 대응표·검산·해시·참조 경로가 확보돼야 한다. 과거 WIP·폐기된 설계 자체는 Git 백업/역사자료에 보존. 대규모 본문 삭제나 코드 변경은 별도 검토.
6. **최종 단계 기록:** 전체 이관 결과, 신규 라이브러리 정본 전환 범위, 남은 미정과 코드 미구현을 명시.
