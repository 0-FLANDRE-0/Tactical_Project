### 보완하며 발견한 누락

1. **TOW-2B 구형 `ammo §14`의 상세 속성표**가 새 TOW 문서에 없었으므로 **원본 그대로 추가**(링크만 현행 원본 경로로 교정).
2. 원본 **§11의 공유 프리셋 54행**을 96행 JSON 외에 **별도 원문 보존 표**로 추가. 원본 **§9·§10의 구형 대기갑 프리셋**도 역사 기록으로 분리하여, 나중에 96개 확정 프리셋으로 잘못 적용되지 않게 함.
3. 전차 원본의 **§7 향후 명중·입사각 검토/§9-F 미정 기준**을 각각 [역사적 피탄 메모](../systems/combat/ARMOR_HIT_FUTURE_NOTES.md) 및 [1989 전차 색인](../vehicles/tanks/1989/README.md)에 보존.
4. 기존 탄약 문서의 **NATO ‘10개 형식’ 오기**는 실제 **미국 5 + 서독 6 = 11형식**으로 표제만 수정(적재 숫자/96개 조합 불변).
5. Bradley 원본의 **구형 TOW 2B §14 앵커**를 새 TOW 정본으로 교정.

## 3. 링크·목차 검사

- **라이브러리의 당시 71개 Markdown 이관/색인 문서**에서 내부 파일 링크 **589건을 영역별로 전수 대조**했고, 실제로 깨진 원본 상대경로 **24건**을 찾아 복구했다. 디렉터리를 가리키는 링크는 파일 경로의 맨 끝 `/`를 구분해 허용했다.
- 과거 TOW 옛 절 앵커는 [현행 TOW 페이지](../ammunition/missiles/TOW_FAMILY.md)를 가리키도록 별도로 수정했다. 원본 전차 BDD/D-Tech `§1-B`, 탄약 `§1`/최신 `§14`의 제목 slug를 실제 헤더와 대조했다.
- [새 `archive/README.md`](../../README.md)는 **이전 14.6k문자 → 간략 정식 색인 약 2.7k문자**로 변경하여 중요 제원·시스템을 직접 찾도록 했다.
- **검증 범위 한계:** GitHub 파일/폴더 대상 존재와 상기 특정 제목 앵커를 검사한 것이다. **외부 웹사이트의 현재 HTTP 접속 여부·모든 Markdown 제목 앵커/동적 JS 링크·실제 게임 코드 실행 테스트까지 전부 검사한 것은 아니다.** 이 검증에 없는 항목을 ‘정상 확인’으로 주장하지 않는다.

### 대량 삭제를 진행하지 않은 이유

**앞선 사용자 지시의 ‘구형 내용 정리’는 가독성 개선과 현재 정본 단일화가 목적**이었다. 기존 63개 안에는 수치 외에도 WIP 구현 당시 판단·출처 링크·미정·반려 아이디어·이미지/실행 파일이 있다. 새 라이브러리의 표 숫자를 검산했다고 해서 모든 오래된 문서의 문맥이나 엔진 코드와의 연결을 자동으로 완벽 검증했다고 선언할 수 없다.

따라서 **현행 공식 목차에서 옛 내용을 제거하고 레거시로 지정하되, 파일 자체는 삭제하지 않는 방식**을 채택했다. 필요하면 Git 기준 커밋으로 모두 복원 가능. 이로써 ‘옛 수치가 최신 정본으로 노출되는 문제’를 해결하면서 자료 손실을 피했다.

## 5. 여전히 별도 결정이 필요한 게임 제원

- 현대 **Anti-ERA 정량 감쇄율**, Relikt 게임용 실제 KE/CE·피복·소모 규칙.
- Trophy HV의 상하 방어각, 탐지/비행시간/요격 성공확률, TOW 2B 상부 공격과의 교전 조건.
- TOW 2B의 별도 최대 사거리·미사일 속도·기폭·비관통 피해, 2A8의 확정 적재탄 구성.
- 다수 WIP 시험 시스템의 전체 차량 범용 적용 여부와 최신 코드 구현 증빙.
- 임시 제안/미정으로 남은 보병·헬기 로켓·M113G·세계관 세부 편제, 외부 보급/포인트 값.

미정값은 **발견된 데이터 누락으로 간주하지 않으며**, 사용자 추가 결정 전까지 임의 설정하지 않는다.
