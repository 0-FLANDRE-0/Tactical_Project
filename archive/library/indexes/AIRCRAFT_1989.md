# TACTICAL 1989 — 공격헬기 전체 설계 현황 (2026-11-15)

> **상태:** 이 문서는 현재까지 대화에서 실제 설계한 **AH-64A Apache / Mi-24D·V·P 4기종**을 한데 모은 **색인·핵심 비교표**다. 전 기종 실제 역사 배치 확정 명세나 게임 코드 구현 보고가 아니다. 다른 헬기 기종을 임의 추가하지 않는다.
> **상세 명세(우선):** [AH-64A](../vehicles/1989/air/AH64A.md), [Mi-24D/V/P](../vehicles/1989/air/MI24_D_V_P.md). 충돌 시 사용자 최신 결정과 각 상세 문서의 해당 탄종값을 우선하며, 이 표는 요약용이다.
> **공통 항공 시스템:** [전술지도·외부 작전 공역, 증원·진입점·ETA, 방공/레이더 LOS](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/air/AIR_ENTRY_AIR_DEFENSE_IFV_AA_RULES_2026-11-14.md).

> **2026-11-21 최신 사용자 HP 정정:** AH-64A **325 HP**(기존 300), Mi-24D/V/P 전부 **400 HP**(기존 325). AH-64A의 장갑은 20(20) 단일값이며, Mi-24는 2026-11-23 후속 사용자 채택에 따라 방향별 확률장갑 25(25)/18(18)/10(10)을 사용한다. 아래 HP 표는 최신값이며 원본 2026-11-15 요약표의 옛 값보다 우선한다. 상세 정본은 [아파치](../vehicles/1989/air/AH64A.md) / [Mi-24](../vehicles/1989/air/MI24_D_V_P.md).

## 1. 기체 확정값

| 기체 | 최대 HP | 장갑 KE(CE), mm | 기본 기관포/기관총 | 대전차 미사일 분류 |
|---|---:|---:|---|---|
| **AH-64A Apache** | **325** | **20(20)** | 30mm M230 / M789 HEDP | AGM-114A Hellfire |
| **Mi-24D Hind** | **400** | **방향별 25(25)/18(18)/10(10)** | 12.7mm Yak-B | 9M17P/MP Falanga |
| **Mi-24V Hind** | **400** | **방향별 25(25)/18(18)/10(10)** | 12.7mm Yak-B | 9M114 계열, 희귀 9M120 |
| **Mi-24P Hind** | **400** | **방향별 25(25)/18(18)/10(10)** | 30mm GSh-30-2K (동체 우측 고정식) | 9M114 계열, 희귀 9M120 |

- **AH-64A는 현재 단일 20(20)mm**, **Mi-24D/V/P는 방향별 3단계 확률장갑**을 사용한다. Mi-24 전면 확률 25/18/10mm = **55/35/10%**, 좌·우 측면 **35/40/25%**, 후면 **0/55/45%**. 평균값은 전면 **21.05mm**, 측면 **18.45mm**, 후면 **14.40mm**(관통에 사용하지 않음). [Mi-24 상세](../vehicles/1989/air/MI24_D_V_P.md).
- 항공기에는 전차 7구역과 입사각 계산을 그대로 적용하지 않는다. Mi-24는 피격 방향만 장갑 확률 선택에 사용하고 관통에는 거리별 0° KE/CE 값을 쓴다. 로터·엔진·조종석 별도 HP는 미도입.
- Mi-24의 실기체 수송칸(최대 8명)은 참고 특성. 게임상 동시 장착 무장/병력/기동 제약·수송 AI는 아직 미정.
- **모든 종류에 같은 치명타 규칙을 적용하지 않는다**. Hellfire 계열만 별도 110% 치명 관통 채택. 일반 기관포·기관총 치명타 없음. 팔랑가/슈투름/아타카 치명타 추가 여부 미정.

- **무유도 로켓**은 개별 발의 낮은 명중률·산포·포드/살보 구성, **유도미사일**은 조준·유도·시야/연막/지형·방공 제약으로 실제 피해량이 달라진다. 최대 적재량을 무조건 전탄 관통 피해로 환산하지 않는다.
- **HEAT는 거리별 관통력 저하 없음**(게임 설계 원칙). HE-FRAG에는 HEAT 관통 수치를 자동 부여하지 않는다.
- 세부 거리·각도별 관통표는 기체별 상세 문서 참조.

- **Hellfire 조건부 치명타:** 관통 성공 + 관통 여유 **최소 10%**에서 미사일당 1회 판정, 전면 **5%** / 측면 **10%** / 후면 **15%** / 상부 **15%**, 발동 시 기본 피해 **110%**. AGM-114A는 884 × 1.1 = **972.4 HP**(정수 처리 미정).
- **유폭 즉사**는 Hellfire 고유 치명타가 아닌 **모든 탄종 공용 별도 전투 시스템**으로 사용자 지정 방향. 발동 조건·확률·전체 확장/코드 구현은 아직 완료되지 않음.
- 아타카의 528은 **최종 결정 수치** (기존 초안 546 아님). M1/M2의 역사적 정확한 접미 형식/탠덤/운용 연도는 사용자 게임 설정과 별개로 검증 필요.

## 4. 남아 있는 설계/구현

1. **Mi-24 무유도 로켓 4종 수치 승인 여부**, 대형 로켓 추가 필요성.
2. **R-60/R-60M**의 1989년 형식별 운용 가능·게임용 관통/피해·유도·탄약량 결정 여부.
3. **헬기 공통 전술 행동:** 비행/고도/기동/사거리/조준·명중률/연사 산포/무장 프리셋·병력 수송/보급.
4. **방공·레이더·LOS·외부 공역:** 비행기의 진입점·ETA, SAM 추적/요격·헬기 지형 엄폐.
5. **전투 엔진 적용:** 선택한 게임용 수치와 치명타/유폭 조건은 현재 아카이브 설계이며, 구현 및 밸런스 실험은 별도 작업이다.

**현재 상태:** 기체·주포·핵심 대전차미사일의 **게임용 숫자 선정은 사실상 완료**, 소련 로켓과 공대공/행동 제원은 일부 제안·미정.
