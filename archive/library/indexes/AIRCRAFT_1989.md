# TACTICAL 1989 — 공격헬기 기존 설계 및 첫 고정익기 A-10A 추가 (2026-11-23)

> **상태:** 2026-11-15 공격헬기 **AH-64A Apache / Mi-24D·V·P 4기종** 기록에, **2026-11-23 최초 고정익기 A-10A Thunderbolt II**를 추가한 색인·핵심 비교표다. 실제 역사 배치 확정 명세나 게임 코드 구현 보고가 아니며, 기종/무장 게임값은 사용자 채택 범위만 정본으로 취급한다.
> **상세 명세(우선):** [A-10A 첫 고정익기](../vehicles/1989/air/A10A.md), [AH-64A](../vehicles/1989/air/AH64A.md), [Mi-24D/V/P](../vehicles/1989/air/MI24_D_V_P.md). 충돌 시 사용자 최신 결정과 각 상세 문서의 해당 탄종값을 우선하며, 이 표는 요약용이다.
> **공통 항공 시스템:** [전술지도·외부 작전 공역, 증원·진입점·ETA, 방공/레이더 LOS](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/air/AIR_ENTRY_AIR_DEFENSE_IFV_AA_RULES_2026-11-14.md).

> **2026-11-21 최신 사용자 HP 정정:** AH-64A **325 HP**(기존 300), Mi-24D/V/P 전부 **400 HP**(기존 325). AH-64A는 2026-11-23 후속 채택한 방향별 25(25)/12(12)/8(8) 확률장갑을, Mi-24D/V/P는 방향별 25(25)/18(18)/10(10) 확률장갑을 사용한다. 아래 HP 표는 최신값이며 원본 2026-11-15 요약표의 옛 값보다 우선한다. 상세 정본은 [아파치](../vehicles/1989/air/AH64A.md) / [Mi-24](../vehicles/1989/air/MI24_D_V_P.md).

- **모든 종류에 같은 치명타 규칙을 적용하지 않는다**. Hellfire 계열만 별도 110% 치명 관통 채택. 일반 기관포·기관총 치명타 없음. 팔랑가/슈투름/아타카 치명타 추가 여부 미정.

- **AGM-65B/D 매버릭 비명중 폭발:** 일반 근접 **최대 50%=690HP**, 초근접 **70 CE / 최대 85%=1,173HP**. **70 CE 관통 = 고정 1,173HP 아님**. 초근접 포함 **HE 장갑별 감쇄** 적용, **폭발거리 감쇄는 장갑 감쇄보다 훨씬 가파른 방향**, 정확한 반경·곡선 미정. [매버릭 정본](../ammunition/missiles/AGM_65B_D_MAVERICK.md). B/D 치명타 **존재만 확정**했으며 아래 헬파이어 세부 수치를 그대로 복제하지 않는다.
- **Hellfire 조건부 치명타:** 관통 성공 + 관통 여유 **최소 10%**에서 미사일당 1회 판정, 전면 **5%** / 측면 **10%** / 후면 **15%** / 상부 **15%**, 발동 시 기본 피해 **110%**. AGM-114A는 884 × 1.1 = **972.4 HP**(정수 처리 미정).
- **유폭 즉사**는 Hellfire 고유 치명타가 아닌 **모든 탄종 공용 별도 전투 시스템**으로 사용자 지정 방향. 발동 조건·확률·전체 확장/코드 구현은 아직 완료되지 않음.
- 아타카의 528은 **최종 결정 수치** (기존 초안 546 아님). M1/M2의 역사적 정확한 접미 형식/탠덤/운용 연도는 사용자 게임 설정과 별개로 검증 필요.

## 4. 남아 있는 설계/구현

1. **Mi-24 무유도 로켓 4종 수치 승인 여부**, 대형 로켓 추가 필요성.
2. **R-60/R-60M**의 1989년 형식별 운용 가능·게임용 관통/피해·유도·탄약량 결정 여부.
3. **헬기 공통 전술 행동:** 비행/고도/기동/사거리/조준·명중률/연사 산포/무장 프리셋·병력 수송/보급.
4. **방공·레이더·LOS·외부 공역:** 비행기의 진입점·ETA, SAM 추적/요격·헬기 지형 엄폐.
5. **전투 엔진 적용:** 선택한 게임용 수치와 치명타/유폭 조건은 현재 아카이브 설계이며, 구현 및 밸런스 실험은 별도 작업이다.

**현재 상태:** 기존 **공격헬기**의 기체·주포·핵심 대전차미사일 게임용 숫자 선정은 사실상 완료(일부 로켓·공대공·행동 제원 미정). **A-10A는 첫 고정익기 HP/장갑, GAU-8/A 3,800RPM·API/HEI 기본피해, API KE 표, HEI CE 8/8/7/6/5/4mm, 5:1 고정 급탄, 30mm HEI 공통 고폭 감쇄 구조까지 채택**. **AGM-65B/D의 830 CE·1,380HP 및 일반/초근접 비명중 폭발 설계도 채택**. **HEI CE별 정확한 폭발 HP·보간, 매버릭 치명타/거리·장갑별 감쇄 세부, 탄약 적재량, 기타 탑재무장·고정익 비행/출격 세부는 미정**.
