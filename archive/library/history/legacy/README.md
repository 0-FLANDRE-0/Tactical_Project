## 우선순위

1. **5단계 완료 이후** 현재 제원은 [정식 라이브러리](../../README.md) 및 [정본 책임 규칙](../../CANONICAL_RULES.md)을 우선한다. 구형 [전차 원본](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/tanks/README.md)과 [탄약 원본](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/ammo/README.md)은 이력 대조용으로만 참조한다.
2. 원본문서 내에 예전 수치/폐기 표식이 남아 있으면 **후속 최신 결정**을 적용. 예: 모듈 **영구 파괴를 도입하지 않는 2026-11-12 결정**은 과거 [관통·모듈 HP 구상](https://github.com/0-FLANDRE-0/Tactical_Project/blob/main/archive/combat/PENETRATION_DAMAGE_AND_VEHICLE_HP_CONCEPT_2026-11-07.md)보다 우선.
3. **초안/예시/잠정**을 확정 게임 수치로 옮기지 않음. 수치가 없다면 **미정**으로 표시.
4. 1989년 32종×3=96개 편성은 [검산한 신규 이관본](../../presets/1989/README.md)으로 비교 가능.
