# TACTICAL 1989 — 탄약 데이터 (Ammo)

> **기준일:** 2026-11-07 | **범위:** 미국·서독·소련·동독 탄약 관통력, 기본탄, 즉응탄/준즉응탄/예비탄, **32종 × 3 = 96개 프리셋**
> **데이터 지위:** 전차 32종의 탄약·적재량 최신 기준표. 폐기된 통합 문서의 이전 기록이 아닌 아래 확정값을 사용한다.
> **관련 문서:** [전차 32종 방호력 데이터](../tanks/README.md) | [아카이브 목차](../README.md)

이 문서는 앞으로 탄약 관통력·탄종·적재 프리셋·탄약 관련 게임 규칙의 **최신 데이터 기준표**다. AP/APFSDS 등은 2,000m/0° KE 설정값을, HEAT/ATGM/HEP 등은 게임 판정용 CE 설정값을 사용한다. 수치는 역사적 실측 확정값이 아니라 협의된 RTS 게임 수치다.

> **탄약별 피해·HEP 후속 설계:** [관통·피해 메모](../combat/PENETRATION_DAMAGE_AND_VEHICLE_HP_CONCEPT_2026-11-07.md) §7~8. M829A1 기본 380(영거리), **0~10m KE 600/505/345**, 치명·과관통 및 근접 비관통 피해곡선 기록. M830 435·폭발 1m는 시험 후보. 탄속 추가 감쇠 계수 미정. 이번에는 **3BM32/3BM42만 2km 3각도 KE를 조정**, 나머지 탄약·속도·프리셋 그대로.

> **WIP11 후속 결정 (2026-11-08):** 양측 M1A2 (1998)에 **M829A2 단일 시험탄**을 사용한다. **100% 기준 차량 HP 피해 405**, A1형 게임 피해 배율 곡선 공유. [피해 메모 §9](../combat/PENETRATION_DAMAGE_AND_VEHICLE_HP_CONCEPT_2026-11-07.md)에 기록했으며 WIP11A 실행 코드에 연결했다.

**고각 관통·탄약별 도탄 후속 설계(2026-11-08):** [선택된 피격면·선형 관통력·탄종별 0/50/100% 도탄각·HEAT 신관](../combat/ANGLE_PENETRATION_RICOCHET_AND_HEAT_FUZE_RULES_2026-11-08.md). **기존 탄약 관통력·탄속·프리셋은 그대로이며 런타임 미구현**.

**0~10m KE 3각도 5mm 기준표 최신화(2026-11-08):** [29종 영거리 0°/30°/60° KE 관통력표](NEAR_ZERO_10M_KE_PENETRATION_2026-11-08.md). **3BM32 2km 505/425/275로 상향, 3BM42 450/380/250으로 하향**. WT 동명 22종, 기등록 M829A1 1종, 인접탄 추정 6종. **기타 2km·탄속·96개 프리셋은 변경 없음**.

**현재 확정:** 전차 **32종 전체**에 기본·대기갑·화력지원 **3종씩 96개** 편성 완료. Leopard 2 KVT (1989)는 Leopard 2A4 C-Type과 동일한 편성을 사용한다. NVA 일부 즉응탄 구획의 역사적 정합성 검증은 별도이며, 독일 105mm HEP의 명칭은 **DM512**만 사용한다.

## 1. 미국 105mm 탄약

- M392A2와 M728은 0° 수치만 보면 전자가 높지만, 30°·60° 경사 대응 차이는 나중에 별도 설정. 숫자를 근거 없이 일괄 상승시키지 않음.
- 미국 105mm 수치의 현행 기준은 표에 있는 M728 KE 230, M735 KE 275, M833 KE 375, M900 KE 490이며 구형 설계값은 사용하지 않는다.
- 미국 105mm M392A2와 독일 105mm DM13 등 명칭이 다른 각국 탄약은 별도 레코드.
- **포구초속 제1출처 (군 교범):** 미 육군 [FM 3-20.12 Tank Gunnery (Abrams)](https://www.military-references.com/wp-content/uploads/books/tanks/usa/m1_abrams/M1_Abrams_Tank_Gunnery_FM_3-20_12_2001.pdf)(2001년), 도판 4-6(M900/M833/M774/M735), 4-7(M728/M392A2), 4-8(M456A1/A2), 4-25(M393A2), 4-26(M494). 상기 **미국 105mm 10종 전부 실제 공개 군 교범값**을 우선한다.
- **워썬더와 군 교범의 차이:** M833 1,485(워썬더) vs **1,493m/s(교범)**; M774 1,509 vs **1,508**; M393A2 732 vs **731**; M456A2 1,174 vs **1,173**. 군 교범값을 사용하며, 각 수치는 **포구초속**이고 기존 2,000m/0° 관통력 설정은 바꾸지 않는다.


### 미국 105mm 경사관통력 잠정 적용 기준 (2026-11-07)

- **확정·잠정 구분:** 기존 **2,000m/0° KE·CE 게임 수치와 탄속은 유지**한다. 새 30°·60° 수치는 **워썬더 2,000m 탄종별 경사관통력 비율을 적용해 만든 TACTICAL 게임용 잠정 수치**이고 실측 제원이 아니다. 모든 30°·60° 산출값을 **5mm 단위 반올림**했다. 0° 수치 역시 WT의 숫자로 갈아끼우지 않는다.
- **계산 원리:** `TACTICAL 30° = roundTo5(TACTICAL 0° × WT 30° / WT 0°)` / 60°도 동일. 각도는 **피격된 평면의 법선에 대한 입사각**이며 30°·60° 수치는 **해당 각도에서 관통 가능한 공칭 판두께 게임값(LOS 아님)**으로 통일한다. 기존 7구역 방호력은 고정하고 **장갑에 별도 경사/LOS 배율을 중복 적용하지 않는다**.
- **참고 자료:** [워썬더 공식 위키의 경사관통력 표 해설](https://wiki.warthunder.com/661-shell-normalization-against-angled-armor-in-war-thunder) / [워썬더 M68A1 105mm 탄약표](https://old-wiki.warthunder.com/M68A1_%28105_mm%29/Ammunition) / [워썬더 L7 계열 탄약표](https://old-wiki.warthunder.com/index.php?printable=yes&title=L7_%28105_mm%29_%28Family%29%2FAmmunition). 구 위키는 주로 거리별 **0°** 값을 보여주므로, 각도별 2km 비율은 [M728/M735 각도 표의 커뮤니티 보존본](https://seore.org/w/%EC%9B%8C%20%EC%8D%AC%EB%8D%94/%EC%A7%80%EC%83%81%20%EB%B3%91%EA%B8%B0/%EB%AF%B8%EA%B5%AD%20%ED%8A%B8%EB%A6%AC/%EC%A4%91%ED%98%95%EC%A0%84%EC%B0%A8%20%C2%B7%20MBT), [M392A2 각도 표 보존본](https://www.namu.moe/w/%EC%9B%8C%20%EC%8D%AC%EB%8D%94/%EC%A7%80%EC%83%81%20%EB%B3%91%EA%B8%B0/%EC%9D%B4%ED%83%88%EB%A6%AC%EC%95%84%20%ED%8A%B8%EB%A6%AC/%EC%A4%91%ED%98%95%EC%A0%84%EC%B0%A8%20%C2%B7%20MBT), [M774/M833 각도 표 보존본](https://seore.org/w/%EC%9B%8C%20%EC%8D%AC%EB%8D%94/%EC%A7%80%EC%83%81%20%EB%B3%91%EA%B8%B0/%EB%AF%B8%EA%B5%AD%20%ED%8A%B8%EB%A6%AC/%EC%A4%91%EC%A0%84%EC%B0%A8%20%C2%B7%20MBT), [M900 각도 표 보존본](https://seore.org/w/%EC%9B%8C%20%EC%8D%AC%EB%8D%94/%EC%A7%80%EC%83%81%20%EB%B3%91%EA%B8%B0/%EB%AF%B8%EA%B5%AD%20%ED%8A%B8%EB%A6%AC/%EB%8C%80%EC%A0%84%EC%B0%A8%20%EC%9E%90%EC%A3%BC%ED%8F%AC) 및 [WT 포럼 60° 교차 자료](https://forum.warthunder.com/t/the-comprehensive-apfsds-penetration-datasheet/4806)를 대조했다. **워썬더 패치·포별 표에 차이가 있을 수 있으므로 절대값이 아니라 같은 표의 각도 비율을 참고**했다.
- **예시 비율:** M392A2 WT 2,000m `252/231/96`(0/30/60), M728 `222/193/121`, M735 `312/242/146`, M774 `319/269/184`(보존본 구형 표), M833 `369/311/약213`, M900 `486/410/281`. 모두 **WT 스냅샷의 게임값**이며 한 시점의 최신 공식 실측표가 아니다. M774 등은 위키 업데이트마다 0° 값이 다른 사례가 있다.
- **예외·승인 전제:** M456A1은 직접 대응되는 WT 형식별 경사표가 확인되지 않아 **M456A2의 비율(400/346/200)을 잠정 상속**한다. 두 탄의 불리한 입사 조건 **신관 신뢰성 차이는 관통력과 별개 판정 아이디어**로 유지. M393A2는 **HEP 효과지표 CE 120을 세 각도에서 동일한 게임값**으로 둔다(워썬더 HESH 프로필 참고). M494는 WT 직접 대응값이 없고 **대인용 효과지표 KE 5**이므로 **2026-11-07 사용자 지정 게임 판정값 5/0/0(0°/30°/60°)**으로 기록한다. 30°·60°의 KE 0은 실제 시험 관통력이 아니라 게임 설계값이다. HEP/APERS 수치를 실제 관통 시험치처럼 해석하지 않는다.
- **상태:** 이 30°·60° 값은 논의용 **잠정 게임 데이터**이며 **관통 확률식·거리 보간·도탄/신관 실패·게임 코드 구현은 미확정/미구현**이다. 추후 사용자가 값·공식을 확정하면 여기서 갱신한다.

- **M829A1 영거리 기록 보정(2026-11-08):** 기본 차량 피해 **380은 영거리 기준**. [구 WT M256](https://old-wiki.warthunder.com/M256_%28120_mm%29/Ammunition)의 10m 0° **598**은 원자료이고, **TACTICAL 5mm 기준은 0~10m 0°/30°/60° KE600/505/345**. 원자료 중간 100m=596, 500m=589, 1km=580, 1.5km=570, 2km=560은 게임에서 0° 595/590/580/570/560으로 표준화(영거리와 각도 상세는 [10m 29종 기준표](NEAR_ZERO_10M_KE_PENETRATION_2026-11-08.md)). 기존 2km KE560/475/325, 포구초속 1575 유지. 잔여 관통력 비율은 0%→65%, 7.1429%→105%, 14.2857%→108%, 71.4286%→65%, 85.7143%→35%, 93% 이상→20%로 선형 보간. 비관통 근접피해 0+mm120/5mm80/10mm35/15mm 이상0은 내부 피해 발생 시 시험값이며 확률·탄속 추가 감쇠계수 미정.
- **M830 시험 후보(2026-11-08):** 직접 관통 차량 피해 **435**, 보병·비장갑 대상 폭발 반경 **1m**, 기갑 차량에는 **범위 폭발 피해 없음**. 직접 HEAT 관통 판정과 별도, 중복 피해 없음. [피해 메모 §8](../combat/PENETRATION_DAMAGE_AND_VEHICLE_HP_CONCEPT_2026-11-07.md).
- **포구초속 1순위 근거 (공개 미군 자료):** [USMC *MCWP 3-12 Marine Corps Tank Employment* (2005), Appendix D](https://www.marines.mil/Portals/1/Publications/MCWP%203-12%20Marine%20Corps%20Tank%20Employment.pdf)는 M829 **1,670**, M829A1 **1,575**, M829A2 **1,680**, M830A1 **1,410m/s**를 제시한다. [미 육군 *Direct Fire Ammunition Handbook* (2021), pp. 113·116·118](https://jpeoaa.army.mil/Portals/94/MAS/Documents/MASHandbook_2021.pdf)은 M830A1 **1,410**, M830 **약 1,140(1,139.9)**, M829A2 **1,680m/s**를 확인한다. [Jane's Ammunition Handbook (2001–2002)](https://index.crashjb.site.nfoservers.com/Boogaloo2020/Marksmanship%20%26%20Ballistics/Ballistics/Jane%27s%20Ammunition%20Handbook.pdf)도 M829 **1,670m/s**를 제시한다.
- **출처 충돌 처리:** USMC *MCWP 3-12*의 M830 도판에는 **1,410m/s**가 기재되지만, 독립적인 미 육군 2021 핸드북 및 *FM 3-20.12*의 M830 수치는 **1,140m/s**이다. 본 게임 기준값은 **1,140m/s**로 채택하며 도판의 불일치를 기록한다. **M830과 M830A1은 서로 다른 탄**이므로 같은 초속으로 처리하지 않는다.
- **운용 상태:** **M829A2는 WIP11A의 양측 M1A2 (1998) 시험용으로 실행 코드에 적용했다.** 100% 기준 피해는 405, A1형 게임 피해 배율 곡선을 공유한다. **M830A1은 후기 시대용 사전 데이터 상태**를 유지한다. 두 탄 모두 **1989년 본편 전차의 기본탄·96개 프리셋·선택 목록·AI 선택·재보급 후보에는 포함하지 않는다.** WIP11 시험용 채택과 1989년 본편 편성을 구분한다.
### 미국 120mm 경사관통력 산출 기준 (2026-11-07, 잠정)

- **기본값 보호:** 기존 2,000m/0° KE·CE 게임 관통력, 포구초속, 기본탄·적재 상태는 **일절 수정하지 않았다**. 새 **30°/60° 수치만 워썬더의 2,000m 각도별 표 비율**로 계산하고 **5mm 단위 반올림**했다. 각도는 장갑면 법선 기준이며 이 수치는 **공칭 장갑판 두께(LOS 두께 아님)**로 비교한다. 전차별 KE(CE) 방호력은 고정값으로 두고 추가 장갑 LOS 배율을 동시에 곱하지 않는다.
- **산식:** `TACTICAL(30°)=round5(TACTICAL(0°)×WT(30°)/WT(0°))`; 60°도 동일. 이 값은 공개 게임 데이터로 맞춘 TACTICAL의 **잠정 밸런스 값**이지 실제 전차탄의 측정값이 아니다.
- **비율 원자료 — 2,000m / 0°·30°·60°:** M829 = **454/383/262**; M829A1 = **560/473/324**; M830 = **480/416/240**; M830A1 = **350/303/175** ([워썬더 미국 MBT 과거 각도별 표 스냅샷](https://seore.org/w/%EC%9B%8C%20%EC%8D%AC%EB%8D%94/%EC%A7%80%EC%83%81%20%EB%B3%91%EA%B8%B0/%EB%AF%B8%EA%B5%AD%20%ED%8A%B8%EB%A6%AC/%EC%A4%91%EC%A0%84%EC%B0%A8%20%C2%B7%20MBT?rev=148)). M829A2 = **597/504/345** ([워썬더 중국어 위키 M1A2 SEPv3](https://wiki.biligame.com/warthunder/M1A2_SEPv3), [공식 WT M1A2 0° 재확인](https://wiki.warthunder.com/unit/us_m1a2_abrams)).
- **HEAT-MP 판독 주의:** M830A1은 WT에서 운동에너지 소형 표시값과 **화학에너지 관통력 350/303/175**가 별도 구분되므로, 해당 **CE 비율만** 가져왔다. M830도 480/416/240의 CE 비율을 사용한다.
- **워썬더 판본 차이:** M829의 최신 공식 위키 0° 값은 444mm, 일부 과거 각도표는 454mm이며, M829A1도 558/560 등 시점 차이가 있다. **서로 다른 판본의 각도값을 섞지 않고 동일한 표 내 0·30·60 비율을 사용했다.** 이전 게임 수치로 정확한 물리 결과가 보장되는 것은 아니다.
- **1989년 본편 제외 상태 유지:** **M829A2·M830A1은 TACTICAL 1989 시나리오와 96개 적재 프리셋에서 사용하지 않는다.** M829A2의 WIP11 채택은 별도 1998년형 시험에 한정한다. M830A1의 채택 여부는 미정이다.
- **아직 미정:** 거리별 탄속·관통력 감쇠, 0~30~60° 사이 보간 방식, 고경사 도탄·신관 판정, 실제 전투 명중·관통 확률식과 구현.

- M830 등 HEAT계 탄약의 거리별 관통력 감쇠 규칙은 KE탄과 별도로 처리할 예정이며 세부표 미정.

### 서독 105mm 경사관통력 잠정 적용 기준 (2026-11-07)

- 위 미국 105mm 절과 동일한 원칙으로 **원래 게임 0° 값을 유지하고 워썬더 각도 비율만 반영**, 30°/60°만 5mm 단위 반올림한다. 값은 **모두 게임용 잠정 수치**다.

### 서독 120mm 경사관통력 산출 기준 (2026-11-07, 잠정)

- **적용 원칙:** 미국 120mm와 동일한 `WT 2,000m 30°/0°, 60°/0°` 비율 × 기존 게임 0° 수치, **5mm 반올림**. 모든 탄종의 기존 **0° KE·CE는 유지**하며, 포구초속도 **DM43의 1,660→1,740m/s 변경을 제외하고 유지**한다.
- **동명 WT 2,000m 원자료 (0°/30°/60°):** DM13 **359/311/208** ([워썬더 스웨덴 Strv 121 차량 각도표](https://seore.org/w/%EC%9B%8C%20%EC%8D%AC%EB%8D%94/%EC%A7%80%EC%83%81%20%EB%B3%91%EA%B8%B0/%EC%8A%A4%EC%9B%A8%EB%8D%B4%20%ED%8A%B8%EB%A6%AC/%EC%A4%91%ED%98%95%EC%A0%84%EC%B0%A8%20%C2%B7%20MBT?rev=20), DM23 **376/317/217**, DM33 **440/371/254**, DM12·DM12A1 **480/416/240** ([독일 Leopard 2 각도별 커뮤니티 보존본](https://seore.org/w/%EC%9B%8C%20%EC%8D%AC%EB%8D%94/%EC%A7%80%EC%83%81%20%EB%B3%91%EA%B8%B0/%EB%8F%85%EC%9D%BC%20%ED%8A%B8%EB%A6%AC/%EC%A4%91%ED%98%95%EC%A0%84%EC%B0%A8%20%C2%B7%20MBT)). [워썬더 공식 Rh120 L/44 0° 탄약표](https://old-wiki.warthunder.com/Rh120_L/44_%28120_mm%29/Ammunition)에서 동명 탄약의 2,000m 0° 자료를 교차 확인했다.
- **동명 경사 표가 없는 형식 — 명시적 대체:** DM23A1은 **DM23 비율(376/317/217)**, DM33A1은 **DM33 비율(440/371/254)**을 **가상 게임용 대체**로 사용한다. 실차의 독립된 30°/60° 측정 성능을 확인했다는 뜻은 아니다.
- **DM43 경사 비율 업데이트(2026-11-07):** 사용자가 확인한 워썬더 위키의 DM43 **2,000m 기준 0°/30°/60° = 493/416/292mm**를 새로운 **잠정 참고 스냅샷**으로 기록한다. 이 정확한 숫자 조합을 접근 가능한 공식 위키 페이지에서 독립적으로 재확인하지는 못했다. 과거 [워썬더 구 공식 Rh120 L/44 탄약표](https://old-wiki.warthunder.com/Rh120_L/44_%28120_mm%29/Ammunition)에는 **DM43 1,660m/s, 2,000m/0° 507mm**로 표시돼 판본/게임 설정 차이가 있다. 기존 게임 **KE 505(0°)**는 유지하고 비율 **416/493, 292/493**을 적용해 **30° KE 425, 60° KE 300**(5mm 단위 반올림)으로 바꾼다. **이전 DM33 대용 비율 및 60° KE 290은 폐기**한다. 후속 1989년 시나리오 희귀 시험탄 지위는 그대로다.
- **HEAT:** DM12와 DM12A1은 워썬더에서 2,000m/0°·30°·60° **480/416/240**으로 확인되며 TACTICAL의 기본 CE 480을 그대로 사용해 **480/415/240 (5mm 반올림)**로 기록했다. 거리별 감쇠·도탄은 아직 미정.
- **상태:** 30°·60°는 모두 **잠정 게임 데이터**, 워썬더 패치별 차이 및 대체 프로필 이용 기록을 반드시 보존. 미결정인 탄약별 고유 경사 효과는 향후 개별 조정할 수 있다.

- DM23과 DM23A1의 **현실 제식명·개량형 구분에는 사료상 불확실성이 있다는 논의가 있었으나**, 게임에서는 서로 다른 수치/재고의 별도 탄약으로 유지하기로 함.
- 120mm DM33은 **KE 450**, DM33A1은 **KE 470**의 별도 게임 탄종이다. 역사적으로 서로 다른 실측 관통력을 확정했다는 주장이 아니며, 게임상 재고·보급을 구분하기 위한 독립 레코드다.
- DM12와 DM12A1은 **대장갑 관통력 동일(CE 480)**. A1의 파편 슬리브에 따른 **대인 파편 효과 강화**로 선택 가치를 구분하고, DM12는 낮은 가격/구형 재고로 구분.
- DM43은 실제 1989년 정상 배치형으로 적지 말 것. WARNO식 대체역사에서 **LKE I 계열 시험탄을 조기 투입**한 게임 전용 상황.
- **DM33A1** 재고 부족 시 배치 단계 또는 **전투 중 재보급 단계**에서 **DM33(450)** 또는 **DM23A1(410)** 등을 선택해 화력을 어느 정도 유지하는 것이 설계 의도. 플레이어가 발사마다 탄종을 고르는 방식은 아님.

- 105mm/120mm처럼 이름이 겹치는 DM13, DM23, DM33, DM12는 **구경별 별도 내부 ID**가 필요. DM33_105mm(KE 365)는 이번 변경 대상이 아니며 DM33_120mm(KE 450)와 DM33A1_120mm(KE 470)를 별개 ID로 구분.

### 125mm 2,000m 경사관통력 — 잠정 설계안 (2026-11-07)

- **기준:** 기존 0° KE/CE 게임값, 탄약 속도(포탄 포구초속/미사일 비행속도), 채택 상태, 적재 프리셋을 **그대로 유지**하고 30°·60° 열만 추가. 모든 추가값은 **게임 밸런스용 잠정값이며 실제 탄약 관통 시험값으로 사용하지 않는다.** 표의 각도는 선택된 피격면의 법선 기준, 관통력은 해당 각도의 **공칭 판두께 게임 수치(LOS 환산두께 아님)**. 장갑 7구역 KE(CE)에 별도 LOS 배수를 중복 적용하지 않는 현재 논의 방향을 따른다.
- **워썬더 참고 방식:** [최신 공식 T-64A](https://wiki.warthunder.com/unit/ussr_t_64a_1971), [최신 공식 T-80B](https://wiki.warthunder.com/unit/ussr_t_80b), [최신 공식 T-72B](https://wiki.warthunder.com/unit/ussr_t_72b)는 주로 거리별 0° 값을 직접 노출한다. 30°/60°는 [워썬더 각도별 탄약표 보존본(소련 전차)](https://seore.org/w/%EC%9B%8C%20%EC%8D%AC%EB%8D%94/%EC%A7%80%EC%83%81%20%EB%B3%91%EA%B8%B0/%EC%86%8C%EB%A0%A8%20%ED%8A%B8%EB%A6%AC/%EC%A4%91%EC%A0%84%EC%B0%A8%20%C2%B7%20MBT) 및 [또 다른 각도별 표 보존본](https://namu.moe/w/%EC%9B%8C%20%EC%8D%AC%EB%8D%94/%EC%A7%80%EC%83%81%20%EB%B3%91%EA%B8%B0/%EC%86%8C%EB%A0%A8%20%ED%8A%B8%EB%A6%AC/%ED%94%84%EB%A6%AC%EB%AF%B8%EC%97%84%20%EC%B0%A8%EB%9F%89)을 대조했으며, 이는 **최신 공식 위키 팝업에서 3각도를 직접 확인한 자료가 아니다**. 서로 다른 버전의 0° 수치와 임의로 각도값을 섞지 않는다.
- **동명 WT 3각도 비율 (과거 근거):** 3BM9 `248/217/141` → 게임 `300/265/170`, 3BM15 `400/328/154` → `390/320/150`, 3BM22 `380/322/173` → `425/360/195`. **3BM42** 원자료 `406/343/235`의 비율로 만든 옛 게임값 `465/395/270`은 **후속 밸런스 하향으로 폐기**. 최신 3BM42 `450/380/250`은 원자료 비율을 그대로 강제한 값이 아닌 **사용자 승인 수치**다.
- **각도표 직접 확인이 부족한 게임 설정:** 3BM26 `405/365/200`, 3BM29 `440/375/255`는 잠정 밸런스안. **3BM32 Vant는 495/410/255 → 505/425/275 상향**, **3BM42 Mango는 465/395/270 → 450/380/250 하향**(2026-11-08 사용자 승인). 게임 관통력이지 실제 실험값이 아니다.
- **HEAT, ATGM:** 동명 WT 3BK12M·3BK18M·9M112·9M119의 게임상 경사 감소 경향에 맞춰 **30° 약 86.6%, 60° 50%**를 채택해 5mm로 반올림. 동명 자료를 찾지 못한 3BK14M·3BK21B·3BK29와 9M112M/M2·9M124·9M119M은 **HEAT 공통비율을 상속한 게임용 추정**이며 실측값 아님. **9M119M은 1989년 게임 미사용**, **9M124·9M112M2는 선택 여부 미정**이며 이 열을 추가했다고 사용 가능 상태가 되는 건 아니다.
- **HE/벌집탄:** 3OF19·3OF26은 워썬더 HE의 각도별 대표 게임 피해 수치가 일정한 특성을 참고해 각각 **CE 35/35/35** 및 **CE 40/40/40**으로 단순화. 3Sh7은 M494처럼 대인 특수탄의 상징적 방호 판정값으로 **KE 5/0/0**을 임시 사용한다. 고폭탄의 실제 장갑 관통 실험 결과를 뜻하지 않는다.
- **기존 보류 HEAT 탄약의 참고용 미채택 경사값:** 3BK12M `CE 420/365/210`; 3BK14 `CE 450/390/225`; 3BK18 `CE 500/435/250`; 3BK21 `CE 550/475/275`. 전부 HEAT 공통 비율의 **게임용 참고안**이며, 보류탄을 실제 전력·정식 기본탄으로 승격하지 않는다. 3BK12M은 동독 후보 표에 반영한다.
- **추후 결정:** 실제 게임 적용 승인, 거리·입사각 보간, 상부 피탄, 도탄·신관 확률, 3BM 계열 간 밸런스, 보급 비용/가용량. **현재 전투 엔진 구현이나 96개 프리셋을 변경하지 않는다.**

**125mm 속도 출처·적용 원칙 (2026-11-07)**

- 9M112 계열 초기탄 대비 M(20%), M2(40%), 9M124(80%) 개선이라는 역사적 상대적 목표는 참고 가능하나, 이 문서의 480/600/680/850 수치 자체는 **게임 설계값**.

- 나머지 **3BK12M 420 (905m/s), 3BK14 450 (905m/s), 3BK18 500 (905m/s), 3BK21 550 (905m/s)**은 예비 후보/보류 원안을 유지한다. 이 포구초속 사전 기입은 게임 사용 승인과 별개다.
- **탄종별 방호 판정 분류:** APDS/APFSDS = KE; **ATGM, HEAT, HE/HE-FRAG, HEP/HESH = CE; 벌집탄/APERS = KE**. HE/HEP가 실제 성형작약 제트를 사용한다는 뜻이 아니라 **게임 엔진의 저항 참조값**을 통일하는 목적.
- 위 125mm 탄약의 전차별 기본 대표탄 명칭과 기본·대기갑·화력지원 프리셋의 AP/HEAT/HE/ATGM 발수는 §7·§11에서 확정했다. 같은 범주 안의 세부 HE-FRAG 종류·희귀 미사일 보급 범위 등은 별도 검토이며 주포·유도체계 호환성은 유지한다.
- 전차의 미사일 사격통제장치/유도기와 호환되는 ATGM만 적재·발사 가능하게 제한할 필요가 있음. 모든 125mm 전차에 모든 125mm ATGM을 자동 허용하지 않음.

## 8. 동독 NVA 탄약 및 역사적 전투탄수

### 100mm 경사관통력 잠정 적용 기준 (2026-11-07)

- **0° KE/CE 및 탄속은 기존 확정·잠정값을 그대로 유지한다.** 30°·60°만 앞서 제안하고 사용자와 논의한 **게임용 잠정값**으로 기입했다. 각도는 피격면 법선 기준이고, 수치는 해당 각도에서 대응 가능한 **공칭 RHA 판두께 게임값(LOS 환산 두께 아님)**이다. 장갑 KE/CE에 별도의 경사 LOS 보정 배수를 중복 적용하지 않는 방향을 따른다.
- **BR-412B / BR-412D:** 워썬더 동명탄 경사표의 경향을 참고한 155/130/65, 170/130/60을 사용. 워썬더 버전에 따라 차이가 있을 수 있으며 모두 게임용 잠정값이다.
- **3BM8:** APDS(분리철갑탄)이며, 이전 워썬더 경사관통력 비율을 참고해 **275/250/105**로 잠정 표기한다. 현대 워썬더 상세창의 2km 전 각도값을 동일 판본에서 확정 검증한 것은 아니다.
- **3BM20:** APFSDS(날개안정분리철갑탄)이며 **255/210/95**는 **동명탄의 직접 확인된 워썬더 관통력 표가 없는 게임용 추정값**이다. 3BM8보다 세 각도 모두 낮다는 한계를 확인했지만, 사용자 결정대로 **일단 이 잠정안을 유지**한다. 억지로 3BM20의 경사관통력을 상향하거나 3BM8의 0° KE를 낮추지 않는다. **향후 전차별 탄종 보급 가용량·희소도·포인트를 이용해 사용 가치를 차별화할 수 있는지 검토**한다. 이는 **보급량 수치나 탄약 프리셋을 지금 변경했다는 뜻이 아니다**.
- **BK-5 / BK-5M:** 기본 CE 380/390에 **HEAT 계열의 30° 약 86.6%, 60° 50% 비율**을 게임용으로 적용해 380/330/190 및 390/340/195를 사용. BK-5M은 동명탄 3각도 직접 자료가 없어 계열 비율을 상속한다.
- **OF-412:** CE 25/25/10은 **고폭탄의 게임용 유효피해 지표**이며, 실물 고폭탄의 장갑 관통 시험값이 아니다. 워썬더 고폭탄 경사값의 패턴을 참고한 임시 판정값이다.
- **9M117:** CE 600/520/300은 워썬더 동명 미사일의 경사관통력 비율을 반영한 잠정안이다. 표의 **370m/s는 포구초속이 아닌 미사일 대표 비행속도**로 유지한다. T-55AM2B 유도체계 호환 제한도 기존대로 유지.
- **조사 참고:** [최신 워썬더 T-55A](https://wiki.warthunder.com/unit/ussr_t_55a) / [최신 T-55AMD-1](https://wiki.warthunder.com/unit/ussr_t_55_amd_1) / [구 워썬더 D-10T 탄약표](https://old-wiki.warthunder.com/D-10T_%28100_mm%29/Ammunition). 최신 위키의 개별 탄종 상세 팝업은 완전한 동일 버전 각도별 수치를 독립 확인하지 못해, **워썬더 실측 제원이나 최신 공식 확정값이라고 주장하지 않는다**.
- **상태:** 30°·60° 수치 전부 **잠정**, 경사각 사이 보간·도탄·피해 확률·거리별 관통력 보정 및 게임 코드 구현 **미정/미구현**. 필요하면 이후 개별 탄종만 다시 조정한다.

- **속도 의미:** 위 일반 포탄 **7종은 포구초속**, **9M117은 미사일 비행속도**를 기록한다. 9M117의 포구 이탈 순간 속도를 포탄과 동일한 '포구초속' 열로 취급하거나 게임용 비행속도와 바꿔 사용하지 않는다. 향후 다른 포발사 미사일에도 별도의 **미사일 비행속도**를 적용한다.

## 9. 소련 기존 대기갑 적재 프리셋

**대기갑 프리셋:** 확정된 최신값만 기록한다. T-64A 예비탄 AP/HEAT/HE는 **4/3/2**이며, 기본·화력지원 프리셋은 아래 §11을 따른다. 즉응탄은 자동장전장치의 준비탄, 예비탄은 그 외 주포탄을 뜻한다.

| 해당 형식 | 즉응 AP/HEAT/HE/ATGM | 즉응 합 | 예비 AP/HEAT/HE/ATGM | 예비 합 | 총합 |
|---|---|---:|---|---:|---:|
| T-64A (1969/1975) | 14 / 10 / 4 / 0 | 28 | **4 / 3 / 2 / 0** | 9 | **37** |
| T-64B (1976/1984), T-64BV (1985) | 14 / 6 / 4 / 4 | 28 | 0 / 4 / 4 / 0 | 8 | **36** |
| T-72A (1979/1983) | 12 / 6 / 4 / 0 | 22 | 8 / 8 / 6 / 0 | 22 | **44** |
| T-72B (1985/1989) | 12 / 5 / 2 / 3 | 22 | 8 / 8 / **5** / 2 | 23 | **45** |
| T-80B (1978/1984), T-80BV (1985) | 14 / 7 / 4 / 3 | 28 | 5 / 3 / 2 / 0 | 10 | **38** |
| T-80U (1985/1989) | 14 / 6 / 4 / 4 | 28 | 7 / 6 / 4 / 0 | 17 | **45** |

- **최종 수정:** T-72B 예비 HE를 4발에서 **5발**로 변경하여 준비탄 22발 + 예비탄 23발 = 총 45발 완성.
- **즉응탄 설계 원칙(소련·NATO 공통):** 즉응탄과 예비탄을 별도의 수량으로 추적한다. 소련식 자동장전 차량은 장전장치 내부 준비탄, 서방식 수동장전 차량은 우선 장전 구역을 즉응탄으로 취급. 준비탄 소모 뒤의 예비탄 이전·재충전 소요 시간 및 실행 방식은 후속 협의.
- 이 표의 적재량은 **게임용 대기갑 적재 프리셋**이며 실제 특정 부대의 1989년 탄약 편성표라는 주장은 아님. 사용자가 선택하거나 AI 임무에 따라 다른 프리셋도 사용 가능하다.
- 서방 전차의 게임용 총 적재량·즉응탄/준즉응탄/예비탄 프리셋은 아래 **11-B절**에 별도 보관. 탄약 이동 및 장전 방식은 **11-C절 예정 설계** 참조.


## 10. NATO 기존 대기갑 적재 프리셋

주포 탄약 적재 구분은 **즉응탄 / 준즉응탄 / 예비탄**. M1·IPM1의 포탑 내 별도 3발은 사용자 의사에 따라 즉응탄 25발에 통합하여 게임에서 따로 추적하지 않는다. 아래 값은 사용자가 제시하고 합계 검증을 마친 **게임 대기갑 프리셋**이며 공개군 교범의 실전 기본 편성표는 아님. 일반 AI는 아래 **11-E절의 기본 프리셋**을 사용.

| NATO 전차 | 즉응탄 AP/HEAT/HEP | 준즉응 AP/HEAT/HEP | 예비 AP/HEAT/HEP | 합계 |
|---|---|---|---|---:|
| M1, IPM1 (105mm) | 15 / 6 / 4 = **25** | 8 / 8 / 6 = **22** | 4 / 4 / 0 = **8** | **55** |
| M1A1, M1A1 HA (120mm) | 12 / 5 / 0 = **17** | 10 / 7 / 0 = **17** | 3 / 3 / 0 = **6** | **40** |
| Leopard 1A5 (105mm) | 6 / 4 / 3 = **13** | 없음 | 18 / 14 / 10 = **42** | **55** |
| Leopard 2A3, Leopard 2A4 C (120mm) | 9 / 6 / 0 = **15** | 없음 | 17 / 10 / 0 = **27** | **42** |

- 총 적재량은 각각 55/40/55/42발.
- **NATO의 기본 적재 수치와 게임상의 탄종 구성은 향후 변경 가능**. 기본 탄약 이름은 본 문서의 기존 NATO 각 전차별 기본탄 지정과 연결한다.


## 11. 32종·96개 기본/대기갑/화력지원 프리셋

> **상태: RTS 게임 적재 설정 확정.** 미국 5·서독 6·소련 14·동독 7개 전차, 합계 **32개 형식 × 3프리셋 = 96개**. Leopard 2 KVT는 Leopard 2A4 C-Type과 동일한 3종을 공유한다. 아래 표는 적재 패턴이 같은 차종을 묶어 **18개 편성 그룹 × 3 = 54개 표 행**으로 기록했다. T-64A 대기갑 예비탄 AP/HEAT/HE는 4/3/2이다. 편성별 총탄수와 각 구획 발수는 게임용 확정값이다.

- **기본:** AI 일반 배치의 표준 적재. **대기갑:** 기존 사용자 확정 기본 적재를 임무별 선택으로 이전. **화력지원:** 대인·경장갑 대응 탄약의 높은 비중. AI 임무/시나리오 배치 시 프리셋 선택 가능하며 플레이어는 자유 편집 가능. 적재 변경은 포인트·보급 희소성 규칙을 따른다.
- **공통 용량:** 즉응탄 / 준즉응탄(있는 차종만) / 예비탄 구획을 별개로 추적. **소련/NVA는 AP/HEAT/HE/ATGM**, **NATO는 AP/HEAT/HEP** 순서. 120mm NATO는 HEP 없음(0), HEAT-MP가 다목적/대인 역할. 소련·NVA의 HE는 HE-FRAG.
- **주의:** 아래 설정은 역사적 실제 전장 적재가 아니라 게임 프리셋이며, NVA T-55의 즉응탄 **18발은 역사적 검증 전인 게임 잠정 구획값**. NVA T-72 Ural 39발(22+17), M/M1 44발(22+22), T-55A 43발(18+25), AM2/B 38발(18+20)은 현재 게임용 구획. 역사적 NVA 전투탄수는 위 참고 표를 유지하며 혼동 금지.
- 전차별 기본 APFSDS·HEAT·ATGM **탄약의 이름**은 위의 전차별 기본탄 지정표에서 가져오며, 이 표는 그 탄종별 **발수**만 정의한다. T-55AM2B는 9M117, 동독 T-72 계열은 ATGM 유도 불가. NVA 보급 미확인 탄종은 기본 프리셋에 자동 채택하지 않는다.
- **Leopard 2 KVT (1989):** Leopard 2A4 C-Type과 동일한 120mm **DM33A1/DM12A1** 조합, 기본·대기갑·화력지원 **각 42발**. 즉응탄 AP/HEAT는 각각 **7/8, 9/6, 5/10**, 예비탄은 **13/14, 17/10, 8/19**이며 준즉응탄은 없다. DM43은 희귀 선택 후보로만 유지한다.
- **추가 서방 3종 기본탄 연결:** M60A3 TTS는 M735 APFSDS + M456A2 HEAT + M393A2 HEP; Leopard 1A1A1은 DM23(105) + DM12(105) + 독일 105mm HEP; M48A2GA2는 DM13(105) + DM12(105) + 독일 105mm HEP. M60A3는 M392A2 등 구형탄 선택 가능, **시나리오 상한 M833, M900 제외**. 탄약 실제 발수는 아래 표의 AP/HEAT/HEP에 대응하고, **독일 105mm HEP는 DM512(CE 120), 미국 105mm HEP는 M393A2(CE 120)**로 지정. HESH 별도 게임 분류는 없음.
- **독일 105mm HEP 확정:** **DM512**(CE 120) 1종만 사용하며 **HESH**는 같은 탄의 대체 표시명이다. 미국 **M393A2**(CE 120)는 별개 탄종. HEP와 HESH를 서로 다른 게임 판정 분류로 나누지 않는다.
- **신규 NATO 3종 구획별 정원:** M60A3 TTS **즉응 13 / 준즉응 21 / 예비 29 = 63발**; Leopard 1A1A1 **즉응 13 / 준즉응 없음 / 예비 47 = 60발**; M48A2GA2 **즉응 20 / 준즉응 4 / 예비 22 = 46발**. 특히 M48 20/4와 M60 13/21/29는 게임용 구획 분류이며 역사적 확정 군 교범 발수라고 단정하지 않음.

## 12. 장전·탄약고 간 이동 예정 시스템

> **상태: 설계 의도 메모, 세부 수치 미확정. 실제 코드/게임 시스템에 반영됐다는 뜻이 아님.** 시간·확률·피해/스트레스 계수는 나중에 설정.

> **WIP15 구현 (2026-11-09, PR 검토 대기):** [가변 장전·피격 동요·장비 일시 이상](../../docs/tasks/TACTICAL_WIP15_RELOAD_AND_TEMPORARY_REACTIONS.md)에서 현재 단일 시험탄의 장전탄/저장탄 보존과 가변 장전을 구현했다. 사용자 기준은 기본 5.98초, 연속 4발째 뒤 장전부터 피로 지연, 비관통/근접 비관통/관통 동요, 장전 작업 최대 14초다. 세부 증감·회복률은 지시서의 초기 시험 제안이다. **아래 구획별 이전·자동 보충·부상·대체 장전·자동장전 차량은 후속 구상**이며 WIP15에도 구현되지 않았다.

### 공통 상태
- 각 전차의 즉응탄, 준즉응탄(있는 경우), 예비탄을 종류별·구역별 재고로 관리한다.
- **비전투 중 자동 재정리:** 일정 시간 교전이 없고, 안전이 확인되며, 전차가 정지 중일 때 즉응탄 구역을 자동 보충한다. 잠시 교전이 중단됐거나 안전 지역으로 빠져 조건이 성립해도 적용. 전투 재개·이동 시에는 보충 작업 일시 중단을 기본 방향으로 검토.
- 구체적인 '안전' 판정 기준, 대기시간, 보충 단위, 중단 후 진행률, 운용 UI 등은 미정.
- **탄종별 판정:** 즉응탄 전체 잔량이 남아 있더라도 현재 요구되는 탄종이 해당 구역에 없으면 그 탄종의 다른 저장 구역을 참조한다.

### 수동장전 (미국·서독)
- 기본 장전시간은 장전 담당 인원의 **훈련수준·스트레스·부상·차량 손상**에 따라 가변.
- 장전수가 무력화되면 전차장 대체로 장전이 매우 느려지고 지휘 기능에도 영향. 전차장도 없으면 포수의 대체 장전은 정상 연속 사격이 사실상 불가능할 정도로 느리게 표현한다. 대체인원의 훈련수준·상태도 별도 반영한다.
- 전투 중 즉응탄이 모자라면 **준즉응탄을 우선 사용**하며 장전 지연. 준즉응탄이 없거나 소진되면 **예비탄 사용**으로 더 큰 지연. 준즉응탄이 없는 Leopard 1/2는 즉응에서 예비로 바로 넘어감.
- 기본 상대관계: **즉응탄 장전시간 < 준즉응탄 장전시간 < 예비탄 장전시간**. 그중 예비탄 지연은 크게 나타나도록 구상.
- 안전·정지 조건이 성립한 비전투 중에는 **준즉응탄 → 즉응탄**을 우선 보충하고, 이후 예비탄 → 즉응탄 보충.

### 자동장전 (T-64·T-72·T-80)
- 자동장전장치가 정상 작동하고 즉응탄이 남아 있는 동안에는 **기본 기계적 장전주기가 일정**하며 승무원 훈련수준이나 스트레스 때문에 상시 느려지지 않는다.
- 선택한 탄종의 즉응탄이 떨어진 전투 상황에선 예비탄을 즉응탄 위치로 이동시키는 추가 작업이 필요하여 **장전까지의 시간이 크게 증가**. 자동장전장치 종류(MZ/AZ)에 따른 게임적 차등은 후속 검토.
- 장치 자체의 **신뢰도·차량 피해** 등으로 일시적인 장전불량이나 지연이 발생할 수 있음. 평상시 장전속도가 항상 일정 비율로 감소하는 효과와는 구별한다.
- 안전한 비전투 정지 상태에서 예비탄을 즉응탄 구역으로 자동 보충.
- 장전불량의 발생률/복구 방식, 보충 시간 및 승무원 능력의 영향 범위는 미정.


## 13. 탄약 비용·보급·편성 원칙

### 합의된 UX 및 게임 규칙

1. 덱 구성에서는 장비 성능, 탄약 후보, 부대 가용성을 보고 전차 카드를 편성.
2. **전투 시작 전 배치 화면에서 전차를 클릭**해 중장갑(대물) 및 경장갑(대인) 슬롯에 **여러 종류의 탄약을 선택**. 차종별 기본 혼합 적재 프리셋을 쓰되 필요하면 수정 가능하게 구상. **전투 중 보급할 때에도 슬롯 내 탄종 구성/수량을 변경 가능**.
3. 전차별 총 적재량과 구획별 프리셋 발수는 §11의 확정값을 따른다. 플레이어가 기본 혼합 적재를 수정할 수 있으며, 구체적인 편집 UI와 한 슬롯당 최대 선택 탄종 수는 미정이다.
4. 전차 포인트와 탄약 포인트를 더해 **그 차량을 배치할 때 1회 지불**. 기본탄도 원가가 포함된다는 개념; '기본탄=공짜'는 아님. 기본 구성의 총액이 합리적인 기준 가격이 되게 설계.
5. 전투 중 한 발씩 탄종을 직접 고르는 조작은 지양. **적재된 여러 탄종 중 탄을 전투 AI가 자동 선택**, AI의 **숙련도가 표적 인식·탄약 선택의 정확도/효율**에 영향을 주도록 구상. 보급 시 구성을 바꿔도 사격은 자동.
6. 희귀 탄약은 **해당 탄약을 장착한 차량의 최대 배치 대수**로 제한. 호환 차종들이 공유하는 보급 풀을 구상. **전투 중 탄약 교체로 제한을 우회할 수 없도록 보급 시에도 검사**. 복수 탄종 적재는 허용하지만 모든 프리셋에 반드시 혼합을 강제하는 것은 아님.
7. IOC/FOC 관련 희소성은 성능 포인트와 별개의 경제/가용성 요소로 사용. 1989년 기준 실제 미배치 탄약을 **게임에서 전시 가속/긴급도입한 가정**과 혼동하지 않음.
8. 구형탄을 선택해 화력은 희생하고 포인트를 절약하거나 재고를 활용하는 선택 가능.

### 아직 정하지 않은 항목

- 탄약 포인트 산정: **발당 단가 × 자동 적재 발수** vs **탄약 패키지 고정가**. 둘 다 **최초 배치 시에만 지불**하는 모델로 논의됐으며 선택 전.
- 모든 차량의 차체 포인트, 탄약별 발당/패키지 포인트, 희귀탄별 배치 대수, 복수 탄종 혼합 적재 비용 모델, UI 세부 규칙.
- **전투 중 중간 보급에서 탄종 변경 가능**은 새로 합의한 설계 요구. 단차별 남은 탄환을 어떻게 처리할지(즉시 교체·회수·이월), 보급 화면의 단계/소요 시간, 탄종별 보급 재고량, 비용·자원, 자동 대체 여부는 미정.
- 캠페인 차원의 탄약 재고/전투 후 보급 체계는 제안된 단계. **확정 구현 사항이 아님**.
- 타 전차·부대별 허용 탄약 목록/IOC·FOC 적용 수치.
