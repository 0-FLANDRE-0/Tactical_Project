> **기준 연결:** [기존 APC 4종 및 기관총 기본탄](APC_M113_BTR_AND_MACHINEGUN_DESIGN_NOTES_2026-11-14.md) · [1989년 4개 군사집단 보유량 원안](../world/WW3_1989_JUNE20_FORCE_INVENTORY_OOB_DRAFT_2026-11-13.md)

## 1. BTR-60PB — 기본형·BTR-70 공통 무장 재활용

장갑 표기 **KE(CE), mm RHAe**. 아래 7구역은 사용자가 차체 측면 및 포탑 측후면을 5로 수정한 **채택 장갑값**.

| 구역 | BTR-60PB | 참고: 기존 BTR-70 |
|---|---:|---:|
| 차체 전면 | **10(10)** | 15(15) |
| 차체 측면 | **5(5)** | 10(10) |
| 차체 후면 | **5(5)** | 10(10) |
| 포탑 전면 | **10(10)** | 10(10) |
| 포탑 측면 | **5(5)** | 10(10) |
| 포탑 후면 | **5(5)** | 10(10) |
| 상부 | **5(5)** | 5(5) |
| 차량 HP | **325 (직전 제안 유지)** | 350 |

- **무장:** 14.5mm KPVT + 7.62mm PKT. 기존 기본탄의 관통력·기본 차량 HP 피해량 **23/7**을 그대로 재사용. 별도 신규 탄약을 만들지 않는다.
- **HP 325:** 기존 추천값을 수정 없이 이어간 **기본값**. 사용자가 명시적으로 변경한 것은 장갑 3구역이며, HP 별도 재확정 발언은 없었으므로 **후속 조정 가능**으로 기록한다.
- 구형 이중 가솔린 엔진·기동력·승하차 방식 등은 차량 특성으로 후속 구분. 실시간 기동·화재 위험 확률은 미정.

## 2. 서독 M113G 계열 — 미군 M113 장갑 재활용 방향

> **아직 세부 제원 전부 확정되지 않음.** 이전 대화는 미국 M113을 재활용하자는 방향에 동의했지만, 독일형 각 생산/개량 버전의 독립 HP와 무장 차이까지 모두 사용자 확정한 것은 아니다.

| 항목 | M113A1G 중심 **제안/재활용 방향** |
|---|---|
| 차체 전면 | **25(25)** — M113A2 참조 |
| 차체 측면 | **20(20)** — M113A2 참조 |
| 차체 후면 | **15(15)** — M113A2 참조 |
| 상부 | **10(10)** — M113A2 참조 |
| 장갑 포탑 | **해당 없음** |
| 차량 HP | **400 후보** — M113A2 참조, 독일형 최종 미확정 |
| 대표 무장 | **7.62mm MG3**, 공통 기본탄 **7 HP** |

- M113G / M113A1G / M113A2G 등의 실차 차이 및 1989년 주력 세부형 지정, 지휘차·박격포차·구난차 포함 범위는 **후속 검토**.
- 서독 세계관의 **M113G 계열 4,020대는 전체 계열 원안 수량**이다. 이를 모두 단일 수송형에 배정하지 않는다.

## 3. TPz 1 Fuchs — [사용자 채택]

> 1989년 기본 병력수송형 기준. 장갑포탑 없는 **6×6 차륜형 APC**. 장갑은 KE(CE) 게임값.

| 구역 | 채택값 |
|---|---:|
| 차체 전면 | **20(20)** |
| 차체 측면 | **20(20)** |
| 차체 후면 | **15(15)** |
| 상부 | **15(15)** |
| 장갑 포탑 | **해당 없음** |
| **차량 HP** | **425** |
| 기본 무장 | **7.62mm MG3 / 기본 HP 피해 7** |

- 사용자가 최초 추천 차체 측면 **15 → 20**, 후면 **10 → 15**, 상부 **10 → 15**로 상향하고 **HP 425 유지**를 채택했다.
- 대형 수송·지휘·통신·전자전·화생방 등 **실차 파생형과 보유량은 이후 분리**. 기본형에 시제 20mm 무장을 소급하지 않는다.
- 기본 엔진 320마력, 차륜형·수륙양용 특징은 역사 참고. 게임상 기동/수상 이동 수치, 전면 방탄유리·기관총 사수 피격 등은 미정.

## 4. BTR-50PK와 MT-LB — [사용자 제안 채택]

> 차체·포탑·상부의 KE(CE) 게임값. **포탑 '없음'은 0mm가 아닌 해당 없음**.

| 구역 | BTR-50PK | MT-LB |
|---|---:|---:|
| 차체 전면 | **15(15)** | **15(15)** |
| 차체 측면 | **10(10)** | **10(10)** |
| 차체 후면 | **5(5)** | **5(5)** |
| 포탑 전면 | **해당 없음** | **15(15)** |
| 포탑 측면 | **해당 없음** | **10(10)** |
| 포탑 후면 | **해당 없음** | **5(5)** |
| 상부 | **10(10)** | **5(5)** |
| **최대 HP** | **325** | **300** |

- **BTR-50PK:** PT-76 계열 차체를 활용하는 밀폐형 대형 수송형, **장갑포탑 없음**. 기관총 세부 탑재형/사수 방호 및 게임 기본 무장 편성은 별도 확정하지 않았다.
- **MT-LB:** 7.62mm PKT 장착 소형 포탑의 수송/견인/지원형을 출발점으로 함. **7.62mm 공통 기본탄 7 HP** 재사용. 다목적 파생형별 임무·무장은 추후 분리.
- 지면 접지압·습지·수륙양용·탑승/하차 등은 후속 게임 성능 설계 대상.

## 5. 1989년 범위·잔여 미결정 메모

- **기존 APC 4종** M113A2/A3(400/450HP), BTR-70/80(350/400HP)은 [기존 기준표](APC_M113_BTR_AND_MACHINEGUN_DESIGN_NOTES_2026-11-14.md)에 그대로 보존. 이 문서가 그 수치를 바꾸지 않는다.
- **BTR-80A 30mm 2A72형**은 1989년 기본 전력에서 제외, 후대 확장 후보로 유지.
- **공통 미정:** 기관총의 장갑·비장갑 표적별 사거리, 이동 중 명중, 연사 산포, 승하차 및 탑승 보병 보호, 기관총 사수 노출, 연료/화재/정비, 차량 기동 속도, 보급·가격, 장비 프리셋.
- **세계관 수량과 모델 수를 혼동하지 않음:** 원안 보유량(기타 BTR, M113G 계열, 기타 차륜형)은 세부 파생차·부대별 가용 차량 수로 아직 분할하지 않았다.
- **코드 미구현:** 이 파일은 기록만 갱신한다. 실제 전투·장갑·탄약·AI·병력수송 로직은 변경하지 않았다.
