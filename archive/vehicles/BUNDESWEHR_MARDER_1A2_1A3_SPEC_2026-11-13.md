# TACTICAL 1989 — 서독 Marder 1A2·1A3 IFV 장갑·무장·탄약 게임 설계 (2026-11-13)

> **상태:** 2026-11-13 사용자 대화에서 채택한 **게임 설계 확정값**을 정리한다. 구체적 실전 배치량·역사적 장갑 실측 수치와 혼동하지 않는다.
> **범위:** Marder 1A2, Marder 1A3의 7구역 게임용 장갑, 차량 HP, Rh 202 철갑·고폭탄, 교전거리·상대 명중 특성, MILAN 1/2.
> **구현 경계:** 아카이브 설계 자료. 실제 차량/탄약 데이터 및 런타임 코드 적용·검증은 **미실시**.
> **관련 자료:** [기관포 피해 정책](../combat/AUTOCANNON_PENETRATION_DAMAGE_POLICY_2026-11-13.md), [주독미군 브래들리](USAREUR_IFV_CFV_ROSTER_PLAN_2026-11-12.md), [소련 BMP](SOVIET_BMP_1_1P_2_SPEC_2026-11-13.md), [전역 세계관·편제 초안](../world/WW3_1989_JUNE20_FORCE_INVENTORY_OOB_DRAFT_2026-11-13.md).

## 1. 기본 장갑 7구역·차량 HP — [사용자 확정]

**장갑 단위:** 게임용 mm RHAe, `KE(CE)`; **7구역 순서:** 차체 전면 / 측면 / 후면, 포탑 전면 / 측면 / 후면, 차체·포탑 통합 상부. **장갑 두께 실측이 아니다.**

| 장갑 구역 | Marder 1A2 | Marder 1A3 |
|---|---:|---:|
| 차체 전면 | **35(35)** | **70(70)** |
| 차체 측면 | **25(25)** | **40(50)** |
| 차체 후면 | **20(20)** | **30(30)** |
| 포탑 전면 | **35(35)** | **40(45)** |
| 포탑 측면 | **20(20)** | **25(25)** |
| 포탑 후면 | **15(15)** | **20(20)** |
| 상부 통합 | **10(10)** | **15(15)** |
| **차량 최대 HP** | **550** | **600** |

- **Marder 1A2 한 줄:** `35(35) / 25(25) / 20(20) / 35(35) / 20(20) / 15(15) / 10(10)`, HP 550.
- **Marder 1A3 한 줄:** `70(70) / 40(50) / 30(30) / 40(45) / 25(25) / 20(20) / 15(15)`, HP 600.
- 1A3의 **차체 측면 CE 50** 및 **포탑 전면 CE 45**는 KE와 구분한 사용자 지정 게임값이다. 간격장갑 효과를 추상적으로 표현하지만 실측 방호 성적이라는 뜻이 아니다.
- 1A3는 1A2 대비 방호 개량형으로 취급하되, **차체 전면 70 KE와 포탑 전면 40 KE의 방호력 차이**를 유지한다. '전면 30mm 탄 완전 방호' 같은 전 구역 절대 면역 판정은 추가하지 않는다.
- 두 차량 모두 20mm Rh 202 및 600마력급 엔진 계열을 사용하는 것으로 설정한다. 무게 증가에 따른 세부 기동력/최고속도 차이의 **게임 적용값은 미정**.
- 1989-06-20 개전 설정에서 **Marder 1A3 270대**는 별도 [전역 원안](../world/WW3_1989_JUNE20_FORCE_INVENTORY_OOB_DRAFT_2026-11-13.md)에서 온 세계관 집계값이며, 실제 역사적 해당 일자의 배치 보유량 검증값이나 최종 게임 편성 확정값은 아니다.

## 2. 주무장 및 기본 미사일 — [사용자 확정]

| 항목 | Marder 1A2 | Marder 1A3 |
|---|---|---|
| 주무장 | **20mm Rh 202 기관포** | **20mm Rh 202 기관포** |
| 부무장 | 7.62mm MG3 계열 | 7.62mm MG3 계열 |
| 기본 대전차미사일 | **MILAN 1** | **MILAN 2** |
| 기본 차량 HP | **550** | **600** |
| 주포 장갑 표적 사거리 | **1,450m** | **1,450m** |
| 주포 비장갑 표적 사거리 | **2,500m** | **2,500m** |

- 기본 미사일 지정은 **기본 지급 종류**에 대한 사용자 결정이다. MILAN 1/2의 각 차량 교차 호환성, 탄수, 장전/재장전 간격, 실제 부대 보급량은 추후 별도 결정.
- 20mm 주포의 두 최대 교전거리는 **장갑/비장갑 표적을 구분한 게임상 사격 가능 한도**다. 탄종별로 서로 다른 고정 사거리 상한을 부여한 게 아니다. **MILAN의 사거리는 별도**이다.
- **Rh 202 명중률은 BMP-2의 2A42보다 상대적으로 높게 설정한다**는 게임 방향을 채택. 2A42는 연발 시 분산이 크게 늘어나는 특성이 있는 반면, Rh 202의 구체 명중 확률·연발 패널티·회복 시간은 미정.
- Rh 202의 **실물 이론 최대 발사속도 약 1,000발/분**은 참고 성능이지, 게임에서 지속 연발할 수 있는 발사속도나 탄약 소모량으로 확정한 값이 아니다.

## 3. Rh 202 20mm 철갑탄 — [사용자 채택]

> 관통 수치는 KE(mm RHAe), 순서는 **0° / 30° / 60°**. 거리별 수치는 실제 시험 결과가 아닌 **사용자 게임값**이다. 5mm 단위 기준표를 보존한다.

| 탄종 | 사용자 분류 표기 | 포구초속 | 10m KE 0°/30°/60° | 2,000m KE 0°/30°/60° | 기본 HP 피해 |
|---|---|---:|---|---|---:|
| **DM43** | HVAP-T (APCR-T) | **1,100m/s** | **55 / 40 / 15** | **10 / 5 / 0** | **43** |
| **DM43A1** | HVAP-T (API-T) | **1,100m/s** | **55 / 40 / 15** | **10 / 5 / 0** | **45** |
| **DM63** | APDS-T | **1,150m/s** | **65 / 60 / 25** | **40 / 35 / 15** | **42** |

- **DM43과 DM43A1은 관통력과 포구초속 동일**, 기본 HP 피해만 **43/45**로 구분. DM43A1의 API 성격에 따른 추가 소이/착화 확률의 별도 게임 수치는 미정.
- **DM63**은 APDS-T로 구형 HVAP 계열보다 장거리 관통력을 잘 유지하지만 기본 HP 피해는 **42**로 작게 둔다.
- DM63은 사용자가 대화 중 제시한 당시 참고 게임 자료의 **10m 약 66/61/25, 2km 약 38/35/15**를 5mm급 기준표로 반영한 값이라는 사용자 설명을 보존한다. **오래된 게임판의 '2km 수직 관통 14mm'라는 이전 답변은 오류로 철회**되었으며, 14mm를 최신 기준으로 사용하지 않는다.
- **철갑탄 공통:** 기관포 치명타 보너스 없음, 과관통 시 HP 피해 크게 감소. 상세 기관포 전용 배율 곡선·도탄·비관통/모듈 판정은 [별도 정책](../combat/AUTOCANNON_PENETRATION_DAMAGE_POLICY_2026-11-13.md)을 따르며 미확정 부분을 임의 채우지 않는다.
- 각 탄종의 공식 탄종 분류·1989년 운용 배치 근거는 역사 자료로 추가 교차검증할 수 있으나, **분류 표기 검토가 여기 합의한 게임 관통력·피해값을 자동 변경하지는 않는다**.

## 4. Rh 202 20mm 고폭탄 — [사용자 채택]

| 탄종 | 게임 내 역할 | 10m 관통력 | 2,000m 관통력 | 기본 HP 피해 |
|---|---|---:|---:|---:|
| **DM51A2** | 고폭/파편 계열 | **5 CE** | **0 CE** | **88** |
| **DM81A1** | 고폭/파편 계열 | **5 CE** | **0 CE** | **88** |

- 사용자가 2개 탄종 모두 선택하고 **기본 피해 88 HP**, 방호 판정값 **10m 5 CE → 2,000m 0 CE** 방안을 수락. 중간 거리값은 선형 보간으로 시작한다.
- 이 CE 수치는 **폭발·파편 효과용 게임상 경장갑 판정**이며 HEAT 성형작약의 관통력이나 실제 장갑시험 결과를 뜻하지 않는다. **HEAT 고각 공통 비율을 그대로 상속하지 않는다.**
- 고폭탄의 세부 파편 반경/폭발 범위/소이효과·신관·보병 및 엄폐물 상대 피해 등은 미정.
- DM51A2/DM81A1의 정식 분류/1989년 형식별 보급 사실은 추가 고증 대상이다. 현재는 **확정한 게임 탄종 이름**으로 유지한다.

## 5. MILAN 1·MILAN 2 — [사용자 채택]

> 게임용 HEAT 관통력. **거리별 관통력 감소 없음.** 기존 공통 입사각 비율 **0° 100%, 30° 86.6%, 60° 50%**, 5mm 단위 반올림을 사용한다.

| 구분 | MILAN 1 | MILAN 2 |
|---|---:|---:|
| 탄두 구경 참고 | 약 103mm | 약 115mm |
| **0° 관통력** | **530 CE** | **680 CE** |
| **30° 관통력** | **460 CE** | **590 CE** |
| **60° 관통력** | **265 CE** | **340 CE** |
| **기본 HP 피해** | **388 HP** | **435 HP** |
| 최대 교전거리 | **2,000m** | **2,000m** |
| 유도 방식 | **SACLOS 유선유도** | **SACLOS 유선유도** |
| ERA 대응 탠덤탄두 | 없음 | 없음 |
| 기본 지급 차량 | **Marder 1A2** | **Marder 1A3** |

- **MILAN 2T는 이 1989년 게임의 기본 MILAN 2와 혼동하지 않는다.** 차후 시대/특수 시나리오에서 별도 검토.
- HEAT 관통력·기본 HP 피해는 구경만으로 기계적으로 환산한 것이 아니라 **사용자가 선택한 게임 설계 수치**다.
- 탄약별 기본 적재량, 재보급 가격, 유도 중 제압/연막 영향 등은 아직 정하지 않았다.

## 6. 다른 IFV와의 게임상 비교·후속 미정

| 항목 | BMP-1/1P/2 | Marder 1A2 | Marder 1A3 | M2/M2A1 Bradley | M2A2 Bradley |
|---|---:|---:|---:|---:|---:|
| 최대 차량 HP | **500** | **550** | **600** | **550** | **650** |
| 차체 전면 KE | **25** | **35** | **70** | **40** | **80** |

- 마르더 계열은 20mm 주포라 단발 기본 HP 피해가 상대적으로 낮고, **1A3은 방호력 강화·HP 600을 얻는 대신 중량 증가에 따른 기동성 영향 검토**가 남았다. 장갑으로 모든 30mm 위협을 완전히 막는 차량으로 취급하지 않는다.
- 별도로 미정인 항목: 실제 탄약 적재량과 프리셋, Rh 202의 게임용 고/저속 발사 모드·점사/연사 명중률 수치·이동 중 정확도, 세부 관측/사통과 승무원 기능이상, 화재·탄약고, 차량 가격과 배치량.
- **이번 변경은 Marder 1A2/1A3 확정 게임 설계값의 기록에 한정**한다. 브래들리/BMP/전차의 기존 수치와 현재 실행 게임 코드를 변경하지 않는다.
