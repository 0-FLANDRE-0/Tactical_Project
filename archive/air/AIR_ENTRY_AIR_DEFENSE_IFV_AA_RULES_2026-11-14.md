# TACTICAL — 항공기 투입·간략 외부 작전지도·방공레이더 LOS·IFV 대공사거리 (2026-11-14)

> **상태:** 2026-11-13~14 논의의 **사용자 확정값**, **채택 방향**, **제안·미정 사항**을 구별한 아카이브 설계 백업. 실제 게임 코드와 지형 파일은 이번 기록에서 수정하지 않음.
> **범위:** 전술지도(현행 4×4km, 8×8km 확장 후보)와 외부 항공기 접근 공역, 증원 ETA·진입점·방향, 맵 안의 중·장거리 방공체계, 레이더 LOS 계산 부담, 기존 IFV 기관포 대공사거리.
> **참조:** [현재 지도 크기·기존 LOS 최적화 기록](../performance/LARGE_MAP_PATHFINDING_LOS_AND_SQUAD_AI_2026-11-08.md), [WIP17 가변 맵 크기 구현 범위](../../docs/VARIABLE_MAP_FOUNDATION_WIP17.md), [브래들리](../vehicles/USAREUR_IFV_CFV_ROSTER_PLAN_2026-11-12.md), [BMP-2](../vehicles/SOVIET_BMP_1_1P_2_SPEC_2026-11-13.md), [마르더](../vehicles/BUNDESWEHR_MARDER_1A2_1A3_SPEC_2026-11-13.md).

## 1. 기존 맵 기반 및 이 대화의 방향

- **현행 정밀 전술지도 4×4km**, **8×8km는 지원 기틀 검증 후 실제 지도 제작 전**, 9×12km는 장기 가능성 후보다. **기본·최대 지도 크기를 새로 확정한 것은 아니다.**
- 장거리 대공미사일을 이유로 정밀 전술지도를 수십~수백 km로 확대하거나 **방공 사거리를 무조건 맵 크기에 맞춰 축소하지 않는다**.
- **사용자 방향:** 현재 전술지도는 기존처럼 정밀 유지. 그 바깥에 **축소·간략화된 더 넓은 장거리 작전지도**를 두고, **그 안에 현재 작전 중인 전술지도가 포함된 형태**로 연계한다.
- 이는 이전에 우선순위에서 보류한 **독립적인 전체 전역지도/다중 전술맵 전략 캠페인**을 지금 바로 구현한다는 결정이 아니다. 전술지도 주변의 간략 공역·접근 경로를 표현하는 **설계 방향**이다.
- 외부 작전지도의 실제 범위·표현 수준·지형 데이터 해상도·UI/카메라 설계, 지도 전환/확대 비율·세계 좌표 연결은 **미정**.

## 2. 항공기·지상 증원 및 접근 공역 — [사용자 방향 확정]

- **지상/공중 유닛 모두 지정된 시작 투입 지점·진입 방향에서 등장**한다. 투입 요청 시 플레이어에게 **ETA(예상 도착시간)**를 표시한다.
- **항공기**는 접근 방향, 진입지점 및 **설정 고도**를 지정할 수 있는 방식으로 설계. 외부 간략 공역에서는 비행/접근·위협을 처리하고, 전술지도 경계 도달 시 정밀 전술 유닛으로 연결하는 방향.
- **지상군**은 진입로·도로/투입지점 등으로 배치. 군단/작전 수준의 이동과 직접 전장에 들어오는 차량 생성의 연결은 세부 미정.
- 비행기 현실적 속도를 크게 왜곡하지 않고 전술지도 통과시간을 검토한다. 예를 들어 직선 8km를 800km/h로 비행하면 약 36초이며, 단순 예시일 뿐 게임 속도 제한으로 확정하지 않는다.
- **전투기·공격기**는 진입 → 공격·임무 수행 → 이탈, **헬기**는 지형을 활용해 상대적으로 오래 머무는 전술 유닛이라는 방향을 논의. 출격 준비/재진입·연료·재공격·항공기 AI의 세부 규칙은 미정.
- 고도 단위(지면 기준 AGL / 해수면 기준 MSL), 각 접근 고도 선택지·변경 제한·ETA 보정·복수 항로 지정은 **미정**.

## 3. 지도 안의 장거리 방공체계와 외부 공역 — [사용자 방향]

- **Patriot, Hawk, S-300 등 중·장거리 방공체계도 전술지도 안에 실제 유닛으로 배치·피격·파괴될 수 있어야 한다.** '맵 밖 고정 지원 확률 버튼'으로 대체하는 방향은 사용자가 원하지 않는다.
- 방공 레이더/발사대가 전술지도 안에 있더라도 **맵 밖 접근 공역**을 감시/교전할 수 있는 설계 방향. **실제 장비의 긴 사거리**를 전술지도 폭에 맞춰 무작정 잘라내지는 않는다.
- 단, 화면 밖 교전의 **탐지/추적/미사일 비행/회피/격추 처리의 정밀도는 별도 미정**. 전술지도 안의 방공 유닛과 임의로 중복 집계된 가상 방공망이 같은 항공기를 이중 공격하게 만들지 않는다.
- 항공기가 반드시 맵에 진입해 생존하는 것도, 장거리 SAM의 사거리 안에 진입했다는 이유만으로 자동 격추되는 것도 아니다. **탐지 → 추적 → 교전 조건 성립 → 미사일 발사/유도 → 결과**라는 별도 단계 검토.
- 항공 접근 시 미사일 회피·우회, SEAD(적 방공 제압)의 전술적 가치가 생길 수 있으나 **SEAD를 무조건 선행해야만 항공기 투입 가능하다는 강제 규칙은 미확정/비권장 제안**. 항로/고도/위협 정보·전자전의 구체 규칙 미정.

## 4. 방공 레이더 LOS 성능 문제 — [사용자 문제 제기 + 채택한 계산 방향]

**사용자가 지적한 핵심 문제:** 외부 지도보다도 **4×4/8×8km 정밀 전술지도 내부의 장거리 방공레이더**가 사실상 맵 전체를 덮으면서, 기존 전술지도 고해상도 **LOS 계산이 지나치게 많아질 수 있음**.

### 4-A. 별도 탐색/추적/유도 계층

1. **탐색(넓은 시야·낮은 계산 비용):** 레이더의 넓은 탐지 범위 전 지역을 매 프레임 2m 정밀 광선으로 검사하지 않는다. **고정 위치에서 지형 차폐 정보를 사전 계산·캐시**하고, 실제 존재하는 항공기/헬기 후보의 현재 위치·고도에 대해 빠른 조회를 수행.
2. **추적(필요한 표적만):** 실제로 발견한 제한된 표적에 한해서 **정밀 LOS/추적** 확인. 표적이 이동하거나 지형 차폐·고도가 변하면 유효 범위만 갱신할 수 있는지 검토.
3. **미사일 유도(교전 중인 표적만):** 추적/유도에 필요한 실시간 상태와 정밀 계산을 별도 수행. 매번 전장 전체를 다시 검사하지 않음.
4. **업데이트 분산:** 레이더와 표적별 갱신을 분산하고 탐색·추적·유도 주기를 다르게 할 수 있으나 **정확한 Hz와 최적화 정책은 미정**.
5. **차폐 캐시 갱신:** 레이더가 배치·철수·재배치되거나 정적 지형·동적 차폐 조건이 변할 때 무효화/부분 재계산. 레이더 가동 중 이동을 제한하면 캐시를 재사용하기 쉬움.

### 4-B. 사전 계산 시 주의

- **전술지도와 외부 공역 LOS의 해상도는 달라도 됨.** 다만 외부 공역의 저해상도 고도 표본이 큰 능선·차폐를 지워버리지 않도록 보수적 요약·검증 필요.
- **레이더 LOS 가시성(지형 차폐)**은 곧 **탐지/추적 성공**을 뜻하지 않는다. 거리·표적 고도/특성·레이더 성능·클러터·전자전 등은 별도 게임 탐지 조건.
- 정밀 광학 LOS와 장거리 레이더 LOS는 **분리해서 관리**하며 기존 광학 LOS 구현을 함부로 변경하지 않는다.
- 레이더를 고정형/전개형으로 운용하고 **이동→전개→가동→철수→재배치** 상태를 두는 것은 **유용한 설계 방향**이지만, 체계별 기동·전개 시간, 이동 중 탐지 가능 여부, 모든 장비의 공통 전개 상태는 **아직 사용자 최종 확정 수치/규칙이 아니다**.
- 성능은 4×4/8×8 지도, 레이더 수, 항공기/헬기 수에 대해 **캐시 생성비용·최대 프레임/틱 지연·실시간 LOS 검사량·Worker 메모리**를 계측해 검증해야 한다. 이 아카이브는 **최적화 효과가 이미 구현/측정됐다**고 주장하지 않는다.

## 5. IFV 기관포 대공 교전거리 — [2026-11-14 사용자 확정]

> 기존 대화에서 잠시 제안한 **2.0/2.4/3.0km 상향안은 미채택**, 사용자가 **최초 제안인 1.5/2.0/2.5km**를 **명시적으로 확정**하였다.

| 기관포 | 운용 차량 대표 | **대공 최대 경사거리** | 기존 지상 장갑 표적 최대거리 | 기존 지상 비장갑 표적 최대거리 |
|---|---|---:|---:|---:|
| **20mm Rh 202** | Marder 1A2/1A3 | **1,500m** | 1,450m | 2,500m |
| **25mm M242 Bushmaster** | M2/M2A1/M2A2 Bradley, M3 계열 | **2,000m** | 2,400m | 3,800m |
| **30mm 2A42** | BMP-2 | **2,500m** | 2,000m | 4,000m |

- **경사거리(slanted range):** 대공 사거리는 수평거리만이 아니라 **항공기/헬기와 포 사이 3차원 직선거리**. 추가로 주포 고각·최저고도/가시선·사격통제 조건에 따라 실제 교전 가능 여부 결정.
- **대공 목표 등급:** 이 IFV 기관포들은 **저고도 항공 표적 상대의 제한적 자위용**. 게임에서 운용하는 **헬기의 모든 고도를 '저고도 범주'에 포함**하지만, 실제 경사거리/앙각/LOS 제한을 제거하는 것은 아니다. 고고도 전투기 방공용으로 취급하지 않음.
- **거리 ≠ 명중률:** 허용 사거리 내에서도 헬기와 고속 고정익기, 표적 속도·비행 형태, 조준 시간·관측 상태에 따라 명중률 차이. 최대거리에서 고확률 명중을 보장하지 않는다.
- **전용 방공 차량(게파르트·쉴카·M163·퉁구스카)의 대공 사거리는 이번에 확정하지 않았다.**
- 기존 **장갑/비장갑 지상 교전거리와 탄약 관통력·피해·장갑·HP는 전혀 변경하지 않음**.

- 4×4/8×8 전술지도에서 **수십 km 사거리의 방공레이더 LOS 캐시** 구조와 탐색·추적·유도 갱신 주기/성능 예산.
- 지상/공중 유닛 투입 위치 지정 규칙, 연료·전개/철수·레이더 기동 제한, 항공기 경로 선택·명중·요격·격추/피해 사건 모델.
