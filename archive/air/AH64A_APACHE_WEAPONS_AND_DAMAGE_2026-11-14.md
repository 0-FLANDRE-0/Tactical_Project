# TACTICAL 1989 — AH-64A Apache 장갑·HP·무장·헬파이어 치명타 게임 설계 (2026-11-14)

> **문서 지위:** 2026-11-14 사용자 대화에서 **승인/채택한 게임용 수치**와 역사적 참고·아직 미정인 항목을 구분해 보존. 실물 장갑 시험·정식 탄약 관통 시험 결과가 아니며, **런타임 유닛/전투 엔진 구현 및 테스트 완료 아님**.
> **범위:** 1989년 AH-64A 초기형. 이후 AH-64D Longbow 등 후기형 기능을 이 기체에 소급하지 않는다.
> **관련:** [항공 투입·간략 외부 작전지도·방공레이더 LOS·IFV 대공사거리](AIR_ENTRY_AIR_DEFENSE_IFV_AA_RULES_2026-11-14.md), [차량 관통/피해 설계](../combat/PENETRATION_DAMAGE_AND_VEHICLE_HP_CONCEPT_2026-11-07.md), [탄약고·승무원/모듈 방향](../combat/TEMPORARY_MODULE_CREW_AMMO_DESIGN_UPDATE_2026-11-12.md).

## 1. AH-64A 기체 HP·장갑 — [사용자 확정]

| 항목 | 게임 설계값 |
|---|---|
| 최대 기체 HP | **300 HP** |
| 단일 기체 기본 장갑 | **20(20) mm RHAe, KE(CE)** |
| 장갑 구역 | **기체 전체 하나의 공통 방호값** — 전차의 7구역 구분 미적용 |
| 별도 조종석·엔진·로터 장갑/모듈 HP | **현재 사용하지 않음** |
| HP 소진 | **비행 불능·추락 처리 방향 채택** |
| 주된 생존 요소 | 기동·고도·지형 차폐·관측·낮은 피탄 확률, 방공 위협 |

- 이 **20(20)은 실제 AH-64A 동체 전체에 균일한 20mm 강판이 존재한다는 뜻이 아니라** 게임용 단일 KE/CE 방호값이다. 실제 주요 부위의 국부 방호를 게임 편의상 추상화한 것이다.
- 미사일/기관포의 **피격 확률**과 **장갑 관통 뒤 HP 피해**는 별개다. 실제 추락 연출·추락 후 피해, 승무원 생존, 로터 고장·기동 불능 등은 후속 세부 미정.
- 별도 모듈 HP를 도입하지 않는 것은 기존 차량의 모듈 영구 파괴 미도입 방침과 연결된다. 추가 일시 이상까지 자동 금지한다는 뜻은 아니다.

## 2. 30mm M230 Chain Gun / M789 HEDP — [사용자 확정]

| 항목 | 게임값 |
|---|---:|
| 무장 | **30mm M230 체인건** |
| 탄약 | **M789 HEDP** (이중목적 고폭/성형작약) |
| 0° 관통력 | **50 CE** |
| 30° 관통력 | **45 CE** |
| 60° 관통력 | **25 CE** |
| 기본 HP 피해 | **150 HP** |
| 거리별 CE 관통력 감소 | **없음** |
| 폭발·파편 | **소규모 범위 폭발·파편/제압 효과** 방향 |

- 관통 0°/30°/60°는 다른 HEAT와 동일한 **100% / 86.6% / 50%, 5mm 반올림** 규칙으로 계산한 게임값이다.
- **직격 관통 기본 피해 150 HP**와 폭발/파편 효과는 별도 처리한다. 동일한 대상에 '150 + 폭발 기본 피해'를 무조건 중복 적용하지 않는다.
- M230의 게임상 지상/대공 교전거리, 조준·명중률, 점사·연사 산포·탄약 적재/장전, 폭발 반경과 제압 효과 정량은 **미정**. 발사속도 약 625발/분 및 최대 적재 약 1,200발은 역사적 참고제원으로만 취급한다.
- 미국 **M792 HEI-T는 최신 피해 133 HP**, 소련 **3UOF8 HEI는 155 HP**, **3UOR6 HE-T는 133 HP**이며, M789 150 HP 합의는 그 수정과 별개다.

## 3. AGM-114A Hellfire — [사용자 확정]

| 항목 | 게임값 |
|---|---:|
| 탄종·탄두 | **AGM-114A / 단일 HEAT** |
| 0° 관통력 | **1,100 CE** |
| 30° 관통력 | **955 CE** |
| 60° 관통력 | **550 CE** |
| 거리별 관통력 감소 | **없음** |
| **기본 차량 HP 피해** | **884 HP** |
| **치명 관통 배율** | **110% (1.10배)** |
| 치명타 시 기본 피해 | **972.4 HP (정수 반올림 정책 미정)** |
| 최대 사거리 | **8,000m** (게임 설계 기준) |
| 유도 | **반능동 레이저 유도(SAL)** |
| ERA 무력화/탠덤 | **초기 A형에는 없음** |

- **1,100 CE**는 사용자가 고른 **게임 관통력**이며 초기 A형의 공인 실측 관통력으로 주장하지 않는다.
- 실제 명중 성공과 고관통/고피해는 별개. 레이저 조사·추적, 지형 차폐, 연막/표적 움직임, 시야·승무원 상태, 적 방공 및 유도 실패 조건은 추후 공통 항공 ATGM 모델과 연결.
- 헬파이어 **최대 16발** 탑재는 역사 제원 참고. 무장 하드포인트·히드라 로켓과의 조합, 출격 보급비용, 실제 1989년 부대별 비축량은 미정. 16발을 모든 출격의 기본 탑재량으로 자동 확정하지 않는다.

### 3-A. Hellfire 계열 치명타 — [사용자 채택, A형에 적용]

**발동 조건:** 해당 미사일의 **명중 및 장갑 관통에 성공**하고, **관통 여유가 최소 10% 이상**일 때만 **미사일 한 발당 딱 한 번** 치명타 확률 판정. 비관통·ERA에 저지된 경우 해당 치명타는 발동하지 않는다.

| 피격 구역 | **조건 충족 시 치명타 확률** |
|---|---:|
| 차체 전면·포탑 전면 | **5%** |
| 차체 측면·포탑 측면 | **10%** |
| 차체 후면·포탑 후면 | **15%** |
| 상부장갑 | **15%** |

- 치명타가 발동하면 해당 미사일의 **기본 HP 피해를 110%**로 적용. AGM-114A의 경우 `884 × 1.10 = 972.4 HP`.
- **헬파이어 계열 공통 치명타 구조**로 채택하되, 후속 헬파이어 형식의 자체 관통력/기본 HP 피해·탠덤/유도 특성은 별도 정한다.
- **관통 여유 비율의 정확한 계산식, 관통 후 기본 피해 감쇄·기존 피해배율·치명타의 적용 순서, 정수 반올림 방식, 각종 추가장갑/ERA를 어느 단계에서 처리할지**는 미정. 제시된 5/10/15/15%와 임계값 10%를 변경하지 않고 후속 구현에서 판정 순서를 정한다.

### 3-B. 탄약고 유폭에 의한 즉시 격파 — [사용자 별도 공통 시스템 방향]

- **탄약고 유폭 즉시 격파는 헬파이어 전용 치명타가 아니라 모든 탄종에서 공통으로 검토/적용할 별도 시스템**이라는 사용자 지정 방향을 기록한다.
- **헬파이어 치명타(기본 HP 피해 110%)와 탄약고 유폭(조건 만족 시 HP와 별개 즉시 격파 가능)은 완전히 다른 판정**으로 취급. 중복 효과/우선순위와 이벤트 표시 방식은 미정.
- 실제 탄약고 특성, 피격 부위, 관통 여부, 확률, 발동 가능한 차종/탄약고 구성, 승무원 생존/화재 연동 등 **세부 규칙·실제 구현은 아직 확정되지 않음**.
- **'모든 탄종 공용'은 모든 명중에서 무작위 즉사 확률이 발생한다는 뜻이 아니다**. 조건/물리적 개연성은 후속 설계에서 제한한다.

## 4. Hydra 70 / M247 HEAT — [사용자 채택]

| 항목 | 게임값 |
|---|---:|
| 로켓 구경 | **70mm** |
| 탄두 | **M247 HEAT** |
| 0° 관통력 | **290 CE** |
| 30° 관통력 | **250 CE** |
| 60° 관통력 | **145 CE** |
| 기본 차량 HP 피해 | **288 HP** |
| 거리별 HEAT 관통력 감소 | **없음** |
| 유도 방식 | **무유도** |
| 폭발·파편 | **소규모 범위 효과** 방향 |

- 관통 0°/30°/60°는 공통 HEAT 100%/86.6%/50%와 5mm 반올림 적용.
- **고관통·기본피해와 실명중 성능을 혼동하지 않음**: 무유도 로켓 산포·포드 발사량·헬기 기동·거리/조준에 따라 개별 명중 실패 가능. 구체 명중률·로켓 발사 간격, 살보 크기, 폭발/파편 정량, 최대 교전거리와 기본 탑재 조합은 **미정**.
- 최대 76발 로켓 포드 장착 가능이라는 실물 제원은 참고이며, 16발 헬파이어와 76발 로켓을 **동시에 각각 최대 적재할 수 있다는 뜻이 아니다**.

## 5. 1989년 시점 참고 제원 (게임 수치와 구별)

- 형식: 미국 육군 **AH-64A Apache**, 조종사 1명 + 부조종사/사수 1명.
- 엔진: T700 계열 2기. M230 30mm 기관포, AGM-114A 초기 헬파이어, 70mm 무유도 로켓 사용.
- 관측 장비: **TADS/PNVS**, 당대의 적외선 관측·야간 비행 능력. **AH-64D Longbow의 밀리미터파 레이더는 1989년 AH-64A에 없음**.
- 항공기 투입·외부 단순 작전지도·장거리 방공 레이더 LOS에 관한 논의는 [별도 항공 시스템 설계](AIR_ENTRY_AIR_DEFENSE_IFV_AA_RULES_2026-11-14.md)를 따른다.

## 6. 아직 미정·코드 적용 경계

- **M230/Hydra:** 사거리, 명중률·산포, 폭발·보병 제압, 탄약 적재 프리셋과 동시 장착 조합.
- **헬기 비행:** 지형 추종 고도, 선회·가속·호버링, 기관포/미사일 이동 간 발사 조건, 항공 레이더/광학 LOS, 방공미사일 요격과 기체 피해·추락.
- **헬파이어 치명:** 위 조건·확률·배율은 합의했지만 **피해 계산·관통률 보간과 탄약고 유폭의 이벤트 적용 순서**는 후속 구현에서 검증.
- **게임 코드 미구현:** 본 파일은 아카이브 백업이며 실제 AH-64A 유닛/탄약/항공 이동/치명타/투입 AI 데이터를 **구현하거나 수정하지 않았다**.
