## 1. 모듈 피해 방향 — [사용자 확정]

- **모듈의 영구적인 손상 또는 파괴는 도입하지 않는다.**
- 피격에 따른 모듈 영향은 **일시적인 성능 저하** 중심으로 설계한다.
- 이유: 세부 고장과 영구 파괴를 지속 관리하는 방식보다 RTS 게임성에 적합한 구조를 지향한다.
- 차량 전체 HP, 일반적인 차량 격파, 관통·피해 판정, 기존 잔해 규칙을 이 발언만으로 폐지하거나 변경하지 않는다.
- WIP15에서 이미 구현된 관측·사통 일시 이상은 기존 구현이며, 이 문서의 범용 모듈 상태 체계 전체가 구현됐다는 뜻이 아니다.

### 종전 기록과의 관계

- `archive/combat/PENETRATION_DAMAGE_AND_VEHICLE_HP_CONCEPT_2026-11-07.md`에 있던 '차량 전체 HP + 모듈별 HP/상태', 영구적 기능 상실 및 모듈별 수리 모델은 당시 논의의 이력으로 남긴다. **모듈의 영구 파괴를 전제한 부분은 현행 방향으로 사용하지 않는다.**
- `archive/NEXT_STEPS_2026-11-07.md`에 있던 포신 파괴·승무원 사망/충원 등과 관련된 과거 검토·제안은 그대로 확정된 현행 규칙으로 해석하지 않는다.
- 기존의 현장 수리·보급 수리 구상은 *일시적 상태를 어떤 방식으로 회복시킬지*와 관계가 있을 수 있으므로, 폐지·유지 여부와 조건을 별도로 재검토한다.

## 2. 승무원 상태 — [사용자 검토 중]

- 승무원 피해를 **경상 / 중상** 정도로 단순화하고, 단계에 따른 **능률 저하**를 만드는 구상을 검토한다.
- 상해별 능률 차이, 누적/중첩 여부, 부상 지속 시간, 회복·보급·승무원 교체 방식은 아직 미정.
- 이 발언으로 승무원 사망·영구 이탈·충원 규칙을 새로 확정하거나 구현했다고 취급하지 않는다.

## 3. 탄약고 예외 — [사용자 검토 중]

> **후속 사용자 승인 (2026-11-14):** [WIP20 지시서](../../docs/tasks/TACTICAL_WIP20_M1A2_AMMUNITION_INCIDENTS.md)를 등록했다. 현재 M1A2_1998 전용으로 관통 피격·실제 잔탄·차량별 구획 위험/격리 설정에 따라 탄약 소실 / 격리 화재와 일시 사격 중단 / 치명 사고를 구현하는 범위를 승인했다. **구현·검증 대기**이며 구체 확률·시간·재고 구획의 위험 매핑은 초기 게임 시험 제안이다. 아래 검토 중 항목은 최초 기록 당시 상태이며 실제 배치/생존율이나 모든 차량 공통 즉사 확률을 확정한 것이 아니다. 일반 모듈 영구 손상·파괴 미도입 원칙은 유지한다.

- **탄약고의 형태/구조에 따라 피격 시 '즉사'가 일어날 수도 있는 예외**를 구상한다.
- 일반 모듈의 영구 손상·파괴 금지와 별도의 **탄약고 특수 사건**으로 분리해서 검토한다.
- 탄약고 형태별 구분, 유폭 또는 즉시 격파 판정, 차량/승무원 피해에 미치는 정확한 효과, 발생 조건과 확률은 아직 미정이다.
- 특정 차종이나 배치 방식이 즉시 격파된다고 단정하지 않으며 보편적 확률도 정하지 않는다.

## 4. 이번 대화에서 확정하지 않은 것 — [미정]

1. 모듈별 일시 성능 저하의 세기·지속·회복 방식 및 상태 중복 규칙
2. 승무원 경상/중상 피해량과 역할별 능률 하락
3. 탄약고 구조별 특수 판정 조건과 확률·차량 즉시 격파 처리 방식
4. 게임 UI 알림·보급/정비와의 연계, 구현 단계·테스트
5. 기존 완성 전차 제원·장갑·차량 최대 HP의 변경: **이번에 변경 없음**
