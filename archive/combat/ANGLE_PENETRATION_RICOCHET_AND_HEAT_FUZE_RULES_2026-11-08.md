# TACTICAL — 탄약별 입사각·선형 관통력·도탄·HEAT 신관 규칙 (2026-11-08)

> **기록 상태:** 합의된 **게임 전투 판정 설계 방향을 아카이브에 저장**. **WIP10은 발사·착탄/확률적 피격 구역까지만 구현**, 실제 관통력 보간·도탄·신관·피해 판정은 **아직 게임 코드 미구현**. 도탄각은 **워썬더 구 위키의 게임 수치**를 참고한 TACTICAL 기준으로, 실제 물리 시험치가 아니다.
>

## 1. 피격면의 상대 입사각: WIP10 박스 확률을 계승

- WIP10의 **명중→차체/포탑 전·측·후 확률 피격 구역** 결정을 먼저 수행한다. 상부 구역은 현행 WIP10에서 **0%**이며 후속 구현 대상으로 남는다.
- **선택된 면의 법선과 공격 방향**의 차이를 `theta`(0°=정면 직각 입사, 90°=면에 평행)로 사용한다. 차체와 포탑의 **실제 착탄 시 방향을 독립적으로 참조**한다.
- 표적 차체 정면축 기준 **20° 비스듬한 공격**에서 전면이 선택되면 입사각 **20°**, 오른쪽 측면이 선택되면 **70°**다. 따라서 현행 WIP10의 확률적 면 선정 방식만으로도 **60° 초과 고각 피격은 발생 가능**하다.
- 상대 방위 `a`를 [-180°,180°] 범위로 정규화해, 선택된 **전면**은 `theta=abs(a)`, **후면**은 `theta=180-abs(a)`, **측면**은 `theta=abs(90-abs(a))`를 사용한다. **전면/후면은 해당 면이 투영 노출돼 선택 가능한 범위에서만** 판정한다. 포탑과 차체는 각자 상대 방위로 계산한다.
- **피격 부위 확률과 피격면 입사각은 다른 값**이다. 실물 장갑판 고유 경사각을 또 더하거나 고정 KE(CE) 방호력에 별도의 LOS 배율을 곱하는 **중복 계산은 금지**한다. 표시용 탄착 좌표에서 실제 장갑 메시 충돌을 복원하지 않는다.

## 2. 탄약별 경사 관통력: 0/30/60/90° 구간별 선형 감소

- 기준 노드 `P0`, `P30`, `P60`은 **각 탄약별** 이미 확정/잠정 기록된 값이다. **0~30°**, **30~60°** 구간에서 각 노드 사이를 **직선 보간**하고 **60~90°** 구간은 **60° 관통력부터 90°의 0까지 직선 감소**하는 게임용 외삽 원칙을 사용한다. 고각 추가 관통력표를 탄약마다 새로 만들지 않는다.

```text
clamp theta to 0°..90°
if theta <= 30: P = lerp(P0,  P30, theta/30)
else if theta <= 60: P = lerp(P30, P60, (theta-30)/30)
else: P = lerp(P60, 0, (theta-60)/30)
```

- **KE 29종:** [영거리 0/30/60° 표](../ammo/NEAR_ZERO_10M_KE_PENETRATION_2026-11-08.md)와 [2km 0/30/60° 표](../ammo/README.md)를 이용해 **각 각도 노드의 거리별 관통력을 선형 보간**한다. 0~10m는 근거리 기준값을 사용하고, **10m~2km**는 두 지점 사이 보간한다. **M829A1 0°**는 기존 100/500/1000/1500m 추가 노드를 우선 사용.
- **HEAT·ATGM CE:** 별도 거리 감쇄식이 정해지기 전까지 **기존 CE 2km 노드를 전 거리에서 동일하게 사용**하되, 각도별 보간은 위 방식으로 수행한다.
- **HEP 스폴 CE 120**, **HE-FRAG CE 35·40**, **APERS KE 5** 등 *효과 지표*를 **직접 관통력으로 자동 재해석하면 안 된다**. 추후 별도 폭발관통·스폴·대인 판정 수치가 결정되면 그 전용 수치에 맞는 각도 보정을 설계한다.
- **모든 보간 계산은 실수(소수점)**로 수행하며 탄약 데이터 노드만 5mm 단위다. **각 판정마다 5mm로 다시 반올림하지 않는다**. 기존 7구역 장갑의 RHAe에 별도 경사/LOS 배수를 중복 적용하지 않는다.
- **2km 초과 거리·90° 수직 지붕 명중 및 신관 특성의 세부 처리**는 이후 미정. 이 60~90° 외삽과 아래 도탄 곡선은 **게임용 단순화**이며 실제 관통 현상을 나타낸다고 주장하지 않는다.

## 3. 탄약별 도탄확률: 0/50/100% 각도를 연결하는 선형 곡선

각 탄약은 `a0, a50, a100`의 **서로 다른 도탄 기준각 3개**를 갖는다.

```text
if theta <= a0:       ricochetChance = 0
else if theta < a50:  ricochetChance = 0.5*(theta-a0)/(a50-a0)
else if theta < a100: ricochetChance = 0.5 + 0.5*(theta-a50)/(a100-a50)
else:                 ricochetChance = 1
```

- **도탄 확률은 개별 탄약별**이며, 기준각 사이에서는 실수값으로 보간한다. 1° 단위 정수 구간 도약이나 한꺼번에 고정 도탄 확률을 적용하지 않는다.
- **WT 동명 수치**는 아래 표에 직접 표시하고, 확인할 수 없는 변형탄은 **동계열 기본 모델을 잠정 상속**한다. 특히 3BM9·3BM15·3BM22는 일반 APFSDS와 다른 도탄각을 유지한다.

## 4. HEAT 고각 신관 실패: M456A1을 M456A2보다 불리하게

- 일반 HEAT 기본 **도탄각 65°/72°/77°**와 **정상 신관 작동 여부**는 독립적으로 기록한다.
- **M456A1과 M456A2의 기존 CE 관통력 410/355/205는 동일하게 유지**한다. **기본 도탄곡선도 동일**하지만, **M456A1의 고각 신관 미작동 위험이 M456A2보다 크다**는 별도 게임 차별화 방향을 확정한다.
- 도탄하지 않았더라도 HEAT 신관이 실패하면 **메탈제트 관통/정상 폭발관통/범위 폭발 피해를 자동 발동시키지 않는다**. M830·DM12·3BK 계열도 향후 탄종별 신관 확률을 추가 가능하도록 하고 **정량 확률·각도 임계값은 아직 미정**으로 둔다.
- 판정 순서: **실제 명중 → 피격구역 선정 → 입사각 → 도탄 판정 → (HEAT이면) 신관 판정 → 거리·각도 유효 관통력 P와 구역 방호력 R 비교 → 관통/비관통/HP·모듈 피해**. 실패한 분기에 관통/폭발 피해를 중복 적용하지 않는다.
- **각도에 따른 관통력 하락·도탄·신관 실패는 서로 다른 효과**다. 다만 HEAT가 과도하게 여러 번 약해지지 않도록 신관 정량 수치는 플레이테스트에서 따로 조정한다.
