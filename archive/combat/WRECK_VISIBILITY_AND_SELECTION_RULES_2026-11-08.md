# TACTICAL — 잔해 영구 유지·식별·선택 규칙

> 결정일: 2026-11-08 (KST). 사용자 확정 방향. 코드 적용은 별도 작업이다.
> 검토 기준: WIP11A PR #9, `4745173b2ebc24627d166da886c821e709d1fecd`.

## 확정 규칙

| 항목 | 동작 |
|---|---|
| 잔해 수명 | 격파된 차량의 잔해는 해당 전투가 끝나거나 시험장을 초기화할 때까지 영구 유지한다. 시간 만료로 제거하지 않는다. |
| 잔해 선택 | 아군·적군 잔해 모두 선택하거나 표적으로 지정할 수 없다. 지도 클릭·터치, 선택 순환, 명단과 지정 후보에서 제외한다. |
| 관측한 격파 | 격파를 관측해 잔해임을 확인했다면 그 시점부터 계속 표시한다. |
| 미관측 격파 | 격파 순간을 보지 못했다면 내부 잔해만 남기고 즉시 공개하지 않는다. |
| 이후 발견 | 미관측 격파였더라도 나중에 아군이 잔해를 한 번 식별하면 해당 팀에 영구 표시한다. 단순히 화면에 들어온 것을 식별로 취급하지 않는다. |
| 식별 후 시야 상실 | 다시 시야가 끊겨도 잔해 표시는 사라지거나 일반 기억 접촉처럼 만료되지 않는다. |
| 통행 | 현재 잔해의 동적 차량 점유 반경을 유지한다. 선택 불가와 충돌·점유 여부는 별개다. |

영구 유지는 한 전투 안의 규칙이다. 시험장 초기화 뒤 이전 잔해, 공개 상태나 차량 ID 기록이 새 전투에 넘어가면 안 된다.

## 구현 연결 시 주의할 점

- **관측자와 관측 대상을 분리한다.** 격파 차량은 관측·이동·사격을 수행하지 않지만, 미확인 잔해는 살아 있는 아군의 발견·식별 대상에 남아 있어야 한다. 격파 차량을 관측 후보에서 통째로 제거하면 나중에 잔해를 발견할 수 없다.
- 잔해 식별에는 기존 게임 관측·식별 경로를 재사용한다. 새 탐지 거리나 식별 시간 수치를 이 결정에서 추가하지 않는다.
- 확인된 잔해는 팀별 공개 사본으로 유지한다. 공개 사본을 조회할 때 비공개 실제 상태나 좌표를 따라 갱신하지 않는다.
- **미확인 격파 여부로 공개 명령의 반응을 바꾸지 않는다.** 플레이어에게 같은 기억 접촉으로 보인다면, 숨겨진 생존/격파 상태만으로 지정 명령이 성공하거나 실패해서는 안 된다. 실제 발사 허용은 기존 자체 관측·확보 조건을 따른다.
- 확인된 잔해는 렌더링 대상에만 남기고 선택·표적 지정의 hit-test에서 제외한다. 격파 전 선택이 남아 있다면 정리하며, 선택 가능한 생존 차량이 없는 경우도 UI 오류 없이 처리한다.
- 표적 상세를 열기 위해 잔해를 클릭하게 만들지 않는다. 기존 착탄 이펙트와 허용된 결과 기록은 별도 공개 규칙을 따른다.

## 수정 후 검증할 사례

1. 관측 중 격파한 잔해가 장시간 시야 밖에서도 남고 선택·지정되지 않는다.
2. 미관측 격파 직후에는 잔해를 새로 공개하지 않는다.
3. 미관측 격파 위치를 나중에 다시 관측·식별하면 잔해가 나타난다. 일반 접촉 기억의 만료 시간 이후에도 재현한다.
4. 한 번 식별한 잔해는 이후 관측이 끊기거나 일반 접촉이 만료돼도 같은 공개 위치에 남는다.
5. 공개 정보가 같은 생존/미확인 격파 기억 접촉은 지정 입력의 반응으로 구별되지 않는다.
6. 아군·적군 잔해 모두 클릭·터치·선택 순환·명단·지정에서 선택되지 않으며 통행 점유는 유지한다.
7. 선택 중인 차량의 격파, 마지막 아군 차량의 격파, 시험장 초기화에서 선택·공개 사본·충돌 상태가 안전하게 정리된다.

현재 PR #9 구현은 미관측 격파 뒤의 잔해 재발견과 미확인 격파에 대한 지정 반응을 수정해야 한다. 이 문서의 추가는 해당 코드 수정이나 PR 병합 완료를 의미하지 않는다.
