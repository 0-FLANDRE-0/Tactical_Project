## 1. 플레이어와 내부 AI의 역할 — 사용자 방향

- 경계·관측·상황 판단·조준·사격은 내부 AI가 수행한다.
- 플레이어는 이동, 점령 목표, 부대 운용과 탄약 관리를 지정한다.
- 분대 단위로 지휘하되 내부에서는 병사 한 명 한 명의 상태와 피격 결과를 관리한다.
- 전차는 흔하지 않고 존재감이 큰 전력으로 구상한다. 강한 전력이 손실될 수 있다는 긴장감과, 보병 분대가 전차를 겨우 격파했을 때의 성취감을 의도한다.
- 보병·차량·여러 장비를 추가하는 장기 확장 방향이며, 보병 구현의 WIP 번호와 시점은 아직 정하지 않았다.

## 2. 병사별 누적 피해와 부상 — 사용자 방향

- 피격 여부와 피격 부위를 확률로 판정한다.
- **피해는 같은 병사 전체에 누적된다.** 부위마다 별개의 피격 횟수를 쌓고 다른 부위의 기존 피해를 무시하는 구조로 해석하지 않는다.
- 맞은 부위와 보호구 처리 결과가 해당 병사의 누적 피해·부상 결과에 영향을 준다.
- 사용자 설명: 팔에 4~5발 정도 맞아 이미 큰 피해를 받은 병사가 몸통에 추가 피격되면, 기존 피해를 합쳐 사망할 수 있다.
- 방탄복에 막히면 피해 없음 또는 경상으로 처리하는 방향이다. 보호구의 세부 판정은 미정이다.

### 사용자 제시 부상 예시 — 검토용 게임 밸런스 값

| 예시 | 논의한 결과 |
|---|---|
| 팔에 보통탄 누적 1~3발 | 경상 |
| 팔에 누적 4발째부터 | 중상 |
| 팔에 누적 약 6발 | 사망 |
| 몸통에 누적 1~2발 | 중상 |
| 몸통에 누적 약 3발 | 사망 |
| 여러 부위에 연속 피격 | 동일 병사의 기존 누적 피해와 합산 |

위 발수는 사용자가 설명한 **게임상 예시**다. 탄약별 피해량, HP 단위, 부상 임계값, 판정 변동을 최종 확정한 표가 아니다. 실제 총상·생존성의 기준으로 사용하지 않는다.

## 3. 포탄과 파편 — 사용자 방향

- 포탄이 떨어지면 게임에서 정한 파편 영향 범위에 포함된 병사들을 대상으로 한다.
- **범위 안의 병사마다 개별적으로 파편 피격 확률을 판정한다.** 분대 전체에 하나의 피격 결과만 부여하는 것으로 해석하지 않는다.
- 피격 결과는 해당 병사의 부위·보호구·기존 누적 피해와 연결한다.
- 한 번의 포탄 영향으로도 분대원마다 무피해·경상·중상·사망 등 결과가 달라질 수 있는 구상이다.
- 파편 범위, 피격 확률식, 한 병사의 중복 피격 처리, 차폐·자세의 영향, 파편별 피해량은 아직 정하지 않았다.

## 4. 보병 대전차탄 — 사용자 제시 검토값

아래는 대화에서 제시한 **TACTICAL용 가정값**의 원문 수치 보존이다. 전차·탄약의 기존 기준표를 덮어쓰거나 정식 사용 목록에 추가한 것이 아니다.

| 탄약 후보 | 0° CE | 30° CE | 60° CE | 상태 |
|---|---:|---:|---:|---|
| PG-7VL | 550 | 475 | 275 | 사용자가 가정한 게임용 후보값 |
| PG-7VM | 330 | 285 | 165 | 사용자가 제시한 구형탄 게임용 후보값 |

- VM과 VL의 장비 세대 차이가 게임 안에서 드러나는 방향을 논의했다.
- 무유도 특성과 명중의 불확실성을 표현하려는 의도가 있다. 정확한 명중률이나 공통 조준 규칙과의 연결 방식은 미정이다.
- TOW 같은 대전차 미사일 장비도 향후 등장 후보로 언급했다. 세부 형식·게임 제원·운용 규칙은 정하지 않았다.
- 이 문서는 실물 성능을 검증하거나 특정 전차에 대한 관통·격파 가능성을 판정한 자료가 아니다.

## 5. 탄약 편성과 재보급 — 사용자 방향

- 배치 단계에서 어느 탄약을 어떤 비율로 적재할지 정할 수 있다.
- 보급지점에서는 **보급포인트를 소모해 탄약을 채우면서 탄약 비율·프리셋도 변경**할 수 있게 한다.
- 전투 중 세부 사격과 탄종 선택의 자동화 방향은 기존 [탄약 설계 §13](../ammo/README.md)과 연결한다.
- 보급 비용, 잔탄 회수·교환, 소요 시간, 작업 중 이동·중단 처리와 UI는 미정이다.

## 6. 논의 중 제안 — 사용자 확정 사항과 구분

다음은 보조 아이디어이며, 사용자 방향만으로 세부 구현까지 승인됐다고 해석하지 않는다.

- 부위별 부상에 조준·장전·이동 등의 기능 제한을 연결한다. 구체적인 계수는 미정이다.
- 분대 표시는 전투 가능 인원과 경상·중상·사망 인원을 요약하고, 선택 시 병사별 상세 상태를 제공한다.
- 탄약 프리셋을 보급 완료 후의 목표 구성으로 보고, 필요한 포인트와 시간을 표시한다.
- 보급 도중 출발했을 때 완료된 교환분을 유지하는 방식은 제안이며 확정 규칙이 아니다.
- 탄약 후보의 비용·재고·희소성으로 선택 이유를 구분하는 방안을 검토한다. 구체 값은 미정이다.

## 7. 후속 결정 목록

- 병사 누적 피해의 저장 형식, 부위 목록, 부위 선택 확률과 보호구 모델.
- 경상·중상·전투 불능·사망의 상태 전이와 기능 제한.
- 치료·회복·후송·인원 충원 여부와 플레이어 조작 범위.
- 파편 피격의 게임 확률·범위·중복 판정 및 성능 예산.
- 보병 장비 목록, 탄약 후보의 채택 여부, 휴대 탄수와 보급 규칙.
- 분대별 상태를 관측·AI·이동·점령·표시에 연결하는 방식.
