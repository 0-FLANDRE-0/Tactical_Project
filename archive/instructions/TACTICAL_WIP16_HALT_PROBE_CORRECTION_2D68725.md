# WIP16 추가 수정 — 기준 2d68725

대상은 `src/tactical-ai.js`의 차폐 재확인(`probePending`/`retryBlocked`) 처리다.

차폐 재확인을 위해 자동사격 억제를 해제하면서 `halt` 정책도 제동 전에 실제 첫 탄을 발사하는 문제를 수정한다. 발사선 재확인과 실제 발사를 구분하고, `halt`는 재확인 중에도 첫 발부터 제동·정차 유지 조건을 지킨다. 검사만 수행한다면 탄약·발사 번호·난수·비행체·효과를 생성하지 않는다. `maintain`의 기동간 사격, 차폐 해제 뒤 자동 교전 복구와 지속 차폐의 반복 방지는 유지한다.

기동간 사격 가능한 차량에 `halt`를 적용해 능선을 전진·후진 통과시키고, 차폐 해제 뒤 첫 자동 발사부터 실제 속도와 정차 유지 시간을 검사한다.
