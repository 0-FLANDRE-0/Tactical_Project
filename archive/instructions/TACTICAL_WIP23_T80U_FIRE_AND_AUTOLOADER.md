# WIP23 — T-80U 정지 사격·3BM42·6초 자동장전

> **지시서 등록 / 구현·검증 대기.** 사용자 합의: 탄약 피해는 최신 아카이브의 확정값을 사용한다. T-80U 자동장전은 **6.0초**로 한다. 관측·조준·명중·발사·피해 시스템은 공용으로 사용하고, 차량별 성능과 장전 방식은 해당 프로파일에서 결정한다. 아래에서 별도로 표시한 시험값은 실차 성능 확정값이 아니다.

## 1. 시작점과 완료 목표

- 저장소 `0-FLANDRE-0/Tactical_Project`. 작성 기준 main은 **`b4716768638e794f3de859a3a24f231e2084b1dd`**다. WIP22 독립 검토와 격파 시 큐폴라 자세 보완이 main에 통합됐고, 이후 탄약 피해·구경별 과관통·ERA 설계 기록이 갱신됐다. 작업 시작 때 최신 main을 갱신하고 새 작업 브랜치에서 구현한다. 완료된 WIP21/22나 모델 수정을 다시 적용하지 않는다.
- `T80U_1989`가 **자체 관측 → 지시/인계 → 포수 확보 → 실제 포탑 정렬·조준 → 최신 포구 발사선 확인 → 3BM42 발사 → 착탄/피해 → 6초 자동장전**을 수행하게 한다. 포수 자체 발견 경로도 기존 공통 규칙대로 유지한다.
- 기존 M1A2와 같은 시뮬레이션에서 서로 사격·피격·격파할 수 있어야 한다. T-80U 차체는 정지하며, 관측·추적·발사는 기존 공통 엔진과 정상 정보 경계를 통과한다. 별도 T-80U 전투 엔진이나 적 전용 명중률을 만들지 않는다.
- 이번 추가 무장은 **125mm 2A46M-1 / 3BM42 Mango 한 종류**다. 이동·순찰·전술 교전 AI, 기동간 사격, 기관총, HEAT/HE/ATGM, 혼합탄 자동 선택, 예비탄 보충·외부 보급, 자동장전장치 고장, T-80U 승무원/모듈/탄약고 피해는 후속이다.
- **ERA 소모·손상도 이번 범위에서 제외한다.** 최신 아카이브의 소모율 확정은 후속 설계 근거다. WIP21의 비소모 Kontakt-5 피복/방호를 그대로 유지하며 이번 작업에 소모 규칙을 함께 구현하지 않는다.

## 3. 공용 시스템과 차량별 성능 소유권

### 3.1 공통 판정은 하나로 유지

- 관측 증거·현재/기억 구분·인계·포수 확보, 포탑 정렬·조준 진행, 오차 예산·명중/피격면 선택, 발사선 검사, 탄 비행·착탄·피해·효과 생성은 기존 공통 경로를 사용한다.
- 성능은 `T80U_1989`의 센서/선회/사격 프로파일, 탄약 특성은 탄약 레지스트리, 피격 반응은 **피격 차량의 프로파일**에 둔다. 처리 코드에서 차량 ID·팀 색으로 명중률/장전시간/관측 예외를 나누지 않는다. 다른 차량도 같은 스키마로 등록할 수 있어야 한다.
- 장전은 공통 탄약·장전 상태 진행 안에서 **수동 / 자동 방식**을 데이터로 구분한다. T-80U 전용 복제 타이머나 실제 발사와 무관한 `shotIntervalSeconds`로 우회하지 않는다.
- M1A2/M1A2_1998의 기존 관측·조준·정렬·오차, 5.98초 수동장전과 피로/피격 동요·14초 상한, 탄약·승무원·사고 반응을 보존한다. T-80U를 위해 M1A2 설정 전체를 깊은 복사하거나 기존 장전수를 제거하지 않는다.

### 3.2 T-80U 관측·선회는 WIP22 값 유지

| 항목 | 유지할 T-80U 값 | 근거 상태 |
|---|---:|---|
| 장비 | PNK-4S / TKN-4S + 1G46 | 기존 자료 노트 |
| 포탑 / 큐폴라 최대 선회 | 24°/s / 40°/s | 2차 자료 기반 채택 상한 |
| 전차장 관측 / 포수 관측 | 2,000m·전체각 90° / 2,000m·전체각 30° | WIP22 게임 시험값 |
| 전차장 / 포수 관측점 높이 | 2.50m / 2.15m | 기존 외형 근사 |
| 전차장 탐색 / 포수 탐색 | 차체 기준 ±180°·90초·12°/s / ±30°·24초·8°/s | WIP22 게임 시험값 |
| 전차장 인계 / 포수 자체 확보 | 연속 자격 0.50초 / 연속 자체 관측 0.40초 | WIP22 게임 시험값 |

나머지 관측 주기·증거·기억·상실/만료 설정도 WIP22 그대로 시작한다. `hunterKiller:false`, `commanderDesignation:true`의 의미를 유지한다. 발사를 가능하게 하려고 CITV를 복사하거나 인계·포수 확보를 즉시 완료하지 않는다.

### 3.3 이번에 추가할 T-80U 사격 초기 시험값

아래는 **구현을 시작하기 위한 게임 시험 설정**이다. 실차 1A45/1G46의 실측 조준시간·분산·명중률이라는 의미가 아니다. 차량별 데이터를 분리해 조정할 수 있게 하며, 기존 M1A2의 값은 바꾸지 않는다.

| 필드/항목 | 초기값 | 용도 |
|---|---:|---|
| `aimSeconds` | 1.60초 | 기존 공통 조준 진행의 기준 시간 |
| `alignmentTolerance` | 1.5° | 기존 공통 정렬 허용각을 명시 채택 |
| `maxRange` | 2,000m | 이번 포수 관측/사격 시험 한계 |
| `fireHeight` | 2.05m | 게임 포구 높이 근사, 실제 포구 발사선에 사용 |
| `dispersionMrad` | 0.30 | 정적 분산 |
| `layStartMrad` / `layMinMrad` | 1.80 / 0.12 | 초기/수렴 조준 오차 |
| `layTauSeconds` | 0.80초 | 조준 오차 수렴 속도 |
| `rangeErrorM` | 8m | 거리 오차 항 |
| `leadResidual` | 0.12 | 관측한 표적 이동에 대한 잔여 선행 오차 |
| `velocityRetention` | 0.94 | 기존 공통 시험 비행 근사의 명시 채택 |

- 명중률은 이 설정과 사거리·조준 경과·표적의 관측 이동·실제 노출 형상으로 **공통 오차 예산에서 계산**한다. ‘T-80U 명중률 70%’ 같은 별도 고정 확률, 적 보정, 미관측 실제 속도/기동 가산을 넣지 않는다.
- 포구초속은 현재 장전된 **3BM42의 1,700m/s**를 사용한다. 총기 기본값이나 M829A2의 1,680m/s가 착탄 시간/거리 오차에 남지 않게 한다. `velocityRetention`을 관통력이나 HP에 추가 곱하지 않는다.
- T-80U 피격 형상/제시 높이는 WIP21 값을 사용한다. 사격 가능 차량이 됐다고 M1A2의 높이/모델을 피격 측에 적용하지 않는다. 조준 오차와 관측 점/포구 높이를 혼동하지 않는다.
- 같은 표적 형상·거리·관측 속도·조준 경과를 놓고 500/1,000/2,000m의 오차 항과 계산 명중률을 비교 기록한다. 수치가 다르다는 증거와 실제 모델 크기로 생긴 차이를 구분한다. 시험 결과에 따른 조정은 근거와 최종값을 보고서에 남긴다.

## 4. 3BM42와 125mm 피해 곡선

### 4.1 확정값을 탄약 데이터로 등록

| 항목 | 적용값 |
|---|---|
| 내부 ID / 종류 | `3BM42` / APFSDS·KE·125mm |
| 주포 / 탄명 | 2A46M-1 / 3BM42 Mango |
| 기본 차량 HP 피해 | **370 HP** |
| 포구초속 | **1,700m/s** |
| 10m KE, 입사각 0°/30°/60° | **505 / 425 / 280mm** |
| 2,000m KE, 입사각 0°/30°/60° | **450 / 380 / 250mm** |
| 도탄 0% / 50% / 100% | **78° / 80° / 81°**, 사이 선형 보간, `roll < chance` |

- 거리 10~2,000m와 각도 0/30/60° 사이는 공통 선형 보간한다. 이번 시험의 중간 거리별 별도 실측 표는 만들지 않는다. 기존 공통 규칙대로 범위 밖 거리는 끝값 고정, 60~90° 관통력은 60° 값에서 90°의 0까지 선형 연장한다. 발사 사거리 제한은 별도로 유지한다.
- 선택된 차체/포탑·전/측/후면의 **착탄 시 자세와 면 법선**으로 입사각을 계산하고 기존 상면 근사를 유지한다. 각도별 KE 표에 장갑 경사/LOS 배율을 다시 곱하지 않는다. 도탄 판정·피복 추첨·관통·피해는 각각 기존 위치에서 한 번만 수행한다.
- **3BM42의 근접 비관통 HP 피해는 이번에 비활성으로 명시한다.** 최신 아카이브에서도 해당 세부 수치는 미정이다. 피격 M1A2의 `readiness.nearNonPenetration`을 fallback으로 상속해 30%/120 HP 규칙을 암묵 적용하지 않는다. 기존 M829A1/A2의 근접 비관통 규칙은 유지한다.

### 4.2 125mm APFSDS 공통 곡선 사용

관통 성공 `P≥R`, `P>0`일 때 `r=(P-R)/P`, `피해=370×F_125(r)`다. `P`는 거리·입사각 반영 KE 유효 관통력, `R`은 피격 구역의 최종 KE 방호력이다. ERA가 적용된 경우 그 방호를 포함한다.

| 잔여 관통력 비율 r | 0% | 9% | 18% | 77% | 90% | 96% 이상 |
|---|---:|---:|---:|---:|---:|---:|
| 피해 배율 | 65% | 104% | 107% | 65% | 35% | 25% |
| 3BM42 피해 HP | 240.5 | 384.8 | 395.9 | 240.5 | 129.5 | 92.5 |

- 기준점 사이는 선형 보간, 96% 이후 하한 25% 유지. 추가 고정 과관통 페널티나 탄속 피해 계수를 곱하지 않는다. 내부 HP/피해는 기존 부동소수점 흐름을 유지하고 표시 반올림을 실제 피해에 역적용하지 않는다.
- 구경/탄종 정책을 참조하는 데이터 구조로 둔다. **3BM42만 개별 최고/과관통 곡선을 새로 설계하지 않는다.** 기존 120mm APFSDS 곡선은 값·정밀도·기존 결과를 보존해 공통 참조할 수 있게 한다. 이번 런타임 신규 탄은 3BM42 하나이며, 아직 없는 소련 5종이나 서방/독일 탄을 함께 등록하지 않는다.
- 관통 실패/도탄은 HP 0이다. 시각 도탄탄은 2차 충돌·추가 피해를 일으키지 않는다. 발사/명중/피격면/입사각/도탄/관통·피해 결과를 결정하고 파티클은 그 결과를 표현한다. 파티클의 접촉으로 다시 결과를 추첨하지 않는다.

## 5. 6초 자동장전과 유한 재고

### 5.1 이번 단일탄 시험 적재

- 기본 시험 적재는 **장전된 3BM42 1발 + 즉응 재고 12발 = 총 13발**로 한다. 이는 아카이브 기본 프리셋의 AP 즉응 13발을 쓰는 **제한된 사격시험 구성**이다. 전체 45발 혼합 프리셋을 구현했다거나 28/45발 전부가 Mango라는 뜻이 아니다.
- T-80U 최대 적재 제원 **45발**, 아카이브 즉응/예비 **28/17발**과 이번 초기 적재량을 구분한다. 게임 재고 계산은 장전탄을 즉응 총량에 포함하여 중복하지 않는다. 구획 상한을 둘 경우 약실 1 + 즉응 저장 27 + 예비 17로 회계상 총 45가 되게 하고, 초기 즉응 저장은 12·예비는 0으로 시작한다. 이 회계 구분은 실제 MZ 슬롯/약실 이송의 물리 시뮬레이션을 뜻하지 않는다.
- 기존 공통 재고의 `loadedAmmoId`, 구획 재고, 장전 예약탄/진행을 재사용한다. 최대 용량과 초기 적재량을 동일시하던 검증은 **초기 적재 ≤ 각 구획/총 상한**으로 구분하고 음수·비정수·초과·미등록/비호환 탄은 거부한다. M1A2_1998의 기존 초기 42발과 저장 분배는 그대로다.
- T-80U는 준즉응/예비 초기 재고가 없고 보충 기능을 명시 비활성으로 둔다. 호환상 빈 구획을 유지해도 존재하지 않는 보충 작업/시간이나 인간 장전수를 만들지 않는다. 지원탄 목록은 3BM42만이다.

### 5.2 장전 상태의 공통 진행

- 정상 장전탄을 실제로 발사·소비한 시뮬레이션 시각부터 다음 자동장전 완료까지 **6.00초**다. 고정 0.05초 틱의 부동소수점 허용 오차는 둘 수 있지만 6초 미만 발사를 허용하지 않는다. 초기 1발은 이미 장전된 상태이며 생성 직후 6초를 강제로 기다리지 않는다.
- 장전과 관측/포탑 선회/조준은 기존 방식으로 병행할 수 있다. 6초는 **다음 탄의 준비시간**이며, 관측·정렬·조준·발사선이 미충족이어도 무조건 6초마다 발사하는 주기가 아니다. 장전 완료만으로 조준·관측을 초기화하지 않는다.
- 자동장전에는 M1A2의 연속사격 피로, 피격 동요에 따른 장전 지연, 장전수 부상/효율, 수동장전의 14초 상한을 적용하지 않는다. 이번 T-80U는 장전장치 고장·피격 일시 이상도 추가하지 않으므로 생존하고 재고가 있으면 기계 주기는 6초로 유지된다.
- 발사 불허·조준 취소·표적 변경·UI 조회는 탄을 소비하지 않는다. 장전 중 표적이 사라져도 정상 기계 장전은 계속되며 보류 모드에서도 완료할 수 있다. 마지막 탄·장전 중 마지막 예약탄·0발에서 허수 재고나 무한 사격을 만들지 않는다.
- `초기 13 = 실제 발사 수 + 약실 + 저장 + 예약탄`을 모든 중간 상태에서 만족한다. 재고에서 예약 시 뺀 탄을 다시 총량에서 빼거나 약실과 예약에 동시에 세지 않는다. reset은 새 초기 재고를 만들고, 격파는 추가 발사·장전을 정지한다.
- 일시정지·배속은 시뮬레이션 시간 계약을 따른다. 이미 발사된 탄은 발사 당시 탄약/초속/조준 정보를 보관하며 사수 격파·표적 전환·장전 상태 변경 뒤에도 정상 도착해 한 번만 피해를 적용한다.

## 6. 능력·장전·피격 정책의 기존 결합 해제

이번 작업에서는 다음 결합을 실제 호출부까지 정리해야 한다. 검증 전체를 생략하거나 가짜 M1A2 필드를 채워 통과시키지 않는다.

1. **정지 사격 차량:** `target:true, observation:true, fire:true, mobility:false, ai:false`를 허용한다. 구동 검증은 기동 기능, 사격 검증은 발사 기능, 반응 검증은 해당 기능에 따라 수행한다. AI의 기존 필수 의존성과 관측 없는 발사 금지는 유지한다. T-80U에 `drive`·이동 임무·TacticalAI 상태를 생성하지 않는다.
2. **선택적 장전/반응:** 현재 `fire-control` 초기화·장전 진행·발사 소비·관측 페널티·`react()`는 모든 사수가 수동장전/피로/피격 동요/일시 이상 설정을 가진다고 가정한다. 장전 방식과 피격 반응 활성 여부를 분리하고, T-80U에는 필요한 사격·재고·자동장전 상태만 생성한다. 설정 없는 피로/승무원/탄약고 사고를 초기화하거나 undefined를 읽지 않는다. M1A2 반응은 종전 순서/계수 그대로다.
3. **발사 불가 통보:** `onFireBlocked` 등에서 AI 비활성 T-80U를 TacticalAI에 등록하지 않는다. 기존 Observation의 유효 표적 유지·상실/재탐색을 사용하고, 실제 숨은 좌표를 전달하는 표적 재선택을 만들지 않는다.
4. **구형 시험 마스크:** `t80u-armor` T-80U는 `{observation:false, fire:false}`, `t80u-observation` T-80U는 `{fire:false}`로 기존 동작을 보존한다. 실행 마스크는 허용 기능을 끄기만 하며 비활성 기동/AI를 켜지 못한다. 기존 시험에서 T-80U 탄약·장전·발사 상태도 생기지 않아야 한다.

### 6.1 3BM42가 기존 M1A2를 맞혔을 때

- 공격탄 등록과 **피격 차량의 반응 정책 연결**을 모두 처리한다. 새 탄약이라 정책을 못 찾아 기존 M1A2_1998 승무원·일시 고장·탄약고 반응이 누락되거나 예외가 발생하면 안 된다.
- 이번 초기 시험은 `M1A2_1998`의 **기존 KE 피격 반응 표/가중치/감수성**을 3BM42 공격에 **명시적으로 연결**한다. 정책 ID 예: `tank-ke/3BM42`. M829A2 KE 표를 같은 시험 정책으로 참조/복제하되 탄약 연결은 3BM42로 검증한다. 새로운 실차 피해 확률을 입증한 것이 아니라 기존 M1A2 게임 반응의 적용 범위를 명시한 것이다. 3BM42 근접 비관통 HP 피해는 §4대로 비활성이므로 그 분기는 실제 발생시키지 않는다.
- M1A2_1998 탄약고 사고의 공격탄 정책도 `tank-ammo-incident/3BM42`, **기본 발생 계수 0.30**으로 명시 연결한다. 기존 M829A2와 같은 초기 KE 시험값이며, 피격 구역 분포·실제 저장량/적재율·저장탄 반응·구획 보호·결과 분포와 중복 방지를 그대로 사용한다. 실제 저장탄은 M1A2가 보유한 세 탄종뿐이다.
- **들어오는 공격탄 정책과 자기 적재/발사 지원탄 목록을 분리**한다. 현재 사고 검증의 `정책 수 == 지원탄 수` 가정을 수정하되 정책의 등록 탄약/ID·값은 전부 검증한다. 기존 세 탄의 필요한 연결·저장탄 반응 검증은 유지한다. Mango를 맞게 하려고 M1A2 적재 가능 목록이나 저장탄 반응 표에 3BM42를 넣지 않는다.
- WIP15의 M1A2 피격 동요·포탑 일시 이상은 기존 피격 차량 설정과 최종 계산 피해로 한 번만 처리한다. 이 경로를 T-80U에 역으로 상속하지 않는다. T-80U가 맞을 때는 기존 HP/장갑/K5·격파만 적용하며, 3인 승무원은 구성 정보로 유지하고 가짜 장전수·부상·장치 고장·유폭을 추가하지 않는다.

## 7. 정상 발사·효과·정보 경계

- 발견/팀 공유/기억만으로 사격을 허용하지 않는다. 유효 자기 포수 확보, 현재 표적·명령 소유권, 사거리, 실제 포탑 정렬, 조준 완료, 장전탄, 정지 사격 정책, **현재 포구에서의 최신 발사선**을 공통 발사 직전 검사로 모두 통과해야 한다. 전차장만 보거나 광학 관측선은 열렸어도 포구가 능선/건물에 가려지면 발사하지 않는다.
- 발사선은 기존 캐시 계약과 신선도/자세 무효화 규칙을 사용한다. LOS가 막혀도 관측 인계/발사 요청을 무한 반복하거나 매 렌더 프레임 전수 조회하지 않는다. 기존 블록 재확인·유계 재시도를 보존한다.
- 실제 포구 월드 위치/방향은 수정 T-80U 모델의 `muzzleLocal`·포탑 회전축과 공통 좌표 계산에서 구한다. 화면 그림 기준 임의 오프셋이나 M1A2 포구를 사용하지 않는다. 부모 상대 도 단위 원본과 월드 절대 라디안 어댑터의 계약을 보존한다.
- 발사 화염·연기·예광·착탄/도탄은 WIP12 공통 효과를 사용한다. 보이지 않는 적이 쏴도 **발사 시 고정 월드 위치의 효과와 탄도 효과**는 기존 정책대로 보일 수 있다. 그것만으로 적 모델·접촉·시야·체력·탄약/장전·승무원 정보를 공개하지 않는다. 숨은 사수의 이후 위치/회전에 효과를 붙여 추적하지 않는다.
- 발사/효과 렌더·UI 조회가 명중 RNG/판정 횟수를 바꾸지 않아야 한다. 장전/발사 불허는 실제 샷 번호·전투 판정 난수를 소비하지 않는다. 동일 탄은 단 한 번만 착탄/피해를 적용한다.
- 아군 UI의 적 체력·자세는 허용된 관측 사본과 최신 관측값 병합 규칙을 유지한다. 관측 상실 시 적 포탑/큐폴라가 숨은 실제 선회를 따라가지 않고 마지막 관측 자세를 유지한다. WIP22 보완의 **실제 격파 순간 큐폴라 자세 보존**도 회귀 검사한다.

## 8. 게임 연결과 시험 시나리오

- 기존 기본 전투·방호시험·관측시험을 유지하고 우측 기존 시나리오 선택기에 **T-80U 정지 교전시험**(예: `t80u-fire`)을 추가한다. 콘솔/단위 테스트 전용 기능으로 끝내지 않는다.
- 정상 기본 구성은 아군 M1A2_1998 1대, 적 T80U_1989 1대다. 둘 다 자동사격이며, **기존 관측·발사 조건으로 실제 상호 교전 가능한 지형/배치/초기 방위**를 검증해 선정한다. 자동 발사는 TacticalAI 없이도 기존 Observation 인계/추적과 공통 fire-control로 작동해야 한다.
- T-80U는 차체 위치·방위를 고정한다. 이 시나리오의 M1A2도 이동 임무 없이 정지 출발하되 기존 조작 기능은 유지한다. 정면 장갑 때문에 비관통이 반복되는 정상 결과를 보장 명중/보장 관통/HP 감소로 우회하지 않는다. 추가 검증에서 측면 배치로 실제 피해/격파도 확인한다.
- 자동 교전과 정상 플레이어 보류/재개를 실제 페이지에서 확인한다. 내부 로그는 자기 관측 출처·인계·포수 확보·정렬·조준·발사선·발사·장전 시작/완료·착탄을 연결해 남기되 정상 UI에 적 내부 상태를 노출하지 않는다.
- 아군 T-80U fixture/역할 교환 검증도 수행한다. 아군으로 배치됐을 때 기존 선택 유닛 패널에 무장/현재 탄/유한 잔량/장전 진행을 표시할 수 있어야 한다. 자동장전은 `자동장전 4s`처럼 기존 지도 위 작업 표시를 재사용하고 가짜 장전수 피로나 부상 항목은 표시하지 않는다. 적에게 같은 내부 작업 글자를 공개하지 않는다. 새로운 편성/탄약 편집 화면은 만들지 않는다.
- 시나리오 전환/reset은 마스크·재고·장전/임무·관측·진행 탄/효과·Worker 세대 토큰을 초기화한다. 이전 전투의 탄/콜백이 새 시험의 차량을 때리지 않아야 한다.
