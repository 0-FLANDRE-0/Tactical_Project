## 2. 다음 작업 순서 [제안]

1. **WIP10 검토·병합.** 7절 기준값 대조, 정보 공개 규칙(미관측 착탄은 결과 미확인) 확인.
2. **최소 전투 모델 (WIP11 후보): 두 차종으로 "쏴서 터지는 데"까지.**
   - 차종 선택 [미정]: 현재 게임 시험 차량은 M1A2인데, 아카이브 기준 M1A2 (1992/1998)는 1989 본편 32종 밖의 후속 시대 형식이다. 1989 본편과 맞추려면 **M1A1 HA 대 T-80U (1989)**, 시험 차량을 유지하려면 **M1A2 대 T-80U**. 상면 도안은 M1A1/M1A1 HA 변형이 이미 있다(CITV 대신 덮개판, CWS 큐폴라). M1A1 HA는 헌터킬러가 없어 OODA 경로 비교 시험에도 쓸 수 있다.
   - 데이터만 32종 + 프리셋 96개로 늘어나고 실제 게임은 한 차종에 관통·피해가 없는 상태라, 아카이브 수치(K5 등)를 검증할 수단이 없음. 두 차종 1:1 시험으로 밸런스를 직접 보는 단계가 필요함.
   - 필요한 것: T-80U 프로파일(기동·센서·치수·노출 표본), 상면 도안, 7구역 KE/CE 관통 판정, ERA 피복률 소모, HEP 성공 = 관통 처리, 최소 피해(격파/기동 불능/화력 불능 정도).
   - 이 단계 전에 3절의 **동률 관통 규칙**과 **K5 소모량**은 결정돼 있어야 함.
3. **자동 교전 (OODA 루프)** — 2절 2번 이후.
   - 관측(Observe)·실행(Act)은 매 틱 연속, 상황 판단(Orient)·결정(Decide)만 주기적으로. 주기는 숙련도·스트레스로 변화 [제안]
   - 훈련된 반사행동(정면에서 조준당함 → 즉시 응사/연막 등)은 결정 주기를 건너뜀 [제안]
   - 헌터킬러 경로: 전차장이 식별·판단 → 포수 인계 → 포수는 판단 없이 확보("확인") → 조준 → 발사. 포수 단독 발견 경로는 좁은 판단으로 빠르지만 표적 선택이 엉성할 수 있음 [제안]
   - 교전 규칙 3단계: 자유 사격 / 응사만 / 사격 금지 [제안]
   - 표적 우선순위: 나를 겨누는 위협 > 위협 큰 기갑 > 거리. 아군이 이미 쏘는 표적 감점. 플레이어 지정 최우선 [제안]
   - AI 발사 판단: 예상 명중률이 숙련도·위협별 기준을 넘으면 발사 [제안]. 이때 표적 속도 추정은 조준 상태와 분리돼 있어야 함 (WIP10에서 분리 예정)
4. **상태 표시·모듈 피해·수리**
   - 레드드래곤식으로 유닛 위에 원인과 해결 시간 표시 [확정]
   - 맞은 부위에 따라 손상 모듈을 확률로 결정 [확정]
   - 궤도·엔진 현장 수리 가능, 완전 수리는 보급지점에서 보급포인트 사용 [확정]
   - 표시는 카테고리 5종(기동/화력/관측/승무원/탄약)으로 묶고 세부는 선택 시 표시 [제안]
   - 타이머는 3종: 저절로 회복 / 승무원 수리(피격 시 정지) / 보급지점 필요 [제안]
   - 현장 수리는 성능 일부만 회복(예: 최고속도 70%) [제안]
   - 보급지점 전용: 포신 파괴, 탄약고 유폭 후 손상, 승무원 사망·충원 [제안]
   - 관통 후 모듈은 잔여 관통력·탄종 성격(HEAT 좁음, 날탄 파편 넓음, HEP 승무원 피해)에 따라 개수·범위 결정 [제안]
   - 비관통 피격도 외부 모듈(궤도·조준경·포신·ERA) 피해 가능 [제안]
   - 탄약 배치 차이(에이브람스 버슬 블로우오프, 소련 회전식 장전장치, 레오2 차체 탄약고)가 모듈 표에 반영되면 진영 차이가 저절로 생김 [제안]
   - 피격 로그/표시가 없으면 다단 확률 결과가 랜덤해 보이므로 함께 구현 [제안]
5. **고폭탄·파편.** WIP10의 판정 뒤 탄착점을 기반으로 파편 판정 추가. 고폭탄은 장갑을 "관통"하지 않고 외부 모듈 피해 위주로 정의하는 방향 [제안] (3절 HE 항목 참고).
6. **세부 부위(subzone)·경사 보정.** 7구역 최소 모델이 검증된 뒤 도입. 조종수 해치·차체 하부 등은 사용자 구상에 있음 [확정 구상]. 면당 2~4개 이내, 세부 면적 가중 평균이 기존 7구역 값과 같아지도록 재분배해 이중 계산 방지 [제안]. 차체 은폐 시 하부 가중치 0 [제안].

## 4. 아카이브 정리 필요 목록

1. **`combat/TWO_STAGE_HIT_AND_360_ARMOR_RESOLUTION_DESIGN_2026-11-07.md` 7절 표가 WIP06 기준.** 현재는 사격(WIP08A)·명중 확률(WIP09)이 있고, 포탑 노출 표본은 실제 포탑 각도를 사용함. 다른 AI가 이 표를 믿고 작업하지 않도록 갱신 필요.
2. **`combat/…` 3절 입력표의 "표적 관측·식별"** 은 확률에 곱하지 않고 **확보 조건(관문)으로만** 쓴다고 명시 필요 (ARMOR_SUBZONES 메모 6절의 이중 적용 금지와 충돌 방지). WIP09·10 구현은 이미 이 방식.
3. **`tanks/README.md` 8절 M1A2 (1992/1998)**
   - **반영됨 (a750d6a):** 차체 전면을 1992형 385(700), 1998형 390(720)으로 낮춰 포탑 위주 개량에 맞춤. 에이브람스 6개 형식 포탑 후면 55(55) 통일.
   - 남은 것: 8절 마지막 줄 "현행 WIP06 소스" 문구 갱신.
4. **`ammo/README.md` M829A2·M830A1** 에 9M119M처럼 "1989 목록 제외, 후기 시나리오용" 문구 추가. 문서 제목이 "TACTICAL 1989"라 1989 선택탄으로 오해될 수 있음.
