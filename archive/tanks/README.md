# TACTICAL 1989 — 전차 데이터 (Tanks)

> **기준일:** 2026-11-07 | **범위:** 1989년 본편 32종 + 후속 시대 M1A2 (1992/1998) 2종, 7구역 KE(CE) 실효 방호력, ERA/BDD/D-Tech
> **데이터 지위:** 본편 32종과 후속 시대 M1A2 2종의 게임 방호력 최신 기준표. 폐기된 통합 문서의 이전 기록 대신 이 문서의 확정 수치를 사용한다.
> **관련 문서:** [탄약 데이터·적재 프리셋](../ammo/README.md) | [아카이브 목차](../README.md) | [세부 장갑면·확률 모델 아이디어 (미확정)](ARMOR_SUBZONES_AND_PROBABILITY_IDEAS_2026-11-07.md)

이 문서는 앞으로 전차 방호력/장갑 개량을 관리하기 위한 **최신 데이터 기준표**다. 사용자가 지정한 모든 KE(CE) 수치는 게임용 RHAe 환산값이며 실제 장갑 실측값이 아님. 기존 6구역 자료와 상부 7번째 구역은 서로 분리되어 있으므로 합쳐서 읽어야 한다.

**관리 원칙:** 확정 수치와 실제로 미정인 시스템만 유지한다. 구형 값·오래된 진행 상태는 현재 기준에서 폐기. 탄약 이름·적재량·프리셋은 [탄약 기준표](../ammo/README.md)를 우선한다.

## 1. 공통 방호력 판정 기준

1. **2026-11-07 갱신:** 전차 방호력은 차체 **전면·측면·후면** 및 포탑 **전면·측면·후면**의 기존 **6구역 + 차체·포탑 지붕을 통합한 상부장갑 1구역 = 총 7구역**을 별도로 보유한다. 하부장갑은 현 단계에서 제외한다. 기존 방호력 6구역의 확정 수치와 규칙은 유지하며, **제7구역 상부 KE(CE)는 계열별 30(30)·40(40)·45(45)로 확정**했다. 자세한 32개 차종별 값은 아래 1-A절 참고.
2. 방호력 표기는 **KE(CE)**. KE는 운동에너지 탄 대응, CE는 화학에너지/성형작약 및 일부 특수탄의 추상화 판정용. 측정값이 아닌 게임용 대표 RHAe.
3. 탄약 표의 수치는 **2,000m에서 장갑 표면에 법선 방향으로 들어오는 0° 조건**을 뜻하며, 각도별 성능은 별도 테이블을 도입할 예정.
4. 명중 성공과 기존 차체/포탑 전·측·후 구역 선정은 주로 확률 기반. **상부 피격으로 분류된 경우에는 별도 제7구역 상부장갑**을 참조한다. 명중 후 부위 방호력과 피격 조건을 계산.
5. 각 장갑 구역에 대략 알려진 **대표 장갑 수직 경사각**을 향후 저장하고, 피탄 수평 방향(차체/포탑 방향)과 합성해 최종 입사각을 구상 중. 정확한 장갑판 전체 형상을 정밀 재현하지는 않음.
6. 이미 정한 KE/CE 방호력은 **기준 정면 피탄 조건의 실효값**으로 취급하므로 대표 경사각을 다시 온전히 곱해 방호력을 이중 계산하지 않음. 변동된 입사 조건에 대한 **추가 보정**으로 사용.
7. 각도별 탄약 성능(0/30/60°), 도탄, HEAT 신관 활성화 실패 등은 장기적으로 반영. 도탄률·실패 임계각·세부 확률값은 **아직 미정**.
8. HEP/HESH의 장갑 내부 파편화는 게임에서 유효 내부 피해가 발생하면 **결과적으로 관통 성공과 같은 피해 성공으로 처리**. 별도 '관통은 실패했지만 파편만 성공' 같은 불필요한 상태는 만들지 않기로 정리. 성공 시 높은 내부 피해율; 경장갑 표적은 크게 파괴될 수 있음.
9. 미군/서독군은 같은 진영이므로 두 나라 전차끼리 전투할 때의 대칭 밸런스를 억지로 강제할 필요 없음. 실제 상대하는 동구권 장비와 비교해 밸런스를 잡는다.
10. 실제 자료가 불확실한 복합장갑은 **고증 참고 + 게임 밸런스 허용**. 미래 시대의 전차도 같은 mm 기반 데이터 체계를 확장 가능.


## 2. 상부장갑 — 32종 값 및 ERA 지붕 피복률

**상태: 기존 6구역에 상부장갑 제7구역 추가 및 32개 형식 KE(CE) 값 모두 확정.** 사용자가 단일 수치로 제시한 상부 방호력은 **KE=CE**의 RTS용 단순화로 기록함.

- **7구역 구성:** ① 차체 전면 ② 차체 측면 ③ 차체 후면 ④ 포탑 전면 ⑤ 포탑 측면 ⑥ 포탑 후면 ⑦ **상부장갑**.
- **상부장갑은 1개 구역으로 단순화:** 차체 상판과 포탑 상판을 별개의 8번째 구역으로 쪼개지 않음. 곡면·국소 두께·개별 장갑판의 LOS 길이를 구현하지 않는 RTS용 대표 방호력.
- **수치 체계:** 상부도 기존과 같은 **KE(CE), mm RHAe**. 이미 기존 장갑 형상의 원래 기울기 등을 고려한 게임 대표 방호값으로 설정하며, 중복 LOS 보정을 하지 않는다. 지붕에 해당하는 구역 판정 후 별도 방호력값을 참조.
- **유효 타격의 분류:** 일반적인 수평 직사 교전에서는 상부 피탄이 드물다는 설계 전제를 둔다. 고각·상부공격 등 **상부 피탄으로 판정되는 특수 상황**에서만 제7구역 수치를 참조. 일반 폭발·파편·근접폭발 효과와 직접 명중의 장갑 관통 판정은 별개이며, 세부 판정·각도·도탄·피해 계수는 미정. **3OF19(CE 35)·3OF26(CE 40) 등과의 수치 비교에서 방호력=관통력 동률 결과는 아직 미정**.
- **상부 ERA 최신 확정(2026-11-07):** 기존 전·측·후 ERA 피복률은 자동 상속하지 않지만, **T-64BV·T-72B(1985/1989)·T-80BV·T-80U(1985/1989)** 6형식은 아래 **별도 상부 ERA 피복률**을 명시적으로 채택. 해당 장갑의 Kontakt-1/5 KE·CE 추가 방호력은 기존 설정값을 그대로 사용하며, 반응·소모 시 상부 피복률도 감소.
- **BDD 및 D-Tech 상부:** 사용자 별도 설정 전까지 **상부 피복률·추가 방호력 미설정**. 기본 전·측·후 장갑 및 피복률은 그대로 보존.

### Leopard 2 KVT (1989) / D-Technologie — 시제 전차 게임 방호력 확정 (2026-11-07)

## 7. 향후 명중·입사각·효과 시스템

> **발사·착탄 판정 검토 문서:** [2단계 명중 평가와 360° 구역 확률 구상](../combat/TWO_STAGE_HIT_AND_360_ARMOR_RESOLUTION_DESIGN_2026-11-07.md). 발사 당시 품질 평가와 착탄 시 최종 명중 판정, 차체·포탑 독립 방향, 선택된 면의 게임용 LOS 보정을 제안한다. **공식·수치·구현은 미확정**.

> **논의 메모:** [7구역 내부 세부 장갑면 및 물리 상태 기반 확률 판정 구상](ARMOR_SUBZONES_AND_PROBABILITY_IDEAS_2026-11-07.md). 차체 상·하부/조종수 해치, 포탑 좌우 뺨·포방패, 측면 전·후방, 상부 차체·포탑 지붕 구분과 이동 상태·사통장치에 따른 확률 변화는 **검토 중**이며 확정 수치/기능이 아니다.

- 부위 선택: 차체/포탑 노출 비율과 전·측·후 방향 등을 기반으로 **확률적 명중부위 선정**.
- 기하학: 각 부위의 대략 알려진 **대표 수직 경사각** + 포탄이 들어오는 **수평 상대각**을 합성.
- 기준 KE/CE 수치는 명시적인 **기준 입사 상황의 게임상 방호력**이므로 경사에 의한 효과를 중복 적용하지 않도록 입사각 상대 변화만 반영.
- 탄약: 2km/0° 숫자는 존재하지만, 탄약마다 30°·60° 및 거리별 보정 곡선은 아직 없음.
- 높은 입사각에서 도탄, 특정 HEAT 신관 작동 실패 등을 **탄종별 효과**로 나중에 추가. M456A1/A2 같은 차별화 후보.
- HEP: 내부 박리/파편화로 적 내부에 유효 피해가 나면 게임상 **유효 관통 성공으로 처리**. **M393A2/DM512**는 장갑 저항값과 성공 시 큰 내부 피해로 표현. HESH라는 별도 게임 판정 분류는 신설하지 않음.
- M494 APERS는 대인 특화 특수탄으로 게임상 KE 5를 사용한다. 실제 대장갑 관통 시험값이 아닌 상징적 판정 지표다.
- ERA: 부착 부위별 별도 방호 구성이고 반응 시 **일회성 소모**. 기초 장갑 수치에 영구 합산하지 않음. T-80BV의 Kontakt-1은 KE +5/CE +380, 4개 부위 피복률 95/60/100/55%로 우선 설정. HEP 역시 CE/ERA 방호 판정을 쓰되 외부 장갑 탈락량을 더 크게 하는 게임 특성을 구상.
- 전차 전면/측면/후면 경계에서 갑작스러운 판정 급변을 어떻게 완화할지는 미정.
